Capriole AI 面向两类用户：想用 GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5 和 Gemini 4 Argon、又不想同时付好几份订阅的人，以及想用一个 API Key 调用所有这些模型的开发者和编程智能体用户。一份每月 USD 8 的 Premium 会员同时满足两者：网页聊天无限使用，API 价格最多比官方 API 低 92%。聊天和 API 共用一个账户，但分开计量，所以聊天从不占用你的应用和编程智能体要用的 token。

## 速览

| Team | 每月 USD 70，含 5 个席位，每位成员都能无限网页聊天，另有每月 5,000 万团队共享 API token。[Team 方案](/zh/guides/team-plan) |

## USD 8 无限聊天

**Thinking** 预设同样不限量；如果下一个问题更适合另一个模型，可以在同一个对话中直接切换。[比较方案与限额](/zh/guides/plans-and-limits)，或[选择模型](/zh/guides/choose-a-model)。

## API 价格最多比官方低 92%

- 充值价格为每 500 万 token USD 8，可用于任意受支持的模型，一次购买多包最多优惠 15%。
- 同一个 Key 可运行 10 个有配置文档的编程智能体，包括 Codex、Claude Code、GitHub Copilot CLI 和 OpenCode。参见[使用一个 API Key 配置编程智能体](/zh/guides/one-api-key-coding-agents)。
- 想让配置自动跟随推荐的旗舰模型，就用别名；测试、审计或可重复运行需要固定到某个版本时，使用具体的模型 ID。
