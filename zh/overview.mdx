## 为什么选择 Capriole AI

Capriole AI 还为已登录并使用 **Server Storage** 的 Free、Premium 和 Team 用户提供免费的 **GPT Image 2** 网页生图。可以使用 **Image** 模式，也可以在聊天中让 **Text Agent** 生成图片。生图本身不消耗 API token 额度；Text Agent 的文字对话仍遵循普通聊天限制。这是网页功能，不是公开图片 API 或 Coding Agent 模型。

[查看生图指南](/zh/guides/files-web-search).

Capriole AI 通过一个 API 提供主流 AI 模型。

你只需维护一套集成，便可按需切换模型。

- 使用一个 API 访问模型
- 切换支持的模型时无需修改集成
- 使用 Token 包获得清晰、简单且成本更低的价格

## 配置一次即可持续使用

如果希望 Capriole AI 自动让 API 或编程代理使用对应提供商当前推荐的旗舰模型，可选择 `openai-latest`、`claude-latest` 或 `google-latest`。

如果测试、审计或可重复运行需要固定到特定模型版本，请使用具体的模型 ID。
