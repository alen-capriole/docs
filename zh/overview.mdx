Capriole AI 由 Capriole Investments 打造，与该公司的市场数据平台 [Capriole Quant](https://quant.capriole.com/)（原 Capriole Charts）和投资基金是不同的产品。有效的 Capriole Quant 订阅用户可以免费使用 Capriole AI。

## USD 8 无限聊天

- Premium 每月 USD 8，可在网页聊天中无限使用所有受支持的模型，包括 GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5 和 Gemini 4 Argon。
- 如果下一个问题更适合另一个模型，可以在同一个对话中直接切换。
- 登录后的网页聊天设有合理使用上限：每个账户每天 200 条消息。它用于阻止脚本驱动的自动化滥用，正常使用远低于这个上限。
- 访客无需账户，每天可试用 5 条消息。免费账户每月另有 50 万 token 的网页聊天额度。

[比较方案与限额](/zh/guides/plans-and-limits)，或[选择模型](/zh/guides/choose-a-model)。

## API 价格最多比官方低 92%

- 一个 API Key 即可用于 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 客户端。
- Premium 包含每月 API 额度，充值价格为每 500 万 token USD 8，可用于任意受支持的模型。[Claude API 价格](/zh/articles/claude-api-pricing)和 [OpenAI API 价格](/zh/articles/openai-api-pricing)列出了 92% 是如何按官方价格计算的。
- 同一个 Key 可运行 10 个有配置文档的编程智能体，包括 Codex、Claude Code、GitHub Copilot CLI 和 OpenCode。参见[使用一个 API Key 配置编程智能体](/zh/guides/one-api-key-coding-agents)。

先从 [API 快速开始](/zh/quickstart)入手。

## 配置一次即可持续使用

如果希望 Capriole AI 自动让 API 或编程智能体使用对应提供商当前推荐的旗舰模型，可选择 `openai-latest`、`claude-latest` 或 `google-latest`。

如果测试、审计或可重复运行需要固定到特定模型版本，请使用具体的模型 ID。

已登录并使用 **Server Storage** 的 Free、Premium 和 Team 账户，可以在网页聊天中用 **GPT Image 2.5** 和 **Nano Banana 2.1** 免费生图。文件、网页搜索、项目、聊天导出和存储控制都内置在工作区中。[查看生图指南](/zh/guides/files-web-search)。
