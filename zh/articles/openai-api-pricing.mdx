## OpenAI API 每 100 万 token 价格

OpenAI 在其 [API 定价页面](https://developers.openai.com/api/docs/pricing)公布了以下标准费率。所有价格均以 USD 计，单位为每 100 万 token，适用于输入不超过 272K token 的提示词。

| 模型 | API 模型 ID | 输入 | 缓存输入 | 缓存写入（30 分钟） | 缓存写入（12 小时） | 输出 |
|---|---|---:|---:|---:|---:|---:|
| GPT-6 Astra | `gpt-6-astra` | USD 10 | USD 1 | USD 12.50 | USD 25 | USD 50 |
| GPT-6.1 Sol | `gpt-6.1-sol` | USD 2 | USD 0.10 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Sol | `gpt-6-sol` | USD 2 | USD 0.20 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Luna | `gpt-6-luna` | USD 0.10 | USD 0.01 | USD 0.125 | USD 0.25 | USD 0.50 |

OpenAI 的定价页和模型页列出了会改变这些费率的规则：

- **Batch 和 Flex**：两者都是标准费率的 50%。GPT-6 Astra 输入 USD 5、输出 USD 25。
- **长提示词**：输入超过 272K token 的请求，整个请求的输入和缓存费率按 2 倍、输出费率按 1.5 倍计算。
- **快速模式**：价格为标准费率的 2 倍。GPT-6 Astra 在快速模式下输入 USD 20、输出 USD 100。
- **区域处理**：在可用的地区加收 10%。

official_cost = input_millions × input_price + output_millions × output_price

## 缓存和批处理如何影响对比

- **缓存输入**：OpenAI 按输入费率的 10% 收费，GPT-6 Astra 为每 100 万缓存 token USD 1。Capriole 同样按 10% 计算缓存输入，折合每 100 万缓存 token USD 0.16。[计费 token 说明](/zh/articles/charged-tokens)给出了计算公式。
- **缓存写入**：OpenAI 对 30 分钟缓存写入收取输入价格的 1.25 倍，对 12 小时缓存写入收取 2.5 倍。Capriole 对所有未缓存的输入 token（包括缓存写入）都按正常费率计算。
- **Batch 和 Flex**：按半价计算，GPT-6 Astra 的 500 万 token 示例要 USD 50。Capriole 没有批处理端点，但对这项工作负载，它的 USD 8 仍低 84%。

## 通过 Capriole 的 API 调用 GPT-6 Astra

Capriole 的 API 兼容 `POST /v1/responses` 上的 OpenAI Responses 和 `POST /v1/chat/completions` 上的 OpenAI Chat Completions。把 OpenAI SDK 的 base URL 设为 `https://api.caprioletech.com/v1`。

- `openai-latest` 选择 GPT-6 Astra，你的配置会始终跟随当前推荐的 OpenAI 模型。
- 在 Responses 上，`gpt-6-astra` 这样的原生 ID 和 `openai/gpt-6-astra` 这样带前缀的 ID 选择的是同一个模型。
- Chat Completions 接受 `openai-latest`，以及 `GET /v1/models` 返回的模型 ID。

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com/v1",
)

response = client.responses.create(
    model="openai-latest",
    input="Write a release note for this change.",
)
print(response.output_text)
```

每个 key 每分钟最多 300 个请求。所有可用的模型 ID 见 [Responses 参考](/zh/api-reference/endpoint/responses)和 [Chat Completions 参考](/zh/api-reference/endpoint/chat-completions)；如需用 Capriole key 运行 Codex，请参阅 [Codex 配置](/zh/integrations/codex)。
