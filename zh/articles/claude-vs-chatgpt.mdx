同一账户还包含 API，价格最多比官方 API 低 92%，应用和编程智能体用一个 key 即可。

## Anthropic 如何介绍 Claude Fable 5.1 和 Opus 5.5

Anthropic 称，Claude Fable 5.1 在长时间运行的智能体编程、多步骤研究，以及文档、表格和幻灯片工作上更强。它是两者中较慢的一个。

对于大多数工作负载，Anthropic 建议先从 Claude Opus 5.5 开始。其发布公告称，Opus 5.5 在大多数工作上达到 Fable 5.1 的水平，并在 Anthropic 的基准测试中，于智能体编程、计算机操作和知识工作方面领先。如果调高推理强度后 Opus 5.5 仍然不够，Anthropic 建议改用 Fable 5.1。

两个模型的思考都始终开启，都能读取文本和图片、输出文本，上下文窗口均为 100 万 token。

## OpenAI 如何介绍 GPT-6 Astra

OpenAI 称 GPT-6 Astra 是它面向最高难度工作、能力最强的模型，主要用途包括复杂推理、编程、计算机操作、研究和文档创建。推理强度可以从 `low` 设到 `max`。

GPT-6 Astra 能读取文本和图片、输出文本。在 API 上，输入超过 272K token 的提示词价格更高：整个请求按 2 倍输入价格和 1.5 倍输出价格计费。

## 各家订阅包含什么

**Claude。** 所有 Claude 方案都有五小时会话限制，付费方案另有每周限制。Claude Pro 每个会话的用量至少是 Free 方案的 5 倍。Max 5x 和 Max 20x 每个会话的用量分别是 Pro 的 5 倍或 20 倍。在 Pro 上，Fable 5.1 不计入方案的用量限制，而是通过用量积分（usage credits）按标准 API 价格计费。在 Max 上，Fable 模型最多可使用每周限制的 50%。详情请阅读 [Claude 用量限制详解](/zh/articles/claude-usage-limits)。

**ChatGPT。** 在 Plus 上，Chat 中的 GPT-6 由 GPT-6 Sol 运行。GPT-6 Astra 包含在 ChatGPT Work 和 Codex 中，OpenAI 估计每五小时可发送 5 至 45 条本地消息，并称还可能有每周限制。GPT-6 Pro 是 Chat 中由 Astra 驱动的选项，需要 Pro、Business 或 Enterprise。OpenAI 表示，即使在 Pro 上，GPT-6 Pro 也不能无限使用。[ChatGPT Plus 替代方案](/zh/articles/chatgpt-plus-alternative)一文完整对比了 Plus 与 Capriole AI。

Claude Pro 和 ChatGPT Plus 都不包含 API 用量，使用这两个方案时，API 需要另外付费。

## 每月 USD 8，在一个对话中同时使用

Capriole AI Premium 每月 USD 8，可在网页聊天中无限使用所有受支持的模型，包括 GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5 和 Gemini 4 Argon。登录后的网页聊天设有合理使用上限：每个账户每天 200 条消息。它用于阻止脚本驱动的自动化滥用，正常使用远低于这个上限。

每个对话不必只选一家厂商。[在对话中切换模型](/zh/articles/switch-models-mid-chat)后，对话线程、其中的文件和上下文都会保留：

1. 用 GPT-6 Astra 起草。
2. 切换到 Claude Fable 5.1，让它质疑这份草稿。
3. 切换到 Claude Opus 5.5 或 Gemini 4 Argon，获取第三种看法，或完成剩下的工作。

Premium 还包括用 GPT Image 2.5 和 Nano Banana 2.1 免费生图、文件和网页搜索、项目、聊天导出、个性化以及存储控制。

## API 价格对比

用于应用和编程智能体时，Capriole AI 对所有受支持的模型收取同样的价格。

| 模型 | 官方 API 价格，每 100 万 token（输入 / 输出） | Capriole AI |
|---|---|---|
| GPT-6 Astra | USD 10 / USD 50 | 每 500 万 token USD 8 |
| Claude Fable 5.1 | USD 10 / USD 50 | 每 500 万 token USD 8 |
| Claude Opus 5.5 | USD 4 / USD 20 | 每 500 万 token USD 8 |

每 500 万 token USD 8，相当于每 100 万 token USD 1.60，输入和输出同价。Premium 每月含 500 万 API token，充值价格为每 500 万 token USD 8。缓存输入按 10% 计算，详见[计费 token](/zh/articles/charged-tokens)。一个 key 可用于 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 客户端，以及 [10 个有文档说明的编程智能体](/zh/guides/one-api-key-coding-agents)，包括 Codex 和 Claude Code。

## 该用哪一个？

- **先用 Claude Opus 5.5** 处理大多数编程和知识工作。这是 Anthropic 自己的建议，它的 API 价格也是三者中最低的。
- **改用 Claude Fable 5.1** 处理最难的推理或长时间智能体任务，适合 Opus 5.5 不够用的时候。
- **使用 GPT-6 Astra** 处理高难度的推理、研究、编程和文档工作，或听听另一家厂商的第二意见。

厂商的基准测试无法告诉你哪个模型最适合你的任务。在同一个对话里问两个模型，就能知道。
