## Anthropic 如何介绍 Claude Fable 5.2 和 Opus 5.5

2026 年 11 月 9 日，Anthropic 发布了 **Claude Fable 5.2**，它取代 Claude Fable 5.1，成为 Anthropic 面向要求最高的技术工作的模型。Anthropic 表示，它在编程、推理和视觉上都比 Fable 5.1 有所提升；测试人员还发现它表达更清晰。它的 API 价格为每 100 万 token USD 8 / USD 40，比 Fable 5.1 的 USD 10 / USD 50 低 20%。

对于大多数编程和知识类任务，Anthropic 仍建议先从 Claude Opus 5.5 开始，称它是其最强的日常主力模型。Anthropic 表示，在它评估的几乎所有能力上，Fable 5.2 都比 Opus 5.5 更进一步；当任务需要的能力超出 Opus 5.5 时，Anthropic 建议升级到 Fable。

两个模型的思考都始终开启，都能读取文本和图片、输出文本，上下文窗口均为 100 万 token。

## OpenAI 如何介绍 GPT-6.2 Astra 和 GPT-6 Astra

2026 年 11 月 18 日，OpenAI 发布了 **GPT-6.2 Astra**，称其是面向你最艰巨项目的全新前沿模型，它取代 GPT-6 Astra，成为 OpenAI 的旗舰模型。OpenAI 表示，它做出的幻灯片、表格和文档更不像 AI 写的，写的代码也更简洁。它的 API 价格为每 100 万 token USD 8 / USD 40，比 GPT-6 Astra 的 USD 10 / USD 50 低 20%。

OpenAI 现在将 GPT-6 Astra 描述为面向复杂编程和专业工作的推理模型，主要用途包括复杂推理、编程、计算机操作、研究和文档创建。推理强度可以从 `low` 设到 `max`。

两个模型都能读取文本和图片、输出文本。在 API 上，输入超过 272K token 的提示词价格更高：整个请求按 2 倍输入价格和 1.5 倍输出价格计费。

## 各家订阅包含什么

**Claude。** Free、Pro 和 Max 都有五小时会话限制和每周限制。Claude Pro 每个会话的用量多于 Free 方案。Max 每个会话的用量是 Pro 的 5 倍，Ultra 每周的用量是 Pro 的 10 倍，已验证账户没有五小时限制。在 Pro 上，Fable 5.1 不计入方案的用量限制，而是通过用量积分（usage credits）按标准 API 价格计费。在 Max 和 Ultra 上，Fable 模型最多可使用每周限制的 50%。详情请阅读 [Claude 用量限制详解](/zh/articles/claude-usage-limits)。

**ChatGPT。** 在 Plus 上，Chat 中的 GPT-6 由 GPT-6 Sol 运行。Plus 只在 ChatGPT Work 和 Codex 中包含 GPT-6.2 Astra 和 GPT-6 Astra，OpenAI 表示这次 GPT-6.2 上线不会把 GPT-6.2 Astra 加入常规 Chat。在 Work 和 Codex 中，OpenAI 估计 Plus 用户每五小时可发送 6 至 50 条本地 GPT-6.2 Astra 消息和 5 至 45 条 GPT-6 Astra 消息，并称还可能有每周限制。GPT-6 Pro 是 Chat 中由 GPT-6 Astra 驱动的选项，需要 Pro、Business 或 Enterprise。OpenAI 表示，即使在 Pro 上，GPT-6 Pro 也不能无限使用。[ChatGPT Plus 替代方案](/zh/articles/chatgpt-plus-alternative)一文完整对比了 Plus 与 Capriole AI。

Claude Pro 和 ChatGPT Plus 都不包含 API 用量，使用这两个方案时，API 需要另外付费。

Capriole AI Premium 每月 USD 9，可在网页聊天中无限使用所有受支持的模型，包括 GPT-6.2 Astra、Claude Fable 5.2、Claude Opus 5.5 和 Gemini 4 Carbon。

## API 价格对比

用于应用和编程智能体时，Capriole AI 对所有受支持的模型收取同样的价格。

| 模型 | 官方 API 价格，每 100 万 token（输入 / 输出） | Capriole AI 个人 API 充值 |
|---|---|---|
| GPT-6.2 Astra | USD 8 / USD 40 | 每 500 万 token USD 8 |
| GPT-6 Astra | USD 10 / USD 50 | 每 500 万 token USD 8 |
| Claude Fable 5.2 | USD 8 / USD 40 | 每 500 万 token USD 8 |
| Claude Fable 5.1 | USD 10 / USD 50 | 每 500 万 token USD 8 |
| Claude Opus 5.5 | USD 4 / USD 20 | 每 500 万 token USD 8 |

每 500 万 token USD 8，相当于每 100 万 token USD 1.60，输入和输出同价。Premium 每月含 500 万 API token，充值价格为每 500 万 token USD 8。缓存输入按 10% 计算，详见[计费 token](/zh/articles/charged-tokens)。一个 key 可用于 OpenAI Chat Completions、OpenAI Responses 和 Anthropic Messages 客户端，以及 [10 个有文档说明的编程智能体](/zh/guides/one-api-key-coding-agents)，包括 Codex 和 Claude Code。

## 该用哪一个？

- **先用 Claude Opus 5.5** 处理大多数编程和知识工作。这是 Anthropic 自己的建议，它的 API 价格也是三者中最低的。
- **改用 Claude Fable 5.2** 处理最难的推理或长时间智能体任务，适合 Opus 5.5 不够用的时候。
- **使用 GPT-6.2 Astra** 处理 OpenAI 重点介绍的文档、幻灯片、表格、编程和计算机操作，或听听另一家厂商的第二意见。

厂商的基准测试无法告诉你哪个模型最适合你的任务。在同一个对话里问两个模型，就能知道。

[选择模型指南](/zh/guides/choose-a-model)对比了全部四个旗舰模型（包括 Gemini 4 Carbon），并说明了 **Thinking** 和 **Fast** 预设。
