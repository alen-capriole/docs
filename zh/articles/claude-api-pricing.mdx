Anthropic 在其 [Claude API 定价页面](https://platform.claude.com/docs/en/about-claude/pricing)公布了以下标准费率。所有价格均以 USD 计，单位为每 100 万 token。

| 模型 | API 模型 ID | 输入 | 输出 | 缓存读取 | 5 分钟缓存写入 | 1 小时缓存写入 |
|---|---|---:|---:|---:|---:|---:|
| Claude Fable 5.1 | `claude-fable-5-1` | USD 10 | USD 50 | USD 0.25 | USD 12.50 | USD 20 |
| Claude Opus 5.5 | `claude-opus-5-5` | USD 4 | USD 20 | USD 0.20 | USD 5 | USD 8 |

同一页面还列出了会改变这些费率的规则：

- **Batch API**：异步批处理的输入和输出价格均低 50%。Fable 5.1 为 USD 5 和 USD 25，Opus 5.5 为 USD 2 和 USD 10。
- **长上下文**：两款模型都以标准费率提供完整的 100 万 token 上下文窗口。
- **仅限美国的推理**：把 `inference_geo` 设为 `"us"` 后，所有 token 价格都乘以 1.1。
- **快速模式**：Opus 5.5 在快速模式下输入 USD 8、输出 USD 40，且快速模式不能与 Batch API 一起使用。

## 100 万和 500 万 token 的费用

这些示例采用标准费率，不使用缓存，输入与输出 token 比例为 3:1。

```text
official_cost = input_millions × input_price + output_millions × output_price
```

| Token 数 | 输入 / 输出 | Claude Fable 5.1 | Claude Opus 5.5 | Capriole AI，任一模型 |
|---|---|---:|---:|---:|
| 100 万 | 75 万 / 25 万 | USD 20 | USD 8 | USD 1.60 |
| 500 万 | 375 万 / 125 万 | USD 100 | USD 40 | **USD 8** |

在 Fable 5.1 上，500 万 token 的费用为 3.75 × USD 10 + 1.25 × USD 50 = USD 100，因此 Capriole 的 USD 8 低 92%。在 Opus 5.5 上，同样的工作负载要 USD 40，USD 8 低 80%。Capriole 以每包 500 万 token 出售 API token，100 万这一行是一包的五分之一，仅供对比。

Anthropic 的输出价格是输入的五倍。Capriole 对输入和输出按同一费率计算，所以能省多少取决于你自己的输入输出比例。例如，仅 500 万输入 token 在 Fable 5.1 上就要 USD 50，在 Opus 5.5 上要 USD 20。

## 缓存和批处理如何影响对比

- **缓存读取**：Anthropic 对 Fable 5.1 的缓存 token 收取每 100 万 USD 0.25，对 Opus 5.5 收取 USD 0.20。Capriole 按 10% 计算缓存输入，折合每 100 万缓存 token USD 0.16。[计费 token 说明](/zh/articles/charged-tokens)给出了计算公式。
- **缓存写入**：Anthropic 对 5 分钟缓存写入收取输入价格的 1.25 倍，对 1 小时缓存写入收取 2 倍。Capriole 把缓存写入按普通输入计算。
- **批处理**：按 Anthropic 的批处理费率，500 万 token 示例在 Fable 5.1 上要 USD 50，在 Opus 5.5 上要 USD 20。Capriole 没有批处理端点，但对这项工作负载，它的 USD 8 仍分别低 84% 和 60%。

## 通过 Capriole 的 Messages API 调用 Claude

Capriole 的 API 兼容 Anthropic Messages。把 Anthropic SDK 或任意 Messages 客户端指向 `https://api.caprioletech.com`，然后调用 `POST /v1/messages`。

- `claude-latest` 选择 Claude Fable 5.1，你的配置会始终跟随当前推荐的 Claude 模型。
- `claude-fable-5-1` 和 `claude-opus-5-5` 用于明确指定模型。
- 以 Bearer token 发送你的 key。在 Anthropic SDK 中，把它作为 `auth_token` 传入。

```python
import os

from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com",
)

message = client.messages.create(
    model="claude-latest",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Summarize this pull request."}],
)
print(message.content[0].text)
```

同一个 key 也可用于 `/v1/chat/completions` 上的 OpenAI Chat Completions，该端点同样接受 `claude-latest`。每个 key 每分钟最多 300 个请求。所有可用的 Claude 模型 ID 见 [Messages 参考](/zh/api-reference/endpoint/messages)；如需用 Capriole key 运行 Claude Code，请参阅 [Claude Code 配置](/zh/integrations/claude-code)。

## 常见问题

### Claude API 多少钱

Claude Fable 5.1 每 100 万输入 token USD 10，每 100 万输出 token USD 50。Claude Opus 5.5 分别为 USD 4 和 USD 20。批处理请求价格减半。

### Claude Opus 5.5 比 Claude Fable 5.1 便宜吗

是的。在 Anthropic 的 API 上，Opus 5.5 每 token 的价格比 Fable 5.1 低 60%。在 Capriole AI 上，两者价格相同，都是每 500 万 token USD 8。

### `claude-latest` 在 Capriole AI 上指什么

`claude-latest` 指向 Claude Fable 5.1，可用于 `/v1/messages` 和 `/v1/chat/completions`。

### 可以用 Capriole AI key 运行 Claude Code 吗

可以。把 `ANTHROPIC_BASE_URL` 设为 `https://api.caprioletech.com`，把 `ANTHROPIC_AUTH_TOKEN` 设为你的 Capriole key。完整配置见 [Claude Code 配置](/zh/integrations/claude-code)。

### 无限聊天包含 API 用量吗

不包含。无限只适用于网页聊天。API 和编程智能体请求会消耗你的 API token 余额。
