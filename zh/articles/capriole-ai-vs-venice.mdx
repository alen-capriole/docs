## 隐私

隐私是 Venice 的核心重点。其文档介绍了四种模式，按模型设定：

- **Anonymized**：匿名化模式。Venice 不会把你的身份发送给模型提供商，但提供商仍能看到提示词。Venice 的 API 定价把它的 Claude、GPT 和 Gemini 模型列在这一模式下。
- **Private**：私密模式。提示词和响应只用于推理处理，不会保留。
- **TEE**：可信执行环境。受支持的模型在硬件隔离的安全飞地中运行。
- **E2EE**：端到端加密。你的客户端加密提示词，只有经过验证的安全飞地才能解密。

Venice 表示，常规推理时不会存储或记录提示词和响应内容。其定价页列出对话历史存储在本地，Pro 提供加密备份和恢复。

Capriole 不会用你的聊天、文件或 API 内容训练模型；聊天历史可以保存在账户中、只留在浏览器里，或完全不保存，详情见[隐私与数据控制](/zh/guides/privacy-and-security)。

对于 Anthropic、OpenAI 和 Google 的前沿模型，两款产品都会把你的提示词发送给相应提供商。Venice 更强的保障适用于它以 Private、TEE 或 E2EE 模式运行的开源模型。

## 常见问题

### Capriole AI 比 Venice 便宜吗

就前沿模型而言，是的。Capriole Premium 每月 USD 8，可无限畅聊全部四款当前旗舰模型。Venice Pro 为 USD 18，前沿文本模型按 credits 计费，每月包含 100 credits，即 USD 1。

### Venice 的 API 比官方价格便宜吗

对这些旗舰模型来说并不便宜。Venice 给 Claude Fable 5.1 和 GPT-6 Astra 标的价格是每 100 万 token 输入 USD 10、输出 USD 50，与 Anthropic 和 OpenAI 相同。Capriole 对任意受支持模型收取每 500 万 token USD 8，最多比官方 API 价格低 92%。

### 哪个更注重隐私

在 Private、TEE 或 E2EE 模式下使用开源模型时，Venice 更注重隐私。对于 Claude、GPT 和 Gemini，两者都会把你的提示词发送给模型提供商。Capriole 允许你完全不保存聊天历史，也不会用你的内容训练模型。

### Venice 支持 Claude Code 吗

支持，但需要额外工具。Venice 的指南会安装 claude-code-router，把 Claude Code 的 Anthropic Messages 请求转换成它兼容 OpenAI 的格式。Capriole 直接支持 Anthropic Messages，因此 Claude Code 只需配置自身设置。请参阅 [Claude Code 配置](/zh/integrations/claude-code)。
