OpenRouter 按各提供商的公开价格计费，Standard 用户用银行卡充值时另收 5.5% 手续费。对于下文固定的 500 万 token 工作负载，表中 Capriole 提供的每个模型，**成本均为 USD 9**。按照付费 Standard 公开价格，使用相同模型需要 **USD 6.75 至 USD 90**。计入 OpenRouter 公开的充值手续费后，计算所得现金总额为 **USD 7.55 至 USD 94.95**。USD 9 的 Premium 方案还包含四个旗舰模型的无限网页聊天：GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5 和 Gemini 4 Carbon。

在这次对比中，对于 Capriole 提供的所有模型，Premium 都更便宜，唯一的例外是 Gemini 3.8 Flash：它的官方直连和 OpenRouter 费用都低于 USD 9 的订阅价。Gemini 3.1 Pro Preview 保留在表中仅供参考，Capriole AI 已不再提供该模型。

这是一项可复现的对比，不代表所有情况下的价格承诺。测试固定了 token 构成，并采用文中引用的公开价格。价格核查日期为 2026 年 11 月 17 日。

## 500 万 token 在各家 API 上要多少钱？

## 如何复现计算

官方提供商分别公布输入和输出价格。这项工作负载采用下面的公式。

```text
direct_cost = 4 × input_price_per_1M + 1 × output_price_per_1M
```

因此，GPT-6 Astra、Claude Fable 5.1 和 Claude Fable 5 的成本如下。

```text
4 × USD 10 + 1 × USD 50 = USD 90
```

OpenRouter 表示，它会按所选提供商的推理价格计费，不额外加价。其 Standard 方案列明，刷卡购买充值额度时收取 5.5% 的手续费，最低 USD 0.80。采用页面展示的推理价格时，现金成本计算如下。

```text
openrouter_cash = inference_cost + max(USD 0.80, inference_cost × 0.055)
USD 90 + max(USD 0.80, USD 4.95) = USD 94.95
```

按同样的方法计算，Claude Opus 5.5 的结果为 USD 37.98，Gemini 4 Carbon、Gemini 4 Argon 和 GPT-6.1 Sol 为 USD 18.99，Gemini 3.1 Pro Preview 为 USD 21.10。按 Google 截至 2026 年 12 月 31 日的 Standard 推广价，Gemini 3.8 Flash 为 USD 6.75（4 × USD 0.75 + 1 × USD 3.75）。加上 OpenRouter USD 0.80 的最低刷卡手续费，合计 USD 7.55。

OpenRouter 可以把同一个模型路由到不同的提供商或服务层级，回退也可能改变实际响应请求的端点。因此，表格比较的是页面展示的匹配推理价格，无法保证每一种默认路由配置都会产生相同账单。

## Capriole 为什么采用不同的计量单位

Capriole 面向客户的公开余额不会照搬各提供商的输入和输出价格表。它从一个统一余额中扣减，单位称为计费 token。

```text
charged_tokens = uncached_input + ceil(cached_input × 0.1) + output
```

未缓存输入和输出均按 100% 计入，缓存输入按 10% 计入。本例没有缓存输入，因此 400 万输入 token 加 100 万输出 token，正好消耗 500 万计费 token。

计费 token 是账户余额单位，与提供商的输入 token 或输出 token 价格并非同一概念。表格比较固定工作负载在不同计费系统下的成本，并未声称这些定价单位可以互换。[Capriole AI 计费 token 说明](/zh/articles/charged-tokens)还提供了三个示例、取整方式和 Premium 配额边界。

## USD 9 在 API 余额之外还包含什么

官方直连 API 和 OpenRouter 允许用户只购买推理服务，无需订阅 Capriole。此表比较的是一名新个人用户购买 Premium 的情况。除此之外，使用 Capriole API 需要有效的个人 Premium 或 Team 方案，Team 定价不在本次对比范围内。

USD 9 的 Premium 方案包含以下内容。

- 受支持 Premium 模型范围内的无限浏览器聊天，设有每天 200 条消息的[合理使用上限](/zh/guides/plans-and-limits#“无限”是什么意思)，用于阻止脚本化滥用
- 每月首批 500 万 API 计费 token
- 公共 API 和持续维护的编程智能体集成访问权限
- 提供模型切换、文件、网页搜索和聊天存储控制的统一浏览器工作区

订阅前，未登录访客和 Free 用户可以在有限的浏览器聊天中试用 GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5 和 Gemini 4 Carbon。该免费旗舰模型试用与上面的 API 成本对比表彼此独立。

如果你既想和前沿模型聊天，又需要 API 访问，USD 9 即可涵盖浏览器工作区和每月 500 万 API token。同一个账户还可用于 [10 项有文档说明的编程智能体集成](/zh/articles/coding-agent-compatibility)。

这首批 500 万 token 并不作为独立的 API 产品出售，用户支付的是完整的 Premium 组合。有效的个人 Premium 会员如需额外 500 万计费 token，可以购买一份 USD 8 充值包。

## 哪些情况下表格无法预测你的账单

本例没有纳入几种可能显著改变成本的定价路径。

- **缓存**。提供商分别为缓存写入和读取定价。Capriole 在计费 token 公式中按 10% 计算缓存输入。
- **长提示词**。请求的输入超过 272,000 token 时，OpenAI 会对 GPT-6 Astra 和 GPT-6.1 Sol 采用更高费率；单条提示词超过 200,000 token 时，Google 会对 Gemini 3.1 Pro Preview 采用更高费率。
- **服务层级和批处理**。Free、Flex、Priority、Batch 或其他提供商层级的价格可能不同于本例采用的付费 Standard 费率。
- **OpenRouter 路由**。实际处理请求的端点或回退目标，可能采用不同于表格匹配费率的价格。
- **工具和搜索**。服务端工具、搜索增强（grounding）和搜索可能增加按请求或用量计算的费用。
- **输出占比较高的工作负载**。表格采用 80/20 的输入输出比例。如果某个模型的输出价格明显更高，增加输出会让官方直连和 OpenRouter 成本增长得更快。
- **企业条款**。批量折扣、私有报价、数据驻留和协商承诺可能取代公开标价。

选择提供商前，请根据你预期使用的模型、token 构成和功能重新计算。
