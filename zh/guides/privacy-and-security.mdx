Capriole AI 不会使用你的对话、文件或 API 内容训练 AI 模型。你可以选择聊天历史保存在哪里：你的账户中、仅在浏览器中，或完全不保存。API 不保留请求或响应内容，只保留 token 数量等用量记录。你可以导出所有对话，随时删除对话，也可以删除你的账户。跨对话记住关于你的事实的记忆功能默认开启，你可以随时关闭。

本指南概述我们如何处理你的数据，完整内容见[隐私政策](/zh/legal/privacy)；方案、限额和禁止的用途见[服务条款](/zh/legal/terms)。

## 你的内容不会用于训练

Capriole AI 不会使用你的对话、文件或 API 内容训练 AI 模型。

每个请求仍会发送给回答它的 AI 模型提供商：OpenAI、Anthropic、Google、xAI、Z.ai、Moonshot AI 或字节跳动，或托管这些模型的云平台。该提供商按其自身条款处理请求。

## 选择聊天历史的保存位置

| 存储方式 | 聊天历史保存在哪里 | 如何选择 |
|---|---|---|
| **Server Storage**（默认） | 你的账户，位于 Capriole AI 的服务器上 | 两个存储开关都保持关闭 |
| **Local Storage** | 你的浏览器，不在我们的数据库中 | 开启 **启用本地存储** |
| **No Storage** | 不保存 | 开启 **启用 No Storage** |

使用 Server Storage 可以跨设备同步聊天、上传文件、生图和使用记忆。

两个开关都在 **账户** → **设置** 中。无论使用哪种方式，你的消息都会经过我们的服务器发送给回答它的模型，Capriole AI 也会保留一条用量记录。如果你举报某条回答，无论使用哪种方式，我们都会收到这条回答和你在它前面发的那条消息。[聊天存储指南](/zh/guides/chat-storage)逐一介绍了每种方式。

<Warning>
开启 **启用 No Storage** 并确认后，服务器和当前浏览器中的全部聊天历史会被永久删除。
</Warning>

访客的对话不会保存在我们的服务器上。浏览器标签页中会保留一份副本，以便你登录后把它保存到账户中。

## Capriole AI 保留哪些数据

| 数据 | 保留的内容 |
|---|---|
| 账户 | 登录时获得的邮箱地址、姓名和头像。该账户与 Capriole Quant 共用。 |
| 对话 | 消息、附件、生成的图片和对话标题，取决于你的存储方式 |
| 个性化 | 你在账户中添加的名字、工作和指令 |
| 记忆 | 通用记忆和各项目记忆中关于你的简短事实：你自己添加的，以及 **记忆** 开启时 Capriole AI 从对话中保存或更新的 |
| 项目 | 名称、指令和你添加的文件 |
| 标签 | 名称、颜色，以及加了这些标签的对话 |
| 语音输入 | 不保留。录音会被发送去转写，音频和文字都不会存储。 |
| 举报 | 你举报某条回答时：这条回答、你在它前面发的那条消息、勾选的图片、你选的原因和补充说明，以及模型、浏览器和国家等技术信息；登录时还包括你的账户邮箱。举报会通过邮件发到我们的客服邮箱。 |
| 用量记录 | 每次聊天和 API 请求的时间、模型、token 数量、状态、延迟、成本和 IP 地址；API 请求还会记录所用的 Key。不包含消息内容。 |
| 付款 | 你的订阅状态和账单标识符。付款由 Stripe 处理，我们不会收到你的卡号。 |

## 记忆

Capriole AI 的记忆会保存关于你的简短事实，例如你住在哪里、喜欢怎样的回答，并在之后的对话中使用。记忆默认开启，你可以在 **账户** → **记忆** 中关闭。Capriole AI 可能会在每次回复后保存你说到的关于自己的新事实，或更新已保存的事实，并保留你书写时的语言。只有已登录并用 Server Storage 保存的对话会使用记忆，网页和 App 都是如此。Local Storage、No Storage 和访客对话不会使用记忆，API 也不会。

记忆随你的账户保存在我们的服务器上，分为两种列表：

| 列表 | 在哪里管理 | 哪些对话使用 | 容量 |
|---|---|---|---|
| 通用记忆 | **账户** → **记忆** | 所有对话。不在项目中的对话把新事实保存到这里。 | 最多 2,400 个字符 |
| 项目记忆 | [项目的 **记忆** 标签](/zh/guides/projects#使用项目记忆) | 该项目中的对话（同时使用你的通用记忆）。这些对话把新事实保存到这里。 | 每个项目最多 2,400 个字符 |

在这两个列表中，你都可以查看已保存的全部内容，选择 **添加记忆**，编辑或删除某条记忆，或选择 **全部删除**。**账户** → **记忆** 中的 **全部删除** 只清空通用记忆；各项目的记忆要在各自的标签中清空。两个列表都在网页上管理，App 中的对话也会使用它们。列表满了以后，你和 Capriole AI 都无法再添加，直到你缩短或删除某条记忆。

关闭 **记忆** 后，Capriole AI 不再使用或更新记忆。列表会保留，你仍然可以添加、编辑或删除记忆。删除对话或全部聊天历史不会删除记忆；删除项目会同时删除它的记忆。

## API 保留哪些数据

API 不保存请求或响应内容。Capriole AI 保存 API 密钥和用量记录，用于管理额度、计费和提供支持。你可以在网页聊天中设置个性化回复。

## 安全

Capriole AI 使用加密连接和私有文件存储，并限制员工访问。

我们的主要服务器和数据库位于印度。我们的服务提供商会在其他国家处理数据，包括美国。

## 导出对话

在 **账户** → **设置** 中，选择 **导出聊天历史**。你会得到一个 ZIP 文件，其中每个对话都是一个 Markdown 文件，还有你附加的文件和生成的图片，以及 `conversations.json`，它以程序可读的格式包含所有对话。项目的指令和文件在 `projects/` 文件夹中，`conversations.json` 也记录了每个对话所属的项目。

历史较多时需要几分钟。下载会保留 24 小时，付费方案结束后也可以导出。

要导出单个对话，在侧栏中打开它的菜单，选择 **导出**。项目从项目的菜单导出。Local Storage 对话会立即下载，不会存储到我们的服务器上。

## 删除对话或账户

- **单个对话**：在侧栏中打开该对话的菜单，选择 **删除**。
- **全部对话**：在 **账户** → **设置** 中，选择 **删除全部聊天历史** 旁边的 **全部删除**。记忆会保留，项目及其指令、文件和记忆也会保留。
- **项目**：打开项目的菜单，选择 **删除**。项目的指令、文件、记忆和对话会一并删除。
- **记忆**：在 **账户** → **记忆** 或项目的 **记忆** 标签中，删除单条记忆，或选择 **全部删除**。
- **你的账户**：打开 **账户**，选择 **管理账号**，在 **安全** 标签页中选择 **删除账户**。如果你有生效中的付费订阅，请改为发送邮件至 [info@capriole.ai](mailto:info@capriole.ai)。由于该账户与 Capriole Quant 共用，删除后你也将无法登录 Capriole Quant。

删除单个对话、全部聊天历史、单条记忆或单个项目，会将其从我们的服务器上永久移除。已删除的数据可能会在数据库备份中保留最多 7 天。Local Storage 对话会一直保留在你的浏览器中，直到你清除它们。

## 谁会收到你的数据

| 接收方 | 收到的内容 |
|---|---|
| AI 模型提供商 | 每个请求所需的内容：你的消息、文件、语音录音、对话上下文和记忆（开启时），以及你的时区和据此推断的大致位置 |
| 基础设施提供商 | 发往模型提供商途中的请求 |
| 搜索提供商，例如 Tavily | 模型发出的搜索查询 |
| 天气服务提供商 | 你询问的地点；如果你没有说明地点，则是你的 IP 地址 |
| 服务提供商 | Amazon Web Services（服务器、数据库、文件）、Vercel（网站托管和分析）、Clerk（登录）、Stripe（网页付款）、Apple、Google Play 和 RevenueCat（购买交易）、Resend 和 Brevo（邮件）以及错误监控工具 |
| Google 和 LinkedIn | 通过我们网站上的标签获得的网站访问和广告效果 |
| 你所在 [Team](/zh/guides/team-plan) 的所有者和管理员 | 你的邮箱、角色和 Team API 用量 |

Capriole AI 不会出售你的个人信息。

## 常见问题

### Capriole AI 会用我的对话训练 AI 模型吗？

不会。Capriole AI 不会使用你的对话、文件或 API 内容训练 AI 模型。模型提供商会收到每个请求，并按其自身条款处理。

### Capriole AI 会存储我的 API 请求吗？

不会。它不保留任何 API 请求或响应内容，只保留时间、模型和 token 数量等用量记录。

### 可以在不保存对话的情况下使用 Capriole AI 吗？

可以。开启 **启用 No Storage**，对话会在你离开或刷新页面时消失；或开启 **启用本地存储**，只在浏览器中保留历史。

### Capriole AI 有跨对话记忆吗？

有。**记忆** 默认开启：Capriole AI 可能会在已登录的 Server Storage 对话中保存你说到的关于自己的简短事实，并在之后的对话中使用。每个项目也有自己的记忆。每条事实都可以查看、添加、编辑和删除，你也可以随时在 **账户** → **记忆** 中关闭 **记忆**。

### 怎样删除 Capriole AI 的记忆？

在 **账户** → **记忆** 中，把指针移到某条记忆上并选择 **×**，或选择 **全部删除**。项目的记忆在项目的 **记忆** 标签中。删除对话或关闭 **记忆** 都不会删除已保存的记忆。已删除的记忆可能会在数据库备份中保留最多 7 天。

### 怎样删除我的 Capriole AI 账户？

打开 **账户**，选择 **管理账号**，在 **安全** 标签页中选择 **删除账户**。如果你有生效中的付费订阅，请改为发送邮件至 [info@capriole.ai](mailto:info@capriole.ai)。由于两款产品共用一个账户，删除后你也将无法登录 Capriole Quant。

### Capriole AI 的数据存储在哪里？

我们的主要服务器和数据库位于印度。我们的服务提供商会在其他国家处理数据，包括美国。
