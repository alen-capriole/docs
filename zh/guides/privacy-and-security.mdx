Capriole AI 不会使用你的对话、文件或 API 内容训练 AI 模型。你可以选择聊天历史保存在哪里：你的账户中、仅在浏览器中，或完全不保存。API 不保留请求或响应内容，只保留 token 数量等用量记录。你可以导出所有对话，随时删除对话，也可以请我们删除你的账户。

本指南概述我们如何处理你的数据，完整内容见[隐私政策](/zh/legal/privacy)。

## 你的内容不会用于训练

Capriole AI 不会使用你的对话、文件或 API 内容训练 AI 模型。

每个请求仍会发送给回答它的 AI 模型提供商：OpenAI、Anthropic、Google、xAI、Z.ai 或 Moonshot AI，或托管这些模型的云平台。该提供商按其自身条款处理请求。

## 选择聊天历史的保存位置

| 存储方式 | 聊天历史保存在哪里 | 跨设备同步 | 上传和生图 | 如何选择 |
|---|---|---|---|---|
| **Server Storage**（默认） | 你的账户，位于 Capriole AI 的服务器上 | 是 | 可用 | 两个存储开关都保持关闭 |
| **Local Storage** | 你的浏览器，不在我们的数据库中 | 否 | 关闭 | 开启 **启用本地存储** |
| **No Storage** | 不保存 | 否 | 关闭 | 开启 **启用 No Storage** |

两个开关都在 **账户** → **设置** 中。无论使用哪种方式，你的消息都会经过我们的服务器发送给回答它的模型，Capriole AI 也会保留一条用量记录。[聊天存储指南](/zh/guides/chat-storage)逐一介绍了每种方式。

<Warning>
开启 **启用 No Storage** 并确认后，服务器和当前浏览器中的全部聊天历史会被永久删除。
</Warning>

访客的对话不会保存在我们的服务器上。浏览器标签页中会保留一份副本，以便你登录后把它保存到账户中。

## Capriole AI 保留哪些数据

| 数据 | 保留的内容 |
|---|---|
| 账户 | 登录时获得的邮箱地址、姓名和头像。该账户与 Capriole Quant 共用。 |
| 对话 | 消息、附件、生成的图片和对话标题，取决于你的存储方式 |
| 个性化 | 你在账户中添加的名字、工作和指令 |
| 项目 | 名称、指令和你添加的文件 |
| 语音输入 | 不保留。录音会被发送去转写，音频和文字都不会存储。 |
| 用量记录 | 每次聊天和 API 请求的时间、模型、token 数量、状态、延迟、成本和 IP 地址；API 请求还会记录所用的 Key。不包含消息内容。 |
| 付款 | 你的订阅状态和账单标识符。付款由 Stripe 处理，我们不会收到你的卡号。 |

## API 保留哪些数据

API 不保留请求或响应内容，因此没有 API 对话历史。Capriole AI 会保留你的 API Key 以及每个请求的用量记录，用于配额、计费和支持。账户的个性化设置不适用于 API。

## 安全

Capriole AI 使用加密连接和私有文件存储，并限制员工访问。没有任何系统是绝对安全的。

我们的主要服务器和数据库位于印度。我们的服务提供商会在其他国家处理数据，包括美国。

## 导出对话

在 **账户** → **设置** 中，选择 **导出聊天历史**。你会得到一个 ZIP 文件，其中每个对话都是一个 Markdown 文件，还有你附加的文件和生成的图片，以及 `conversations.json`，它以程序可读的格式包含所有对话。项目的指令和文件在 `projects/` 文件夹中，`conversations.json` 也记录了每个对话所属的项目。

历史较多时需要几分钟。下载会保留 24 小时，付费方案结束后也可以导出。

要导出单个对话，在侧栏中打开它的菜单，选择 **导出**。项目从项目的菜单导出。Local Storage 对话会立即下载，不会存储到我们的服务器上。

## 删除对话或账户

- **单个对话**：在侧栏中打开该对话的菜单，选择 **删除**。
- **全部对话**：在 **账户** → **设置** 中，选择 **删除全部聊天历史** 旁边的 **全部删除**。项目及其指令和文件会保留。
- **项目**：打开项目的菜单，选择 **删除**。项目的指令、文件和对话会一并删除。
- **你的账户**：发送邮件至 [info@capriole.ai](mailto:info@capriole.ai)。由于该账户与 Capriole Quant 共用，删除后你也将无法登录 Capriole Quant。

删除单个对话、全部聊天历史或单个项目，会将其从我们的服务器上永久移除。已删除的数据可能会在数据库备份中保留最多 7 天。Local Storage 对话会一直保留在你的浏览器中，直到你清除它们。

## 谁会收到你的数据

| 接收方 | 收到的内容 |
|---|---|
| AI 模型提供商 | 每个请求所需的内容：你的消息、文件、语音录音和对话上下文，以及你的时区和据此推断的大致位置 |
| 基础设施提供商 | 发往模型提供商途中的请求 |
| 搜索提供商，例如 Tavily | 模型发出的搜索查询 |
| 服务提供商 | Amazon Web Services（服务器、数据库、文件）、Vercel（网站托管和分析）、Clerk（登录）、Stripe（付款）、Resend（邮件）以及错误监控工具 |
| Google 和 LinkedIn | 通过我们网站上的标签获得的网站访问和广告效果 |
| 你所在 [Team](/zh/guides/team-plan) 的所有者和管理员 | 你的邮箱、角色和 Team API 用量 |

Capriole AI 不会出售你的个人信息。

## 常见问题

### Capriole AI 会用我的对话训练 AI 模型吗？

不会。Capriole AI 不会使用你的对话、文件或 API 内容训练 AI 模型。模型提供商会收到每个请求，并按其自身条款处理。

### Capriole AI 会存储我的 API 请求吗？

不会。它不保留任何 API 请求或响应内容，只保留时间、模型和 token 数量等用量记录。

### 可以在不保存对话的情况下使用 Capriole AI 吗？

可以。开启 **启用 No Storage**，对话会在你离开或刷新页面时消失；或开启 **启用本地存储**，只在浏览器中保留历史。

### 怎样删除我的 Capriole AI 账户？

发送邮件至 [info@capriole.ai](mailto:info@capriole.ai)。由于两款产品共用一个账户，删除后你也将无法登录 Capriole Quant。

### Capriole AI 的数据存储在哪里？

我们的主要服务器和数据库位于印度。我们的服务提供商会在其他国家处理数据，包括美国。
