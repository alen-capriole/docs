## “无限”是什么意思

Premium 和 Team 的网页聊天在所有[受支持的模型](/zh/guides/choose-a-model)上都不计 token，包括 **Thinking** 预设。登录后的网页聊天设有合理使用上限：每个账户每个 UTC 日 200 条消息。它用于阻止脚本驱动的自动化滥用，正常使用远低于这个上限。

达到上限时，Capriole AI 会显示提示，聊天在 UTC 时间 00:00 恢复。这个上限不适用于 API Key。

Claude 自己的 Pro 和 Max 方案规则不同：有五小时会话上限和每周上限。[Claude 用量限制详解](/zh/articles/claude-usage-limits)把它们与 Capriole AI 做了对比。

## 哪些操作消耗 API token

网页聊天和 API 分开计算。

| 操作 | 消耗什么 |
|---|---|
| Premium 或 Team 的网页聊天 | 不消耗，无限使用。 |
| Free 的网页聊天 | 每月 50 万 token 的聊天额度 |
| 在网页聊天中生图 | 不消耗，免费。 |
| API 请求，包括 API 页面上的 **API 调试台** | API token |
| Codex、Claude Code 等编程智能体 | API token |

API token 按计费 token 计算：未缓存输入，加上缓存输入的 10%，再加上输出。所有模型的计算方式都相同。Thinking 模型会消耗更多 token。[计费 token 说明](/zh/articles/charged-tokens)提供了计算示例。

每月包含的 token 会先被使用，之后才使用充值的 token。API Key 需要 Premium 或 Team；Free 账户的 API 页面会显示 **订阅后即可访问 API。**

## 购买方案

在侧栏底部选择你的名字，选择 **定价**，然后在 Premium 上选择 **订阅**。在 **账户** 页面上，**升级** 会打开同样的方案。

付款由 Stripe 处理。支持主要的信用卡和借记卡，Stripe 会显示你结账时可用的付款方式。Premium 和 Team 结账时可以使用优惠码。

## 常见问题

### Capriole AI 真的无限吗？

是的，Premium 和 Team 的网页聊天在所有受支持的模型上都不计 token，只设有防止脚本滥用的[合理使用上限](#“无限”是什么意思)。API 按 token 计算。

### 可以免费使用 Capriole AI 吗？

可以。访客[无需账户](/zh/articles/ai-chat-without-login)，每天可发 5 条消息。免费账户每月包含 50 万 token 的网页聊天和免费生图，但不包含 API 访问。

### Premium 包含 API 吗？

包含。Premium 每月包含 500 万 API token，可用于应用和编程智能体，价格最多比官方 API 低 92%。更多 token 为每 500 万 USD 8。

### 怎样取消 Premium？

打开 **账户**，选择 **管理订阅**，然后在 Stripe 的账单页面上取消。Premium 会保持有效到账单周期结束。

### 我有 Capriole Quant，还需要 Premium 吗？

不需要。符合条件的付费 Capriole Quant 方案免费包含 Capriole AI 访问权限。
