Capriole AI Team 每月 USD 70，包含 5 个席位。每位成员都可以在网页聊天中无限使用 GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5 和 Gemini 4 Argon，团队每月共享 5,000 万 API token，用于应用和编程智能体，价格最多比官方 API 低 92%。所有者统一付款，通过邮箱邀请成员，并可以查看或限制每位成员的 API 用量。

## Team 适合谁

Team 适合希望统一付款、共享 API token 并了解谁在使用的小团队，例如开发团队。如果你一个人工作，Premium 每月 USD 8 就包含无限网页聊天和自己的 API 额度。[方案指南](/zh/guides/plans-and-limits)比较了所有方案。

## Team 包含什么

| | Team |
|---|---|
| 价格 | 每月 USD 70 |
| 席位 | 5 个，包括所有者。待处理的邀请也占用席位。 |
| 网页聊天 | 每位成员在所有受支持的模型上都无限使用 |
| API token | 每月 5,000 万，团队共享 |
| 充值 | 每 5,000 万 token USD 80，一次购买多个包最多优惠 10% |
| API Key | 每位成员自己创建；用量计入团队账单 |
| 生图 | 在使用 **Server Storage** 的网页聊天中免费 |

登录后的网页聊天设有合理使用上限：每个账户每个 UTC 日 200 条消息。它用于阻止脚本驱动的自动化滥用，正常使用远低于这个上限。每位成员各有自己的上限。

## 开始之前

- 创建团队会替换你的 Premium 方案。如果你付费订阅了 Premium，订阅会立即取消且不予退款。
- 每位成员都要用你邀请的邮箱地址注册或登录 Capriole AI。
- Capriole Quant 附赠的访问权限或促销 Premium 会保留在你的账户上，但在你加入团队期间不会使用。

## 创建团队

<Steps>
<Step title="打开 Team 方案">

登录后，在侧栏底部选择你的名字，选择 **定价**，再选择 **团队使用**。也可以打开 **账户**，在 **Team** 区域选择 **创建团队**。

</Step>

<Step title="订阅">

选择 **订阅**。如果你有 Premium，**创建 Team？** 对话框会说明你的 Premium 订阅将立即取消且不予退款。选择 **继续**。

</Step>

<Step title="在 Stripe Checkout 中付款">

Stripe Checkout 会打开。输入付款信息，如有优惠码也一并输入，然后付款。

</Step>

<Step title="为团队命名">

Capriole AI 会带你回到 **账户**，并打开 **为团队命名**。输入名称，选择 **保存**。

你的方案现在显示为 **Team**，你是团队的所有者。

</Step>
</Steps>

## 邀请成员

<Steps>
<Step title="发送邀请">

在 **账户** → **Team** 中，选择 **邀请成员**。输入成员的 **邮箱**，选择 **邀请**。

Capriole AI 会通过邮件向对方发送邀请链接。邀请会以 **待处理** 状态显示在成员列表中，并占用一个席位。**席位** 显示 5 个席位中已用了几个。

</Step>

<Step title="成员接受邀请">

成员打开链接后注册，或用受邀邮箱登录。对话框会询问是否加入你的团队。成员选择 **接受邀请** 会把当前方案切换为 Team，也可以选择 **拒绝**。

已登录的成员也会在 **账户** → **Team** 中看到邀请。

</Step>
</Steps>

<Warning>
如果成员付费订阅了 Premium，接受邀请会立即取消该订阅，且不予退款。
</Warning>

要撤回邀请，在成员列表中打开该邀请的菜单，选择 **取消邀请**。

## 管理成员

| 角色 | 该角色可以做什么 |
|---|---|
| **所有者** | 管理员能做的一切。所有者不能被移除，所有权也不能转让。 |
| **管理员** | 重命名团队、邀请和移除成员、更改角色、设置提醒和上限 token、购买团队充值以及管理账单 |
| **成员** | 使用无限网页聊天和计入团队账单的 API 访问，并查看自己的 API 用量 |

要更改角色，打开成员的菜单，选择 **成员设置**，选择一个 **角色**，再选择 **保存**。

要移除某人，打开其菜单，选择 **移除** 并确认。该成员会立即失去团队方案访问权限，其席位随即释放。

## 共享 API token

每位成员在 [API 页面](https://www.capriole.ai/zh?view=api)上创建自己的 Key。加入团队期间，每个 API 请求都使用团队的 token：先用每月包含的 5,000 万，再用团队充值的 token。

在 API 页面上，**用量** 会显示 **包含的团队用量** 和 **按需团队用量**。所有者和管理员可以按 **成员** 筛选，查看每个人的请求和计费 token。筛选方法见 [API Key 与用量指南](/zh/guides/api-keys-usage)。

### 设置提醒和上限 token

所有者和管理员可以在 **成员设置** 中为每位成员设置两个可选限制，两者都按滚动 30 天内的计费 token 计算。

- **提醒 tokens**：成员用量达到这个数值时，Capriole AI 会给团队的所有者和管理员发邮件。
- **上限 tokens**：成员用量达到这个数值时，其计入团队账单的 API 访问会停止，直到用量回落到上限以下，或你修改上限。

留空即表示不提醒或不设上限。网页聊天不受影响。

## 购买团队充值

所有者和管理员在 API 页面选择 **充值**。每个包 USD 80，含 5,000 万 token，一次可以买 1 至 5 个包。每多买 1 个包多优惠 2.5%，买 5 个包（2.5 亿 token）最多优惠 10%。

## 重命名、账单与结束团队

- **重命名**：在 **账户** → **Team** 中，打开团队名称旁边的菜单，选择 **重命名**。
- **账单**：所有者和管理员在 **账户** 中选择 **管理订阅**，在 Stripe 中更新付款信息、查看发票或取消订阅。
- **团队结束时**：每位成员的账户回到 Free，或回到仍然有效的 Capriole Quant 附赠访问或促销访问。成员加入时被取消的 Premium 订阅不会恢复。

## 常见问题

### Capriole AI Team 多少钱？

每月 USD 70，含 5 个席位。每位成员都可以无限使用网页聊天，团队每月共享 5,000 万 API token。更多 token 为每 5,000 万 USD 80。

### 加入团队后，我的 Premium 订阅会怎样？

付费的 Premium 订阅会立即取消，且不予退款。Capriole Quant 附赠的访问权限或促销访问会保留在你的账户上，但在你加入团队期间不会使用。

### 待处理的邀请会占用席位吗？

会。席位按成员和待处理的邀请计算，所以请取消不再需要的邀请。

### 可以转让团队所有权吗？

不可以。所有者始终是所有者，不能被移除。管理员拥有与所有者相同的管理和账单权限。

### 团队成员共用每日聊天上限吗？

不共用。每位成员都可以无限使用网页聊天，每个 UTC 日 200 条消息的合理使用上限按账户分别计算。
