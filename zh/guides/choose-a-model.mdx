### GPT-6.2 Astra

OpenAI 称 GPT-6.2 Astra 是其面向你最艰巨项目的全新前沿模型，它取代 GPT-6 Astra，成为 OpenAI 的旗舰模型。OpenAI 表示，它做出的幻灯片、表格和文档更不像 AI 写的，并会遵循模板和所在领域的惯例；它写的代码也更简洁，前端更出色。OpenAI 列出的上下文窗口为 105 万 token，最多输出 128,000 个 token，API 价格比 GPT-6 Astra 低 20%。在 Capriole AI 中，GPT-6.2 Astra 的上下文窗口为 87.2 万 token。在你选择其他模型之前，**GPT-6.2 Astra Thinking** 是网页聊天的默认模型，API 上的 `openai-latest` 使用 GPT-6.2 Astra。

### Claude Fable 5.2

Anthropic 将 Claude Fable 5.2 定位于高要求推理和长周期智能体任务，它取代 Claude Fable 5.1，成为 Anthropic 面向要求最高的技术工作的模型。Anthropic 表示，它在编程、推理和视觉上都比 Fable 5.1 有所提升；测试人员还发现它表达更清晰。Anthropic 列出的上下文窗口为 100 万 token，最多输出 128,000 个 token，API 价格比 Fable 5.1 低 20%。`claude-latest` 使用 Claude Fable 5.2。在 Anthropic 自己的 Pro 方案中，Fable 模型（包括 Fable 5.2）不计入用量限制，而是消耗用量积分（usage credits）计费，详见 [Claude 用量限制详解](/zh/articles/claude-usage-limits)。

### Claude Opus 5.5

Anthropic 为长时间运行的智能体编程和知识工作打造了 Claude Opus 5.5，官方价格是 Fable 5.2 的一半。Anthropic 称 Opus 5.5 是其最强的日常主力模型，建议大多数工作先从它开始，在任务需要更强能力时换用 Fable 5.2。和 Fable 5.2 一样，它始终开启思考，因此在 Capriole AI 中，**Fast** 会降低它的推理强度，而不是关闭思考。

### Gemini 4 Carbon

Google 称 Gemini 4 Carbon 是其最强的模型，专为考验模型智能极限的任务打造，例如复杂的多步骤编程和调试、长周期智能体任务和科学推理。Carbon 每轮消耗的思考 token 比 Gemini 4 Argon 多，因此速度更慢、消耗的 token 也更多；Google 还提到，较难的提示可能需要几分钟。Google 表示，对大多数软件工程和知识工作来说，Argon 仍是理想选择。Carbon 的 100 万 token 上下文窗口由输入、思考和输出共用。`google-latest` 使用 Gemini 4 Carbon。

## Thinking 还是 Fast

网页聊天中的大多数模型都提供一对预设。在输入框中模型菜单的旁边选择 **Thinking** 或 **Fast**。

- **Thinking** 在回答前进行更多推理，适合复杂任务。Claude 的 Thinking 预设会显示思考摘要。
- **Fast** 使用较低的推理强度，回复更快。

Thinking 会消耗更多 token。在 Premium 和 Team 中，无论选哪个，网页聊天都保持无限。在 Free 中，Thinking 会用掉更多月度额度。

| 模型 | 网页聊天中的预设 |
|---|---|
| GPT-6.2 Astra、GPT-6.2 Sol、GPT-6 Astra、GPT-6.1 Sol、GPT-6 Sol、GPT-6 Luna | **Thinking**（中等推理强度）和 **Fast**（低推理强度） |
| Claude Fable 5.2、Claude Fable 5.1、Claude Opus 5.5 | 始终开启思考。**Thinking** 使用中等推理强度，**Fast** 使用低推理强度。 |
| Gemini 4 Carbon、Gemini 4 Argon | 使用 Gemini 4 Carbon / Gemini 4 Argon 时可选择 Thinking 预设。选择 **Fast** 会切换到 Gemini 3.8 Flash。 |
| Kimi K3.1 Pro | 模型始终会思考。**Thinking** 使用高推理强度，**Fast** 使用低推理强度。 |
| GLM | **Fast** 是 GLM 5.3 Flash。**Thinking** 使用较早的 GLM 5.2（API 上为 `zai/glm-5.2`）。 |
| Grok 4.7 | 一个预设 |

在网页聊天中选择 Thinking 预设。在 API 上需要更多推理时，调用模型的 ID，并在请求中设置推理选项。

## 在对话中途切换模型

从模型菜单中选择另一个模型，然后发送下一条消息。对话会保留历史，新模型从这里接着回答。[了解在对话中途切换模型的原理](/zh/articles/switch-models-mid-chat)。

想为最新一条消息换一个回答，在回答下方选择 **重试**，再选另一个模型。新回答会就地替换旧回答，旁边的箭头可以在两个回答之间切换。如果最新的回答失败，在它下方选择 **重试**，可以用同一个模型或换一个模型重新发送你的消息，新回答会取代失败的回答。

在 **账户** → **设置** 中开启 **启用模型自动切换** 后，如果你选择的模型需求过高，Capriole AI 可以改用另一个可用模型回答。该选项默认关闭。

API 基础 URL 是 `https://api.caprioletech.com`。使用具体的模型 ID 可以固定某个模型；使用 `*-latest` 别名，则会跟随我们为该提供商推荐的旗舰模型。

|---|---|---|
| `openai-latest` | `openai/gpt-6.2-astra` | Chat Completions、Responses |
| `claude-latest` | `anthropic/claude-fable-5-2`（Messages 上为 `claude-fable-5-2`） | Chat Completions、Messages |
| `google-latest` | `google/gemini-4-carbon` | Chat Completions |

<Note>
自 2026 年 11 月 17 日起，`google-latest` 使用 Gemini 4 Carbon，不再使用 Gemini 4 Argon。在 Chat Completions 上，Carbon 按 Google 的默认思考等级 `medium` 思考；在我们的测试中，同一提示下它的输出 token 约为 Argon 的 3 到 4 倍。如需更轻量的调用，可以把 Google 的 `thinking_level` 设为 `low`（`medium` 和 `high` 也可以），或调用 `google/gemini-4-argon`。


## 常见问题

### Capriole AI 默认使用哪个模型？

访客和新账户的网页聊天默认使用 GPT-6.2 Astra Thinking。选过模型之后，新对话会使用你上次选择的模型，已保存的对话重新打开时使用它上次用过的模型。在 API 上，`openai-latest` 使用 GPT-6.2 Astra。

### 在 Capriole AI 中，旗舰模型更贵吗？

网页聊天不会：Premium 和 Team 的聊天在所有受支持的模型上都无限。在 API 上，所有模型的 token 单价相同，每 500 万 token USD 8，所以旗舰模型相对官方价格节省得最多。[Claude API 价格](/zh/articles/claude-api-pricing)、[OpenAI API 价格](/zh/articles/openai-api-pricing)和 [Gemini API 价格](/zh/articles/gemini-api-pricing)给出了具体计算。

### 可以用 OpenAI SDK 调用 Claude 或 Gemini 吗？

可以。OpenAI Chat Completions 接受所有公开的模型 ID，包括 `anthropic/claude-fable-5-2` 和 `google/gemini-4-carbon`，以及三个别名。[OpenAI 和 Anthropic SDK 指南](/zh/guides/openai-anthropic-sdks)介绍了配置方法。

### 如何在 API 中设置推理强度？

请调用模型的 API ID，并在请求中设置推理选项。

### 应该先用哪个 Claude 模型？

Anthropic 建议大多数工作先从 Claude Opus 5.5 开始，遇到高要求推理和长周期智能体任务时再换用 Claude Fable 5.2。[Claude vs ChatGPT](/zh/articles/claude-vs-chatgpt) 将这两个 Claude 模型与 GPT-6.2 Astra 做了对比。
