只需一个 Capriole AI API Key，任何支持自定义端点的编程智能体都能使用 GPT-6 Astra、Claude Fable 5.1 和 Opus 5.5，价格比官方 API 最多低 92%。

## 其他智能体

大多数编程智能体只要允许设置自定义端点，就可以使用 Capriole AI。请根据智能体支持的协议使用下表中的值。

| 协议 | Base URL | 模型 ID |
| --- | --- | --- |
| Chat Completions | `https://api.caprioletech.com/v1` | `GET /v1/models` 返回的所有 ID，例如 `claude-latest`、`anthropic/claude-opus-5-5` 或 `moonshot/kimi-k3.1-pro` |
| Responses | `https://api.caprioletech.com/v1` | `openai-latest` 等 GPT 模型，以及 `xai/grok-4.7` |
| Anthropic Messages | `https://api.caprioletech.com` | `claude-latest` 和 `claude-opus-5-5` 等不带前缀的 Claude ID |

Chat Completions 是最简单的选择，因为它支持所有模型。

如需在已有专属页面的编程智能体中使用同一个 Key，请参阅[使用一个 API Key 配置编程智能体](/zh/guides/one-api-key-coding-agents)。

## 身份验证

Capriole AI 只接受通过 `Authorization` 请求头以 Bearer Token 形式发送的 Key。如果智能体在 `x-api-key` 请求头中发送 Key（许多 Anthropic 客户端都是这样），请设置自定义请求头 `Authorization: Bearer YOUR_CAPRIOLE_AI_API_KEY`，或者改用该智能体的 OpenAI 兼容选项。

API Key 需要 Premium 套餐（每月 USD 8，还包含无限网页聊天）或 Team 套餐，可在[此处订阅](https://www.capriole.ai/zh?view=api)。
