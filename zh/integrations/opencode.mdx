## OpenCode 是什么

OpenCode 是开源 AI 编程代理，提供终端界面、桌面应用和 IDE 扩展。这套配置把 Capriole AI 添加为一个自定义提供商，其中每个模型都使用 Capriole AI 为该模型系列提供的 API 协议。

## 前置条件

开始前请确保你已经拥有以下内容。

- Capriole AI 账户，可在[此处注册](https://capriole.ai)
- Capriole AI API Key，可在[此处获取](https://capriole.ai?view=api)

## 安装

使用官方安装脚本安装 OpenCode。

```bash
curl -fsSL https://opencode.ai/install | bash
```

也可以使用 npm 安装。

```bash
npm install -g opencode-ai
```

验证安装。

```bash
opencode --version
```

## 配置

### 模型验证

使用下方配置，OpenCode 1.19.3 经 Capriole AI 调用“支持的模型”一节中的每个模型，都通过了文件读取、文件写入和最终答案检查。

创建或更新 `~/.config/opencode/opencode.json`。

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
        }
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "openai/gpt-6.1-sol": {
          "name": "GPT-6.1 Sol",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "claude-latest": {
          "name": "Claude latest",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "claude-opus-5-5": {
          "name": "Opus 5.5",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "google/gemini-3.8-flash": {
          "name": "Gemini 3.8 Flash",
          "limit": {
            "context": 1048576,
            "output": 65536
          }
        },
        "xai/grok-4.7": {
          "name": "Grok 4.7",
          "limit": {
            "context": 500000,
            "output": 128000
          }
        },
        "zai/glm-5.3-flash": {
          "name": "GLM 5.3 Flash",
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "moonshot/kimi-k3": {
          "name": "Kimi K3",
          "limit": {
            "context": 1048576,
            "output": 131072
          }
        }
      }
    }
  }
}
```

各项设置的作用如下。

- `npm: "@ai-sdk/openai-compatible"` 是该提供商的默认包，因此 Gemini、Grok、GLM 和 Kimi 使用 Chat Completions。
- 每个 GPT 模型都用 `@ai-sdk/openai` 覆盖 `provider.npm`，从而使用 Responses API。每个 Claude 模型都用 `@ai-sdk/anthropic` 覆盖它，从而使用 Anthropic Messages。
- 每个包的 `baseURL` 都包含 `/v1`。
- `{env:CAPRIOLE_AI_API_KEY}` 从环境变量读取你的 API Key。`Authorization` 请求头让每个包都以 Bearer Token 形式发送 Key。没有它时，Anthropic 包会在 `x-api-key` 请求头中发送 Key，而 Capriole AI 不接受这种方式。
- `limit` 告诉 OpenCode 每个模型的上下文窗口和输出上限，让它能跟踪上下文并及时压缩会话。
- `small_model` 是 OpenCode 处理会话标题等轻量任务时使用的模型。

## 运行 OpenCode

设置 API Key，然后在项目目录中启动 OpenCode。

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
opencode
```

使用 `/models` 切换模型。如需非交互式运行，请使用 `opencode run`。

```bash
opencode run -m capriole-ai/claude-latest "Explain this repository."
```

## 支持的模型

模型引用格式为 `capriole-ai/<model-id>`。

| 模型 | 模型 ID | 协议 |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` 和 `claude-latest` 始终指向各自系列中我们最新的旗舰模型。

## 故障排除

### 为什么 OpenCode 返回身份验证错误

启动 OpenCode 前，确认已在同一个 Shell 中导出 `CAPRIOLE_AI_API_KEY`，并确认 `options.headers` 下有 `Authorization` 请求头。

### 为什么 Claude 请求因 `Unsupported Claude Messages model` 失败

使用 `@ai-sdk/anthropic` 的 Claude 模型需要不带前缀的 Claude ID，例如 `claude-opus-5-5`。带 `anthropic/` 前缀的 ID 用于 Chat Completions。

### 为什么 GPT 请求失败

确认每个 GPT 模型都有 `"provider": { "npm": "@ai-sdk/openai" }`，让它的请求使用 Responses API。

### 为什么 Capriole AI 模型没有出现

确认模型引用使用 `capriole-ai/<model-id>` 格式，例如 `capriole-ai/moonshot/kimi-k3`，并确认 `disabled_providers` 没有屏蔽 `capriole-ai`。

### 为什么配置修改没有生效

检查是否存在项目级 `opencode.json` 或 `OPENCODE_CONFIG` 覆盖，然后重新启动 OpenCode。

### 为什么出现提供商包错误

清除 `~/.cache/opencode` 并重新启动 OpenCode，让它重新安装提供商包。

## 说明

- 把 API Key 保存在环境变量中，不要粘贴到 `opencode.json`。
- 如需添加其他 Capriole AI 模型，请复制同一系列中某个模型的条目并修改 ID。`GET https://api.caprioletech.com/v1/models` 会列出所有模型 ID。
- 官方参考资料包括 [OpenCode 安装](https://opencode.ai/docs)、[OpenCode 配置](https://opencode.ai/docs/config)、[OpenCode 提供商](https://opencode.ai/docs/providers)、[OpenCode 模型](https://opencode.ai/docs/models)和 [OpenCode 故障排除](https://opencode.ai/docs/troubleshooting)。
