Capriole AI Premium costs USD 8 a month for unlimited web chat with GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon, and every other supported model. It also includes an API that costs up to 92% less than official API prices, for your apps and coding agents. You can try web chat for free first: 5 messages a day without an account, or 500,000 tokens a month with a free account. Team costs USD 70 a month for 5 seats and a shared pool of API tokens.

## What unlimited means

Premium and Team web chat has no token meter on any [supported model](/guides/choose-a-model), including the **Thinking** presets. Signed-in web chat has a fair-use limit of 200 messages per account per UTC day: it stops scripted, automated abuse, and normal use stays well below it.

If you reach the limit, Capriole AI shows a notice and chat resumes at 00:00 UTC. The limit does not apply to API keys.

Claude's own Pro and Max plans work differently, with a five-hour session limit and a weekly limit. [Claude usage limits explained](/articles/claude-usage-limits) compares them with Capriole AI.

## What uses API tokens

Web chat and the API are counted separately.

| Activity | What it uses |
|---|---|
| Web chat on Premium or Team | Nothing. It is unlimited. |
| Web chat on Free | Your 500,000-token monthly chat allowance |
| Image generation in web chat | Nothing. It is free. |
| API requests, including the **Playground** on the API page | API tokens |
| Coding agents such as Codex and Claude Code | API tokens |

API tokens are counted as charged tokens: uncached input, plus 10% of cached input, plus output. The count works the same way on every model. Thinking models use more tokens. [Charged tokens explained](/articles/charged-tokens) has worked examples.

Your included monthly tokens are used first, then any top-up tokens. An API key needs Premium or Team; on Free, the API page says **Subscribe to access the API.**

## Capriole Quant subscribers

Capriole AI is made by Capriole Investments. Its market-data platform, [Capriole Quant](https://quant.capriole.com/) (formerly Capriole Charts), is a separate product.

Eligible paid Capriole Quant plans include Capriole AI access at no extra cost, so you do not need a separate subscription. The access stays active while your Quant plan is active. The Capriole Quant 3-day free trial includes web chat only, not API access.

## Pay for a plan

Select your name at the bottom of the sidebar, choose **Pricing**, then select **Subscribe** on Premium. On the **Account** page, **Upgrade** opens the same plans.

Stripe processes payments. Major credit and debit cards are supported, and Stripe shows the payment methods available for your checkout. Premium and Team checkout accept promotion codes.

## Cancel Premium

<Steps>
<Step title="Open Account">

Select your name at the bottom of the sidebar, then select **Account**.

</Step>

<Step title="Open your subscription">

Select **Manage subscription**. Stripe's billing page opens.

</Step>

<Step title="Cancel">

Cancel the subscription on that page.

</Step>
</Steps>

You can cancel at any time. There is no long-term contract or cancellation fee. Premium stays active until the end of the current billing period, and then your account returns to Free. Your saved chats stay, and you can still export them.

Premium from a promotion or a redemption code has nothing to cancel: it ends on the date shown in **Account** and does not renew. Team owners and admins manage the Team subscription with the same **Manage subscription** button. The [Team plan guide](/guides/team-plan) covers seats, invites, and shared tokens.

## Common questions

### Is Capriole AI really unlimited?

Yes, for web chat on Premium and Team: there is no token meter on any supported model, only the [fair-use limit](#what-unlimited-means) against scripted abuse. The API is counted in tokens.

### Can I use Capriole AI for free?

Yes. Guests can send 5 messages a day [without an account](/articles/ai-chat-without-login). A free account includes 500,000 tokens of web chat a month and free image generation, but no API access.

### Does Premium include the API?

Yes. Premium includes 5 million API tokens a month for apps and coding agents, at up to 92% less than official API prices. More tokens cost USD 8 per 5 million.

### How do I cancel Premium?

Open **Account**, select **Manage subscription**, and cancel on Stripe's billing page. Premium stays active until the end of the billing period.

### I have Capriole Quant. Do I need Premium?

No. Eligible paid Capriole Quant plans include Capriole AI access at no extra cost.
