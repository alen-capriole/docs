Capriole AI Premium costs USD 9 a month for unlimited web chat with GPT-6.2 Astra, Claude Fable 5.2, Claude Opus 5.5, Gemini 4 Carbon, and every other supported model. It also includes 5M API tokens each month for your apps and coding agents. You can try web chat for free first: 5 messages a day without an account, or 500,000 tokens a month with a free account. Team costs USD 70 a month for 5 seats and a shared pool of API tokens.

USD 9 is the monthly price for new web subscriptions. Existing USD 8 web subscriptions renew at USD 8 while they stay active.

## What unlimited means

Premium and Team web chat has no token meter on any [supported model](/guides/choose-a-model), including the **Thinking** presets, and no five-hour or weekly limit.

The ring in the message box shows how much of the model's context the chat has used. Select it to see **Context (before compaction applies)** and, on Free, what is left of this month's allowance. To hide the ring, turn off **Show usage** in **Account** → **Settings**.

Claude's own Pro and Max plans work differently, with a five-hour session limit and a weekly limit. [Claude usage limits explained](/articles/claude-usage-limits) compares them with Capriole AI.

## What uses API tokens

Web chat and the API are counted separately.

| Activity | What it uses |
|---|---|
| Web chat on Premium or Team | Nothing. It is unlimited. |
| Web chat on Free | Your 500,000-token monthly chat allowance |
| Image generation in web chat | Nothing. It is free. |
| API requests, including the **Playground** on the API page | API tokens |
| Coding agents such as Codex and Claude Code | API tokens |

API tokens are counted as charged tokens: uncached input, plus 10% of cached input, plus output. The count works the same way on every model. Thinking models use more tokens. [Charged tokens explained](/articles/charged-tokens) has worked examples.

Your included monthly tokens are used first, then any top-up tokens. An API key needs Premium or Team; on Free, the API page says **Subscribe to access the API.**

### Up to 3 free accounts per IP address

Each IP address can have up to 3 free accounts, alongside paid and Team accounts.

When more than 3 free accounts are used from one IP address:

- Free chat stops on the extra accounts.
- We email each extra account. 48 hours later, we remove the extra accounts and keep the 3 used the most.
- To keep an extra account, upgrade it to a paid plan.

If you, your family or your team require more than 3 accounts, we request that you upgrade to a paid account. Alternatively, a Capriole AI [Team plan](/guides/team-plan) may be more efficient for you.

To delete an account yourself: sign in, click **Account**, select **Manage account** > **Security**, and click **Delete account**.

If the accounts belong to different people, email [info@capriole.ai](mailto:info@capriole.ai) and we will be glad to help.

## Capriole Quant subscribers

Capriole AI is made by Capriole Investments. Its market-data platform, [Capriole Quant](https://quant.capriole.com/) (formerly Capriole Charts), is a separate product.

Eligible paid Capriole Quant plans include Capriole AI access at no extra cost, so you do not need a separate subscription. The access stays active while your Quant plan is active. The free 3-day Capriole Quant trial covers web chat. API access starts with an eligible paid plan.

## Pay for a plan

Select your name at the bottom of the sidebar, choose **Pricing**, then select **Subscribe** on Premium. On the **Account** page, **Upgrade** opens the same plans.

Stripe processes payments. Major credit and debit cards are supported, and Stripe shows the payment methods available for your checkout. Premium and Team checkout accept promotion codes. In the Android app, Google Play processes the payment.

## Cancel Premium

<Steps>
<Step title="Open Account">

Select your name at the bottom of the sidebar, then select **Account**.

</Step>

<Step title="Open your subscription">

Select **Manage subscription**. Stripe's billing page opens.

</Step>

<Step title="Cancel">

Cancel the subscription on that page.

</Step>
</Steps>

If you subscribed in the Android app, **Manage subscription** opens your Google Play subscriptions instead, and you cancel there.

You can cancel at any time. There is no long-term contract or cancellation fee. Premium stays active until the end of the current billing period, and then your account returns to Free. Your saved chats stay, and you can still export them.

Premium from a promotion or a redemption code has nothing to cancel: it ends on the date shown in **Account** and does not renew. Team owners and admins manage the Team subscription with the same **Manage subscription** button. The [Team plan guide](/guides/team-plan) covers seats, invites, and shared tokens.

## Common questions

### Is Capriole AI really unlimited?

Yes. Paid plans include unlimited web chat on every supported model, with no five-hour or weekly limit.

### Can I use Capriole AI for free?

Yes. Guests can send 5 messages a day [without an account](/articles/ai-chat-without-login). A free account includes 500,000 web chat tokens a month and free image generation with Server Storage.

### Does Premium include the API?

Yes. Premium includes 5 million API tokens a month for apps and coding agents. Personal top-ups cost USD 8 per 5 million tokens, up to 92% below official API prices in the [standard-rate comparison](/overview).

### How do I cancel Premium?

Open **Account**, select **Manage subscription**, and cancel on Stripe's billing page. Premium stays active until the end of the billing period. If you subscribed in the Android app, cancel in Google Play.

### I have Capriole Quant. Do I need Premium?

No. Eligible paid Capriole Quant plans include Capriole AI access at no extra cost.
