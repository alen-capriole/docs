A project keeps related chats together under one name in the sidebar, with instructions that every chat in it follows and files they can all read. Use one for a client, a course, or any work you come back to, and tell Capriole AI once how to work there instead of repeating it in each chat.

## Who can use projects

Projects are available on every plan to signed-in users who keep chats on the server: in **Account** → **Settings**, leave **Enable local storage** and **Enable No Storage** off. The [chat storage guide](/guides/chat-storage) explains the three storage modes.

## Create a project

1. In the sidebar, point to **Projects** and select **+**.
2. Enter a name. Optionally, select the icon to the left of the name to pick a color and an icon.
3. Select **Create**.

The project appears under **Projects**, between **Pinned** and **Recents**, with its icon and color. Select its name to show or hide its chats. They appear five at a time; select **Load more** to see more. Your browser remembers which projects you left open.

To open the project's page, point to the project, open its three-dot menu, and choose **Manage project**. The page has a **New chat** button and the **Chats**, **Files**, **Instructions**, and **Memory** tabs. **Chats** lists every chat in the project.

## Start a chat in a project

On the project page, select **New chat**. In the sidebar, you can also point to the project and select its **+**. The new chat is saved in the project.

## Move a chat into or out of a project

A chat belongs either to **Recents** or to one project.

- **From the chat's menu**: In the sidebar, open the chat's menu, choose **Project**, then a project. To move the chat back to **Recents**, choose **Remove from** followed by the project's name.
- **By dragging**: On a computer, drag the chat from the sidebar onto a project.

From its next reply, a chat moved into a project follows the project's instructions, can read its files, and uses its memory; a chat moved out loses all three. Facts it already saved stay in the list they were saved to.

## Set project instructions

On the project page, select the **Instructions** tab. Write how Capriole AI should work in this project, for example the role to take, the format to use, or the sources to cite. Instructions can be up to 1,500 characters. Once you change the text, a character count, **Cancel**, and **Save** appear; select **Save**.

Saved instructions apply to every chat in the project, including the ones already there, from their next reply. They apply on top of your account instructions in **Account** → **Personalization**. When the two conflict, the project instructions win: if your account instructions ask for short replies and the project's ask for detailed reports, chats in the project get detailed reports.

Capriole AI also knows the project's name in these chats, so you can refer to "this project".

## Add files to a project

On the project page, select the **Files** tab. Select **Add files**, or drag files onto the tab. You can add the same documents and images as chat attachments; the [files and web search guide](/guides/files-web-search) lists the types.

The limits are the same on every plan:

- Up to 40 files in a project.
- Up to 10 MB per file, or 4 MB for documents other than PDF.
- Up to 1 GB of project files in your account.

Each file in a project needs its own name.

Every chat in the project can use these files, including chats already there. Capriole AI sees the list of files and reads a file when your question needs it; the chat shows **Reading** followed by the file's name while it does.

To delete a file, point to it, select **×**, and confirm with **Delete**. The file is permanently deleted and the project's chats can no longer read it; replies that used it stay as they are.

## Use project memory

Each project has its own memory, separate from your general memory in **Account** → **Memory**. When **Memory** is on, a chat in the project uses both, and the new facts it saves go to the project's memory only, so chats outside the project never see them.

On the project page, select the **Memory** tab. You can:

- Select **Add memory**, type a fact, and select **Save** or press Enter.
- Point to a memory and select the pencil to edit it, or **×** to delete it right away.
- Select **Delete all** and confirm with **Delete** to clear the project's memory. Your general memory stays.

A project's memory holds up to 1,200 characters, and the tab counts how many are used. When it is full, **Add memory** is unavailable and Capriole AI adds no new facts until you shorten or delete one.

You turn **Memory** on or off for your whole account in **Account** → **Memory**. While it is off, chats do not use or update the project's memory, and you can still add, edit, or delete memories. The [privacy guide](/guides/privacy-and-security#memory) explains what memory keeps.

## Pin a chat in a project

Pinning changes only where the sidebar shows a chat. A pinned project chat shows under **Pinned** instead of under its project, and returns under the project when you unpin it. It stays in the project: it keeps the project's instructions, files, and memory, and the project's **Chats** tab still lists it.

## Edit or delete a project

In the sidebar, point to the project and open its three-dot menu. Choose **Edit** to change the project's name, color, or icon, or **Delete** to delete it. The same menu is next to **New chat** on the project page.

<Warning>
Once you confirm, Capriole AI permanently deletes the project, its instructions, its files, its memory, and every chat in it. First move out any chat you want to keep, or export the project; the export does not include memory.
</Warning>

## Export a project

Open the same three-dot menu, choose **Export**, and select **Export** in the dialog. Capriole AI prepares a ZIP and shows its progress; when it is ready, select **Download**. The ZIP has the project's chats as Markdown files and a `projects/` folder with the project's instructions and files. **Export chat history** in **Account** → **Settings** includes all your projects the same way.

## Tag chats

Tags are colored labels that work alongside projects. A chat belongs to **Recents** or one project, and it can also have several tags, so you can find related chats wherever they are. Like projects, tags are available to signed-in users who keep chats on the server.

- **Tag a chat**: In the sidebar, open the chat's menu and choose **Tags**, then select the tags you want; select a tag again to remove it. Choose **New tag** to create a tag with a name and a color and add it to the chat. A chat's tags show under its title.
- **Show chats with certain tags**: Select the filter button to the right of **Search Chats** and select one or more tags. The sidebar shows **Tagged chats**: every chat with any of the selected tags, from **Recents** and all your projects. A chat in a project shows the project's name before its tags. To take a tag out of the filter, select **×** on it, or select **Clear filter** to show all chats again.
- **Search tagged chats**: In **Search Chats**, select one or more tags under **Tags** to list the chats that have any of them, then type to search only those chats.
- **Edit or delete a tag**: Open the filter menu, choose **Manage tags**, and use the edit or delete button next to the tag. Editing changes its name and color. Deleting a tag removes it from every chat; the chats themselves stay.

You can create up to 50 tags, each with a name of up to 30 characters, and add up to 10 tags to a chat.

## Common questions

### How do I find a chat in a project?

Select **Search Chats** in the sidebar and type part of the chat's title. Search covers all your chats, including those in projects.

### Does deleting all chat history remove my projects or their files?

No. It deletes every chat, including those in your projects, but the projects keep their names, instructions, files, and memory.
