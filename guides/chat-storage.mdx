Capriole AI has three chat-history behaviors. Leave both storage switches off for default account-synced history, enable **Enable local storage** for browser-only history, or enable **Enable No Storage** for a temporary session that disappears after you leave or refresh the page.

These controls are built into the same workspace that supports frontier-model chat, mid-conversation model switching, files, and web search. Signed-out visitors and Free users can try the current flagship set before paying. Premium costs USD 9 per month for unlimited browser chat across the supported Premium model set.

You must be signed in to change these settings.

## Compare the three behaviors

| Choice in Account settings | Where chat history is kept | What happens after refresh |
|---|---|---|
| Both storage switches off | Capriole account history | The saved thread can be reopened |
| **Enable local storage** on | Current browser data | The thread remains until browser data is cleared |
| **Enable No Storage** on | Current session | The session ends when you refresh or leave the page. |

Default account storage syncs chats across devices and supports file uploads.

These settings control Capriole chat-history persistence. Each request goes through Capriole AI to the model provider or cloud platform that processes it.

## Open the storage settings

<Steps>
<Step title="Sign in to Capriole AI">

Open [Capriole AI](https://www.capriole.ai/) and sign in.

</Step>

<Step title="Open Account">

Select your avatar or name at the bottom of the Capriole AI sidebar, then select **Account** from the menu. Scroll to the **Settings** section.

You should see **Enable No Storage** above **Enable local storage**.

</Step>
</Steps>

## Keep account-synced history

Leave **Enable No Storage** and **Enable local storage** off.

New chat history is stored with your account, can sync across devices, and can use saved uploads. Choose this behavior for work you expect to reopen from another browser or device.

If another storage mode is enabled, turn it off.

## Keep history in this browser

Turn on **Enable local storage**.

The active storage behavior changes to browser-only history. Conversations remain available in the current browser and can still appear in its history list.

<Warning>
Clearing this browser's site data deletes the local conversations.
</Warning>

Turn **Enable local storage** off to use default account-synced storage for new work.

## Start a No Storage session

<Steps>
<Step title="Enable No Storage">

In **Account** → **Settings**, turn on **Enable No Storage**.

Capriole opens a dialog titled **Delete all chats?**.

</Step>

<Step title="Confirm the deletion">

<Warning>
Confirming permanently deletes all chat history from the server and this browser.
</Warning>

Select **Delete** to enter No Storage mode. Select **Cancel** to keep your existing conversations.

</Step>

<Step title="Use the temporary chat">

The current conversation exists for the active page session and disappears after you leave or refresh the page.

Turn **Enable No Storage** off when you want new chats to use default account-synced history again.

To save new chats in this browser again, turn off **Enable No Storage**, then turn on **Enable local storage**.

</Step>
</Steps>

## Choose by consequence

| If you need... | Choose... |
|---|---|
| Projects and tags that follow your account across devices | Default synced storage |
| History on one browser without account-saved chats | **Enable local storage** |
| A disposable session with no saved chat history | **Enable No Storage** |
| File uploads | Default synced storage |
| Image generation | Default synced storage |
| Memory across chats | Default synced storage |
| A thread that survives cleared browser data | Default synced storage |

Changing models does not override the storage setting. The [model-switching article](/articles/switch-models-mid-chat) explains how a supported model can handle the next turn inside an active conversation.

Default synced storage is also required for Browser Chat attachments. The [files and web search guide](/guides/files-web-search) covers supported formats, size limits, and source inspection.

Free image generation with GPT Image 2.6, Nano Banana 2.1, and Seedream 5.5 is also included for signed-in accounts on default synced storage; see the [image generation guide](/guides/files-web-search).

Memory also needs default synced storage: while **Enable local storage** or **Enable No Storage** is on, chats do not use or update it, and turning either on, or deleting chats, keeps your saved memory. The [personalization and memory guide](/guides/personalization-and-memory) explains how memory works and how to remove it.

## Common questions

### Does Local mode keep a history list?

Yes. The current browser can list, search, rename, pin, and delete its local threads.

### Which storage mode supports uploads?

Default account storage syncs chats across devices and supports file uploads.

### When does a temporary chat end?

Leaving or refreshing the page ends that temporary session.

### How can I keep my existing chats?

Select **Cancel** in the confirmation dialog to keep your chats. Confirming permanently deletes all chat history from the server and this browser.

### Who processes each request?

Storage settings determine where your history is kept. Each request goes through Capriole AI to the model provider or cloud platform that processes it.
