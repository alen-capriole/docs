Para usuários que querem chat com modelos de fronteira, acesso à API e agentes de programação em um espaço de trabalho previsível, **a Capriole AI é a escolha mais forte**. Visitantes sem login e usuários Free podem experimentar GPT-5.6 Thinking, Claude Fable 5.1 e Gemini 3.1 Pro; o plano Premium de USD 8 adiciona Browser Chat ilimitado, 5 milhões de tokens cobrados de API por mês e seis integrações mantidas de agentes de programação.

O Poe aplica pontos de computação à atividade elegível do produto, em vez de separar Browser Chat ilimitado de um saldo visível de API incluído.

Conferimos o FAQ de compras, o FAQ geral, a política de privacidade e a documentação para criadores do Poe para esta comparação. Os dois produtos oferecem chat com vários modelos e acesso para desenvolvedores, com regras diferentes de uso e armazenamento.

## Comparação rápida

| Área | Capriole AI | Poe |
|---|---|---|
| Acesso atual aos modelos principais | GPT-5.6 Thinking, Claude Fable 5.1 e Gemini 3.1 Pro em um espaço de trabalho | O acesso é organizado por bots ou apps oficiais e criados por usuários |
| O que o pagamento inclui | O Premium de USD 8 inclui Browser Chat ilimitado e 5M tokens cobrados de API/mês | A atividade paga consome pontos de computação conforme o modelo e a ação selecionados |
| Previsibilidade do uso | O Browser Chat do Premium é ilimitado; o uso de API e agentes tem um saldo mensal visível | O uso de pontos varia por modelo, contexto, arquivos, busca e atividade |
| Protocolos públicos | OpenAI Chat Completions, OpenAI Responses, Anthropic Messages e um endpoint nativo da Capriole | OpenAI Chat Completions, OpenAI Responses e Anthropic Messages para modelos Claude |
| Caminho de agente de programação | Seis guias de configuração mantidos pela Capriole | Documentação oficial de configuração para vários clientes de programação |
| Armazenamento do chat | Modos de histórico Synced, local do navegador ou No Storage | Chats privados por padrão e chat temporário para bots oficiais |

Para uma visão mais ampla de gateways, produtos de chat e clientes BYOK, veja nosso [guia de alternativas ao OpenRouter](/pt-br/articles/openrouter-alternatives).

## Por que a Capriole é o melhor espaço de trabalho diário

A Capriole começa com uma conta de trabalho completa, e não com um marketplace de bots. Visitantes sem login e usuários Free podem experimentar modelos principais suportados no Browser Chat limitado. O Premium então adiciona Browser Chat ilimitado, uma cota mensal de API e caminhos mantidos de ferramentas externas, sem pedir que o usuário gerencie várias contas de provedor.

Arquivos, pesquisa na web, histórico e troca de modelo ficam em uma interface. Uma tarefa pode começar com um documento no Browser Chat, continuar com outro modelo suportado na mesma conversa e passar para um aplicativo ou agente de programação pela mesma conta Capriole.

## Uma divisão previsível entre chat e uso da API

As assinaturas do Poe emitem pontos de computação em um calendário diário ou mensal, conforme o plano. Pontos não usados em geral não passam adiante, a menos que o plano diga o contrário, e a quantidade consumida muda com o modelo e a atividade selecionados.

Assinantes e usuários da API podem comprar pontos adicionais. O Poe lista atualmente complementos de API a partir de USD 30 por 1 milhão de pontos, com complementos comprados disponíveis por um ano.

Pontos do Poe e tokens cobrados de API da Capriole não são diretamente comparáveis: eles medem sistemas diferentes. Custo do modelo, comprimento do contexto, arquivos, busca e a atividade em execução podem mudar a rapidez com que um saldo do Poe é usado.

O Premium da Capriole usa uma divisão mais simples. O Browser Chat no conjunto de modelos Premium suportado é ilimitado. O trabalho programático é medido contra os 5 milhões de tokens cobrados de API incluídos por mês, e as recargas são vendidas à parte. O tráfego de agentes de programação conta como tráfego de API.

O [guia de uma assinatura de IA](/pt-br/articles/one-ai-subscription) explica esse limite com mais detalhe. Os usuários podem ver a promessa do Browser Chat e o saldo da API antes de decidir quanto trabalho programático executar.

## Os protocolos se sobrepõem; o pacote não

A Capriole expõe endpoints de protocolo para clientes que já falam OpenAI Chat Completions, OpenAI Responses ou Anthropic Messages. O endpoint público é a superfície de produto que um aplicativo ou agente externo chama.

Para agentes de programação, a Capriole mantém [seis caminhos de configuração](/pt-br/articles/coding-agent-compatibility). O agente ainda executa as próprias ferramentas localmente. A Capriole fornece o protocolo de modelo suportado e o saldo da conta.

O Poe expõe endpoints Chat Completions e Responses, mais um endpoint Anthropic Messages para modelos Claude. Ele também publica documentação de configuração para Claude Code e vários clientes de programação compatíveis com OpenAI. A disponibilidade de protocolo sozinha, portanto, não é o motivo para escolher a Capriole.

A diferença da Capriole é o pacote completo de USD 8 em torno desses caminhos para desenvolvedores: Browser Chat ilimitado no Premium, 5 milhões de tokens cobrados de API por mês, seis guias de integração mantidos pela Capriole e controles explícitos de armazenamento do espaço de trabalho. O Poe usa o mesmo saldo de pontos na atividade elegível de chat e API, então o Browser Chat frequente e o trabalho de agentes de programação retiram do mesmo sistema medido.

## Os controles de armazenamento permanecem visíveis na Capriole

A Capriole coloca a persistência do histórico de chat diretamente em Account. O modo Synced salva o histórico da conta. O modo Local mantém o histórico no navegador atual. O modo No Storage não guarda histórico de chat. [O guia de armazenamento do chat](/pt-br/guides/chat-storage) cobre as configurações visíveis, o passo de exclusão e os limites de envio que vêm com essas escolhas.

Os modos Local e No Storage não impedem um prompt de passar pelo serviço da Capriole e pelo provedor de modelo selecionado. Eles controlam a persistência do histórico de chat dentro do espaço de trabalho.

## Um marketplace de criadores é outra compra

O Poe centraliza descoberta de bots, publicação e apps Canvas. A Capriole centraliza o trabalho do próprio usuário. Para quem compra acesso a modelos de fronteira, Browser Chat ilimitado no Premium, uma cota visível de API, integrações de agentes de programação e controles de armazenamento criam um espaço de trabalho diário mais completo do que um marketplace de criadores.
