## Como funcionam os limites de uso do Claude

A central de ajuda da Anthropic descreve dois limites nos planos pagos:

- **Um limite de sessão**, renovado a cada cinco horas.
- **Um limite semanal** para todos os modelos, renovado em um horário fixo definido para a sua conta.

A Anthropic diz que também pode limitar o uso de outras formas, como tetos mensais ou limites em modelos e recursos específicos. Você acompanha seu consumo em **Settings** → **Usage** no claude.ai.

Os limites são compartilhados. O uso no claude.ai, no Claude Desktop e no Claude Code conta para a mesma franquia, então uma sessão longa no Claude Code pode deixar pouco espaço para o chat. Trocar para outro modelo do Claude não zera a franquia, porque o limite semanal cobre todos os modelos.

## Por que você bate no limite antes do esperado

A Anthropic lista o que consome mais da sua franquia:

- conversas longas e complexas
- o modelo que você escolhe
- níveis de esforço mais altos e raciocínio estendido
- ferramentas e conectores, que usam muitos tokens
- arquivos de projeto grandes, que ocupam contexto
- chats longos que acionam o gerenciamento automático de contexto

O Fable 5.1 tem uma regra própria. No Pro, o Fable 5 e o Fable 5.1 não fazem parte dos limites de uso do plano, então cada mensagem do Fable usa créditos de uso cobrados aos preços padrão da API. No Max, os modelos Fable podem usar até 50% dos seus limites semanais sem custo extra.

## O que a Anthropic sugere quando você bate no limite

1. **Espere a renovação.** O limite de sessão é renovado a cada cinco horas, e **Settings** → **Usage** mostra quando.
2. **Faça upgrade.** A Anthropic descreve o Max 5x como ideal para quem usa o Claude com frequência, e o Max 20x como ideal para quem usa o Claude todos os dias na maioria das tarefas. Os limites do novo plano valem na hora.
3. **Ative os créditos de uso.** Os créditos deixam você continuar trabalhando depois de um limite, cobrados aos preços padrão da API. Você pode definir um teto de gastos mensal.
4. **Gaste menos por mensagem.** Comece uma conversa nova em vez de estender uma longa, reduza o nível de esforço, desative o raciocínio estendido e as ferramentas desnecessárias e encurte as instruções do projeto.

Se você atingir o limite de cinco horas no meio de uma resposta do Claude Code, o Claude Code pode concluir a etapa atual antes de parar. No Pro, isso acontece no máximo uma vez por período semanal de uso.

## Uso intenso de agentes de programação: o caminho da API

O chat web ilimitado não cobre agentes de programação. Para o Claude Code e outros agentes, use uma API key da Capriole AI. As solicitações dos agentes consomem um saldo medido de API que custa até 92% menos que os preços oficiais das APIs.

| Modelo | Preço oficial da API por 1M de tokens (entrada / saída) | Capriole AI |
|---|---|---|
| Claude Fable 5.1 | USD 10 / USD 50 | USD 8 a cada 5M de tokens |
| Claude Opus 5.5 | USD 4 / USD 20 | USD 8 a cada 5M de tokens |
| GPT-6 Astra | USD 10 / USD 50 | USD 8 a cada 5M de tokens |

USD 8 a cada 5M de tokens equivalem a USD 1.60 por milhão, tanto na entrada quanto na saída. O Premium inclui 5M de tokens de API por mês, e as recargas custam USD 8 a cada 5M de tokens de qualquer modelo suportado. A entrada em cache conta a 10%, como explica o artigo sobre [tokens cobrados](/pt-br/articles/charged-tokens).

O Claude Code se conecta pelo endpoint Anthropic Messages da Capriole AI. A mesma key funciona com [10 agentes de programação documentados](/pt-br/guides/one-api-key-coding-agents), incluindo o Codex. Comece pela [configuração do Claude Code](/pt-br/integrations/claude-code).

O Claude Max inclui créditos mensais de API, mas [a Anthropic diz](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans) que eles não cobrem sessões interativas do Claude Code nem o uso extra depois que você atinge os limites do plano.
