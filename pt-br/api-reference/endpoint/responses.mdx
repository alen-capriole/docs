Use este endpoint quando seu aplicativo, SDK ou agente esperar o formato de solicitação e resposta do OpenAI Responses.

Envie um payload padrão de Responses com `model` e `input`. A Capriole AI resolve os aliases latest para o ID de modelo upstream selecionado antes do despacho, encaminha campos compatíveis como `instructions`, `tools`, `reasoning`, `previous_response_id` e `stream`, e devolve o JSON ou o stream SSE do upstream sem alteração.

`POST /v1/responses` aceita `openai-latest`, `openai/gpt-6-astra`, `openai/gpt-6.1-sol`, `openai/gpt-6-sol`, `openai/gpt-6-luna`, `openai/gpt-5.6-terra`, `openai/gpt-5.6-luna` e `openai/gpt-5.5`. Use `openai-latest` para deixar a Capriole AI escolher o modelo principal de OpenAI Responses que recomendamos.

Você também pode enviar IDs nativos da OpenAI sem o prefixo `openai/`, como `gpt-6-astra`. Os IDs nativos e os que têm prefixo usam a mesma entrada de modelo para roteamento, preços e cota.

Este endpoint também aceita os modelos Grok `xai/grok-4.7`, `xai/grok-4.6` e `xai/grok-4.5`. Sempre envie os IDs do Grok com o prefixo `xai/`; um ID sem prefixo, como `grok-4.7`, é tratado como ID nativo da OpenAI e é rejeitado. As solicitações do Grok são encaminhadas para a própria API de Responses da xAI sem conversão de formato.

Os demais modelos não são suportados neste endpoint: `claude-latest`, `google-latest`, IDs de modelos Claude e Gemini como `anthropic/claude-fable-5-1` e `google/gemini-4-argon`, e os modelos GLM e Kimi (`zai/glm-5.3-flash`, `zai/glm-5.2`, `moonshot/kimi-k3.1-pro` e `moonshot/kimi-k3`). Use `POST /v1/chat/completions` quando quiser um único endpoint compatível com OpenAI que possa chamar todos os modelos públicos.

## Pesquisa na web

Adicione a ferramenta integrada `web_search` para que os modelos GPT ou Grok pesquisem na web:

```bash
curl https://api.caprioletech.com/v1/responses \
  -X POST \
  -H "Authorization: Bearer YOUR_CAPRIOLE_AI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "xai/grok-4.7",
    "input": "Summarize the latest AI news.",
    "tools": [{"type": "web_search"}],
    "stream": true
  }'
```

A pesquisa na web adiciona os resultados obtidos aos tokens de entrada da solicitação, então uma resposta com pesquisa pode usar muito mais tokens de entrada do que o prompt sozinho.

`POST /v1/chat/completions` não oferece pesquisa na web.

## Tarefas longas

Para tarefas longas, como pesquisa na web ou raciocínio extenso, defina `"stream": true`. Sem streaming, a conexão pode expirar após cerca de 2 minutos.
