O Premium da Capriole AI custa USD 8 por mês e inclui chat web ilimitado com GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon e todos os outros modelos suportados. Ele também inclui uma API que custa até 92% menos que os preços oficiais das APIs, para seus apps e agentes de programação. Você pode testar o chat web de graça antes: 5 mensagens por dia sem conta, ou 500.000 tokens por mês com uma conta gratuita. O Team custa USD 70 por mês por 5 assentos e um saldo compartilhado de tokens de API.

## O que significa ilimitado

O chat web do Premium e do Team não tem medidor de tokens em nenhum [modelo suportado](/pt-br/guides/choose-a-model), incluindo os modos **Thinking**. O chat web com login tem um limite de uso justo de 200 mensagens por conta por dia UTC: ele impede abusos automatizados feitos por scripts, e o uso normal fica bem abaixo disso.

Se você atingir o limite, a Capriole AI mostra um aviso e o chat volta a funcionar às 00:00 UTC. O limite não se aplica às API keys.

Os planos Pro e Max do próprio Claude funcionam de outro jeito, com um limite por sessão de cinco horas e um limite semanal. [Limites de uso do Claude](/pt-br/articles/claude-usage-limits) compara esses planos com a Capriole AI.

## O que consome tokens de API

O chat web e a API são contados separadamente.

| Atividade | O que consome |
|---|---|
| Chat web no Premium ou no Team | Nada. É ilimitado. |
| Chat web no Free | Sua franquia mensal de 500.000 tokens de chat |
| Geração de imagens no chat web | Nada. É grátis. |
| Solicitações à API, incluindo o **Ambiente de testes** na página da API | Tokens de API |
| Agentes de programação como Codex e Claude Code | Tokens de API |

Os tokens de API são contados como tokens cobrados: entrada sem cache, mais 10% da entrada em cache, mais a saída. A conta é a mesma em todos os modelos. Modelos Thinking usam mais tokens. [Tokens cobrados explicados](/pt-br/articles/charged-tokens) traz exemplos passo a passo.

Os tokens mensais incluídos são usados primeiro, depois os tokens de recarga. Uma API key exige Premium ou Team; no Free, a página da API mostra **Assine para acessar a API.**

## Compre mais tokens de API

Quando precisar de mais tokens, selecione **Recarregar** na página da API. Comprar vários pacotes de uma vez reduz o preço.

| | Recarga Premium | Recarga Team |
|---|---|---|
| Preço | USD 8 a cada 5M de tokens | USD 80 a cada 50M de tokens |
| Pacotes por compra | De 1 a 11 (de 5M a 55M de tokens) | De 1 a 5 (de 50M a 250M de tokens) |
| Desconto por vários pacotes | 1.5% para cada pacote extra, até 15% | 2.5% para cada pacote extra, até 10% |
| Quem pode comprar | Assinantes Premium | Proprietários e administradores do Team |

## Assinantes do Capriole Quant

A Capriole AI é desenvolvida pela Capriole Investments. A plataforma de dados de mercado da empresa, o [Capriole Quant](https://quant.capriole.com/) (antigo Capriole Charts), é um produto separado.

Os planos pagos elegíveis do Capriole Quant incluem acesso à Capriole AI sem custo extra, então você não precisa de outra assinatura. O acesso continua ativo enquanto seu plano do Quant estiver ativo. O teste gratuito de 3 dias do Capriole Quant inclui apenas o chat web, sem acesso à API.

## Assine um plano

Selecione seu nome na parte inferior da barra lateral, escolha **Preços** e selecione **Assinar** no Premium. Na página **Conta**, **Fazer upgrade** abre os mesmos planos.

O Stripe processa os pagamentos. Os principais cartões de crédito e débito são aceitos, e o Stripe mostra as formas de pagamento disponíveis no seu checkout. O checkout do Premium e do Team aceita códigos promocionais.

## Perguntas comuns

### A Capriole AI é mesmo ilimitada?

Sim, no chat web do Premium e do Team: não há medidor de tokens em nenhum modelo suportado, apenas o [limite de uso justo](#o-que-significa-ilimitado) contra abusos feitos por scripts. A API é contada em tokens.

### Posso usar a Capriole AI de graça?

Sim. Visitantes podem enviar 5 mensagens por dia [sem conta](/pt-br/articles/ai-chat-without-login). Uma conta gratuita inclui 500.000 tokens de chat web por mês e geração de imagens grátis, mas não dá acesso à API.

### O Premium inclui a API?

Sim. O Premium inclui 5 milhões de tokens de API por mês para apps e agentes de programação, até 92% abaixo dos preços oficiais das APIs. Tokens extras custam USD 8 a cada 5 milhões.

### Como cancelo o Premium?

Abra **Conta**, selecione **Gerenciar assinatura** e cancele na página de cobrança do Stripe. O Premium continua ativo até o fim do período de cobrança.

### Tenho o Capriole Quant. Preciso do Premium?

Não. Os planos pagos elegíveis do Capriole Quant incluem acesso à Capriole AI sem custo extra.
