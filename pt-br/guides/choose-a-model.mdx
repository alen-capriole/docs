A Capriole AI inclui quatro modelos principais: GPT-6 Astra, da OpenAI; Claude Fable 5.1 e Claude Opus 5.5, da Anthropic; e Gemini 4 Argon, do Google. O Premium dá chat web ilimitado com os quatro por USD 8 por mês, e a API custa até 92% menos que os preços oficiais das APIs. O chat web começa no GPT-6 Astra Thinking. Troque de modelo quando o fabricante de outro modelo disser que ele foi feito para a sua tarefa, conforme o resumo abaixo.

## Os quatro modelos principais

| Modelo | Para que o fabricante o desenvolve | Janela de contexto | Preço oficial da API por 1M de tokens (entrada / saída) |
|---|---|---|---|
| [GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra) (OpenAI) | Raciocínio complexo, programação, uso do computador, pesquisa e criação de documentos | 1.05M de tokens | USD 10 / USD 50 |
| [Claude Fable 5.1](https://platform.claude.com/docs/en/models/fable-5-1/overview) (Anthropic) | Raciocínio exigente e trabalho agêntico de longo horizonte | 1M de tokens | USD 10 / USD 50 |
| [Claude Opus 5.5](https://platform.claude.com/docs/en/models/opus-5-5/overview) (Anthropic) | Programação agêntica de longa duração e trabalho do conhecimento | 1M de tokens | USD 4 / USD 20 |
| [Gemini 4 Argon](https://ai.google.dev/gemini-api/docs/latest-model) (Google) | Os problemas mais difíceis, com raciocínio mais longo em tarefas complexas de programação, agênticas, de matemática e de ciências | 1M de tokens | USD 2 / USD 10 até 30 de novembro de 2026; depois, USD 4 / USD 20 |

Na Capriole AI, todos os modelos desta tabela são ilimitados no chat web do Premium e do Team. Na API, um token custa o mesmo em todos os modelos: USD 8 a cada 5M de tokens.

### GPT-6 Astra

A OpenAI apresenta o GPT-6 Astra como seu modelo mais capaz para o trabalho mais exigente. A OpenAI informa uma janela de contexto de 1.05M de tokens e até 128.000 tokens de saída. Na Capriole AI, o **GPT-6 Astra Thinking** é o padrão do chat web, e `openai-latest` usa o GPT-6 Astra na API.

### Claude Fable 5.1

A Anthropic posiciona o Claude Fable 5.1 para raciocínio exigente e trabalho agêntico de longo horizonte. Segundo a Anthropic, ele melhora em relação ao Claude Fable 5 em programação agêntica de longa duração, pesquisa em várias etapas e trabalho com documentos, planilhas e apresentações. A Anthropic o classifica como mais lento que o Claude Opus 5.5. `claude-latest` usa o Claude Fable 5.1. No plano Pro da própria Anthropic, o Fable 5.1 fica fora dos limites de uso e é cobrado com créditos de uso; veja [Limites de uso do Claude](/pt-br/articles/claude-usage-limits).

### Claude Opus 5.5

A Anthropic criou o Claude Opus 5.5 para programação agêntica de longa duração e trabalho do conhecimento, por menos da metade do preço oficial do Fable 5.1. A Anthropic recomenda começar a maioria das cargas de trabalho no Opus 5.5 e passar para o Fable 5.1 quando o Opus 5.5 com mais esforço ainda não der conta. Como no Fable 5.1, o raciocínio dele fica sempre ligado, então na Capriole AI o **Fast** reduz o esforço em vez de desligar o raciocínio.

### Gemini 4 Argon

O Google apresenta o Gemini 4 Argon como seu modelo mais capaz, criado para resolver os problemas mais difíceis. Segundo o Google, ele consegue raciocinar por mais tempo em tarefas complexas de programação, agênticas, de matemática e de ciências. A janela de contexto de 1M de tokens é compartilhada entre entrada, raciocínio e saída. `google-latest` usa o Gemini 4 Argon.

## Thinking ou Fast

A maioria dos modelos do chat web vem em dois modos. Selecione **Thinking** ou **Fast** ao lado do seletor de modelos, na caixa de mensagem.

- **Thinking** raciocina mais antes de responder, para tarefas complexas. Os modos Thinking do Claude mostram um resumo do raciocínio.
- **Fast** usa menos esforço de raciocínio para responder mais rápido.

O Thinking usa mais tokens. No Premium e no Team, o chat web continua ilimitado nos dois modos. No Free, o Thinking consome mais da sua franquia mensal.

| Modelo | Modos no chat web |
|---|---|
| GPT-6 Astra, GPT-6.1 Sol, GPT-6 Sol, GPT-6 Luna | **Thinking** (esforço médio) e **Fast** (esforço baixo) |
| Claude Fable 5.1, Claude Opus 5.5 | O raciocínio fica sempre ligado. **Thinking** usa esforço médio e **Fast**, esforço baixo. |
| Gemini 4 Argon | O chat web oferece só o modo **Thinking**. Ao selecionar **Fast**, o chat troca para o Gemini 3.8 Flash. |
| Kimi K3.1 Pro | O modelo sempre raciocina. **Thinking** usa esforço alto e **Fast**, esforço baixo. |
| GLM | **Fast** é o GLM 5.3 Flash. **Thinking** usa o GLM 5.2, a versão anterior (`zai/glm-5.2` na API). |
| Grok 4.7 | Um único modo |

Os modos Thinking existem só no chat web. Na API, chame o ID do modelo e defina a opção de raciocínio na sua solicitação quando precisar de mais raciocínio.

## Troque de modelo no meio de um chat

Escolha outro modelo no seletor de modelos e envie a próxima mensagem. O chat mantém o histórico, e o novo modelo responde a partir dali. [Como funciona a troca de modelo no meio do chat](/pt-br/articles/switch-models-mid-chat).

Com **Ativar troca automática de modelo** ligado em **Conta** → **Configurações**, a Capriole AI pode responder com outro modelo disponível quando o modelo escolhido estiver com alta demanda. Essa opção vem desligada por padrão.

## IDs de modelo para a API

A URL base da API é `https://api.caprioletech.com`. Use um ID de modelo concreto para fixar um modelo, ou um alias `*-latest` para acompanhar o modelo principal que recomendamos para aquele provedor.

| Alias | Usa | Endpoints |
|---|---|---|
| `openai-latest` | `openai/gpt-6-astra` | Chat Completions, Responses |
| `claude-latest` | `anthropic/claude-fable-5-1` (`claude-fable-5-1` no Messages) | Chat Completions, Messages |
| `google-latest` | `google/gemini-4-argon` | Chat Completions |

Os IDs dos modelos principais são `openai/gpt-6-astra`, `anthropic/claude-fable-5-1`, `anthropic/claude-opus-5-5` e `google/gemini-4-argon`. No Anthropic Messages, use IDs do Claude sem prefixo, como `claude-opus-5-5`. Chame `GET /v1/models` para ver a lista atual ou consulte [Listar modelos](/pt-br/api-reference/endpoint/get).

A Capriole AI conta os tokens cobrados do mesmo jeito em todos os modelos: entrada sem cache, mais 10% da entrada em cache, mais a saída. [Tokens cobrados explicados](/pt-br/articles/charged-tokens) traz exemplos.

Para criar imagens, escolha **Imagem** no seletor de modelos e selecione GPT Image 2.5 ou Nano Banana 2.1. Os modelos de imagem funcionam só no chat web. [Veja o guia de geração de imagens](/pt-br/guides/files-web-search).

## Perguntas comuns

### Qual modelo a Capriole AI usa por padrão?

O chat web começa no GPT-6 Astra Thinking. Na API, `openai-latest` usa o GPT-6 Astra.

### Os modelos principais custam mais na Capriole AI?

Não no chat web: o chat do Premium e do Team é ilimitado em todos os modelos suportados. Na API, todos os modelos custam o mesmo por token, USD 8 a cada 5M de tokens, então a economia em relação aos preços oficiais é maior nos modelos principais. [Preços da API do Claude](/pt-br/articles/claude-api-pricing), [Preços da API da OpenAI](/pt-br/articles/openai-api-pricing) e [Preços da API do Gemini](/pt-br/articles/gemini-api-pricing) fazem as contas.

### Posso usar Claude ou Gemini com o SDK da OpenAI?

Sim. O OpenAI Chat Completions aceita todos os IDs de modelo públicos, incluindo `anthropic/claude-fable-5-1` e `google/gemini-4-argon`, além dos três aliases. O [guia dos SDKs OpenAI e Anthropic](/pt-br/guides/openai-anthropic-sdks) mostra a configuração.

### Posso usar os modos Thinking pela API?

Não. Eles existem só no chat web. Chame o ID de API do modelo e defina a opção de raciocínio na sua solicitação.

### Com qual modelo Claude devo começar?

A Anthropic recomenda começar a maior parte do trabalho no Claude Opus 5.5 e passar para o Claude Fable 5.1 em raciocínio exigente e trabalho agêntico de longo horizonte. [Claude vs ChatGPT](/pt-br/articles/claude-vs-chatgpt) compara os dois com o GPT-6 Astra.
