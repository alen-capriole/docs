A Capriole AI oferece chat web ilimitado com GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon e outros modelos líderes por USD 8 por mês. A mesma conta inclui uma API que custa até 92% menos que os preços oficiais das APIs, e seus apps e agentes de programação funcionam com uma única API key.

A Capriole AI é desenvolvida pela Capriole Investments; a plataforma de dados de mercado [Capriole Quant](https://quant.capriole.com/) (antigo Capriole Charts) e o fundo de investimento da empresa são produtos separados da Capriole AI. Assinantes ativos do Capriole Quant recebem acesso gratuito à Capriole AI.

## Chat ilimitado por USD 8

- O Premium custa USD 8 por mês e inclui chat web ilimitado em todos os modelos suportados, incluindo GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5 e Gemini 4 Argon.
- Troque de modelo no mesmo chat quando outro modelo combinar melhor com a próxima pergunta.
- O chat web com login tem um limite de uso justo de 200 mensagens por conta por dia. Ele impede abusos automatizados feitos por scripts; o uso normal fica bem abaixo disso.
- Visitantes podem testar 5 mensagens por dia sem conta. Uma conta gratuita acrescenta 500.000 tokens de chat web por mês.

[Compare planos e limites](/pt-br/guides/plans-and-limits) ou [escolha um modelo](/pt-br/guides/choose-a-model).

## API até 92% abaixo dos preços oficiais

- Uma API key funciona com clientes OpenAI Chat Completions, OpenAI Responses e Anthropic Messages.
- O Premium inclui uma franquia mensal de API, e as recargas custam USD 8 a cada 5M de tokens de qualquer modelo suportado. [Preços da API do Claude](/pt-br/articles/claude-api-pricing) e [Preços da API da OpenAI](/pt-br/articles/openai-api-pricing) mostram como os 92% são calculados a partir dos preços oficiais.
- A mesma key roda 10 agentes de programação documentados, incluindo Codex, Claude Code, GitHub Copilot CLI e OpenCode. Veja [uma API key para agentes de programação](/pt-br/guides/one-api-key-coding-agents).

Comece pelo [início rápido da API](/pt-br/quickstart).

## Configure uma vez

Use `openai-latest`, `claude-latest` ou `google-latest` quando quiser que a Capriole AI mantenha sua API ou agente de programação no modelo principal que recomendamos para aquele provedor.

Use um ID de modelo concreto quando precisar de uma versão exata para testes, auditorias ou execuções reproduzíveis.
