## Por que Capriole AI

O Capriole AI também oferece geração gratuita com **GPT Image 2** no chat web para contas Free, Premium e Team conectadas e usando **Server Storage**. Use o modo **Image** ou peça ao **Text Agent** durante a conversa. A geração de imagens não consome a franquia de tokens da API; as mensagens do Text Agent continuam sujeitas aos limites normais do chat. É um recurso do navegador, não uma API pública de imagens nem um modelo para agentes de programação.

[Veja o guia de geração de imagens](/pt-br/guides/files-web-search).

A Capriole AI oferece uma API para os principais modelos de IA.

Você mantém uma integração e troca de modelo conforme precisar.

- Uma API para acesso aos modelos
- Troque entre modelos suportados sem alterar a integração
- Preços claros e simples, com pacotes de tokens a um custo bem menor

## Configure uma vez

Use `openai-latest`, `claude-latest` ou `google-latest` quando quiser que a Capriole AI mantenha sua API ou agente de programação no modelo principal que recomendamos para aquele provedor.

Use um ID de modelo concreto quando precisar de uma versão exata para testes, auditorias ou execuções reproduzíveis.

## Observação

Assinantes ativos do [Capriole Charts](https://capriole.com/charts/) recebem acesso gratuito à Capriole AI.
