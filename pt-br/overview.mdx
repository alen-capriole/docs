A Capriole AI é para quem quer GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5 e Gemini 4 Argon sem pagar várias assinaturas, e para desenvolvedores e usuários de agentes de programação que querem uma única API key para todos eles. A assinatura Premium de USD 8 atende os dois casos: chat web ilimitado e uma API até 92% abaixo dos preços oficiais das APIs. O chat e a API compartilham a mesma conta, mas são contados separadamente, então conversar nunca consome os tokens que seus apps e agentes de programação usam.

A Capriole AI é desenvolvida pela Capriole Investments; a plataforma de dados de mercado [Capriole Quant](https://quant.capriole.com/) (antigo Capriole Charts) e o fundo de investimento da empresa são produtos separados da Capriole AI. Assinantes ativos do Capriole Quant recebem acesso gratuito à Capriole AI.

## Chat ilimitado por USD 8

O chat ilimitado também inclui os modos **Thinking**, e você pode trocar de modelo no mesmo chat quando outro combinar melhor com a próxima pergunta. [Compare planos e limites](/pt-br/guides/plans-and-limits) ou [escolha um modelo](/pt-br/guides/choose-a-model).

## API até 92% abaixo dos preços oficiais

- As recargas custam USD 8 a cada 5M de tokens de qualquer modelo suportado, com até 15% de desconto quando você compra vários pacotes de uma vez.
- A mesma key roda 10 agentes de programação documentados, incluindo Codex, Claude Code, GitHub Copilot CLI e OpenCode. Veja [uma API key para agentes de programação](/pt-br/guides/one-api-key-coding-agents).
- Use um alias para continuar no modelo principal recomendado quando ele mudar, ou um ID de modelo concreto quando testes, auditorias ou execuções reproduzíveis precisarem de uma versão exata.

Comece pelo [início rápido da API](/pt-br/quickstart).
