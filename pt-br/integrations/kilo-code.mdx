## O que é Kilo Code

O Kilo Code é um assistente de programação com IA para IDEs e terminais. Ele pode usar a Capriole AI pelo provedor compatível com OpenAI do Kilo, que envia solicitações à API compatível com Chat Completions da Capriole AI.

## Pré-requisitos

Antes de começar, confira se você tem:

- Uma conta Capriole AI ([Cadastre-se aqui](https://capriole.ai))
- Uma API key da Capriole AI ([Obtenha sua key](https://capriole.ai?view=api))
- Kilo Code instalado no VS Code ou como Kilo CLI

## Instalação

### Extensão do VS Code

Instale o Kilo Code na visualização de extensões do VS Code. Pesquise `Kilo Code` e instale a versão pré-lançamento.

### Kilo CLI

```bash
npm install -g @kilocode/cli
```

## Configuração

As verificações do Gemini 3.8 Flash usam `"tool_call": true`; o Gemini 3.5 Flash mantém `"tool_call": false` na configuração abaixo.

`xai/grok-4.6` aceita solicitações de Chat Completions, mas não passou nas verificações de tarefas de agentes e não está na configuração abaixo. Testes diretos no provedor também encontraram uso inconsistente de ferramentas no Grok 4.5; concluir uma solicitação API não comprova uma resposta correta do agente.

- Configuração global: `~/.config/kilo/kilo.jsonc`

## Executar Kilo Code

Defina sua API key e inicie o Kilo no diretório do projeto:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo
```

Inicie com um modelo específico:

```bash
kilo -m openai-compatible/openai-latest
kilo -m openai-compatible/claude-latest
kilo -m openai-compatible/google-latest
kilo -m openai-compatible/openai/gpt-5.5
kilo -m openai-compatible/openai/gpt-5.4-mini
kilo -m openai-compatible/anthropic/claude-fable-5-1
kilo -m openai-compatible/anthropic/claude-fable-5
kilo -m openai-compatible/anthropic/claude-opus-5
kilo -m openai-compatible/anthropic/claude-opus-4-8
kilo -m openai-compatible/anthropic/claude-opus-4-7
kilo -m openai-compatible/google/gemini-3.1-pro-preview
kilo -m openai-compatible/google/gemini-3.8-flash
kilo -m openai-compatible/google/gemini-3.5-flash
kilo -m openai-compatible/zai/glm-5.3-flash
kilo -m openai-compatible/moonshot/kimi-k3
```

Execute uma solicitação pontual com Gemini 3.5 Flash:

```bash
kilo run --agent ask -m openai-compatible/google/gemini-3.5-flash "Summarize this project."
```

Para uma solicitação pontual na CLI, passe um prompt para `kilo run`:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo run -m openai-compatible/openai-latest "Explain this repository structure."
```

## Modelos suportados

Comece com `openai-latest` em configurações novas do Kilo Code. Use `claude-latest` ou `google-latest` quando quiser que a Capriole AI roteie para o modelo principal Claude ou Gemini que recomendamos, e use um ID de modelo concreto quando precisar de uma versão exata.

A documentação do Kilo usa a mesma ordem de famílias do seletor de modelos da Capriole AI: OpenAI, Anthropic e depois Google. As integrações da API pública excluem predefinições exclusivas do chat na web, como Fable 5 Thinking e Opus 5 Thinking.

Mantenha `"tool_call": false` para Gemini 3.5 Flash no Kilo Code. A Capriole AI suporta chamadas de ferramenta simples de Chat Completions para este modelo, e o Kilo Code pode executar fluxos de ferramenta locais com esta configuração, mas ativar declarações nativas de função do Gemini ainda pode expor o subconjunto mais estreito de schema OpenAPI do Gemini.

Outros IDs públicos de modelo compatíveis com Chat Completions retornados por `GET /v1/models` também podem ser configurados quando você quiser testá-los. Valide o uso de ferramentas antes de usar um modelo em fluxos de edição de código.

## Solução de problemas

### Por que o Kilo Code retorna um erro de autenticação?

Confirme que `CAPRIOLE_AI_API_KEY` está exportada no mesmo shell antes de executar `kilo`.

### Qual arquivo de configuração devo editar?

Use `~/.config/kilo/kilo.jsonc` para a Kilo CLI e a extensão do VS Code atuais. Execute `kilo config check` depois de editá-lo.

### Por que as solicitações falham com erros de endpoint?

Confirme que `baseURL` é `https://api.caprioletech.com/v1`. O Kilo envia solicitações de Chat Completions para `/v1/chat/completions`.

### Por que o Kilo Code diz que o modelo está ausente?

Confirme que o modelo selecionado usa o formato `openai-compatible/<model-id>` e que `provider.openai-compatible.models` contém a entrada correspondente. Por exemplo, `openai-compatible/openai-latest` mapeia para a chave de configuração `openai-latest`.

### Por que o uso de ferramentas falha?

Para entradas de GPT, Claude, Gemini 3.1 Pro e aliases latest, confirme que a entrada do modelo inclui `"tool_call": true`. O Kilo Code executa ferramentas localmente e envia solicitações de acompanhamento de Chat Completions para a Capriole AI.

Para Gemini 3.5 Flash, mantenha `"tool_call": false`. O Gemini suporta chamada de função, mas as declarações de função usam um subconjunto suportado do schema OpenAPI. Alguns schemas nativos de ferramenta são mais amplos do que esse subconjunto.

## Observações

- A Capriole AI expõe o Kilo Code por `POST /v1/chat/completions`.
- O Kilo Code executa ferramentas de programação localmente. A Capriole AI só trata a solicitação de modelo.
- O Kilo Code 7.3.16 conclui uma chamada de ferramenta bash com streaming e o turno seguinte do assistente com Kimi K3.
- Comece com a configuração mínima do provedor. Adicione limites de modelo do Kilo ou outras opções de modelo só quando quiser gerenciar o contexto no lado do cliente.
