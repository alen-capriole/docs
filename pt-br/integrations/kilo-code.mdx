## O que é Kilo Code

O Kilo Code é um agente de programação com IA para o VS Code e o terminal. Esta configuração adiciona a Capriole AI como um único provedor personalizado. Cada modelo dele usa o protocolo de API que a Capriole AI oferece para a família desse modelo.

## Pré-requisitos

Antes de começar, confira se você tem:

- Uma conta Capriole AI ([Cadastre-se aqui](https://capriole.ai))
- Uma API key da Capriole AI ([Obtenha sua key](https://capriole.ai?view=api))

## Instalação

### Kilo CLI

```bash
npm install -g @kilocode/cli
```

Verifique a instalação:

```bash
kilo --version
```

### Extensão do VS Code

Instale o Kilo Code pela visualização de extensões do VS Code. A extensão lê o mesmo arquivo de configuração global que a CLI.

## Configuração

O que cada configuração faz:

- `npm: "@ai-sdk/openai-compatible"` é o pacote padrão do provedor, então Gemini, Grok, GLM e Kimi usam Chat Completions.
- Cada modelo GPT substitui `provider.npm` por `@ai-sdk/openai`, que usa a API Responses. Cada modelo Claude o substitui por `@ai-sdk/anthropic`, que usa Anthropic Messages.
- `{env:CAPRIOLE_AI_API_KEY}` lê sua key do ambiente. O cabeçalho `Authorization` a envia como Bearer token em todos os pacotes. Sem ele, o pacote Anthropic envia a key em um cabeçalho `x-api-key`, que a Capriole AI não aceita.
- `tool_call: true` permite que o modelo chame as ferramentas do Kilo.
- `limit` define a janela de contexto e o limite de saída de cada modelo. Sem ele, o Kilo trata os dois como `0` e não compacta sessões longas.

Mantenha este provedor na sua configuração global. O Kilo não resolve referências `{env:...}` em uma configuração no nível do projeto.

Execute `kilo config check` depois de editar o arquivo.

## Executar Kilo Code

Defina sua API key e inicie o Kilo no diretório do projeto:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo
```

Inicie com um modelo específico:

```bash
kilo -m capriole-ai/openai-latest
```

Para uma solicitação pontual, passe um prompt para `kilo run`:

```bash
kilo run -m capriole-ai/claude-latest "Explain this repository."
```

## Modelos suportados

As referências de modelo usam o formato `capriole-ai/<model-id>`.

| Modelo | ID do modelo | Protocolo |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` e `claude-latest` sempre apontam para o nosso modelo principal mais recente de cada família.

## Solução de problemas

### Por que o Kilo Code retorna um erro de autenticação?

Confirme que `CAPRIOLE_AI_API_KEY` está exportada no mesmo shell antes de executar `kilo` e que o provedor está em `~/.config/kilo/kilo.jsonc`, e não em uma configuração de projeto.

### Por que as solicitações Claude falham com `Unsupported Claude Messages model`?

Os modelos Claude que usam `@ai-sdk/anthropic` precisam dos IDs Claude sem prefixo, como `claude-opus-5-5`. Os IDs com o prefixo `anthropic/` são para Chat Completions.

### Por que o Kilo Code diz que o modelo está ausente?

Confirme que o modelo selecionado usa o formato `capriole-ai/<model-id>` e que `provider.capriole-ai.models` tem uma entrada correspondente. Execute `kilo models capriole-ai` para listar os modelos que o Kilo carregou.

### Por que o uso de ferramentas falha?

Confirme que a entrada do modelo inclui `"tool_call": true`.

## Observações

- O Kilo Code executa ferramentas de programação no seu computador. A Capriole AI só trata as solicitações de modelo.
- Para adicionar outro modelo da Capriole AI, copie a entrada de um modelo da mesma família e altere o ID. `GET https://api.caprioletech.com/v1/models` lista todos os IDs de modelo.
