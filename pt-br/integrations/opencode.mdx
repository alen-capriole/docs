## O que é OpenCode

O OpenCode é um agente de programação com IA de código aberto, disponível como interface de terminal, aplicativo de desktop e extensão de IDE. Com a configuração de provedor, ele pode enviar solicitações de modelo suportadas pelos endpoints compatíveis com OpenAI e Anthropic da Capriole AI.

## Pré-requisitos

Antes de começar, confira se você tem:

- Uma conta Capriole AI ([Cadastre-se aqui](https://capriole.ai))
- Uma API key da Capriole AI ([Obtenha sua key](https://capriole.ai?view=api))

## Instalação

Instale o OpenCode com o script oficial de instalação:

```bash
curl -fsSL https://opencode.ai/install | bash
```

Ou instale com npm:

```bash
npm install -g opencode-ai
```

Verifique a instalação:

```bash
opencode --version
```

## Configuração

### Validação dos modelos

OpenCode 1.14.48 passa nas verificações de leitura de arquivo e resposta final com Fable 5.1 via Anthropic Messages (`claude-latest`) e com `zai/glm-5.3-flash` via Chat Completions. Use essas rotas na configuração abaixo.

Para `anthropic/claude-fable-5-1` e `google/gemini-3.8-flash` via Chat Completions, a sessão salva do OpenCode contém a leitura concluída e a resposta correta, mas `run --format json` omite o evento de texto final. Essas rotas não passam na verificação completa de saída da CLI e não foram adicionadas à configuração abaixo.

`xai/grok-4.6` aceita solicitações de Chat Completions, mas não passou nas verificações de tarefas de agentes e não está na configuração abaixo. Testes diretos no provedor também encontraram uso inconsistente de ferramentas no Grok 4.5; concluir uma solicitação API não comprova uma resposta correta do agente.

## Executar OpenCode

Depois de substituir `YOUR_CAPRIOLE_AI_API_KEY` na configuração, inicie o OpenCode:

```bash
opencode
```

Use `/models` para selecionar OpenAI latest, GPT-6 Astra, GPT 5.6 Thinking, GPT 5.6, GPT 5.5, GPT 5.4 mini, Fable 5.1, Fable 5, Opus 5, Grok 4.5, GLM 5.3 Flash, GLM 5.2, Kimi K3, Claude latest, Opus 4.8, Opus 4.7, Opus 4.6 ou Sonnet 4.6. Use `Ctrl+T` para percorrer as variantes de modelo.

## Solução de problemas

### Por que o OpenCode retorna um erro de autenticação?

Confirme que `apiKey` e `authToken` em `~/.config/opencode/opencode.json` usam sua API key da Capriole AI, e não `YOUR_CAPRIOLE_AI_API_KEY`.

### Por que as solicitações GPT falham?

Confirme que o provedor GPT usa `npm: "@ai-sdk/openai"` e `baseURL: "https://api.caprioletech.com/v1"` para que as solicitações usem a API Responses.

### Por que as solicitações Grok, GLM ou Kimi falham?

Confirme que `capriole-ai-compatible` usa `npm: "@ai-sdk/openai-compatible"` e `baseURL: "https://api.caprioletech.com/v1"` para que ambos os modelos usem Chat Completions.

### Por que as solicitações Anthropic falham?

Confirme que o provedor Anthropic usa `npm: "@ai-sdk/anthropic"`, `authToken` e `baseURL: "https://api.caprioletech.com/v1"`.

### Por que os modelos da Capriole AI não aparecem?

Confirme que a referência do modelo usa `<providerId>/<modelId>`, como `capriole-ai-openai/openai-latest`, `capriole-ai-compatible/moonshot/kimi-k3` ou `capriole-ai-anthropic/claude-latest`, e que `enabled_providers` inclui os provedores da Capriole AI enquanto `disabled_providers` não os bloqueia.

### Por que as variantes de modelo não aparecem?

Confirme que você reiniciou o OpenCode depois de atualizar `~/.config/opencode/opencode.json`. Depois, abra `/models` e pressione `Ctrl+T` para percorrer as variantes.

### Por que as mudanças de configuração não se aplicam?

Verifique se há sobreposições de `opencode.json` no nível do projeto ou de `OPENCODE_CONFIG` e reinicie o OpenCode.

### Por que aparecem erros de inicialização do provedor ou de pacote do provedor?

Para `ProviderInitError`, verifique primeiro a configuração do provedor. Para erros de pacote do provedor, limpe `~/.cache/opencode` e reinicie o OpenCode para que os pacotes do provedor sejam reinstalados.

## Observações

- O provedor Anthropic usa `authToken` para o provedor Anthropic do AI SDK enviar autenticação `Authorization: Bearer`.
- O OpenCode 1.14.48 conclui fluxos de ferramenta de shell com Grok 4.5, GLM 5.2 e Kimi K3 por `@ai-sdk/openai-compatible`.
- As variantes do OpenCode são configurações de modelo no lado do cliente. Elas não criam novos IDs de modelo da API da Capriole AI.
