Com uma única API key da Capriole AI, você usa GPT-6 Astra, Claude Fable 5.1 e Opus 5.5 no OpenCode pagando até 92% menos que os preços oficiais da API.

## O que é OpenCode

O OpenCode é um agente de programação com IA de código aberto, disponível como interface de terminal, aplicativo de desktop e extensão de IDE. Esta configuração adiciona a Capriole AI como um único provedor personalizado. Cada modelo dele usa o protocolo de API que a Capriole AI oferece para a família desse modelo.

## Pré-requisitos

Antes de começar, confira se você tem:

- Uma conta Capriole AI ([Cadastre-se aqui](https://www.capriole.ai/pt-br))
- Um plano Premium (USD 8 por mês, também inclui chat na web ilimitado) ou um plano Team, necessário para a API key ([Assine](https://www.capriole.ai/pt-br?view=api))
- Uma API key da Capriole AI ([Obtenha sua key](https://www.capriole.ai/pt-br?view=api))

## Instalação

Instale o OpenCode com o script oficial de instalação:

```bash
curl -fsSL https://opencode.ai/install | bash
```

Ou instale com npm:

```bash
npm install -g opencode-ai
```

Verifique a instalação:

```bash
opencode --version
```

## Configuração

### Validação dos modelos

O OpenCode 1.19.3 passa nas verificações de leitura de arquivo, escrita de arquivo e resposta final pela Capriole AI com todos os modelos da seção Modelos suportados, usando a configuração abaixo.

Crie ou atualize `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
        }
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "openai/gpt-6.1-sol": {
          "name": "GPT-6.1 Sol",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "claude-latest": {
          "name": "Claude latest",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "claude-opus-5-5": {
          "name": "Opus 5.5",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "google/gemini-3.8-flash": {
          "name": "Gemini 3.8 Flash",
          "limit": {
            "context": 1048576,
            "output": 65536
          }
        },
        "xai/grok-4.7": {
          "name": "Grok 4.7",
          "limit": {
            "context": 500000,
            "output": 128000
          }
        },
        "zai/glm-5.3-flash": {
          "name": "GLM 5.3 Flash",
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "moonshot/kimi-k3.1-pro": {
          "name": "Kimi K3.1 Pro",
          "limit": {
            "context": 1048576,
            "output": 131072
          }
        },
        "moonshot/kimi-k3": {
          "name": "Kimi K3",
          "limit": {
            "context": 1048576,
            "output": 131072
          }
        }
      }
    }
  }
}
```

O que cada configuração faz:

- `npm: "@ai-sdk/openai-compatible"` é o pacote padrão do provedor, então Gemini, Grok, GLM e Kimi usam Chat Completions.
- Cada modelo GPT substitui `provider.npm` por `@ai-sdk/openai`, que usa a API Responses. Cada modelo Claude o substitui por `@ai-sdk/anthropic`, que usa Anthropic Messages.
- `baseURL` inclui `/v1` em todos os pacotes.
- `{env:CAPRIOLE_AI_API_KEY}` lê sua key do ambiente. O cabeçalho `Authorization` a envia como Bearer token em todos os pacotes. Sem ele, o pacote Anthropic envia a key em um cabeçalho `x-api-key`, que a Capriole AI não aceita.
- `limit` informa ao OpenCode a janela de contexto e o limite de saída de cada modelo, para que ele acompanhe o contexto e compacte a sessão a tempo.
- `small_model` é o modelo que o OpenCode usa para tarefas leves, como títulos de sessão.

## Executar OpenCode

Defina sua API key e inicie o OpenCode no diretório do projeto:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
opencode
```

Use `/models` para trocar de modelo. Para uma execução não interativa, use `opencode run`:

```bash
opencode run -m capriole-ai/claude-latest "Explain this repository."
```

## Modelos suportados

As referências de modelo usam o formato `capriole-ai/<model-id>`.

| Modelo | ID do modelo | Protocolo |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` e `claude-latest` sempre apontam para o nosso modelo principal mais recente de cada família, atualmente GPT-6 Astra e Claude Fable 5.1.

## Solução de problemas

### Por que o OpenCode retorna um erro de autenticação?

Confirme que `CAPRIOLE_AI_API_KEY` está exportada no mesmo shell antes de iniciar o OpenCode e que o cabeçalho `Authorization` está presente em `options.headers`.

### Por que as solicitações Claude falham com `Unsupported Claude Messages model`?

Os modelos Claude que usam `@ai-sdk/anthropic` precisam dos IDs Claude sem prefixo, como `claude-opus-5-5`. Os IDs com o prefixo `anthropic/` são para Chat Completions.

### Por que as solicitações GPT falham?

Confirme que cada modelo GPT tem `"provider": { "npm": "@ai-sdk/openai" }`, para que as solicitações dele usem a API Responses.

### Por que os modelos da Capriole AI não aparecem?

Confirme que a referência do modelo usa `capriole-ai/<model-id>`, como `capriole-ai/moonshot/kimi-k3`, e que `disabled_providers` não bloqueia `capriole-ai`.

### Por que as mudanças de configuração não se aplicam?

Verifique se há um `opencode.json` no nível do projeto ou uma sobreposição de `OPENCODE_CONFIG` e reinicie o OpenCode.

### Por que aparecem erros de pacote do provedor?

Limpe `~/.cache/opencode` e reinicie o OpenCode para que ele reinstale os pacotes do provedor.

## Observações

- Mantenha sua key no ambiente. Não a cole em `opencode.json`.
- Para adicionar outro modelo da Capriole AI, copie a entrada de um modelo da mesma família e altere o ID. `GET https://api.caprioletech.com/v1/models` lista todos os IDs de modelo.
- Para usar a mesma key nos seus outros agentes de programação, veja [Usar uma API key com agentes de programação](/pt-br/guides/one-api-key-coding-agents).
- Referências oficiais: [Instalação do OpenCode](https://opencode.ai/docs), [Configuração do OpenCode](https://opencode.ai/docs/config), [Provedores do OpenCode](https://opencode.ai/docs/providers), [Modelos do OpenCode](https://opencode.ai/docs/models) e [Solução de problemas do OpenCode](https://opencode.ai/docs/troubleshooting).
