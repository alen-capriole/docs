Com uma única API key da Capriole AI, você usa GPT-6 Astra, Claude Fable 5.1 e Opus 5.5 no OpenCode pagando até 92% menos que os preços oficiais da API.

## O que é OpenCode

O OpenCode é um agente de programação com IA de código aberto, disponível como interface de terminal, aplicativo de desktop e extensão de IDE. Esta configuração adiciona a Capriole AI como um único provedor personalizado. Cada modelo dele usa o protocolo de API que a Capriole AI oferece para a família desse modelo.

## Pré-requisitos

Antes de começar, confira se você tem:

- Uma conta Capriole AI ([Cadastre-se aqui](https://www.capriole.ai/pt-br))
- Um plano Premium (USD 8 por mês, também inclui chat na web ilimitado) ou um plano Team, necessário para a API key ([Assine](https://www.capriole.ai/pt-br?view=api))
- Uma API key da Capriole AI ([Obtenha sua key](https://www.capriole.ai/pt-br?view=api))

## Instalação

O OpenCode 2 e o OpenCode 1 usam o mesmo comando `opencode`, então só um deles fica instalado por vez. Instale o OpenCode 2 com o script oficial de instalação:

```bash
curl -fsSL https://opencode.ai/v2/install | bash
```

Ou instale com npm:

```bash
npm install -g @opencode/cli
```

Para migrar do OpenCode 1, execute `opencode upgrade --major`. O script `https://opencode.ai/install` e o pacote npm `opencode-ai` continuam instalando o OpenCode 1.

Verifique a instalação:

```bash
opencode --version
```

## Configuração

### Validação dos modelos

O OpenCode 2.2.5 passa nas verificações de leitura de arquivo e resposta final pela Capriole AI com todos os modelos da seção Modelos suportados, usando a configuração do OpenCode 2. O OpenCode 1.19.3 passa nas verificações de leitura de arquivo, escrita de arquivo e resposta final com a configuração do OpenCode 1.

```json
    "capriole-ai": {
      "name": "Capriole AI",
      "env": ["CAPRIOLE_AI_API_KEY"],
      "package": "@opencode/ai/providers/openai-compatible",
      "settings": {
        "baseURL": "https://api.caprioletech.com/v1"
      },
      "headers": {
        "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",

            "context": 1050000,

```

O que cada configuração faz:

- `package: "@opencode/ai/providers/openai-compatible"` é o pacote padrão do provedor, então Gemini, Grok, GLM e Kimi usam Chat Completions.
- Cada modelo GPT substitui `package` por `@opencode/ai/providers/openai-compatible/responses`, que usa a API Responses. Cada modelo Claude o substitui por `@opencode/ai/providers/anthropic-compatible`, que usa Anthropic Messages.
- `env` indica a variável que guarda sua key. O cabeçalho `Authorization` envia a key como Bearer token em todos os pacotes. Sem ele, o pacote Anthropic envia a key em um cabeçalho `x-api-key`, que a Capriole AI não aceita.
- `reasoningEffort` dá a cada modelo GPT um nível de raciocínio padrão. Sem ele, os modelos GPT respondem sem raciocinar.
- `baseURL` inclui `/v1` em todos os pacotes. `limit` informa ao OpenCode a janela de contexto e o limite de saída de cada modelo.
- `agents.title` define o modelo que o OpenCode usa para títulos de sessão.

## Executar OpenCode

Defina sua API key e inicie o OpenCode no diretório do projeto:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
opencode service restart
opencode
```

O OpenCode 2 envia as solicitações aos modelos a partir de um serviço em segundo plano que lê a key ao iniciar, então `opencode service restart` faz com que ele pegue a key que você acabou de definir. No OpenCode 1, pule esta etapa.

Use `/models` para trocar de modelo. Para uma execução não interativa, use `opencode run`:

```bash
opencode run -m capriole-ai/claude-latest "Explain this repository."
```

## Modelos suportados

As referências de modelo usam o formato `capriole-ai/<model-id>`.

| Modelo | ID do modelo | Protocolo |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` e `claude-latest` sempre apontam para o nosso modelo principal mais recente de cada família, atualmente GPT-6 Astra e Claude Fable 5.1.

## Solução de problemas

### Por que o OpenCode retorna um erro de autenticação?

Confirme que `CAPRIOLE_AI_API_KEY` está exportada no mesmo shell antes de iniciar o OpenCode e que o cabeçalho `Authorization` está presente em `headers` (OpenCode 2) ou `options.headers` (OpenCode 1). Se o OpenCode 2 retornar `Missing Bearer token`, o serviço em segundo plano dele iniciou sem a key: execute `opencode service restart` nesse shell.

### Por que as solicitações Claude falham com `Unsupported Claude Messages model`?

Os modelos Claude que usam o pacote Anthropic precisam dos IDs Claude sem prefixo, como `claude-opus-5-5`. Os IDs com o prefixo `anthropic/` são para Chat Completions.

### Por que as solicitações GPT falham?

Confirme que cada modelo GPT tem `"package": "@opencode/ai/providers/openai-compatible/responses"` (OpenCode 2) ou `"provider": { "npm": "@ai-sdk/openai" }` (OpenCode 1), para que as solicitações dele usem a API Responses.

### Por que os modelos da Capriole AI não aparecem?

Confirme que a referência do modelo usa `capriole-ai/<model-id>`, como `capriole-ai/moonshot/kimi-k3`, e que `disabled_providers` não bloqueia `capriole-ai`. O OpenCode 1 ignora o formato `providers` do OpenCode 2.

### Por que as mudanças de configuração não se aplicam?

Verifique se há um `opencode.json` no nível do projeto ou uma sobreposição de `OPENCODE_CONFIG` e reinicie o OpenCode.

### Por que aparecem erros de pacote do provedor?

Limpe `~/.cache/opencode` e reinicie o OpenCode para que ele reinstale os pacotes do provedor.

## Observações

- Mantenha sua key no ambiente. Não a cole em `opencode.json`.
- Para adicionar outro modelo da Capriole AI, copie a entrada de um modelo da mesma família e altere o ID. `GET https://api.caprioletech.com/v1/models` lista todos os IDs de modelo.
