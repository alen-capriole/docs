Com uma única API key da Capriole AI, você usa Claude Fable 5.1 e Opus 5.5 no Claude Code pagando até 92% menos que os preços oficiais da API.

## O que é Claude Code

O Claude Code é a ferramenta de programação agentiva da Anthropic para ler bases de código, editar arquivos, executar comandos e integrar-se a ferramentas de desenvolvimento. Esta configuração aponta o Claude Code para a Capriole AI pelas configurações de gateway dele: o endpoint da API, o token de autenticação e o modelo de cada alias.

## Pré-requisitos

Antes de começar, confira se você tem:

- Uma conta Capriole AI ([Cadastre-se aqui](https://www.capriole.ai/pt-br))
- Um plano Premium (USD 8 por mês, também inclui chat na web ilimitado) ou um plano Team, necessário para a API key ([Assine](https://www.capriole.ai/pt-br?view=api))
- Uma API key da Capriole AI ([Obtenha sua key](https://www.capriole.ai/pt-br?view=api))

## Instalação

Instale o Claude Code com o instalador nativo oficial:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Ou instale com Homebrew:

```bash
brew install --cask claude-code
```

Ou instale com npm (Node.js 22 ou posterior):

```bash
npm install -g @anthropic-ai/claude-code
```

Verifique a instalação:

```bash
claude --version
```

## Configuração

### Validação dos modelos

O Claude Code 2.1.304 passa nas verificações de leitura de arquivo, escrita de arquivo e resposta final pela Capriole AI com todos os modelos da seção Modelos suportados, usando a configuração abaixo.

Crie ou atualize `~/.claude/settings.json`:

```json
{
  "model": "claude-fable-5-1",
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.caprioletech.com",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_CAPRIOLE_AI_API_KEY",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-5-5",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-fable-5-1",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-sonnet-4-6"
  }
}
```

O que cada configuração faz:

- `model` é o modelo padrão para novas sessões. Um modelo que você escolhe com `/model` é salvo e usado na próxima vez.
- `ANTHROPIC_BASE_URL` envia as solicitações para a Capriole AI. Não adicione `/v1`; o próprio Claude Code adiciona `/v1/messages`.
- `ANTHROPIC_AUTH_TOKEN` envia sua key como Bearer token, que a Capriole AI exige.
- Os três valores `ANTHROPIC_DEFAULT_*_MODEL` apontam os aliases `opus`, `sonnet` e `haiku` para modelos que a Capriole AI oferece. `haiku` é o modelo que o Claude Code usa para tarefas rápidas em segundo plano.

Para uma configuração pontual no shell, exporte o endpoint e o token e depois passe o modelo:

```bash
export ANTHROPIC_BASE_URL="https://api.caprioletech.com"
export ANTHROPIC_AUTH_TOKEN="YOUR_CAPRIOLE_AI_API_KEY"
claude --model claude-fable-5-1
```

## Executar Claude Code

Inicie o Claude Code no diretório do projeto:

```bash
claude
```

Troque de modelo em uma sessão com `/model`, por exemplo `/model opus` para Opus 5.5. Para uma execução não interativa, use o modo print:

```bash
claude -p "Explain this repository."
```

## Modelos suportados

O Claude Code usa o protocolo Anthropic Messages, então suporta os modelos Claude da Capriole AI:

- `claude-fable-5-1` (Fable 5.1, o padrão recomendado)
- `claude-opus-5-5` (Opus 5.5)
- `claude-fable-5`
- `claude-opus-5`
- `claude-opus-4-8`
- `claude-opus-4-7`
- `claude-opus-4-6`
- `claude-sonnet-4-6`
- `claude-latest`, que sempre aponta para o nosso modelo principal Claude mais recente (atualmente Fable 5.1)

O Claude Code não reconhece `claude-latest` como nome de modelo, então assume uma janela de contexto de 200K para ele. Use um ID concreto, como `claude-fable-5-1`, para ter a janela de contexto completa do modelo.

## Solução de problemas

### Por que o Claude Code retorna um erro de autenticação?

Use `ANTHROPIC_AUTH_TOKEN`, e não `ANTHROPIC_API_KEY`. `ANTHROPIC_API_KEY` envia a key em um cabeçalho `x-api-key`, e a Capriole AI só aceita Bearer token.

### Por que as solicitações falham com erros de endpoint?

Confirme que `ANTHROPIC_BASE_URL` é `https://api.caprioletech.com` sem `/v1`.

### Por que o Claude Code volta para outro modelo a cada inicialização?

Remova `ANTHROPIC_MODEL` das suas configurações e do shell. Quando essa variável está definida, o Claude Code volta para esse modelo na próxima inicialização, em vez de usar o modelo que você salvou com `/model`.

### Por que `/model opus` ou `/model sonnet` falha?

Mantenha os três valores `ANTHROPIC_DEFAULT_*_MODEL`. Sem eles, o Claude Code envia os destinos de alias da própria Anthropic. Por exemplo, `sonnet` solicita `claude-sonnet-5-5`, que a Capriole AI não oferece, e a solicitação falha com `Unsupported Claude Messages model`.

### Por que o Claude Code não usa meu nível de esforço?

O Claude Code salva o nível de esforço separadamente para cada modelo. Escolha-o com `/effort` enquanto o modelo estiver ativo. Um `effortLevel` no nível superior das suas configurações de usuário não se aplica ao Opus 5.5.

### Por que a contagem de tokens falha?

A Capriole AI encaminha `/v1/messages/count_tokens` para o upstream selecionado. Quando esse upstream não oferece suporte à contagem de tokens, o Claude Code estima a contagem, e a sessão continua funcionando.

## Observações

- `~/.claude/settings.json` se aplica à sua conta de usuário em todos os projetos. Substitua `YOUR_CAPRIOLE_AI_API_KEY` pela sua API key da Capriole AI.
- Modelos Gemini, Grok, GLM e Kimi não rodam no Claude Code, porque ele só fala o protocolo Anthropic Messages. Use OpenCode, Kilo Code ou outro agente multiprotocolo para esses modelos.
- Para usar a mesma key nos seus outros agentes de programação, veja [Usar uma API key com agentes de programação](/pt-br/guides/one-api-key-coding-agents).
- Referências oficiais: [Configuração do Claude Code](https://code.claude.com/docs/en/setup), [configuração de modelo](https://code.claude.com/docs/en/model-config) e [configuração de gateway LLM](https://code.claude.com/docs/en/llm-gateway-connect).
