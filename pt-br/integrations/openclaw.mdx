## O que é OpenClaw

O OpenClaw é um assistente pessoal de IA e gateway de código aberto e auto-hospedado. Ele conecta canais de chat como WhatsApp, Slack, Discord, Telegram, iMessage e WebChat a agentes de IA. Esta configuração adiciona a Capriole AI como três provedores de modelo personalizados, um para cada protocolo de API que a Capriole AI oferece.

## Pré-requisitos

Antes de começar, confira se você tem:

- Uma conta Capriole AI ([Cadastre-se aqui](https://capriole.ai))
- Uma API key da Capriole AI ([Obtenha sua key](https://capriole.ai?view=api))

## Instalação

Instale o OpenClaw com o script oficial de instalação:

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Depois, conclua a configuração inicial do próprio OpenClaw:

```bash
openclaw onboard
```

O que cada configuração faz:

- `capriole-ai-openai` envia os modelos GPT para a API Responses. `capriole-ai-anthropic` envia os modelos Claude para Anthropic Messages. `capriole-ai-compatible` envia os modelos Gemini, Grok, GLM e Kimi para Chat Completions.
- `${CAPRIOLE_AI_API_KEY}` lê sua key do ambiente.
- `request.auth` com `authorization-bearer` faz o provedor Anthropic enviar a key como Bearer token. Sem ele, a key vai em um cabeçalho `x-api-key`, que a Capriole AI não aceita.
- O `baseUrl` da Anthropic não tem `/v1`, porque o próprio OpenClaw adiciona `/v1/messages`.
- `reasoning` é `false` para o Opus 5.5. Quando é `true`, o OpenClaw envia um orçamento de thinking, e o Opus 5.5 o rejeita com `requires adaptive thinking`.
- `contextWindow` e `maxTokens` informam ao OpenClaw os limites de cada modelo.
- `agents.defaults.models` é a lista de modelos que os agentes podem usar. `agents.defaults.model.primary` é o padrão.

## Executar OpenClaw

Exporte sua key em cada terminal que inicia o OpenClaw:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
```

Inicie o gateway:

```bash
openclaw gateway
```

Abra a interface de terminal em outro terminal:

```bash
openclaw tui
```

Para uma execução local pontual sem o gateway:

```bash
openclaw agent --local --session-id capriole-test --message "Summarize the files in my workspace."
```

## Modelos suportados

As referências de modelo usam o formato `<provider-id>/<model-id>`.

| Modelo | Referência do modelo | Protocolo |
| --- | --- | --- |
| OpenAI latest | `capriole-ai-openai/openai-latest` | Responses |
| GPT-6.1 Sol | `capriole-ai-openai/openai/gpt-6.1-sol` | Responses |
| Claude latest | `capriole-ai-anthropic/claude-latest` | Anthropic Messages |
| Opus 5.5 | `capriole-ai-anthropic/claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `capriole-ai-compatible/google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `capriole-ai-compatible/xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `capriole-ai-compatible/zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `capriole-ai-compatible/moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `capriole-ai-compatible/moonshot/kimi-k3` | Chat Completions |

`openai-latest` e `claude-latest` sempre apontam para o nosso modelo principal mais recente de cada família.

## Solução de problemas

### Por que a autenticação falha?

Exporte `CAPRIOLE_AI_API_KEY` no terminal que inicia `openclaw gateway` ou `openclaw agent`. O OpenClaw exibe `missing env var` quando a variável não está definida.

### Por que o Opus 5.5 falha com `requires adaptive thinking`?

Defina `reasoning` como `false` para `claude-opus-5-5`.

### Por que o OpenClaw informa que um modelo não é permitido ou está ausente?

Execute `openclaw models list`. Confirme que a referência do modelo está em `agents.defaults.models` e que a entrada do modelo tem o objeto completo mostrado acima, e não só `id` e `name`.

### Por que uma nova sessão começa com uma conversa de configuração?

Essa é a configuração do espaço de trabalho que o OpenClaw faz na primeira execução, e não um problema da Capriole AI. Conclua-a uma vez em `openclaw tui` ou execute `openclaw onboard` de novo.

### Por que o gateway não inicia?

Execute `openclaw status`, `openclaw gateway status`, `openclaw logs --follow` e `openclaw doctor`.

## Observações

- Para adicionar outro modelo da Capriole AI, copie a entrada de um modelo da mesma família, altere o ID e adicione a referência dele a `agents.defaults.models`. `GET https://api.caprioletech.com/v1/models` lista todos os IDs de modelo.
- Referências oficiais: [Instalação do OpenClaw](https://docs.openclaw.ai/install), [Provedores personalizados do OpenClaw](https://docs.openclaw.ai/gateway/config-tools), [Provedores de modelo do OpenClaw](https://documentation.openclaw.ai/concepts/model-providers) e [Solução de problemas do OpenClaw](https://docs.openclaw.ai/gateway/troubleshooting).
