Use this endpoint when your application, SDK, or gateway expects the OpenAI Chat Completions request and response format.

Send a standard Chat Completions payload with `model` and `messages`. Capriole AI resolves latest aliases to the selected provider model ID before upstream dispatch, forwards compatible fields such as `messages`, `tools`, `tool_choice`, `response_format`, and `stream`, and returns the upstream JSON or SSE stream unchanged, except for the GLM SSE correction below. For streaming requests, Capriole AI sets `stream_options.include_usage=true` before forwarding so usage can be recorded.

For SSE responses from the configured Tian, RelayRouter, or VE gateway with `model="zai/glm-5.3-flash"`, Capriole AI removes only the empty legacy `function_call={"name":"","arguments":""}` field from streamed deltas. Real or partial function calls, `tool_calls`, text, and usage remain intact. This exception does not change non-streaming responses or other models.

`POST /v1/chat/completions` accepts `openai-latest`, `claude-latest`, `google-latest`, and public concrete model IDs returned by `GET /v1/models`. Use a latest alias to let Capriole AI choose our recommended flagship model for that provider.

Latest aliases are input shortcuts. Usage is recorded against the resolved model, while the response body keeps the model naming behavior of the selected compatible endpoint.

## Web search

This endpoint does not provide web search. For Grok models, a request with a non-null `web_search_options` or `search_parameters` field fails with HTTP 400:

```json
{
  "detail": "Web search is not supported for xai/grok-4.7 on /v1/chat/completions. Use POST /v1/responses with tools: [{\"type\": \"web_search\"}]."
}
```

Function tools that your client defines, even one named `web_search`, are forwarded unchanged. To search the web with GPT or Grok, use [`POST /v1/responses`](/api-reference/endpoint/responses) with `"tools": [{"type": "web_search"}]`.

## Long tasks

For long tasks such as long reasoning, set `"stream": true`. Without streaming, the connection can time out after about 2 minutes.
