Use this endpoint when your application, SDK, or agent expects the OpenAI Responses request and response format.

Send a standard Responses payload with `model` and `input`. Capriole AI resolves latest aliases to the selected upstream model ID before upstream dispatch, forwards compatible fields such as `instructions`, `tools`, `reasoning`, `previous_response_id`, and `stream`, and returns the upstream JSON or SSE stream unchanged.

`POST /v1/responses` accepts `openai-latest`, `openai/gpt-6-astra`, `openai/gpt-6.1-sol`, `openai/gpt-6-sol`, `openai/gpt-6-luna`, `openai/gpt-5.6-terra`, `openai/gpt-5.6-luna`, and `openai/gpt-5.5`. Use `openai-latest` to let Capriole AI choose our recommended flagship OpenAI Responses model.

You can also send native OpenAI IDs without the `openai/` prefix, such as `gpt-6-astra`. Native and prefixed IDs resolve to the same model entry for routing, pricing, and quota.

This endpoint also accepts the Grok models `xai/grok-4.7`, `xai/grok-4.6`, and `xai/grok-4.5`. Always send Grok IDs with the `xai/` prefix; a bare ID such as `grok-4.7` is treated as a native OpenAI ID and is rejected. Grok requests are forwarded to xAI's own Responses API without format conversion.

Other models are not supported on this endpoint: `claude-latest`, `google-latest`, Claude and Gemini model IDs such as `anthropic/claude-fable-5-1` and `google/gemini-4-argon`, and the GLM and Kimi models (`zai/glm-5.3-flash`, `zai/glm-5.2`, `moonshot/kimi-k3.1-pro`, and `moonshot/kimi-k3`). Use `POST /v1/chat/completions` when you want one OpenAI-compatible endpoint that can call every public model.

## Web search

Add the built-in `web_search` tool to let GPT or Grok models search the web:

```bash
curl https://api.caprioletech.com/v1/responses \
  -X POST \
  -H "Authorization: Bearer YOUR_CAPRIOLE_AI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "xai/grok-4.7",
    "input": "Summarize the latest AI news.",
    "tools": [{"type": "web_search"}],
    "stream": true
  }'
```

Web search adds the retrieved search results to the request's input tokens, so a searched answer can use many more input tokens than the prompt alone.

`POST /v1/chat/completions` does not provide web search.

## Long tasks

For long tasks such as web search or long reasoning, set `"stream": true`. Without streaming, the connection can time out after about 2 minutes.
