With one Capriole AI API key, you can run GPT-6 Astra, Claude Fable 5.1, and Opus 5.5 in Crush at up to 92% less than official API prices.

## What is Crush

Crush is Charm's open-source coding agent for the terminal. It reads its configuration from a `crushrc` file, which is Bash with Crush-specific commands. This setup adds Capriole AI as one OpenAI-compatible provider.

## Prerequisites

Before you begin, make sure you have:

- A Capriole AI account ([Sign up here](https://www.capriole.ai/))
- A Premium plan (USD 8 per month, also includes unlimited web chat) or a Team plan, required for an API key ([Subscribe](https://www.capriole.ai/?view=api))
- A Capriole AI API key ([Get your key](https://www.capriole.ai/?view=api))

## Installation

Install Crush with Homebrew:

```bash
brew install charmbracelet/tap/crush
```

Or install it with npm:

```bash
npm install -g @charmland/crush
```

Verify the install:

```bash
crush --version
```

## Configuration

### Model validation

Crush 0.98.1 passes a file-read, file-write, and final-answer check through Capriole AI with every model in [Supported models](#supported-models), using the configuration below.

Create or update `~/.config/crush/crushrc`:

```bash
provider add capriole --name "Capriole AI" --type openai-compat \
  --base-url "https://api.caprioletech.com/v1" \
  --api-key "$CAPRIOLE_AI_API_KEY" \
  --discover-models false

model add capriole/openai-latest --name "OpenAI latest" --context-window 1050000 --default-max-tokens 32000 --can-reason true
model add capriole/openai/gpt-6.1-sol --name "GPT-6.1 Sol" --context-window 1050000 --default-max-tokens 32000 --can-reason true
model add capriole/claude-latest --name "Claude latest" --context-window 1000000 --default-max-tokens 32000 --can-reason true
model add capriole/anthropic/claude-opus-5-5 --name "Opus 5.5" --context-window 1000000 --default-max-tokens 32000 --can-reason true
model add capriole/google/gemini-3.8-flash --name "Gemini 3.8 Flash" --context-window 1048576 --default-max-tokens 32000 --can-reason true
model add capriole/xai/grok-4.7 --name "Grok 4.7" --context-window 500000 --default-max-tokens 32000 --can-reason true
model add capriole/zai/glm-5.3-flash --name "GLM 5.3 Flash" --context-window 1000000 --default-max-tokens 32000 --can-reason true
model add capriole/moonshot/kimi-k3.1-pro --name "Kimi K3.1 Pro" --context-window 1048576 --default-max-tokens 32000 --can-reason true
model add capriole/moonshot/kimi-k3 --name "Kimi K3" --context-window 1048576 --default-max-tokens 32000 --can-reason true

model large capriole/claude-latest
model small capriole/zai/glm-5.3-flash
```

What each setting does:

- `--type openai-compat` sends every model to Chat Completions. Capriole AI serves all of these models on Chat Completions.
- `--api-key "$CAPRIOLE_AI_API_KEY"` reads your key from the environment when Crush loads the file, and Crush sends it as a Bearer token.
- `--discover-models false` keeps the list to the models you add.
- `model large` is the main coding model. `model small` is the model for light tasks such as session titles.

## Run Crush

Set your API key, then start Crush from your project directory:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
crush
```

Press `Ctrl+L` to switch models. For a non-interactive run, use `crush run`:

```bash
crush run -m capriole/xai/grok-4.7 "Explain this repository."
```

## Troubleshooting

### Why does Crush return an authentication error?

Export `CAPRIOLE_AI_API_KEY` before you start Crush. Crush reads the variable when it loads `crushrc`.

### Why does a Claude model fail with `Unsupported chat model_key`?

On Chat Completions, use the `anthropic/`-prefixed Claude IDs, such as `anthropic/claude-opus-5-5`. The bare IDs, such as `claude-opus-5-5`, are for Anthropic Messages.

### Why don't config changes apply?

A `.crushrc` or `crushrc` file in the project directory takes priority over `~/.config/crush/crushrc`. Check for one, then restart Crush.

## Notes

- `crushrc` runs as a shell script. Do not paste your key into it.
- To add another Capriole AI model, add one more `model add` line. `GET https://api.caprioletech.com/v1/models` lists every model ID.
- To use the same key with your other coding agents, see [Use one API key with coding agents](/guides/one-api-key-coding-agents).
- Official references: [Crush](https://github.com/charmbracelet/crush) and [Crush configuration](https://github.com/charmbracelet/crush#configuration).
