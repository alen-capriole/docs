## What is Kilo Code

Kilo Code is an AI coding agent for VS Code and the terminal. This setup adds Capriole AI as one custom provider. Each model in it uses the API protocol that Capriole AI serves for that model family.

## Prerequisites

Before you begin, make sure you have:

- A Capriole AI account ([Sign up here](https://capriole.ai))
- A Capriole AI API key ([Get your key](https://capriole.ai?view=api))

## Installation

### Kilo CLI

```bash
npm install -g @kilocode/cli
```

Verify the install:

```bash
kilo --version
```

### VS Code extension

Install Kilo Code from the VS Code Extensions view. The extension reads the same global config file as the CLI.

## Configuration

### Model validation

Kilo CLI 7.8.15 passes a file-read, file-write, and final-answer check through Capriole AI with every model in [Supported models](#supported-models), using the configuration below.

Create or update `~/.config/kilo/kilo.jsonc`:

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
        }
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          },
          "tool_call": true
        },
        "openai/gpt-6.1-sol": {
          "name": "GPT-6.1 Sol",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          },
          "tool_call": true
        },
        "claude-latest": {
          "name": "Claude latest",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          },
          "tool_call": true
        },
        "claude-opus-5-5": {
          "name": "Opus 5.5",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          },
          "tool_call": true
        },
        "google/gemini-3.8-flash": {
          "name": "Gemini 3.8 Flash",
          "limit": {
            "context": 1048576,
            "output": 65536
          },
          "tool_call": true
        },
        "xai/grok-4.7": {
          "name": "Grok 4.7",
          "limit": {
            "context": 500000,
            "output": 128000
          },
          "tool_call": true
        },
        "zai/glm-5.3-flash": {
          "name": "GLM 5.3 Flash",
          "limit": {
            "context": 1000000,
            "output": 128000
          },
          "tool_call": true
        },
        "moonshot/kimi-k3": {
          "name": "Kimi K3",
          "limit": {
            "context": 1048576,
            "output": 131072
          },
          "tool_call": true
        }
      }
    }
  }
}
```

What each setting does:

- `npm: "@ai-sdk/openai-compatible"` is the default package for the provider, so Gemini, Grok, GLM, and Kimi use Chat Completions.
- Each GPT model overrides `provider.npm` with `@ai-sdk/openai`, which uses the Responses API. Each Claude model overrides it with `@ai-sdk/anthropic`, which uses Anthropic Messages.
- `{env:CAPRIOLE_AI_API_KEY}` reads your key from the environment. The `Authorization` header sends it as a Bearer token for every package. Without it, the Anthropic package sends the key in an `x-api-key` header, which Capriole AI does not accept.
- `tool_call: true` lets the model call Kilo's tools.
- `limit` sets each model's context window and output limit. Without it, Kilo treats both as `0` and does not compact long sessions.

Keep this provider in your global config. Kilo does not resolve `{env:...}` references in a project-level config.

Run `kilo config check` after you edit the file.

## Run Kilo Code

Set your API key, then start Kilo from your project directory:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo
```

Start with a specific model:

```bash
kilo -m capriole-ai/openai-latest
```

For a one-off request, pass a prompt to `kilo run`:

```bash
kilo run -m capriole-ai/claude-latest "Explain this repository."
```

## Supported models

Model references use the form `capriole-ai/<model-id>`.

| Model | Model ID | Protocol |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` and `claude-latest` always point to our latest flagship in each family.

## Troubleshooting

### Why does Kilo Code return an authentication error?

Confirm that `CAPRIOLE_AI_API_KEY` is exported in the same shell before you run `kilo`, and that the provider is in `~/.config/kilo/kilo.jsonc`, not in a project config.

### Why do Claude requests fail with `Unsupported Claude Messages model`?

Claude models that use `@ai-sdk/anthropic` need the bare Claude IDs, such as `claude-opus-5-5`. The `anthropic/`-prefixed IDs are for Chat Completions.

### Why does Kilo Code say the model is missing?

Confirm that the selected model uses the `capriole-ai/<model-id>` format and that `provider.capriole-ai.models` has a matching entry. Run `kilo models capriole-ai` to list the models Kilo loaded.

### Why does tool use fail?

Confirm that the model entry includes `"tool_call": true`.

## Notes

- Kilo Code runs coding tools on your computer. Capriole AI only handles the model requests.
- To add another Capriole AI model, copy the entry of a model from the same family and change the ID. `GET https://api.caprioletech.com/v1/models` lists every model ID.
- Official references: [Kilo CLI](https://kilo.ai/docs/cli), [Kilo custom models](https://kilo.ai/docs/code-with-ai/agents/custom-models), [Kilo settings](https://kilo.ai/docs/getting-started/settings), and [OpenCode providers](https://opencode.ai/docs/providers).
