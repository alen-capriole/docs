## Other agents

Most coding agents can use Capriole AI if they let you set a custom endpoint. Use the values below for the protocol that the agent supports.

| Protocol | Base URL | Model IDs |
| --- | --- | --- |
| Chat Completions | `https://api.caprioletech.com/v1` | Every ID from `GET /v1/models`, for example `claude-latest`, `anthropic/claude-opus-5-5`, or `moonshot/kimi-k3.1-pro` |
| Responses | `https://api.caprioletech.com/v1` | GPT models such as `openai-latest`, and `xai/grok-4.7` |
| Anthropic Messages | `https://api.caprioletech.com` | Bare Claude IDs such as `claude-latest` and `claude-opus-5-5` |

Chat Completions is the simplest choice, because it serves every model.

## Authentication

Capriole AI accepts the key only as a Bearer token in the `Authorization` header. If an agent sends the key in an `x-api-key` header, which many Anthropic clients do, set a custom `Authorization: Bearer YOUR_CAPRIOLE_AI_API_KEY` header or use the agent's OpenAI-compatible option instead.
