Capriole AI enthält vier Flaggschiff-Modelle: GPT-6 Astra von OpenAI, Claude Fable 5.1 und Claude Opus 5.5 von Anthropic sowie Gemini 4 Argon von Google. Mit Premium chatten Sie für USD 8 im Monat unbegrenzt mit allen vier, und die API kostet bis zu 92% weniger als die offiziellen API-Preise. Der Web-Chat startet mit GPT-6 Astra Thinking. Wechseln Sie, wenn der Anbieter eines anderen Modells es laut der Übersicht unten für Ihre Aufgabe entwickelt hat.

In Capriole AI ist jedes Modell dieser Tabelle im Web-Chat von Premium und Team unbegrenzt. Über die API kostet ein Token auf jedem Modell gleich viel: USD 8 pro 5M Tokens.

### GPT-6 Astra

OpenAI nennt GPT-6 Astra sein leistungsfähigstes Modell für die anspruchsvollste Arbeit. OpenAI gibt ein Kontextfenster von 1.05M Tokens und bis zu 128.000 Ausgabe-Tokens an. In Capriole AI ist **GPT-6 Astra Thinking** der Standard im Web-Chat, und über die API nutzt `openai-latest` GPT-6 Astra.

### Claude Fable 5.1

Anthropic positioniert Claude Fable 5.1 für anspruchsvolles Reasoning und agentische Arbeit über lange Zeiträume. Laut Anthropic ist es besser als Claude Fable 5 bei lang laufendem agentischem Coding, mehrstufiger Recherche und der Arbeit mit Dokumenten, Tabellen und Präsentationen. Anthropic stuft es als langsamer ein als Claude Opus 5.5. `claude-latest` nutzt Claude Fable 5.1.

### Claude Opus 5.5

Anthropic hat Claude Opus 5.5 für lang laufendes agentisches Coding und Wissensarbeit entwickelt, zu weniger als der Hälfte des offiziellen Preises von Fable 5.1. Anthropic empfiehlt, die meisten Workloads mit Opus 5.5 zu beginnen und zu Fable 5.1 zu wechseln, wenn Opus 5.5 auch mit höherer Effort-Stufe nicht ausreicht. Sein Thinking ist immer aktiv, daher senkt **Fast** in Capriole AI die Effort-Stufe, statt Thinking abzuschalten.

### Gemini 4 Argon

Google nennt Gemini 4 Argon sein leistungsfähigstes Modell, entwickelt für die schwierigsten Probleme. Laut Google kann es bei komplexen Coding-, Agenten-, Mathematik- und Wissenschaftsaufgaben länger nachdenken. Sein Kontextfenster von 1M Tokens teilen sich Eingabe, Thinking und Ausgabe. `google-latest` nutzt Gemini 4 Argon.

## Thinking oder Fast

Die meisten Modelle im Web-Chat gibt es als Paar von Presets. Wählen Sie **Thinking** oder **Fast** neben dem Modellmenü im Nachrichtenfeld.

- **Thinking** denkt vor der Antwort gründlicher nach, für komplexe Aufgaben. Die Thinking-Presets von Claude zeigen eine Zusammenfassung ihres Denkprozesses.
- **Fast** nutzt eine niedrigere Effort-Stufe für schnellere Antworten.

Thinking verbraucht mehr Tokens. Mit Premium und Team bleibt der Web-Chat in beiden Fällen unbegrenzt. Mit Free verbraucht Thinking mehr von Ihrem monatlichen Kontingent.

| Modell | Presets im Web-Chat |
|---|---|
| GPT-6 Astra, GPT-6.1 Sol, GPT-6 Sol, GPT-6 Luna, Claude Fable 5.1 | **Thinking** (mittlere Effort-Stufe) und **Fast** (niedrige Effort-Stufe) |
| Claude Opus 5.5 | Thinking ist immer aktiv. **Fast** senkt die Effort-Stufe. |
| Gemini 4 Argon | Der Web-Chat bietet nur das Preset **Thinking**. Wenn Sie **Fast** wählen, wechselt der Chat zu Gemini 3.8 Flash. |
| Kimi K3.1 Pro | Das Modell denkt immer nach. **Thinking** nutzt eine hohe, **Fast** eine niedrige Effort-Stufe. |
| GLM | **Fast** ist GLM 5.3 Flash. **Thinking** nutzt das frühere GLM 5.2 (`zai/glm-5.2` über die API). |
| Grok 4.7 | Ein Preset |

Die Thinking-Presets gibt es nur im Web-Chat. Wenn Sie über die API mehr Reasoning brauchen, rufen Sie die ID des Modells auf und setzen die Reasoning-Option in Ihrer Anfrage.

## Modelle mitten im Chat wechseln

Wählen Sie im Modellmenü ein anderes Modell und senden Sie Ihre nächste Nachricht. Der Chat behält seinen Verlauf, und das neue Modell antwortet ab dort. [So funktioniert der Modellwechsel mitten im Chat](/de/articles/switch-models-mid-chat).

Ist **Automatischen Modellwechsel aktivieren** unter **Konto** → **Einstellungen** eingeschaltet, kann Capriole AI mit einem anderen verfügbaren Modell antworten, wenn das gewählte stark ausgelastet ist. Standardmäßig ist die Option aus.

## Modell-IDs für die API

Die Basis-URL der API ist `https://api.caprioletech.com`. Verwenden Sie eine konkrete Modell-ID, um ein Modell festzulegen, oder einen `*-latest`-Alias, um unserem empfohlenen Flaggschiff des jeweiligen Anbieters zu folgen.

| Alias | Nutzt | Endpunkte |
|---|---|---|
| `openai-latest` | `openai/gpt-6-astra` | Chat Completions, Responses |
| `claude-latest` | `anthropic/claude-fable-5-1` (`claude-fable-5-1` bei Messages) | Chat Completions, Messages |
| `google-latest` | `google/gemini-4-argon` | Chat Completions |

Die Flaggschiff-IDs sind `openai/gpt-6-astra`, `anthropic/claude-fable-5-1`, `anthropic/claude-opus-5-5` und `google/gemini-4-argon`. Verwenden Sie bei Anthropic Messages Claude-IDs ohne Präfix, etwa `claude-opus-5-5`. Rufen Sie `GET /v1/models` für die aktuelle Liste auf oder sehen Sie unter [Modelle auflisten](/de/api-reference/endpoint/get) nach.

Capriole AI zählt abgerechnete Tokens auf jedem Modell gleich: ungecachte Eingabe plus 10% der gecachten Eingabe plus Ausgabe. [Abgerechnete Tokens erklärt](/de/articles/charged-tokens) enthält Beispiele.

Für Bilder wählen Sie im Modellmenü **Bild** und dann GPT Image 2.5 oder Nano Banana 2.1. Bildmodelle funktionieren nur im Web-Chat. [Zur Anleitung für die Bilderzeugung](/de/guides/files-web-search).

## Häufige Fragen

### Welches Modell nutzt Capriole AI standardmäßig?

Der Web-Chat startet mit GPT-6 Astra Thinking. Über die API nutzt `openai-latest` GPT-6 Astra.

### Kosten Flaggschiff-Modelle in Capriole AI mehr?

Im Web-Chat nicht: Der Chat mit Premium und Team ist auf jedem unterstützten Modell unbegrenzt. Über die API kostet jedes Modell pro Token gleich viel, USD 8 pro 5M Tokens, daher ist die Ersparnis gegenüber den offiziellen Preisen bei den Flaggschiffen am größten.

### Kann ich Claude oder Gemini mit dem OpenAI SDK nutzen?

Ja. OpenAI Chat Completions akzeptiert jede öffentliche Modell-ID, darunter `anthropic/claude-fable-5-1` und `google/gemini-4-argon`, sowie die drei Aliase. Die [Anleitung zu OpenAI- und Anthropic-SDKs](/de/guides/openai-anthropic-sdks) zeigt die Einrichtung.

### Kann ich die Thinking-Presets über die API nutzen?

Nein. Sie gibt es nur im Web-Chat. Rufen Sie die API-ID des Modells auf und setzen Sie die Reasoning-Option in Ihrer Anfrage.

### Mit welchem Claude-Modell sollte ich beginnen?

Anthropic empfiehlt, die meiste Arbeit mit Claude Opus 5.5 zu beginnen und für anspruchsvolles Reasoning und agentische Arbeit über lange Zeiträume zu Claude Fable 5.1 zu wechseln.
