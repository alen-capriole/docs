## Was ist GitHub Copilot CLI

GitHub Copilot CLI ist der Coding-Agent von GitHub für das Terminal. Sein Bring-your-own-Key-Modus (BYOK) sendet Modellanfragen an einen Anbieter, den Sie über Umgebungsvariablen festlegen. Dieses Setup richtet ihn auf Capriole AI aus.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

- Ein Capriole AI-Konto ([Hier registrieren](https://capriole.ai))
- Einen Capriole AI API-Schlüssel ([Schlüssel abrufen](https://capriole.ai?view=api))

## Installation

Installieren Sie GitHub Copilot CLI mit npm:

```bash
npm install -g @github/copilot
```

Prüfen Sie die Installation:

```bash
copilot --version
```

Sie müssen sich nicht bei GitHub anmelden, wenn `COPILOT_PROVIDER_BASE_URL` gesetzt ist.

## Konfiguration

### Modellvalidierung

GitHub Copilot CLI 1.0.100 besteht mit den folgenden Profilen für jedes Modell im Abschnitt „Unterstützte Modelle“ eine Prüfung aus Dateilesen, Dateischreiben und abschließender Antwort über Capriole AI.

Copilot CLI verwendet jeweils nur einen Anbieter. Wählen Sie daher das Profil für die gewünschte Modellfamilie. Jedes Profil setzt zwei Modellwerte:

- `COPILOT_PROVIDER_WIRE_MODEL` ist die Capriole AI-Modell-ID, die Copilot sendet.
- `COPILOT_PROVIDER_MODEL_ID` ist ein Modell, das Copilot kennt. Anhand dieses Werts wählt Copilot seine Tools, Prompts und Token-Limits.

### GPT-Modelle

GPT-Modelle verwenden die Responses API:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.caprioletech.com/v1"
export COPILOT_PROVIDER_API_KEY="$CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_WIRE_API="responses"
export COPILOT_PROVIDER_MODEL_ID="gpt-6-astra"
export COPILOT_PROVIDER_WIRE_MODEL="openai-latest"
```

Setzen Sie für GPT-6.1 Sol `COPILOT_PROVIDER_MODEL_ID="gpt-6.1-sol"` und `COPILOT_PROVIDER_WIRE_MODEL="openai/gpt-6.1-sol"`.

### Claude-Modelle

Claude-Modelle verwenden Anthropic Messages:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_TYPE="anthropic"
export COPILOT_PROVIDER_BASE_URL="https://api.caprioletech.com"
export COPILOT_PROVIDER_BEARER_TOKEN="$CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_MODEL_ID="claude-opus-4.6"
export COPILOT_PROVIDER_WIRE_MODEL="claude-latest"
```

Setzen Sie für Opus 5.5 `COPILOT_PROVIDER_WIRE_MODEL="claude-opus-5-5"`.

- `COPILOT_PROVIDER_BEARER_TOKEN` sendet den Schlüssel als Bearer-Token. `COPILOT_PROVIDER_API_KEY` würde ihn in einem `x-api-key`-Header senden, den Capriole AI nicht akzeptiert.
- Die Basis-URL hat kein `/v1`, da Copilot `/v1/messages` selbst ergänzt.
- Behalten Sie `COPILOT_PROVIDER_MODEL_ID="claude-opus-4.6"` bei. Mit einem älteren Profil wie `claude-sonnet-4` sendet Copilot ein Thinking-Budget, das Opus 5.5 mit `requires adaptive thinking` ablehnt.

### Gemini-, Grok-, GLM- und Kimi-Modelle

Diese Modelle verwenden Chat Completions:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.caprioletech.com/v1"
export COPILOT_PROVIDER_API_KEY="$CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_WIRE_API="completions"
export COPILOT_PROVIDER_MODEL_ID="claude-sonnet-4"
export COPILOT_PROVIDER_WIRE_MODEL="moonshot/kimi-k3"
```

Ändern Sie `COPILOT_PROVIDER_WIRE_MODEL` für die anderen Modelle auf `google/gemini-3.8-flash`, `xai/grok-4.7` oder `zai/glm-5.3-flash`.

Behalten Sie `COPILOT_PROVIDER_MODEL_ID="claude-sonnet-4"` bei. Mit einem GPT-Profil wie `gpt-5.4` sendet Copilot Tool-Typen, die diese Modelle ablehnen.

Um ein Profil dauerhaft zu speichern, fügen Sie seine Zeilen zu `~/.zshrc` oder `~/.bashrc` hinzu und öffnen Sie dann ein neues Terminal.

## GitHub Copilot CLI ausführen

Starten Sie Copilot CLI aus Ihrem Projektverzeichnis:

```bash
copilot
```

Für einen nicht interaktiven Lauf übergeben Sie einen Prompt mit `-p`:

```bash
copilot -p "Explain this repository." --allow-all-tools
```

## Unterstützte Modelle

| Modell | `COPILOT_PROVIDER_WIRE_MODEL` | `COPILOT_PROVIDER_MODEL_ID` | Protokoll |
| --- | --- | --- | --- |
| OpenAI latest | `openai-latest` | `gpt-6-astra` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | `gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | `claude-opus-4.6` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | `claude-opus-4.6` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | `claude-sonnet-4` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | `claude-sonnet-4` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | `claude-sonnet-4` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | `claude-sonnet-4` | Chat Completions |

`openai-latest` und `claude-latest` zeigen immer auf unser neuestes Flaggschiff-Modell der jeweiligen Familie.

## Fehlerbehebung

### Warum gibt Copilot CLI einen Authentifizierungsfehler zurück?

Bestätigen Sie, dass `CAPRIOLE_AI_API_KEY` in derselben Shell exportiert ist. Verwenden Sie für Claude-Modelle `COPILOT_PROVIDER_BEARER_TOKEN`, nicht `COPILOT_PROVIDER_API_KEY`.

### Warum schlagen Anfragen mit Endpunktfehlern fehl?

Für GPT-, Gemini-, Grok-, GLM- und Kimi-Modelle ist `COPILOT_PROVIDER_BASE_URL` `https://api.caprioletech.com/v1`. Für Claude-Modelle ist es `https://api.caprioletech.com` ohne `/v1`.

### Warum schlägt Opus 5.5 mit `requires adaptive thinking` fehl?

Setzen Sie `COPILOT_PROVIDER_MODEL_ID="claude-opus-4.6"`.

### Warum schlagen Gemini-, Grok-, GLM- oder Kimi-Anfragen mit einem Tool-Fehler fehl?

Setzen Sie `COPILOT_PROVIDER_MODEL_ID="claude-sonnet-4"`. Ein GPT-Profil sendet Tool-Typen, die nur OpenAI-Modelle akzeptieren.

## Hinweise

- Copilot CLI führt Coding-Tools auf Ihrem Computer aus. Capriole AI verarbeitet nur die Modellanfragen.
- Führen Sie `copilot help providers` aus, um alle BYOK-Umgebungsvariablen anzuzeigen.
- Offizielle Referenzen: [GitHub Copilot CLI installieren](https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/install-copilot-cli) und [BYOK-Modelle in Copilot CLI verwenden](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models).
