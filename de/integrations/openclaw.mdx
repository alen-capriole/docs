## Was ist OpenClaw

OpenClaw ist ein selbst gehosteter, persönlicher Open-Source-KI-Assistent und Gateway. Er verbindet Chat-Kanäle wie WhatsApp, Slack, Discord, Telegram, iMessage und WebChat mit KI-Agents. Dieses Setup fügt Capriole AI als drei benutzerdefinierte Modellanbieter hinzu, einen für jedes API-Protokoll, das Capriole AI bereitstellt.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

- Ein Capriole AI-Konto ([Hier registrieren](https://capriole.ai))
- Einen Capriole AI API-Schlüssel ([Schlüssel abrufen](https://capriole.ai?view=api))

## Installation

Installieren Sie OpenClaw mit dem offiziellen Installationsskript:

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Schließen Sie anschließend die eigene Einrichtung von OpenClaw ab:

```bash
openclaw onboard
```

Was die einzelnen Einstellungen bewirken:

- `capriole-ai-openai` sendet GPT-Modelle an die Responses API. `capriole-ai-anthropic` sendet Claude-Modelle an Anthropic Messages. `capriole-ai-compatible` sendet Gemini-, Grok-, GLM- und Kimi-Modelle an Chat Completions.
- `${CAPRIOLE_AI_API_KEY}` liest Ihren Schlüssel aus der Umgebung.
- `request.auth` mit `authorization-bearer` sorgt dafür, dass der Anthropic-Anbieter den Schlüssel als Bearer-Token sendet. Ohne diese Einstellung landet der Schlüssel in einem `x-api-key`-Header, den Capriole AI nicht akzeptiert.
- Die Anthropic-`baseUrl` hat kein `/v1`, da OpenClaw `/v1/messages` selbst ergänzt.
- `reasoning` ist für Opus 5.5 auf `false` gesetzt. Bei `true` sendet OpenClaw ein Thinking-Budget, das Opus 5.5 mit `requires adaptive thinking` ablehnt.
- `contextWindow` und `maxTokens` teilen OpenClaw die Limits jedes Modells mit.
- `agents.defaults.models` ist die Liste der Modelle, die Agents verwenden können. `agents.defaults.model.primary` ist das Standardmodell.

## OpenClaw ausführen

Exportieren Sie Ihren Schlüssel in jedem Terminal, in dem Sie OpenClaw starten:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
```

Starten Sie das Gateway:

```bash
openclaw gateway
```

Öffnen Sie die Terminal-UI in einem anderen Terminal:

```bash
openclaw tui
```

Für einen einmaligen lokalen Lauf ohne Gateway:

```bash
openclaw agent --local --session-id capriole-test --message "Summarize the files in my workspace."
```

## Unterstützte Modelle

Modellreferenzen haben die Form `<provider-id>/<model-id>`.

| Modell | Modellreferenz | Protokoll |
| --- | --- | --- |
| OpenAI latest | `capriole-ai-openai/openai-latest` | Responses |
| GPT-6.1 Sol | `capriole-ai-openai/openai/gpt-6.1-sol` | Responses |
| Claude latest | `capriole-ai-anthropic/claude-latest` | Anthropic Messages |
| Opus 5.5 | `capriole-ai-anthropic/claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `capriole-ai-compatible/google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `capriole-ai-compatible/xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `capriole-ai-compatible/zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `capriole-ai-compatible/moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `capriole-ai-compatible/moonshot/kimi-k3` | Chat Completions |

`openai-latest` und `claude-latest` zeigen immer auf unser neuestes Flaggschiff-Modell der jeweiligen Familie.

## Fehlerbehebung

### Warum schlägt die Authentifizierung fehl?

Exportieren Sie `CAPRIOLE_AI_API_KEY` in dem Terminal, das `openclaw gateway` oder `openclaw agent` startet. OpenClaw gibt `missing env var` aus, wenn die Variable nicht gesetzt ist.

### Warum schlägt Opus 5.5 mit `requires adaptive thinking` fehl?

Setzen Sie `reasoning` für `claude-opus-5-5` auf `false`.

### Warum meldet OpenClaw, dass ein Modell nicht erlaubt ist oder fehlt?

Führen Sie `openclaw models list` aus. Bestätigen Sie, dass die Modellreferenz in `agents.defaults.models` steht und dass der Modelleintrag das vollständige oben gezeigte Objekt enthält, nicht nur `id` und `name`.

### Warum beginnt eine neue Sitzung mit einem Einrichtungsdialog?

Das ist die Workspace-Einrichtung von OpenClaw beim ersten Start, kein Problem von Capriole AI. Schließen Sie sie einmal in `openclaw tui` ab oder führen Sie `openclaw onboard` erneut aus.

### Warum startet das Gateway nicht?

Führen Sie `openclaw status`, `openclaw gateway status`, `openclaw logs --follow` und `openclaw doctor` aus.

## Hinweise

- Um ein weiteres Capriole AI-Modell hinzuzufügen, kopieren Sie den Eintrag eines Modells derselben Familie, ändern Sie die ID und fügen Sie seine Referenz zu `agents.defaults.models` hinzu. `GET https://api.caprioletech.com/v1/models` listet alle Modell-IDs auf.
