## Was ist Qwen Code

Qwen Code ist ein Open-Source-Coding-Agent für das Terminal. Seine Einstellung `modelProviders` listet die Modelle, die Sie verwenden können, und das API-Protokoll jedes Modells auf. Dieses Setup fügt dieser Liste Capriole AI-Modelle hinzu.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

- Ein Capriole AI-Konto ([Hier registrieren](https://capriole.ai))
- Einen Capriole AI API-Schlüssel ([Schlüssel abrufen](https://capriole.ai?view=api))

## Installation

Installieren Sie Qwen Code mit npm (Node.js 22 oder neuer):

```bash
npm install -g @qwen-code/qwen-code@latest
```

Oder installieren Sie es mit Homebrew:

```bash
brew install qwen-code
```

Prüfen Sie die Installation:

```bash
qwen --version
```

- Modelle unter `openai` verwenden Chat Completions. GPT-Modelle ergänzen `wireApi: "responses"`, um die Responses API zu verwenden.

- `security.auth.selectedType` und `model.name` legen das Standardmodell fest. `/model` aktualisiert beide, wenn Sie das Modell wechseln.

## Qwen Code ausführen

Starten Sie Qwen Code aus Ihrem Projektverzeichnis:

```bash
qwen
```

Wechseln Sie das Modell mit `/model`. Für einen einmaligen Lauf übergeben Sie den Prompt, das Modell und den Auth-Typ seiner Gruppe:

```bash
qwen "Explain this repository." -m claude-latest --auth-type anthropic
```

## Fehlerbehebung

### Warum gibt Qwen Code einen Authentifizierungsfehler zurück?

Bestätigen Sie, dass `~/.qwen/.env` `CAPRIOLE_AI_API_KEY` setzt, oder exportieren Sie die Variable in derselben Shell.

### Warum schlägt ein Modell mit einem Protokollfehler fehl?

Führen Sie das Modell mit dem Auth-Typ seiner Gruppe aus: `--auth-type openai` für Modelle unter `openai` und `--auth-type anthropic` für Modelle unter `anthropic`. `/model` setzt dies automatisch.

### Warum schlagen Claude-Anfragen mit `Unsupported Claude Messages model` fehl?

Claude-Modelle unter `anthropic` benötigen die Claude-IDs ohne Präfix, etwa `claude-opus-5-5`.

## Hinweise

- Bewahren Sie Ihren Schlüssel in `~/.qwen/.env` auf, nicht in `settings.json`.
- Um ein weiteres Capriole AI-Modell hinzuzufügen, kopieren Sie den Eintrag eines Modells derselben Familie und ändern Sie die ID. `GET https://api.caprioletech.com/v1/models` listet alle Modell-IDs auf.
- Offizielle Referenzen: [Qwen Code](https://github.com/QwenLM/qwen-code) und [Modellanbieter in Qwen Code](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/model-providers/).
