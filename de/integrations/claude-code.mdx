## Was ist Claude Code

Claude Code ist das agentische Coding-Tool von Anthropic zum Lesen von Codebasen, Bearbeiten von Dateien, Ausführen von Befehlen und zur Integration mit Entwicklungswerkzeugen. Dieses Setup leitet Claude Code über seine Gateway-Einstellungen an Capriole AI weiter: API-Endpunkt, Auth-Token und das Modell für jeden Alias.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

- Ein Capriole AI-Konto ([Hier registrieren](https://capriole.ai))
- Einen Capriole AI API-Schlüssel ([Schlüssel abrufen](https://capriole.ai?view=api))

## Installation

Installieren Sie Claude Code mit dem offiziellen nativen Installationsprogramm:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

Oder installieren Sie es mit Homebrew:

```bash
brew install --cask claude-code
```

Oder installieren Sie es mit npm (Node.js 22 oder neuer):

```bash
npm install -g @anthropic-ai/claude-code
```

Prüfen Sie die Installation:

```bash
claude --version
```

## Konfiguration

### Modellvalidierung

Claude Code 2.1.304 besteht mit der folgenden Konfiguration für jedes Modell im Abschnitt „Unterstützte Modelle“ eine Prüfung aus Dateilesen, Dateischreiben und abschließender Antwort über Capriole AI.

Erstellen oder aktualisieren Sie `~/.claude/settings.json`:

```json
{
  "model": "claude-fable-5-1",
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.caprioletech.com",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_CAPRIOLE_AI_API_KEY",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-5-5",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-fable-5-1",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-sonnet-4-6"
  }
}
```

Was die einzelnen Einstellungen bewirken:

- `model` ist das Standardmodell für neue Sitzungen. Ein Modell, das Sie mit `/model` auswählen, wird gespeichert und beim nächsten Mal verwendet.
- `ANTHROPIC_BASE_URL` sendet Anfragen an Capriole AI. Fügen Sie kein `/v1` hinzu; Claude Code ergänzt `/v1/messages` selbst.
- `ANTHROPIC_AUTH_TOKEN` sendet Ihren Schlüssel als Bearer-Token, was Capriole AI voraussetzt.
- Die drei `ANTHROPIC_DEFAULT_*_MODEL`-Werte richten die Aliase `opus`, `sonnet` und `haiku` auf Modelle aus, die Capriole AI bereitstellt. `haiku` ist das Modell, das Claude Code für schnelle Hintergrundaufgaben verwendet.

Für eine einmalige Shell-Einrichtung exportieren Sie Endpunkt und Token und übergeben dann das Modell:

```bash
export ANTHROPIC_BASE_URL="https://api.caprioletech.com"
export ANTHROPIC_AUTH_TOKEN="YOUR_CAPRIOLE_AI_API_KEY"
claude --model claude-fable-5-1
```

## Claude Code ausführen

Starten Sie Claude Code aus Ihrem Projektverzeichnis:

```bash
claude
```

Wechseln Sie das Modell in einer Sitzung mit `/model`, zum Beispiel `/model opus` für Opus 5.5. Für einen nicht interaktiven Lauf verwenden Sie den Print-Modus:

```bash
claude -p "Explain this repository."
```

## Unterstützte Modelle

Claude Code verwendet das Anthropic Messages-Protokoll und unterstützt daher die Claude-Modelle von Capriole AI:

- `claude-fable-5-1` (Fable 5.1, der empfohlene Standard)
- `claude-opus-5-5` (Opus 5.5)
- `claude-fable-5`
- `claude-opus-5`
- `claude-opus-4-8`
- `claude-opus-4-7`
- `claude-opus-4-6`
- `claude-sonnet-4-6`
- `claude-latest`, das immer auf unser neuestes Claude-Flaggschiff-Modell zeigt (derzeit Fable 5.1)

Claude Code erkennt `claude-latest` nicht als Modellnamen und nimmt dafür deshalb ein Kontextfenster von 200K an. Verwenden Sie eine konkrete ID wie `claude-fable-5-1`, um das volle Kontextfenster des Modells zu erhalten.

## Fehlerbehebung

### Warum gibt Claude Code einen Authentifizierungsfehler zurück?

Verwenden Sie `ANTHROPIC_AUTH_TOKEN`, nicht `ANTHROPIC_API_KEY`. `ANTHROPIC_API_KEY` sendet den Schlüssel in einem `x-api-key`-Header, und Capriole AI akzeptiert nur ein Bearer-Token.

### Warum schlagen Anfragen mit Endpunktfehlern fehl?

Bestätigen Sie, dass `ANTHROPIC_BASE_URL` `https://api.caprioletech.com` ohne `/v1` ist.

### Warum wechselt Claude Code bei jedem Start zu einem anderen Modell zurück?

Entfernen Sie `ANTHROPIC_MODEL` aus Ihren Einstellungen und Ihrer Shell. Wenn die Variable gesetzt ist, kehrt Claude Code beim nächsten Start zu diesem Modell zurück statt zu dem Modell, das Sie mit `/model` gespeichert haben.

### Warum schlägt `/model opus` oder `/model sonnet` fehl?

Behalten Sie die drei `ANTHROPIC_DEFAULT_*_MODEL`-Werte bei. Ohne sie sendet Claude Code die eigenen Alias-Ziele von Anthropic. Zum Beispiel fordert `sonnet` `claude-sonnet-5-5` an, das Capriole AI nicht bereitstellt, und die Anfrage schlägt mit `Unsupported Claude Messages model` fehl.

### Warum verwendet Claude Code nicht meine Effort-Stufe?

Claude Code speichert die Effort-Stufe für jedes Modell separat. Wählen Sie sie mit `/effort`, während das Modell aktiv ist. Ein `effortLevel` auf oberster Ebene in Ihren Benutzereinstellungen gilt nicht für Opus 5.5.

### Warum schlägt die Token-Zählung fehl?

Capriole AI leitet `/v1/messages/count_tokens` an das gewählte Upstream weiter. Wenn dieses Upstream keine Token-Zählung unterstützt, schätzt Claude Code die Anzahl stattdessen, und die Sitzung funktioniert weiter.

## Hinweise

- `~/.claude/settings.json` gilt für Ihr Benutzerkonto in allen Projekten. Ersetzen Sie `YOUR_CAPRIOLE_AI_API_KEY` durch Ihren Capriole AI API-Schlüssel.
- Gemini-, Grok-, GLM- und Kimi-Modelle laufen nicht in Claude Code, da es nur das Anthropic Messages-Protokoll spricht. Verwenden Sie für diese Modelle OpenCode, Kilo Code oder einen anderen Agent, der mehrere Protokolle unterstützt.
- Offizielle Referenzen: [Claude Code-Einrichtung](https://code.claude.com/docs/en/setup), [Modellkonfiguration](https://code.claude.com/docs/en/model-config) und [LLM-Gateway-Konfiguration](https://code.claude.com/docs/en/llm-gateway-connect).
