## Was ist Kilo Code

Kilo Code ist ein KI-Coding-Agent für VS Code und das Terminal. Dieses Setup fügt Capriole AI als einen benutzerdefinierten Anbieter hinzu. Jedes Modell darin verwendet das API-Protokoll, das Capriole AI für die jeweilige Modellfamilie bereitstellt.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

- Ein Capriole AI-Konto ([Hier registrieren](https://capriole.ai))
- Einen Capriole AI API-Schlüssel ([Schlüssel abrufen](https://capriole.ai?view=api))

## Installation

### Kilo CLI

```bash
npm install -g @kilocode/cli
```

Prüfen Sie die Installation:

```bash
kilo --version
```

### VS Code-Erweiterung

Installieren Sie Kilo Code über die Erweiterungsansicht von VS Code. Die Erweiterung liest dieselbe globale Konfigurationsdatei wie die CLI.

## Konfiguration

### Modellvalidierung

Kilo CLI 7.8.15 besteht mit der folgenden Konfiguration für jedes Modell im Abschnitt „Unterstützte Modelle“ eine Prüfung aus Dateilesen, Dateischreiben und abschließender Antwort über Capriole AI.

Erstellen oder aktualisieren Sie `~/.config/kilo/kilo.jsonc`:

```jsonc
{

  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {

      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"

      }

```

Was die einzelnen Einstellungen bewirken:

- `npm: "@ai-sdk/openai-compatible"` ist das Standardpaket für den Anbieter, sodass Gemini, Grok, GLM und Kimi Chat Completions verwenden.
- Jedes GPT-Modell überschreibt `provider.npm` mit `@ai-sdk/openai`, das die Responses API verwendet. Jedes Claude-Modell überschreibt es mit `@ai-sdk/anthropic`, das Anthropic Messages verwendet.
- `{env:CAPRIOLE_AI_API_KEY}` liest Ihren Schlüssel aus der Umgebung. Der `Authorization`-Header sendet ihn für jedes Paket als Bearer-Token. Ohne diesen Header sendet das Anthropic-Paket den Schlüssel in einem `x-api-key`-Header, den Capriole AI nicht akzeptiert.
- `tool_call: true` erlaubt dem Modell, die Tools von Kilo aufzurufen.
- `limit` legt das Kontextfenster und das Ausgabelimit jedes Modells fest. Ohne diese Angabe behandelt Kilo beide Werte als `0` und komprimiert lange Sitzungen nicht.

Behalten Sie diesen Anbieter in Ihrer globalen Konfiguration. Kilo löst `{env:...}`-Verweise in einer projektbezogenen Konfiguration nicht auf.

Führen Sie nach dem Bearbeiten der Datei `kilo config check` aus.

## Kilo Code ausführen

Setzen Sie Ihren API-Schlüssel und starten Sie Kilo aus Ihrem Projektverzeichnis:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo
```

Starten Sie mit einem bestimmten Modell:

```bash
kilo -m capriole-ai/openai-latest
```

Für eine einmalige Anfrage übergeben Sie einen Prompt an `kilo run`:

```bash
kilo run -m capriole-ai/claude-latest "Explain this repository."
```

## Unterstützte Modelle

Modellreferenzen haben die Form `capriole-ai/<model-id>`.

| Modell | Modell-ID | Protokoll |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` und `claude-latest` zeigen immer auf unser neuestes Flaggschiff-Modell der jeweiligen Familie.

## Fehlerbehebung

### Warum gibt Kilo Code einen Authentifizierungsfehler zurück?

Bestätigen Sie, dass `CAPRIOLE_AI_API_KEY` in derselben Shell exportiert ist, bevor Sie `kilo` ausführen, und dass der Anbieter in `~/.config/kilo/kilo.jsonc` steht und nicht in einer Projektkonfiguration.

### Warum schlagen Claude-Anfragen mit `Unsupported Claude Messages model` fehl?

Claude-Modelle, die `@ai-sdk/anthropic` verwenden, benötigen die Claude-IDs ohne Präfix, etwa `claude-opus-5-5`. Die IDs mit dem Präfix `anthropic/` sind für Chat Completions gedacht.

### Warum meldet Kilo Code, dass das Modell fehlt?

Bestätigen Sie, dass das ausgewählte Modell das Format `capriole-ai/<model-id>` verwendet und dass `provider.capriole-ai.models` einen passenden Eintrag enthält. Führen Sie `kilo models capriole-ai` aus, um die Modelle aufzulisten, die Kilo geladen hat.

### Warum schlägt die Tool-Nutzung fehl?

Bestätigen Sie, dass der Modelleintrag `"tool_call": true` enthält.

## Hinweise

- Kilo Code führt Coding-Tools auf Ihrem Computer aus. Capriole AI verarbeitet nur die Modellanfragen.
- Um ein weiteres Capriole AI-Modell hinzuzufügen, kopieren Sie den Eintrag eines Modells derselben Familie und ändern Sie die ID. `GET https://api.caprioletech.com/v1/models` listet alle Modell-IDs auf.
- Offizielle Referenzen: [Kilo CLI](https://kilo.ai/docs/cli), [Benutzerdefinierte Modelle in Kilo](https://kilo.ai/docs/code-with-ai/agents/custom-models), [Kilo-Einstellungen](https://kilo.ai/docs/getting-started/settings) und [OpenCode-Anbieter](https://opencode.ai/docs/providers).
