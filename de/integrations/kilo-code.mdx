## Was ist Kilo Code

Kilo Code ist ein KI-Coding-Assistent für IDEs und Terminals. Es kann Capriole AI über den OpenAI-kompatiblen Anbieter von Kilo nutzen, der Anfragen an die Chat Completions-kompatible API von Capriole AI sendet.

## Voraussetzungen

Bevor Sie beginnen, stellen Sie sicher, dass Sie Folgendes haben:

- Ein Capriole AI-Konto ([Hier registrieren](https://capriole.ai))
- Einen Capriole AI API-Schlüssel ([Schlüssel abrufen](https://capriole.ai?view=api))
- Kilo Code in VS Code oder als Kilo CLI installiert

## Installation

### VS Code-Erweiterung

Installieren Sie Kilo Code über die VS Code-Ansicht Extensions. Suchen Sie nach `Kilo Code` und installieren Sie die Pre-Release-Version.

### Kilo CLI

```bash
npm install -g @kilocode/cli
```

## Konfiguration

### Modellvalidierung

Die Prüfungen für Gemini 3.8 Flash verwenden `"tool_call": true`; für Gemini 3.5 Flash bleibt unten `"tool_call": false` gesetzt.

`xai/grok-4.6` akzeptiert Chat Completions-Anfragen, besteht aber die Coding-Agent-Aufgabenprüfung nicht und ist daher nicht in der folgenden Konfiguration enthalten. Direkte Anbieterprüfungen zeigen auch bei Grok 4.5 inkonsistente Werkzeugnutzung; eine abgeschlossene API-Anfrage belegt keine korrekte Agent-Antwort.

## Kilo Code ausführen

Setzen Sie Ihren API-Schlüssel und starten Sie Kilo aus Ihrem Projektverzeichnis:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo
```

Starten Sie mit einem bestimmten Modell:

```bash
kilo -m openai-compatible/openai-latest
kilo -m openai-compatible/claude-latest
kilo -m openai-compatible/google-latest
kilo -m openai-compatible/openai/gpt-5.5
kilo -m openai-compatible/openai/gpt-5.4-mini
kilo -m openai-compatible/anthropic/claude-fable-5-1
kilo -m openai-compatible/anthropic/claude-fable-5
kilo -m openai-compatible/anthropic/claude-opus-5
kilo -m openai-compatible/anthropic/claude-opus-4-8
kilo -m openai-compatible/anthropic/claude-opus-4-7
kilo -m openai-compatible/google/gemini-3.1-pro-preview
kilo -m openai-compatible/google/gemini-3.8-flash
kilo -m openai-compatible/google/gemini-3.5-flash
kilo -m openai-compatible/zai/glm-5.3-flash
kilo -m openai-compatible/moonshot/kimi-k3
```

Führen Sie eine einmalige Anfrage mit Gemini 3.5 Flash aus:

```bash
kilo run --agent ask -m openai-compatible/google/gemini-3.5-flash "Summarize this project."
```

Für eine einmalige CLI-Anfrage übergeben Sie einen Prompt an `kilo run`:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo run -m openai-compatible/openai-latest "Explain this repository structure."
```

## Unterstützte Modelle

Beginnen Sie neue Kilo Code-Setups mit `openai-latest`. Verwenden Sie `claude-latest` oder `google-latest`, wenn Capriole AI an unser empfohlenes Claude- oder Gemini-Flaggschiff-Modell weiterleiten soll, und verwenden Sie eine konkrete Modell-ID, wenn Sie eine genaue Modellversion benötigen.

Behalten Sie `"tool_call": false` für Gemini 3.5 Flash in Kilo Code bei. Das Aktivieren nativer Gemini-Function-Declarations kann jedoch weiterhin die engere OpenAPI-Schema-Teilmenge von Gemini sichtbar machen.

Andere öffentliche Chat Completions-kompatible Modell-IDs aus `GET /v1/models` können ebenfalls konfiguriert werden, wenn Sie sie testen möchten. Validieren Sie die Tool-Nutzung, bevor Sie ein Modell für Code-Bearbeitungs-Workflows verwenden.

## Fehlerbehebung

### Warum gibt Kilo Code einen Authentifizierungsfehler zurück?

Bestätigen Sie, dass `CAPRIOLE_AI_API_KEY` in derselben Shell exportiert ist, bevor Sie `kilo` ausführen.

### Welche Konfigurationsdatei sollte ich bearbeiten?

Verwenden Sie `~/.config/kilo/kilo.jsonc` für die aktuelle Kilo CLI und die VS Code-Erweiterung. Führen Sie nach dem Bearbeiten `kilo config check` aus.

### Warum schlagen Anfragen mit Endpunktfehlern fehl?

Bestätigen Sie, dass `baseURL` `https://api.caprioletech.com/v1` ist. Kilo sendet Chat Completions-Anfragen an `/v1/chat/completions`.

### Warum sagt Kilo Code, dass das Modell fehlt?

Bestätigen Sie, dass das ausgewählte Modell das Format `openai-compatible/<model-id>` verwendet und dass `provider.openai-compatible.models` den passenden Modelleintrag enthält. Zum Beispiel wird `openai-compatible/openai-latest` auf den Konfigurationsschlüssel `openai-latest` abgebildet.

### Warum schlägt die Tool-Nutzung fehl?

Bestätigen Sie für GPT, Claude, Gemini 3.1 Pro und Latest-Alias-Einträge, dass der Modelleintrag `"tool_call": true` enthält. Kilo Code führt Tools lokal aus und sendet nachfolgende Chat Completions-Anfragen an Capriole AI.

Behalten Sie für Gemini 3.5 Flash `"tool_call": false` bei. Gemini unterstützt Function Calling, seine Function Declarations verwenden jedoch eine unterstützte Teilmenge des OpenAPI-Schemas. Einige native Tool-Schemas sind breiter als diese Teilmenge.

## Hinweise

- Capriole AI stellt Kilo Code über `POST /v1/chat/completions` bereit.
- Kilo Code führt Coding-Tools lokal aus. Capriole AI verarbeitet nur die Modellanfrage.
- Kilo Code 7.3.16 schließt einen gestreamten Bash-Tool-Aufruf und den nachfolgenden Assistenten-Turn mit Kimi K3 ab.
- Halten Sie die Anbieterkonfiguration zuerst minimal. Fügen Sie Kilo-Modelllimits oder andere Modelloptionen nur hinzu, wenn Sie bewusst clientseitige Kontextverwaltung möchten.
