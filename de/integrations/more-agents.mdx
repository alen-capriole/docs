Mit einem einzigen Capriole-AI-API-Schlüssel nutzen Sie GPT-6.2 Astra, Claude Fable 5.2, Opus 5.5 und Gemini 4 Carbon in jedem Coding-Agenten mit benutzerdefiniertem Endpunkt, bis zu 92% unter den offiziellen API-Preisen.

## Andere Agents

Die meisten Coding-Agents können Capriole AI nutzen, wenn sie einen benutzerdefinierten Endpunkt zulassen. Verwenden Sie die folgenden Werte für das Protokoll, das der Agent unterstützt.

| Protokoll | Basis-URL | Modell-IDs |
| --- | --- | --- |
| Chat Completions | `https://api.caprioletech.com/v1` | Jede ID aus `GET /v1/models`, zum Beispiel `claude-latest`, `anthropic/claude-opus-5-5` oder `moonshot/kimi-k3.1-pro` |
| Responses | `https://api.caprioletech.com/v1` | GPT-Modelle wie `openai-latest` sowie `xai/grok-4.7` |
| Anthropic Messages | `https://api.caprioletech.com` | Claude-IDs ohne Präfix wie `claude-latest` und `claude-opus-5-5` |

Chat Completions ist die einfachste Wahl, da darüber jedes Modell bereitgestellt wird.

Wie Sie denselben Schlüssel in Agents mit eigener Seite nutzen, zeigt [Einen API-Schlüssel mit Coding-Agents nutzen](/de/guides/one-api-key-coding-agents).

## Authentifizierung

Senden Sie Ihren Capriole-AI-Schlüssel als Bearer-Token im Header `Authorization`. Wenn ein Agent den Schlüssel in einem `x-api-key`-Header sendet, wie es viele Anthropic-Clients tun, setzen Sie einen benutzerdefinierten Header `Authorization: Bearer YOUR_CAPRIOLE_AI_API_KEY` oder verwenden Sie stattdessen die OpenAI-kompatible Option des Agenten.

Ein API-Schlüssel setzt Premium (USD 9 pro Monat, inklusive unbegrenztem Web-Chat) oder Team voraus ([Abonnieren](https://www.capriole.ai/de?view=api)).
