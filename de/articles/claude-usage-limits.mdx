Nutzer von Claude Pro und Max stoßen an Nutzungslimits, weil jeder bezahlte Claude-Plan ein Fünf-Stunden-Sitzungslimit und ein Wochenlimit hat und claude.ai, Claude Desktop und Claude Code alle darauf zugreifen. Lange Chats, Tools, höherer Effort und größere Modelle verbrauchen das Kontingent schneller. Wenn Sie vor allem chatten, bietet Ihnen Capriole AI Premium unbegrenzten Web-Chat mit **Claude Fable 5.1** und **Claude Opus 5.5**, dazu **GPT-6 Astra** und **Gemini 4 Argon**, für **USD 8 pro Monat**.

Für intensive Arbeit mit Coding-Agents enthält dasselbe Konto eine API, die bis zu 92% weniger kostet als die offiziellen API-Preise.

## Wie die Nutzungslimits von Claude funktionieren

Das Hilfecenter von Anthropic beschreibt zwei Limits für bezahlte Pläne:

- **Ein Sitzungslimit**, das alle fünf Stunden zurückgesetzt wird.
- **Ein Wochenlimit** über alle Modelle, das zu einem festen, Ihrem Konto zugewiesenen Zeitpunkt zurückgesetzt wird.

Laut Anthropic kann die Nutzung auch auf andere Weise begrenzt werden, etwa durch monatliche Obergrenzen oder Limits für bestimmte Modelle und Funktionen. Ihren Stand sehen Sie auf claude.ai unter **Settings** → **Usage**.

Die Limits werden geteilt. Nutzung in claude.ai, Claude Desktop und Claude Code zählt zum selben Kontingent, sodass eine lange Claude-Code-Sitzung wenig Raum für den Chat lassen kann. Der Wechsel zu einem anderen Claude-Modell setzt es nicht zurück, weil das Wochenlimit alle Modelle umfasst.

## Warum Sie das Limit schneller erreichen als erwartet

Anthropic nennt, was mehr von Ihrem Kontingent verbraucht:

- lange und komplexe Unterhaltungen
- das gewählte Modell
- höhere Effort-Stufen und Extended Thinking
- Tools und Konnektoren, die viele Tokens verbrauchen
- große Projektdateien, die Kontext belegen
- lange Chats, die die automatische Kontextverwaltung auslösen

Für Fable 5.1 gilt eine eigene Regel. Bei Pro gehören Fable 5 und Fable 5.1 nicht zu den Nutzungslimits des Plans, daher läuft jede Fable-Nachricht über Nutzungsguthaben, die zu Standard-API-Preisen abgerechnet werden. Bei Max können Fable-Modelle ohne Zusatzkosten bis zu 50% Ihrer Wochenlimits nutzen.

## Was Anthropic empfiehlt, wenn Sie ein Limit erreichen

1. **Warten Sie auf das Zurücksetzen.** Das Sitzungslimit wird alle fünf Stunden zurückgesetzt, und **Settings** → **Usage** zeigt, wann.
2. **Wechseln Sie in einen höheren Plan.** Anthropic beschreibt Max 5x als ideal für häufige Nutzer und Max 20x als ideal für tägliche Nutzer, die Claude für die meisten Aufgaben einsetzen. Die Limits eines neuen Plans gelten sofort.
3. **Aktivieren Sie Nutzungsguthaben.** Mit Guthaben arbeiten Sie nach einem Limit weiter, abgerechnet zu Standard-API-Preisen. Sie können eine monatliche Ausgabenobergrenze festlegen.
4. **Verbrauchen Sie weniger pro Nachricht.** Beginnen Sie eine neue Unterhaltung, statt eine lange fortzusetzen, senken Sie die Effort-Stufe, schalten Sie Extended Thinking und nicht benötigte Tools aus und kürzen Sie Projektanweisungen.

Wenn Sie das Fünf-Stunden-Limit mitten in einer Antwort von Claude Code erreichen, kann Claude Code den aktuellen Schritt noch abschließen, bevor es anhält. Bei Pro passiert das höchstens einmal pro wöchentlichem Nutzungszeitraum.

## Unbegrenzter Claude-Web-Chat für USD 8

Capriole AI Premium kostet USD 8 pro Monat für unbegrenzten Web-Chat mit jedem unterstützten Modell, darunter Claude Fable 5.1, Claude Opus 5.5, GPT-6 Astra und Gemini 4 Argon.

Der Web-Chat von Capriole AI hat kein Fünf-Stunden-Sitzungslimit und kein Wochenlimit, nur ein Fair-Use-Limit von 200 Nachrichten pro Konto und Tag.

Fable 5.1 braucht kein Nutzungsguthaben. Jedes Modell gehört zum selben unbegrenzten Web-Chat, und Sie können [mitten im Chat das Modell wechseln](/de/articles/switch-models-mid-chat), etwa von Claude Opus 5.5 zu Claude Fable 5.1 für einen schwierigeren Schritt, ohne neu anzufangen.

Premium enthält außerdem kostenlose Bilderzeugung mit GPT Image 2.5 und Nano Banana 2.1, Dateien und Websuche, Projekte, Chat-Export, Personalisierung und Speichersteuerungen.

## Intensive Nutzung von Coding-Agents: der Weg über die API

Unbegrenzter Web-Chat deckt keine Coding-Agents ab. Für Claude Code und andere Agents nutzen Sie einen Capriole-AI-API-Schlüssel. Agent-Anfragen greifen auf ein gemessenes API-Guthaben zu, das bis zu 92% weniger kostet als die offiziellen API-Preise.

| Modell | Offizieller API-Preis pro 1M Tokens (Eingabe / Ausgabe) | Capriole AI |
|---|---|---|
| Claude Fable 5.1 | USD 10 / USD 50 | USD 8 pro 5M Tokens |
| Claude Opus 5.5 | USD 4 / USD 20 | USD 8 pro 5M Tokens |
| GPT-6 Astra | USD 10 / USD 50 | USD 8 pro 5M Tokens |

USD 8 pro 5M Tokens entsprechen USD 1.60 pro Million, für Eingabe und Ausgabe gleichermaßen. Premium enthält 5M API-Tokens pro Monat, und Aufstockungen kosten USD 8 pro 5M Tokens für jedes unterstützte Modell. Gecachte Eingabe zählt zu 10%, wie [Abgerechnete Tokens](/de/articles/charged-tokens) erklärt.

Claude Code verbindet sich über den Anthropic-Messages-Endpunkt von Capriole AI. Derselbe Schlüssel funktioniert mit [10 dokumentierten Coding-Agents](/de/guides/one-api-key-coding-agents), darunter Codex. Beginnen Sie mit der [Einrichtung von Claude Code](/de/integrations/claude-code).

Claude Max enthält monatliches API-Guthaben, aber [laut Anthropic](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans) deckt es weder interaktive Claude-Code-Sitzungen noch zusätzliche Nutzung nach Erreichen der Plan-Limits ab.

## Worauf Sie verzichten

Capriole AI ist ein unabhängiger Arbeitsbereich und steht in keiner Verbindung zu Anthropic. Es ist nicht die Claude-App. Funktionen, die es nur in den Produkten von Anthropic gibt, etwa Artifacts, Konnektoren, Erinnerungen, Claude in Chrome sowie die Desktop- und Mobil-Apps von Claude, gehören nicht zu Capriole AI. Claude Code funktioniert weiterhin, über den oben beschriebenen API-Weg.
