## Warum Capriole AI

Capriole AI bietet außerdem kostenlose Bilderzeugung mit **GPT Image 2.5** im Browser-Chat für angemeldete Free-, Premium- und Team-Konten mit **Server Storage**. Nutze den Modus **Image** oder bitte den **Text Agent** während des Chats darum. Die Bilderzeugung verbraucht kein API-Tokenkontingent; Text-Agent-Nachrichten unterliegen weiterhin den normalen Chat-Limits. Dies ist eine Browser-Funktion, keine öffentliche Bild-API und kein Modell für Coding-Agenten.

[Zur Anleitung für die Bilderzeugung](/de/guides/files-web-search).

Capriole AI gibt Ihnen eine API für führende KI-Modelle.

Sie pflegen eine Integration und wechseln bei Bedarf zwischen Modellen.

- Eine API für den Modellzugriff
- Wechseln Sie zwischen unterstützten Modellen, ohne Ihre Integration zu ändern
- Klare, einfache Preise mit Token-Paketen zu deutlich niedrigeren Kosten

## Einmal konfigurieren

Verwenden Sie `openai-latest`, `claude-latest` oder `google-latest`, wenn Capriole AI Ihre API oder Ihren Coding-Agent auf unserem empfohlenen Flaggschiff-Modell für diesen Anbieter halten soll.

Verwenden Sie eine konkrete Modell-ID, wenn Sie eine genaue Modellversion für Tests, Audits oder reproduzierbare Läufe benötigen.
