Dasselbe Konto enthält eine API, die bis zu 92% weniger kostet als die offiziellen API-Preise, sodass Ihre Apps und Coding-Agents mit einem Schlüssel laufen.

Capriole AI wird von Capriole Investments entwickelt; die Marktdatenplattform [Capriole Quant](https://quant.capriole.com/) (ehemals Capriole Charts) und der Investmentfonds des Unternehmens sind von Capriole AI getrennte Produkte. Aktive Abonnenten von Capriole Quant erhalten kostenlosen Zugang zu Capriole AI.

## Unbegrenzter Chat für USD 8

- Premium kostet USD 8 im Monat und umfasst unbegrenzten Web-Chat mit allen unterstützten Modellen, darunter GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5 und Gemini 4 Argon.
- Wechseln Sie im selben Chat das Modell, wenn ein anderes Modell besser zur nächsten Frage passt.
- Für angemeldeten Web-Chat gilt ein Fair-Use-Limit von 200 Nachrichten pro Konto und Tag. Es stoppt skriptgesteuerten, automatisierten Missbrauch; normale Nutzung bleibt weit darunter.
- Gäste können ohne Konto 5 Nachrichten pro Tag ausprobieren. Ein kostenloses Konto bietet zusätzlich 500.000 Tokens Web-Chat im Monat.

[Pläne und Limits vergleichen](/de/guides/plans-and-limits) oder [ein Modell wählen](/de/guides/choose-a-model).

## API bis zu 92% unter den offiziellen Preisen

- Ein API-Schlüssel funktioniert mit Clients für OpenAI Chat Completions, OpenAI Responses und Anthropic Messages.
- Premium enthält ein monatliches API-Kontingent; Aufstockungen kosten USD 8 pro 5M Tokens für jedes unterstützte Modell. [Claude API Preise](/de/articles/claude-api-pricing) und [OpenAI API Preise](/de/articles/openai-api-pricing) zeigen, wie die 92% aus den offiziellen Preisen berechnet werden.
- Derselbe Schlüssel betreibt 10 dokumentierte Coding-Agents, darunter Codex, Claude Code, GitHub Copilot CLI und OpenCode. Siehe [einen API-Schlüssel mit Coding-Agents nutzen](/de/guides/one-api-key-coding-agents).

Starten Sie mit dem [API-Schnellstart](/de/quickstart).

## Einmal konfigurieren

Verwenden Sie `openai-latest`, `claude-latest` oder `google-latest`, wenn Capriole AI Ihre API oder Ihren Coding-Agent auf unserem empfohlenen Flaggschiff-Modell für diesen Anbieter halten soll.

Verwenden Sie eine konkrete Modell-ID, wenn Sie eine genaue Modellversion für Tests, Audits oder reproduzierbare Läufe benötigen.

## Ebenfalls enthalten

Angemeldete Free-, Premium- und Team-Konten mit **Server Storage** können im Web-Chat kostenlos Bilder mit **GPT Image 2.5** und **Nano Banana 2.1** erstellen. Dateien, Websuche, Projekte, Chat-Export und Speichersteuerungen sind in den Arbeitsbereich integriert. [Zur Anleitung für die Bilderzeugung](/de/guides/files-web-search).
