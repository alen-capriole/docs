## OpenClaw とは

OpenClaw は、オープンソースでセルフホスト型の個人向け AI アシスタント兼ゲートウェイです。WhatsApp、Slack、Discord、Telegram、iMessage、WebChat などのチャット チャネルを AI エージェントにつなぎます。このセットアップでは、Capriole AI が提供する API プロトコルごとに 1 つずつ、計 3 つのカスタム モデル プロバイダーとして Capriole AI を追加します。

## 前提条件

始める前に、次を用意してください。

- Capriole AI アカウント（[こちらから登録](https://capriole.ai)）
- Capriole AI API キー（[キーを取得](https://capriole.ai?view=api)）

## インストール

公式のインストール スクリプトで OpenClaw をインストールします。

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

次に、OpenClaw 自体のセットアップを完了します。

```bash
openclaw onboard
```

各設定の役割は次のとおりです。

- `capriole-ai-openai` は GPT モデルを Responses API に送ります。`capriole-ai-anthropic` は Claude モデルを Anthropic Messages に送ります。`capriole-ai-compatible` は Gemini、Grok、GLM、Kimi のモデルを Chat Completions に送ります。
- `${CAPRIOLE_AI_API_KEY}` は環境変数からキーを読み取ります。
- `authorization-bearer` を指定した `request.auth` により、Anthropic プロバイダーはキーを Bearer トークンとして送ります。これがないとキーは `x-api-key` ヘッダーで送られますが、Capriole AI はこれを受け付けません。
- OpenClaw が `/v1/messages` を自動で付加するため、Anthropic の `baseUrl` には `/v1` を付けません。
- Opus 5.5 では `reasoning` を `false` にします。`true` の場合、OpenClaw は思考予算を送り、Opus 5.5 はそれを `requires adaptive thinking` で拒否します。
- `contextWindow` と `maxTokens` は各モデルの上限を OpenClaw に伝えます。
- `agents.defaults.models` はエージェントが使えるモデルの一覧です。`agents.defaults.model.primary` はデフォルト モデルです。

## OpenClaw を実行する

OpenClaw を起動するすべてのターミナルでキーをエクスポートします。

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
```

ゲートウェイを起動します。

```bash
openclaw gateway
```

別のターミナルでターミナル UI を開きます。

```bash
openclaw tui
```

ゲートウェイを使わずにローカルで単発実行するには、次のようにします。

```bash
openclaw agent --local --session-id capriole-test --message "Summarize the files in my workspace."
```

## 対応モデル

モデル参照は `<provider-id>/<model-id>` の形式です。

| モデル | モデル参照 | プロトコル |
| --- | --- | --- |
| OpenAI latest | `capriole-ai-openai/openai-latest` | Responses |
| GPT-6.1 Sol | `capriole-ai-openai/openai/gpt-6.1-sol` | Responses |
| Claude latest | `capriole-ai-anthropic/claude-latest` | Anthropic Messages |
| Opus 5.5 | `capriole-ai-anthropic/claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `capriole-ai-compatible/google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `capriole-ai-compatible/xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `capriole-ai-compatible/zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `capriole-ai-compatible/moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `capriole-ai-compatible/moonshot/kimi-k3` | Chat Completions |

`openai-latest` と `claude-latest` は、常に各ファミリーの最新の旗艦モデルを指します。

## トラブルシューティング

### 認証が失敗するのはなぜですか？

`openclaw gateway` または `openclaw agent` を起動するターミナルで `CAPRIOLE_AI_API_KEY` をエクスポートしてください。変数が設定されていない場合、OpenClaw は `missing env var` と表示します。

### Opus 5.5 が `requires adaptive thinking` で失敗するのはなぜですか？

`claude-opus-5-5` の `reasoning` を `false` に設定してください。

### OpenClaw がモデルは許可されていない、または見つからないと報告するのはなぜですか？

`openclaw models list` を実行してください。モデル参照が `agents.defaults.models` にあること、およびモデルのエントリーが `id` と `name` だけでなく、上記の完全なオブジェクトになっていることを確認してください。

### 新しいセッションがセットアップの会話から始まるのはなぜですか？

これは OpenClaw の初回起動時のワークスペース セットアップであり、Capriole AI の問題ではありません。`openclaw tui` で一度完了させるか、`openclaw onboard` を再度実行してください。

### ゲートウェイが起動しないのはなぜですか？

`openclaw status`、`openclaw gateway status`、`openclaw logs --follow`、`openclaw doctor` を実行してください。

## 注意事項

- Capriole AI の別のモデルを追加するには、同じファミリーのモデルのエントリーをコピーして ID を変更し、その参照を `agents.defaults.models` に追加します。`GET https://api.caprioletech.com/v1/models` ですべてのモデル ID を一覧できます。
