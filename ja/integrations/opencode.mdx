## OpenCode とは

OpenCode は、ターミナル インターフェイス、デスクトップ アプリ、IDE 拡張機能として使えるオープンソースの AI コーディング エージェントです。このセットアップでは、Capriole AI を 1 つのカスタム プロバイダーとして追加します。各モデルは、Capriole AI がそのモデル ファミリー向けに提供している API プロトコルを使います。

## 前提条件

始める前に、次を用意してください。

- Capriole AI アカウント（[こちらから登録](https://capriole.ai)）
- Capriole AI API キー（[キーを取得](https://capriole.ai?view=api)）

## インストール

公式のインストール スクリプトで OpenCode をインストールします。

```bash
curl -fsSL https://opencode.ai/install | bash
```

または、npm でインストールします。

```bash
npm install -g opencode-ai
```

インストールを確認します。

```bash
opencode --version
```

## 設定

### モデルの検証

OpenCode 1.19.3 は、下記の設定を使い、「対応モデル」のすべてのモデルで、Capriole AI 経由のファイル読み取り、ファイル書き込み、最終回答の確認に合格しています。

`~/.config/opencode/opencode.json` を作成または更新します。

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
        }
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "openai/gpt-6.1-sol": {
          "name": "GPT-6.1 Sol",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "claude-latest": {
          "name": "Claude latest",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "claude-opus-5-5": {
          "name": "Opus 5.5",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "google/gemini-3.8-flash": {
          "name": "Gemini 3.8 Flash",
          "limit": {
            "context": 1048576,
            "output": 65536
          }
        },
        "xai/grok-4.7": {
          "name": "Grok 4.7",
          "limit": {
            "context": 500000,
            "output": 128000
          }
        },
        "zai/glm-5.3-flash": {
          "name": "GLM 5.3 Flash",
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "moonshot/kimi-k3": {
          "name": "Kimi K3",
          "limit": {
            "context": 1048576,
            "output": 131072
          }
        }
      }
    }
  }
}
```

各設定の役割は次のとおりです。

- `npm: "@ai-sdk/openai-compatible"` はプロバイダーのデフォルト パッケージです。そのため、Gemini、Grok、GLM、Kimi は Chat Completions を使います。
- 各 GPT モデルは `provider.npm` を `@ai-sdk/openai` で上書きし、Responses API を使います。各 Claude モデルは `@ai-sdk/anthropic` で上書きし、Anthropic Messages を使います。
- `baseURL` には、どのパッケージでも `/v1` を含めます。
- `{env:CAPRIOLE_AI_API_KEY}` は環境変数からキーを読み取ります。`Authorization` ヘッダーにより、どのパッケージでもキーが Bearer トークンとして送られます。このヘッダーがないと、Anthropic パッケージはキーを `x-api-key` ヘッダーで送りますが、Capriole AI はこれを受け付けません。
- `limit` は各モデルのコンテキスト ウィンドウと出力上限を OpenCode に伝えます。これにより、OpenCode はコンテキストを追跡し、適切なタイミングでセッションを圧縮できます。
- `small_model` は、セッション タイトルの生成などの軽いタスクに OpenCode が使うモデルです。

## OpenCode を実行する

API キーを設定してから、プロジェクト ディレクトリから OpenCode を起動します。

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
opencode
```

`/models` でモデルを切り替えます。非対話で実行するには、`opencode run` を使います。

```bash
opencode run -m capriole-ai/claude-latest "Explain this repository."
```

## 対応モデル

モデル参照は `capriole-ai/<model-id>` の形式です。

| モデル | モデル ID | プロトコル |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` と `claude-latest` は、常に各ファミリーの最新の旗艦モデルを指します。

## トラブルシューティング

### OpenCode が認証エラーを返すのはなぜですか？

OpenCode を起動する前に同じシェルで `CAPRIOLE_AI_API_KEY` がエクスポートされていること、および `options.headers` の下に `Authorization` ヘッダーがあることを確認してください。

### Claude のリクエストが `Unsupported Claude Messages model` で失敗するのはなぜですか？

`@ai-sdk/anthropic` を使う Claude モデルには、`claude-opus-5-5` などのプレフィックスなしの Claude ID が必要です。`anthropic/` プレフィックス付きの ID は Chat Completions 用です。

### GPT のリクエストが失敗するのはなぜですか？

各 GPT モデルに `"provider": { "npm": "@ai-sdk/openai" }` があり、リクエストが Responses API を使うことを確認してください。

### Capriole AI のモデルが表示されないのはなぜですか？

モデル参照が `capriole-ai/moonshot/kimi-k3` のように `capriole-ai/<model-id>` の形式であること、および `disabled_providers` が `capriole-ai` をブロックしていないことを確認してください。

### 設定の変更が反映されないのはなぜですか？

プロジェクト レベルの `opencode.json` や `OPENCODE_CONFIG` による上書きがないか確認してから、OpenCode を再起動してください。

### プロバイダー パッケージのエラーが出るのはなぜですか？

`~/.cache/opencode` をクリアして OpenCode を再起動し、プロバイダー パッケージを再インストールさせてください。

## 注意事項

- キーは環境変数に保持してください。`opencode.json` に貼り付けないでください。
- Capriole AI の別のモデルを追加するには、同じファミリーのモデルのエントリーをコピーして ID を変更します。`GET https://api.caprioletech.com/v1/models` ですべてのモデル ID を一覧できます。
