## Kilo Code とは

Kilo Code は、VS Code とターミナル向けの AI コーディング エージェントです。このセットアップでは、Capriole AI を 1 つのカスタム プロバイダーとして追加します。各モデルは、Capriole AI がそのモデル ファミリー向けに提供している API プロトコルを使います。

## 前提条件

始める前に、次を用意してください。

- Capriole AI アカウント（[こちらから登録](https://capriole.ai)）
- Capriole AI API キー（[キーを取得](https://capriole.ai?view=api)）

## インストール

### Kilo CLI

```bash
npm install -g @kilocode/cli
```

インストールを確認します。

```bash
kilo --version
```

### VS Code 拡張機能

VS Code の拡張機能ビューから Kilo Code をインストールします。拡張機能は CLI と同じグローバル設定ファイルを読み込みます。

## 設定

### モデルの検証

Kilo CLI 7.8.15 は、下記の設定を使い、「対応モデル」のすべてのモデルで、Capriole AI 経由のファイル読み取り、ファイル書き込み、最終回答の確認に合格しています。

`~/.config/kilo/kilo.jsonc` を作成または更新します。

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
        }
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          },
          "tool_call": true
        },
        "openai/gpt-6.1-sol": {
          "name": "GPT-6.1 Sol",
          "provider": {

          },

          },

        },
        "claude-latest": {

        "google/gemini-3.8-flash": {
          "name": "Gemini 3.8 Flash",
          "limit": {
            "context": 1048576,

        "xai/grok-4.7": {

          "name": "Kimi K3",

            "context": 1048576,
            "output": 131072
          },
          "tool_call": true
        }
      }
    }
  }
}
```

各設定の役割は次のとおりです。

- `npm: "@ai-sdk/openai-compatible"` はプロバイダーのデフォルト パッケージです。そのため、Gemini、Grok、GLM、Kimi は Chat Completions を使います。
- 各 GPT モデルは `provider.npm` を `@ai-sdk/openai` で上書きし、Responses API を使います。各 Claude モデルは `@ai-sdk/anthropic` で上書きし、Anthropic Messages を使います。
- `{env:CAPRIOLE_AI_API_KEY}` は環境変数からキーを読み取ります。`Authorization` ヘッダーにより、どのパッケージでもキーが Bearer トークンとして送られます。このヘッダーがないと、Anthropic パッケージはキーを `x-api-key` ヘッダーで送りますが、Capriole AI はこれを受け付けません。
- `tool_call: true` により、モデルが Kilo のツールを呼び出せるようになります。
- `limit` は各モデルのコンテキスト ウィンドウと出力上限を設定します。これがないと、Kilo は両方を `0` として扱い、長いセッションを圧縮しません。

このプロバイダーはグローバル設定に置いてください。Kilo はプロジェクト レベルの設定内の `{env:...}` 参照を解決しません。

ファイルを編集したら、`kilo config check` を実行してください。

## Kilo Code を実行する

API キーを設定してから、プロジェクト ディレクトリから Kilo を起動します。

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo
```

特定のモデルで起動します。

```bash
kilo -m capriole-ai/openai-latest
```

単発のリクエストでは、`kilo run` にプロンプトを渡します。

```bash
kilo run -m capriole-ai/claude-latest "Explain this repository."
```

## 対応モデル

モデル参照は `capriole-ai/<model-id>` の形式です。

| モデル | モデル ID | プロトコル |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` と `claude-latest` は、常に各ファミリーの最新の旗艦モデルを指します。

## トラブルシューティング

### Kilo Code が認証エラーを返すのはなぜですか？

`kilo` を実行する前に同じシェルで `CAPRIOLE_AI_API_KEY` がエクスポートされていること、およびプロバイダーがプロジェクト設定ではなく `~/.config/kilo/kilo.jsonc` にあることを確認してください。

### Claude のリクエストが `Unsupported Claude Messages model` で失敗するのはなぜですか？

`@ai-sdk/anthropic` を使う Claude モデルには、`claude-opus-5-5` などのプレフィックスなしの Claude ID が必要です。`anthropic/` プレフィックス付きの ID は Chat Completions 用です。

### Kilo Code がモデルが見つからないと表示するのはなぜですか？

選択したモデルが `capriole-ai/<model-id>` の形式であること、および `provider.capriole-ai.models` に一致するエントリーがあることを確認してください。`kilo models capriole-ai` を実行すると、Kilo が読み込んだモデルを一覧できます。

### ツール利用が失敗するのはなぜですか？

モデルのエントリーに `"tool_call": true` が含まれていることを確認してください。

## 注意事項

- Kilo Code はコーディング ツールをお使いのコンピューター上で実行します。Capriole AI が処理するのはモデル リクエストだけです。
- Capriole AI の別のモデルを追加するには、同じファミリーのモデルのエントリーをコピーして ID を変更します。`GET https://api.caprioletech.com/v1/models` ですべてのモデル ID を一覧できます。
- 公式リファレンス: [Kilo CLI](https://kilo.ai/docs/cli)、[Kilo のカスタム モデル](https://kilo.ai/docs/code-with-ai/agents/custom-models)、[Kilo の設定](https://kilo.ai/docs/getting-started/settings)、[OpenCode のプロバイダー](https://opencode.ai/docs/providers)。
