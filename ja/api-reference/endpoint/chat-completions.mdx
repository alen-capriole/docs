アプリケーション、SDK、またはゲートウェイが OpenAI Chat Completions のリクエストとレスポンス形式を前提としている場合は、このエンドポイントを使ってください。

`model` と `messages` を含む標準の Chat Completions ペイロードを送信します。Capriole AI は上流へ送る前に latest エイリアスを選択したプロバイダーのモデル ID に解決し、`messages`、`tools`、`tool_choice`、`response_format`、`stream` などの互換フィールドを転送し、上流の JSON または SSE ストリームを、下記の GLM SSE 修正とハートビート コメントを除いてそのまま返します。ストリーミング リクエストでは、使用量を記録できるよう、転送前に `stream_options.include_usage=true` を設定します。

`model="zai/glm-5.3-flash"` の一部の SSE 応答では、Capriole AI はデルタ内の空の旧式フィールド `function_call={"name":"","arguments":""}` だけを削除します。実際の関数呼び出しやその途中のデータ、`tool_calls`、テキスト、使用量は保持します。この例外は非ストリーミング応答や他のモデルには適用されません。

`POST /v1/chat/completions` は `openai-latest`、`claude-latest`、`google-latest`、および `GET /v1/models` が返す公開の具体的なモデル ID を受け付けます。各プロバイダーで当社が推奨する旗艦モデルを Capriole AI に選ばせるには、latest エイリアスを使ってください。

latest エイリアスは、モデル ID の代わりに指定できる略記です。使用量は解決後のモデルに対して記録され、レスポンス本文のモデル名は、選択した互換エンドポイント本来の表記のままです。

## Kimi K3.1 Pro

Kimi K3.1 Pro は `temperature` を 1、`top_p` を 0.95 に固定しています。このモデルでは `temperature`、`top_p`、`n`、`presence_penalty`、`frequency_penalty` を省略し、指示は `developer` ではなく `system` ロールで送ってください。

## Gemini 4 Carbon

`google-latest` は `google/gemini-4-carbon` に解決されます。このエンドポイントはリクエストの残りをそのまま転送するため、Gemini 4 Carbon は Google の既定の思考レベル `medium` で思考します。当社のテストでは、同じプロンプトで Gemini 4 Argon の約 3〜4 倍の出力トークンを使いました。OpenAI の `reasoning_effort` では Carbon の思考レベルは変わりません。設定するには、Google のフィールドを `low`、`medium`、`high` のいずれかで送信してください。

```json
"extra_body": {"google": {"thinking_config": {"thinking_level": "low"}}}
```

OpenAI Python SDK では `extra_body={"extra_body": {"google": {"thinking_config": {"thinking_level": "low"}}}}` を渡してください。Google によると、Carbon では難しいプロンプトに数分かかることがあるため、[長時間のタスク](#長時間のタスク)のとおりストリーミングしてください。待ち時間を短くしたい場合は、`thinking_level` を `low` にするか、`google/gemini-4-argon` を使ってください。

## Gemini 4 Neon

Neon を選ぶには `google/gemini-4-neon` を指定してください。Google のモデル仕様では、入力と出力で共有するコンテキストウィンドウは 1,048,576 トークン、同期出力の既定の上限は 65,536 トークンです。JSON Schema に対応し、思考レベルは `low`、`medium`、`high`（既定）、`xhigh` です。[Google のモデルドキュメント](https://aistudio.google.com/docs/models/gemini-4-neon)をご覧ください。

## ウェブ検索

このエンドポイントはウェブ検索を提供しません。Grok モデルでは、`web_search_options` または `search_parameters` フィールドが null 以外のリクエストは HTTP 400 で失敗します。

```json
{
  "detail": "Web search is not supported for xai/grok-4.7 on /v1/chat/completions. Use POST /v1/responses with tools: [{\"type\": \"web_search\"}]."
}
```

クライアントが定義した関数ツールは、`web_search` という名前でもそのまま転送されます。GPT または Grok でウェブを検索するには、[`POST /v1/responses`](/ja/api-reference/endpoint/responses) で `"tools": [{"type": "web_search"}]` を使ってください。

## 長時間のタスク

長い推論などの長時間タスクでは `"stream": true` を設定してください。ストリーミングを使わない場合、約 2 分で接続がタイムアウトすることがあります。ストリームがモデルを待っている間、Capriole AI は 15 秒ごとに SSE の `: heartbeat` コメントを送ります。ストリーミングする `google/*` リクエストは、最初のトークンを最大 20 分待てます。モデルが 60 秒以内に応答しなかった場合は 200 レスポンスがすでに始まっているため、その後に上流で発生したエラーは、`error` オブジェクトを含む最後の SSE イベントとして届きます。
