最先端モデル チャット、API アクセス、コーディング エージェントを、予測可能な 1 つのワークスペースで欲しいユーザーにとって、**Capriole AI のほうが強い選択です**。サインアウト中の訪問者と Free ユーザーは GPT-5.6 Thinking、Claude Fable 5.1、Gemini 3.1 Pro を試せます。USD 8 の Premium プランは、無制限の Browser Chat、毎月 500 万の課金 API トークン、維持されている 6 つのコーディング エージェント統合を追加します。

Poe は、無制限 Browser Chat と見える included API 残高を分けるのではなく、対象となる製品活動全体に compute points を適用します。

この比較では、Poe の購入 FAQ、一般 FAQ、プライバシー ポリシー、クリエイター ドキュメントを確認しました。両製品ともマルチモデル チャットとデベロッパー アクセスを提供しますが、使用量とストレージの規則が異なります。

## 簡易比較

| 領域 | Capriole AI | Poe |
|---|---|---|
| 現在の旗艦アクセス | 1 つのワークスペースで GPT-5.6 Thinking、Claude Fable 5.1、Gemini 3.1 Pro | 公式およびユーザー作成の bot またはアプリでアクセスが整理される |
| 支払いに含まれるもの | USD 8 Premium に無制限 Browser Chat と月 5M の課金 API トークンが含まれる | 有料活動は選択したモデルと操作に応じて compute points を消費する |
| 使用量の予測しやすさ | Premium の Browser Chat は無制限。API とエージェント使用量には見える月次残高がある | ポイント使用量はモデル、コンテキスト、ファイル、検索、活動によって変わる |
| 公開プロトコル | OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Capriole ネイティブ エンドポイント | OpenAI Chat Completions、OpenAI Responses、Claude モデル向け Anthropic Messages |
| コーディング エージェント経路 | Capriole が維持する 6 つのセットアップ ガイド | 複数のコーディング クライアント向けの公式セットアップ ドキュメント |
| チャット ストレージ | Synced、ブラウザ ローカル、または No Storage 履歴モード | デフォルトは Private chats。公式 bot 向けに temporary chat |

ゲートウェイ、チャット製品、BYOK クライアントのより広い見方は、[OpenRouter 代替ガイド](/ja/articles/openrouter-alternatives) を参照してください。

## Capriole がより良い日常ワークスペースである理由

Capriole は bot マーケットプレイスではなく、完全な作業アカウントから始まります。サインアウト中の訪問者と Free ユーザーは、制限付き Browser Chat で対応旗艦モデルを試せます。Premium はその後、無制限 Browser Chat、月次 API 許容量、維持されている外部ツール経路を追加し、複数のプロバイダー アカウントを管理するよう求めません。

ファイル、ウェブ検索、履歴、モデル切り替えは 1 つのインターフェイスに残ります。タスクは Browser Chat のドキュメントから始まり、同じスレッドで別の対応モデルに続き、同じ Capriole アカウント経由でアプリケーションまたはコーディング エージェントへ移れます。

## チャットと API 使用量の予測しやすい分割

Poe サブスクリプションは、プランに応じて日次または月次のスケジュールで compute points を発行します。未使用ポイントは、プランが別途述べない限り、一般に繰り越されません。消費量は選択したモデルと活動で変わります。

サブスクライバーと API ユーザーはアドオン ポイントを買えます。Poe は現在、API アドオンを 100 万ポイントあたり USD 30 から掲載しており、購入したアドオンは 1 年間利用できます。

Poe のポイントと Capriole の課金 API トークンは直接比較できません。異なるシステムを測っています。モデル コスト、コンテキスト長、ファイル、検索、実行中の活動は、Poe 残高の消費速度を変える場合があります。

Capriole Premium はより単純な分割を使います。対応する Premium モデル群の Browser Chat は無制限です。プログラム作業は含まれる毎月 500 万の課金 API トークンに対して計量され、トップアップは別に販売されます。コーディング エージェント トラフィックは API トラフィックとして数えます。

[1 つの AI サブスクリプション ガイド](/ja/articles/one-ai-subscription) は、その境界をより詳しく説明します。どれだけのプログラム作業を走らせるかを決める前に、Browser Chat の約束と API 残高を見られます。

## プロトコルは重なる。バンドルは重ならない

Capriole は、すでに OpenAI Chat Completions、OpenAI Responses、または Anthropic Messages を話すクライアント向けにプロトコル エンドポイントを公開します。公開エンドポイントは、外部アプリケーションまたはエージェントが呼び出す製品サーフェスです。

コーディング エージェント向けに、Capriole は [6 つのセットアップ経路](/ja/articles/coding-agent-compatibility) を維持します。エージェントは引き続き独自のツールをローカルで実行します。Capriole は対応モデル プロトコルとアカウント残高を供給します。

Poe は Chat Completions と Responses エンドポイント、加えて Claude モデル向けの Anthropic Messages エンドポイントを公開します。Claude Code と複数の OpenAI 互換コーディング クライアント向けのセットアップ ドキュメントも公開します。したがって、プロトコルの可用性だけが Capriole を選ぶ理由ではありません。

Capriole の違いは、それらのデベロッパー経路を囲む完全な USD 8 バンドルです。無制限の Premium Browser Chat、毎月 500 万の課金 API トークン、Capriole が維持する 6 つの統合ガイド、明示的なワークスペース ストレージ制御です。Poe は対象となるチャットと API 活動で同じポイント残高を使うため、頻繁な Browser Chat とコーディング エージェント作業は同じ計量システムから引きます。

## Capriole ではストレージ制御が見えるまま

Capriole はチャット履歴の永続化を Account 設定に直接置きます。Synced モードはアカウント履歴を保存します。Local モードは履歴を現在のブラウザに残します。No Storage モードは保存チャット履歴を残しません。[チャット ストレージ ガイド](/ja/guides/chat-storage) は、見える設定、削除ステップ、それらの選択に伴うアップロード制限を扱います。

Local と No Storage モードは、プロンプトが Capriole のサービスと選択したモデル プロバイダーを通ることを止めません。ワークスペース内のチャット履歴の永続化を制御します。

## クリエイター マーケットプレイスは別の購入

Poe は bot の発見、公開、Canvas アプリを中心にします。Capriole はユーザー自身の作業を中心にします。最先端モデルへのアクセスを買う人にとって、無制限の Premium Browser Chat、見える API 許容量、コーディング エージェント統合、ストレージ制御は、クリエイター マーケットプレイスより完全な日常ワークスペースを作ります。

## ワークフローを Capriole へ持ち込む

対応する最先端モデル、無制限の Premium Browser Chat、明確な月次 API 許容量、維持されている 6 つのエージェント経路、ストレージ制御を 1 つのアカウントの下で欲しいときは、Capriole を選んでください。

[制限付きの無料 Browser Chat を試す](https://capriole.ai)。同じ Capriole ワークスペースが履歴をどう保つかは、[ストレージ ガイド](/ja/guides/chat-storage) で選んでください。
