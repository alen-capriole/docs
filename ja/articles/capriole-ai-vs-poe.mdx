最先端モデルとのチャット、API アクセス、コーディング エージェントを、使用量の見通しが立つ 1 つのワークスペースで使いたいなら、**Capriole AI は無制限のチャットと残高が見える API を分けて提供します**。USD 9 の Premium プランでは、GPT-6.2 Astra、Claude Fable 5.2、Claude Opus 5.5、Gemini 4 Carbon とのウェブチャットが無制限になり、公式 API 価格より最大 92% 安い API アクセスと、10 のコーディング エージェント向けセットアップ ガイドも利用できます。サインアウト中の訪問者と Free ユーザーは、まず旗艦モデルを試せます。

Poe は、無制限のウェブチャットと残高が見える API 利用枠を分けず、対象となるすべての利用で compute points を消費します。

この比較では、2026 年 11 月 17 日に Poe の購入 FAQ、一般 FAQ、プライバシー ポリシー、クリエイター ドキュメントを確認しました。両製品ともマルチモデル チャットとデベロッパー アクセスを提供しますが、使用量とストレージの規則が異なります。

## Capriole がより良い日常ワークスペースである理由

Capriole は bot マーケットプレイスではなく、完全な作業アカウントから始まります。サインアウト中の訪問者と Free ユーザーは、無料のウェブチャットで対応旗艦モデルを試せます。Premium はその後、無制限のウェブチャット、月次 API 利用枠、継続的に整備している外部ツール経路を追加し、複数のプロバイダー アカウントを管理するよう求めません。

ファイル、ウェブ検索、履歴、チャットをまたぐメモリ、モデル切り替えは 1 つのインターフェイスに残ります。タスクはウェブチャットのドキュメントから始まり、同じスレッドで別の対応モデルに続き、同じ Capriole アカウント経由でアプリケーションまたはコーディング エージェントへ移れます。

Server Storage を使うログイン済みアカウントでは、GPT Image 2.6、Nano Banana 2.1、Seedream 5.5 による無料の画像生成も利用できます。詳しくは [画像生成ガイド](/ja/guides/files-web-search) をご覧ください。

## チャットと API 使用量の予測しやすい分割

Poe サブスクリプションは、プランに応じて日次または月次のスケジュールで compute points を発行します。未使用ポイントは、プランが別途述べない限り、一般に繰り越されません。消費量は選択したモデルと活動で変わります。

サブスクライバーと API ユーザーはアドオン ポイントを買えます。Poe は現在、API アドオンを 100 万ポイントあたり USD 30 から掲載しており、購入したアドオンは 1 年間利用できます。

Poe のポイントと Capriole の課金 API トークンは直接比較できません。異なるシステムを測っています。モデル コスト、コンテキスト長、ファイル、検索、実行中の活動は、Poe 残高の消費速度を変える場合があります。

Capriole Premium はより単純な分け方です。ウェブチャットはすべての対応モデルで[無制限](/ja/guides/plans-and-limits#「無制限」の意味)です。プログラム作業は含まれる毎月 500 万の課金 API トークンに対して計量され、チャージは別に販売されます。コーディング エージェント トラフィックは API トラフィックとして数えます。

[1 つの AI サブスクリプション ガイド](/ja/articles/one-ai-subscription) は、その境界をより詳しく説明します。どれだけのプログラム作業を走らせるかを決める前に、ウェブチャットの約束と API 残高を見られます。

## プロトコルは重なる。バンドルは重ならない

Capriole は、すでに OpenAI Chat Completions、OpenAI Responses、または Anthropic Messages を話すクライアント向けにプロトコル エンドポイントを公開します。公開エンドポイントは、外部アプリケーションまたはエージェントが呼び出す製品サーフェスです。

コーディング エージェント向けに、Capriole は [10 のセットアップ経路](/ja/articles/coding-agent-compatibility) を維持します。エージェントは引き続き独自のツールをローカルで実行します。Capriole は対応モデル プロトコルとアカウント残高を供給します。

Poe は Chat Completions と Responses エンドポイント、加えて Claude モデル向けの Anthropic Messages エンドポイントを公開します。Claude Code と複数の OpenAI 互換コーディング クライアント向けのセットアップ ドキュメントも公開します。

Capriole の違いは、それらのデベロッパー経路を囲む完全な USD 9 バンドルです。Premium の無制限のウェブチャット、毎月 500 万の課金 API トークン、Capriole が維持する 10 のコーディング エージェント向けセットアップ ガイド、明示的なワークスペース ストレージ制御です。Poe は対象となるチャットと API 活動で同じポイント残高を使うため、頻繁なウェブチャットとコーディング エージェント作業は同じ計量システムから引きます。

## Capriole ではストレージ制御が見えるまま

Capriole はチャット履歴の永続化を Account 設定に直接置きます。Synced モードはアカウント履歴を保存します。Local モードは履歴を現在のブラウザに残します。No Storage モードは保存チャット履歴を残しません。[チャットの保存ガイド](/ja/guides/chat-storage)では、ファイルのアップロードに使う既定の同期モードの選び方を説明しています。

保存設定で履歴の保存先を選べます。各リクエストは Capriole AI を経由し、処理を担当するモデル提供元またはクラウドプラットフォームに送信されます。

## クリエイター マーケットプレイスは別の購入

Poe は bot の発見、公開、Canvas アプリを中心にします。Capriole はユーザー自身の作業を中心にします。最先端モデルへのアクセスを買う人に向けて、Capriole AI は無制限のウェブチャット、残高が見える API 利用枠、コーディング エージェント連携、ストレージ制御を 1 つのプランにまとめています。

## ワークフローを Capriole へ持ち込む

対応する最先端モデル、無制限の Premium ウェブチャット、明確な月次 API 利用枠、ドキュメントのある 10 種類のエージェント経路、ストレージ制御を 1 つのアカウントの下で欲しいときは、Capriole を選んでください。

[無料ウェブチャットを試す](https://www.capriole.ai/ja) ことも、[USD 9 の Premium にアップグレードして無制限チャットと API キーを入手する](https://www.capriole.ai/ja?view=api) こともできます。同じ Capriole ワークスペースが履歴をどう保つかは、[ストレージ ガイド](/ja/guides/chat-storage) で確認できます。

Capriole AI は、Poe から独立して運営されているワークスペースです。
