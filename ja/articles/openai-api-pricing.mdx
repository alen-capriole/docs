OpenAI の API の料金は、新しい旗艦モデルの **GPT-6.2 Astra が入力 100 万トークンあたり USD 8、出力 100 万トークンあたり USD 40** で、キャッシュ入力は USD 0.40 です。GPT-6 Astra の USD 10 と USD 50 より 20% 安くなっています。GPT-6.2 Sol、GPT-6.1 Sol、GPT-6 Sol は USD 2 と USD 10、GPT-6 Luna は USD 0.10 と USD 0.50 です。出力 1 トークンにつき入力 3 トークンの比率では、OpenAI の標準料金で 500 万トークンは GPT-6.2 Astra で USD 80、GPT-6 Astra で USD 100 になります。

Capriole AI Premium は月額 USD 9 で、GPT-6.2 Astra、Claude Fable 5.2、Claude Opus 5.5、Gemini 4 Carbon とのウェブチャットが無制限です。API は OpenAI Responses と Chat Completions で GPT-6.2 Astra を提供します。個人向け Premium には月に 5,000,000 API トークンが含まれます。どの対応モデルにも使える 5,000,000 トークンの追加パックは USD 8 で、公式 API 料金より最大 92% 割安です。1 つの API キーで、自分のアプリでも Codex などのコーディング エージェントでも使えます。

## 100 万トークンあたりの OpenAI API 料金

OpenAI は次の標準料金を [API の料金ページ](https://developers.openai.com/api/docs/pricing)で公開しています。価格はすべて 100 万トークンあたりの USD で、入力 272,000 トークンまでのプロンプトに適用されます。

| モデル | API モデル ID | 入力 | キャッシュ入力 | キャッシュ書き込み（30 分） | キャッシュ書き込み（12 時間） | 出力 |
|---|---|---:|---:|---:|---:|---:|
| GPT-6.2 Astra | `gpt-6.2-astra` | USD 8 | USD 0.40 | USD 10 | USD 20 | USD 40 |
| GPT-6.2 Sol | `gpt-6.2-sol` | USD 2 | USD 0.10 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Astra | `gpt-6-astra` | USD 10 | USD 1 | USD 12.50 | USD 25 | USD 50 |
| GPT-6.1 Sol | `gpt-6.1-sol` | USD 2 | USD 0.10 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Sol | `gpt-6-sol` | USD 2 | USD 0.20 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Luna | `gpt-6-luna` | USD 0.10 | USD 0.01 | USD 0.125 | USD 0.25 | USD 0.50 |

OpenAI の料金ページとモデル ページには、これらの料金が変わる条件が記載されています。

- **Batch と Flex**: どちらも標準料金の 50% です。Batch では、GPT-6.2 Astra は入力 USD 4、出力 USD 20、GPT-6 Astra は USD 5 と USD 25 です。OpenAI の Flex の料金には GPT-6.2 Astra と GPT-6.2 Sol が掲載されていません。
- **長いプロンプト**: 入力が 272,000 トークンを超えるリクエストは、リクエスト全体に対して入力とキャッシュの料金が 2 倍、出力の料金が 1.5 倍になります。
- **高速モード**: 標準料金の 2 倍です。高速モードの GPT-6.2 Astra は入力 USD 16、出力 USD 80 です。
- **リージョン処理**: 利用できる場合、10% が加算されます。

## 100 万トークンと 500 万トークンのコスト

以下の例は、標準料金、キャッシュなし、272,000 トークン未満のプロンプト、出力 1 トークンにつき入力 3 トークンの条件で計算しています。Capriole AI の API トークン残高が足りていれば、この例の利用で追加の支払いは発生しません。

```text
official_cost = input_millions × input_price + output_millions × output_price
```

| トークン数 | 入力 / 出力 | GPT-6.2 Astra | GPT-6 Astra | GPT-6.2 Sol、GPT-6.1 Sol、または GPT-6 Sol | GPT-6 Luna | Capriole AI の個人向け API チャージ |
|---|---|---:|---:|---:|---:|---:|
| 100 万 | 75 万 / 25 万 | USD 16 | USD 20 | USD 4 | USD 0.20 | USD 1.60 |
| 500 万 | 375 万 / 125 万 | USD 80 | USD 100 | USD 20 | USD 1 | **USD 8** |

GPT-6.2 Astra では、5,000,000 トークンのコストが 3.75 × USD 8 + 1.25 × USD 40 = USD 80 なので、個人向け Premium の追加パック料金 USD 8 は 90% 安くなります。GPT-6 Astra では同じワークロードが USD 100 で、USD 8 は 92% 安くなります。Sol の各モデルでは、USD 8 は 60% 安くなります。同じ使用量での OpenAI の GPT-6 Luna の料金は USD 1 です。Capriole は API トークンを 5,000,000単位のパックで販売しています。1,000,000の行はパックの 5 分の 1 にあたり、比較のために示しています。

Capriole の課金トークンの計算式には長いプロンプト向けの料金区分がないため、300,000 トークンのプロンプトも短いプロンプトと同じトークン単価で数えます。

[無料でチャットを始める](https://www.capriole.ai/ja)ことも、[API キーを取得する](https://www.capriole.ai/ja?view=api)こともできます。

## キャッシュとバッチで比較はどう変わるか

- **キャッシュ入力**: OpenAI はキャッシュされた 100 万トークンあたり、GPT-6.2 Astra で USD 0.40、GPT-6.2 Sol と GPT-6.1 Sol で USD 0.10（いずれも入力料金の 5%）、GPT-6 Astra で USD 1（入力料金の 10%）を請求します。Capriole はどのモデルでもキャッシュ入力を 10% で数えるため、個人向け Premium の追加パック料金では、キャッシュされた 100 万トークンあたり USD 0.16 に相当します。計算式は [Capriole AI の課金トークンの説明](/ja/articles/charged-tokens)で確認できます。
- **キャッシュ書き込み**: OpenAI は、30 分のキャッシュ書き込みに入力の 1.25 倍、12 時間のキャッシュ書き込みに 2.5 倍を請求します。Capriole は、キャッシュ書き込みを含むすべてのキャッシュなし入力トークンを通常のレートで数えます。
- **Batch と Flex**: 半額の場合、GPT-6.2 Astra の 5,000,000 トークンの例は USD 40 です。個人向け Premium の追加パックは 5,000,000 トークンで USD 8 です。このパック価格で比較すると 80% 割安です。

OpenRouter のクレジット手数料も含めた 500 万トークンのテストは、[AI API コスト比較](/ja/articles/ai-api-cost-comparison)をご覧ください。Claude Fable 5.2 と Opus 5.5 は [Claude API の料金](/ja/articles/claude-api-pricing)、Gemini 4 Carbon、Argon、Neon は [Gemini API の料金](/ja/articles/gemini-api-pricing)で確認できます。

## Capriole の API で GPT-6.2 Astra を呼び出す

Capriole の API は、`POST /v1/responses` で OpenAI Responses と、`POST /v1/chat/completions` で OpenAI Chat Completions と互換性があります。OpenAI SDK の base URL を `https://api.caprioletech.com/v1` に設定してください。

- `openai-latest` は GPT-6.2 Astra を選択します。そのため、設定が現在推奨される OpenAI モデルに追従します。
- Responses では、`gpt-6.2-astra` のようなネイティブ ID も、`openai/gpt-6.2-astra` のようなプレフィックス付き ID も同じモデルを選択します。
- Chat Completions は、`openai-latest` と、`GET /v1/models` が返すモデル ID を受け付けます。

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com/v1",
)

response = client.responses.create(
    model="openai-latest",
    input="Write a release note for this change.",
)
print(response.output_text)
```

各キーは 1 分あたり 300 リクエストまで送信できます。使用できるモデル ID の一覧は [Responses リファレンス](/ja/api-reference/endpoint/responses)と [Chat Completions リファレンス](/ja/api-reference/endpoint/chat-completions)、Capriole のキーで Codex を動かす方法は [Codex のセットアップ](/ja/integrations/codex)をご覧ください。

## よくある質問

### GPT-6.2 Astra の料金はいくらですか？

GPT-6.2 Astra は、入力 100 万トークンあたり USD 8、キャッシュ入力 100 万トークンあたり USD 0.40、出力 100 万トークンあたり USD 40 です。GPT-6 Astra は USD 10、USD 1、USD 50 です。Batch のリクエストは半額です。

### 最も安い GPT-6 モデルはどれですか？

GPT-6 Luna です。入力 100 万トークンあたり USD 0.10、出力 100 万トークンあたり USD 0.50 です。

### OpenAI は長いプロンプトに追加料金を請求しますか？

はい。入力が 272,000 トークンを超えるリクエストは、リクエスト全体に対して入力とキャッシュの料金が 2 倍、出力の料金が 1.5 倍になります。

### Capriole AI の `openai-latest` とは何ですか？

`openai-latest` は 2026 年 11 月 18 日から GPT-6.2 Astra を指します。`/v1/responses` と `/v1/chat/completions` で使えます。

### Capriole AI のキーで Codex を使えますか？

はい。Codex はカスタム モデル プロバイダーを使い、Responses API 経由で接続します。設定の全体は [Codex のセットアップ](/ja/integrations/codex)にあります。
