OpenAI の API の料金は、**GPT-6 Astra が入力 100 万トークンあたり USD 10、出力 100 万トークンあたり USD 50** で、キャッシュ入力は USD 1 です。GPT-6.1 Sol と GPT-6 Sol は USD 2 と USD 10、GPT-6 Luna は USD 0.10 と USD 0.50 です。出力 1 トークンにつき入力 3 トークンの比率では、OpenAI の標準料金で GPT-6 Astra の 500 万トークンは USD 100 になります。

Capriole AI Premium は月額 USD 8 で、GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon とのウェブチャットが無制限です。API は OpenAI Responses と Chat Completions で GPT-6 Astra を提供し、料金はどの対応モデルでも 500 万トークンあたり USD 8 と、公式 API 価格より最大 92% 安くなります。1 つの API キーで、自分のアプリでも Codex などのコーディング エージェントでも使えます。

## 100 万トークンあたりの OpenAI API 料金

OpenAI は次の標準料金を [API の料金ページ](https://developers.openai.com/api/docs/pricing)で公開しています。価格はすべて 100 万トークンあたりの USD で、入力 272,000 トークンまでのプロンプトに適用されます。

| モデル | API モデル ID | 入力 | キャッシュ入力 | キャッシュ書き込み（30 分） | キャッシュ書き込み（12 時間） | 出力 |
|---|---|---:|---:|---:|---:|---:|
| GPT-6 Astra | `gpt-6-astra` | USD 10 | USD 1 | USD 12.50 | USD 25 | USD 50 |
| GPT-6.1 Sol | `gpt-6.1-sol` | USD 2 | USD 0.10 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Sol | `gpt-6-sol` | USD 2 | USD 0.20 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Luna | `gpt-6-luna` | USD 0.10 | USD 0.01 | USD 0.125 | USD 0.25 | USD 0.50 |

OpenAI の料金ページとモデル ページには、これらの料金が変わる条件が記載されています。

- **Batch と Flex**: どちらも標準料金の 50% です。GPT-6 Astra は入力 USD 5、出力 USD 25 です。
- **長いプロンプト**: 入力が 272,000 トークンを超えるリクエストは、リクエスト全体に対して入力とキャッシュの料金が 2 倍、出力の料金が 1.5 倍になります。
- **高速モード**: 標準料金の 2 倍です。高速モードの GPT-6 Astra は入力 USD 20、出力 USD 100 です。
- **リージョン処理**: 利用できる場合、10% が加算されます。

## 100 万トークンと 500 万トークンのコスト

以下の例は、標準料金、キャッシュなし、272,000 トークン未満のプロンプト、出力 1 トークンにつき入力 3 トークンの条件で計算しています。

```text
official_cost = input_millions × input_price + output_millions × output_price
```

| トークン数 | 入力 / 出力 | GPT-6 Astra | GPT-6.1 Sol または GPT-6 Sol | GPT-6 Luna | Capriole AI（どのモデルでも） |
|---|---|---:|---:|---:|---:|
| 100 万 | 75 万 / 25 万 | USD 20 | USD 4 | USD 0.20 | USD 1.60 |
| 500 万 | 375 万 / 125 万 | USD 100 | USD 20 | USD 1 | **USD 8** |

GPT-6 Astra では、500 万トークンのコストが 3.75 × USD 10 + 1.25 × USD 50 = USD 100 なので、Capriole の USD 8 は 92% 安くなります。GPT-6.1 Sol と GPT-6 Sol では、USD 8 は 60% 安くなります。GPT-6 Luna は同じワークロードが USD 1 で、OpenAI を直接使うほうが安いため、Capriole が得になるのは Astra または Sol で作業する場合です。Capriole は API トークンを 500 万単位のパックで販売しています。100 万の行はパックの 5 分の 1 にあたり、比較のために示しています。

Capriole の課金トークンの計算式には長いプロンプト向けの料金区分がないため、300,000 トークンのプロンプトも短いプロンプトと同じトークン単価で数えます。

[無料でチャットを始める](https://www.capriole.ai/ja)ことも、[API キーを取得する](https://www.capriole.ai/ja?view=api)こともできます。

## キャッシュとバッチで比較はどう変わるか

- **キャッシュ入力**: OpenAI は入力料金の 10%、GPT-6 Astra ではキャッシュされた 100 万トークンあたり USD 1 を請求します。Capriole もキャッシュ入力を 10% で数えるため、キャッシュされた 100 万トークンあたり USD 0.16 に相当します。計算式は [Capriole AI の課金トークンの説明](/ja/articles/charged-tokens)で確認できます。
- **キャッシュ書き込み**: OpenAI は、30 分のキャッシュ書き込みに入力の 1.25 倍、12 時間のキャッシュ書き込みに 2.5 倍を請求します。Capriole は、キャッシュ書き込みを含むすべてのキャッシュなし入力トークンを通常のレートで数えます。
- **Batch と Flex**: 半額の場合、GPT-6 Astra の 500 万トークンの例は USD 50 です。Capriole にバッチ エンドポイントはありませんが、このワークロードでも USD 8 は 84% 安くなります。

OpenRouter のクレジット手数料も含めた 500 万トークンのテストは、[AI API コスト比較](/ja/articles/ai-api-cost-comparison)をご覧ください。

## Capriole の API で GPT-6 Astra を呼び出す

Capriole の API は、`POST /v1/responses` で OpenAI Responses と、`POST /v1/chat/completions` で OpenAI Chat Completions と互換性があります。OpenAI SDK の base URL を `https://api.caprioletech.com/v1` に設定してください。

- `openai-latest` は GPT-6 Astra を選択します。そのため、設定が現在推奨される OpenAI モデルに追従します。
- Responses では、`gpt-6-astra` のようなネイティブ ID も、`openai/gpt-6-astra` のようなプレフィックス付き ID も同じモデルを選択します。
- Chat Completions は、`openai-latest` と、`GET /v1/models` が返すモデル ID を受け付けます。

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com/v1",
)

response = client.responses.create(
    model="openai-latest",
    input="Write a release note for this change.",
)
print(response.output_text)
```

各キーは 1 分あたり 300 リクエストまで送信できます。使用できるモデル ID の一覧は [Responses リファレンス](/ja/api-reference/endpoint/responses)と [Chat Completions リファレンス](/ja/api-reference/endpoint/chat-completions)、Capriole のキーで Codex を動かす方法は [Codex のセットアップ](/ja/integrations/codex)をご覧ください。

## 月額 USD 8 に含まれるもの

- GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon をはじめ、すべての対応モデルでウェブチャットが無制限です。ログイン中のチャットには、スクリプトによる乱用を防ぐため、1 アカウントあたり UTC 基準で 1 日 200 メッセージのフェアユース上限があります。通常の利用ではこの上限を大きく下回ります。
- アプリとコーディング エージェント向けに、毎月 500 万 API トークンが含まれます。
- 追加の API トークンは 500 万あたり USD 8 で、1 回の購入で 1 から 11 パックまで購入でき、複数パックの割引は最大 15% です。
- GPT Image 2.5 と Nano Banana 2.1 による無料の画像生成、ファイルとウェブ検索、プロジェクト、チャットのエクスポート、[ドキュメントのある 10 種類のコーディング エージェント](/ja/articles/coding-agent-compatibility)も利用できます。

API キーには Premium または Team が必要です。Team は月額 USD 70 で、5 シートと 5,000 万 API トークンが含まれます。ウェブチャットはアカウントなしで 1 日 5 メッセージまで試せます。無料アカウントでは毎月 50 万トークン分のウェブチャットを使えますが、API は利用できません。

## よくある質問

### GPT-6 Astra の料金はいくらですか？

GPT-6 Astra は、入力 100 万トークンあたり USD 10、キャッシュ入力 100 万トークンあたり USD 1、出力 100 万トークンあたり USD 50 です。Batch と Flex のリクエストは半額です。

### 最も安い GPT-6 モデルはどれですか？

GPT-6 Luna です。入力 100 万トークンあたり USD 0.10、出力 100 万トークンあたり USD 0.50 です。

### OpenAI は長いプロンプトに追加料金を請求しますか？

はい。入力が 272,000 トークンを超えるリクエストは、リクエスト全体に対して入力とキャッシュの料金が 2 倍、出力の料金が 1.5 倍になります。

### Capriole AI の `openai-latest` とは何ですか？

`openai-latest` は GPT-6 Astra を指します。`/v1/responses` と `/v1/chat/completions` で使えます。

### Capriole AI のキーで Codex を使えますか？

はい。Codex はカスタム モデル プロバイダーを使い、Responses API 経由で接続します。設定の全体は [Codex のセットアップ](/ja/integrations/codex)にあります。
