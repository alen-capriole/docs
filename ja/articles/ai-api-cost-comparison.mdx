OpenRouter は各プロバイダーの公開価格で課金し、Standard のクレジットをカードで購入すると 5.5% の手数料がかかります。下記の固定 500 万トークン ワークロードでは、表のうち Capriole が提供しているすべてのモデルについて、**Capriole のコストは USD 9** です。同じモデルは有料 Standard のリスト価格で **USD 6.75 から USD 90**、計算した OpenRouter の現金合計は公開のクレジット購入手数料後に **USD 7.55 から USD 94.95** です。月額 USD 9 の Premium プランには、4 つの旗艦モデル（GPT-6.2 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Carbon）との無制限のウェブチャットも含まれます。

この比較では、Gemini 3.8 Flash を除き、Capriole が提供するすべてのモデルで Premium のほうが低額です。Gemini 3.8 Flash は、直接 API と OpenRouter のどちらも月額 USD 9 の契約より安くなります。Gemini 3.1 Pro Preview は参考として表に残していますが、Capriole AI では提供を終了しています。

これは再現可能な比較であり、どんな使い方でもこの価格になると約束するものではありません。トークン構成を一定に保ち、引用した公開価格を使います。料金の確認日：2026 年 11 月 18 日。

## 500 万トークンの料金は API ごとにいくらですか？

入力 400 万・出力 100 万トークンの場合、GPT-6 Astra と Claude Fable 5.1 は、公式 API で USD 90、OpenRouter で USD 94.95 です。GPT-6.2 Astra はそれぞれ USD 72 と USD 75.96 です。Capriole Premium は、表のうち Capriole が提供するすべてのモデルで USD 9 です。

表で揃えているのは課金トークン数で、元のテキストや処理内容までは揃えていません。トークナイザーはモデル系統間で異なります。シナリオは 100 リクエストで、各リクエストがキャッシュなし入力 40,000 トークンと出力 10,000 トークンを使い、すべてのプロンプトを OpenAI と Google の長いプロンプト向け料金の閾値未満に保ちます。[Claude](/ja/articles/claude-api-pricing)、[OpenAI](/ja/articles/openai-api-pricing)、[Gemini](/ja/articles/gemini-api-pricing) の API 料金の記事では、出力 1 トークンにつき入力 3 トークンの比率で計算しているため、500 万トークンの合計はこれより高くなります（たとえば GPT-6 Astra は USD 100）。キャッシュの読み書き、ツール、無料枠、代替サービス階層、バッチ処理、税、アカウント固有の割引は除外します。

## 計算を再現する方法

直接プロバイダーは入力と出力に別々の価格を公開します。このワークロードでは、計算式は次です。

```text
direct_cost = 4 × input_price_per_1M + 1 × output_price_per_1M
```

したがって GPT-6 Astra、Claude Fable 5.1、Claude Fable 5 のコストは次のとおりです。

```text
4 × USD 10 + 1 × USD 50 = USD 90
```

OpenRouter は、選択したプロバイダーの推論料金に上乗せせずに請求すると説明しています。Standard プランでは、クレジットをカードで購入すると 5.5% の手数料（最低 USD 0.80）がかかると記載されています。表示されている推論料金で計算すると、支払額は次のとおりです。

```text
openrouter_cash = inference_cost + max(USD 0.80, inference_cost × 0.055)
USD 90 + max(USD 0.80, USD 4.95) = USD 94.95
```

同じ計算で GPT-6.2 Astra は USD 75.96（直接 API では 4 × USD 8 + 1 × USD 40 = USD 72）、Claude Opus 5.5 は USD 37.98、Gemini 4 Carbon、Gemini 4 Argon、GPT-6.2 Sol は USD 18.99、Gemini 3.1 Pro Preview は USD 21.10 になります。Gemini 3.8 Flash は、2026 年 12 月 31 日までの Google の導入時 Standard 料金で USD 6.75 です（4 × USD 0.75 + 1 × USD 3.75）。カード手数料の最低額 USD 0.80 を加えると、OpenRouter の合計は USD 7.55 です。

OpenRouter は同じモデルを異なるプロバイダーまたはサービス階層へルーティングでき、フォールバックはリクエストを処理するエンドポイントを変える場合があります。したがって表は、表示されている一致推論レートを比較するものです。デフォルトのルーティング設定で必ずこの請求額になるわけではありません。

## Capriole が異なる単位を使う理由

Capriole の顧客残高は、各プロバイダーの入力・出力の価格表をそのまま使いません。課金トークンという共通の単位で残高から差し引きます。

```text
charged_tokens = uncached_input + ceil(cached_input × 0.1) + output
```

キャッシュなし入力と出力は 100% で数えます。キャッシュ入力は 10% で数えます。この例にはキャッシュ入力がないため、400 万入力トークンと 100 万出力トークンは 500 万課金トークンを消費します。

課金トークンはアカウント残高の単位で、プロバイダーの入力トークンや出力トークンの価格とは別物です。表は、固定のワークロードがそれぞれの請求方法でいくらになるかを比べるもので、価格の単位どうしを置き換えられると主張するものではありません。[Capriole AI の課金トークンの説明](/ja/articles/charged-tokens)では、さらに 3 つの例、端数処理、Premium のクォータの境界を説明しています。

## USD 9 が API 残高以外に含むもの

直接 API と OpenRouter では、Capriole メンバーシップなしで推論に支払えます。この表は新規個人 Premium サブスクリプションを扱います。それ以外の場合、Capriole API を使うには有効な個人 Premium プランまたは Team プランが必要です。Team の価格はこの比較の対象外です。

USD 9 の Premium プランには次が含まれます。

- 対応する Premium モデル群の無制限のウェブチャット。スクリプトによる乱用を防ぐ 1 日 200 メッセージの[フェアユース上限](/ja/guides/plans-and-limits#「無制限」の意味)あり
- 毎月最初の 500 万 API 課金トークン
- 公開 API と維持されているコーディング エージェント統合へのアクセス
- モデル切り替え、ファイル、ウェブ検索、チャット ストレージ制御を備えた 1 つのブラウザ ワークスペース

サブスクライブ前に、サインアウト中の訪問者と Free ユーザーは、制限付きのウェブチャットで GPT-6.2 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Carbon を試せます。その無料旗艦トライアルは、上の API コスト表とは別です。

最先端モデルとのチャットと API アクセスを両方使いたいなら、USD 9 でブラウザ ワークスペースと毎月 500 万 API トークンをまかなえます。同じアカウントは [ドキュメントのある 10 種類のコーディング エージェント連携](/ja/articles/coding-agent-compatibility) でも動きます。

最初の 500 万トークンは独立した API 製品として販売しているものではなく、料金は Premium バンドル全体に対するものです。別の 500 万課金トークンが必要な有効な個人 Premium メンバーは、USD 8 のチャージ パック 1 つを購入できます。

## 表が請求を予測しない場合

この例は、コストを実質的に変えうるいくつかの価格経路を除外しています。

- **キャッシュ**: プロバイダーはキャッシュ書き込みと読み取りに別々の価格を付けます。Capriole は課金トークン計算式でキャッシュ入力を 10% で数えます。
- **長いプロンプト**: OpenAI は GPT-6.2 Astra、GPT-6 Astra、GPT-6.2 Sol で、リクエストの入力が 272,000 トークンを超えるとより高いレートを課金します。Google は Gemini 3.1 Pro Preview で、プロンプトが 200,000 トークンを超えると同様に課金します。
- **サービス階層とバッチ処理**: Free、Flex、Priority、Batch、または他のプロバイダー階層は、ここで使う有料 Standard レートと異なる場合があります。
- **OpenRouter ルーティング**: リクエストを処理するエンドポイントまたはフォールバックは、表で使った一致レートと異なる価格になる場合があります。
- **ツールと検索**: サーバー側ツール、grounding、検索は、リクエストまたは使用量課金を追加する場合があります。
- **出力が多いワークロード**: 表は入力対出力 80/20 分割を使います。出力が多いと、出力価格プレミアムが大きいモデルでは、直接と OpenRouter のコストがより速く上がります。
- **エンタープライズ条件**: ボリューム割引、非公開オファー、データ所在地、交渉済みコミットメントは、公開リスト価格を置き換える場合があります。

プロバイダーを選ぶ前に、想定するモデル、トークン構成、機能で再計算してください。
