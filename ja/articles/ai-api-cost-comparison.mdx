OpenRouter は各プロバイダーの公開価格で課金し、Standard のクレジットをカードで購入すると 5.5% の手数料がかかります。下記の固定 500 万トークン ワークロードでは、Claude Fable 5、Gemini 3.1 Pro Preview、Gemini 3.8 Flash のいずれでも **Capriole のコストは USD 9** です。同じモデルは有料 Standard のリスト価格で **USD 6.75 から USD 90**、計算した OpenRouter の現金合計は公開のクレジット購入手数料後に **USD 7.55 から USD 94.95** です。

この比較では Claude Fable 5 と Gemini 3.1 Pro Preview は Premium のほうが低額です。Gemini 3.8 Flash は、直接 API と OpenRouter のどちらも月額 USD 9 の契約より安くなります。

これは再現可能な比較であり、万能の価格約束ではありません。トークン構成を一定に保ち、引用した公開価格を使います。料金の確認日：2026 年 11 月 9 日。

## 500 万トークン比較

表は課金トークン数を一定に保ち、ソース テキストまたは意味的ワークロードは一定にしません。トークナイザーはモデル系統間で異なります。シナリオは 100 リクエストで、各リクエストがキャッシュなし入力 40,000 トークンと出力 10,000 トークンを使い、すべてのプロンプトを Google の 200,000 トークン閾値未満に保ちます。キャッシュの読み書き、ツール、無料枠、代替サービス階層、バッチ処理、税、アカウント固有の割引は除外します。

| 正確なモデル | 新規個人 Capriole Premium | 直接有料 Standard | 同じ表示推論レートの OpenRouter | OpenRouter クレジット（カード手数料込み） | 公開 Standard 入力 / 出力価格（100 万トークンあたり） |
|---|---:|---:|---:|---:|---:|
| `claude-fable-5` | **USD 9.00*** | USD 90.00 | USD 90.00 | USD 94.95 | USD 10 / USD 50 |
| `gemini-3.1-pro-preview` | **USD 9.00*** | USD 20.00 | USD 20.00 | USD 21.10 | USD 2 / USD 12 |
| `gemini-3.8-flash` | **USD 9.00*** | USD 6.75 | USD 6.75 | USD 7.55 | USD 0.75 / USD 3.75 |

\* Premium は月額 USD 9 で、対応する Premium モデル群の無制限 Browser Chat と、毎月最初の 500 万課金トークンを含みます。これはその完全ワークスペース バンドルに対する新規顧客の公開購入価格であり、モデルごとのトークン単価または限界推論コストではありません。含まれる残高が十分な既存 Premium メンバーは、この使用量に追加の現金を払いません。含まれる許容量を使い切ったあと、追加の 500 万課金トークン パック 1 つは基本価格 USD 8 です。個人チャージには、有効な個人 Premium アクセスが必要です。

[制限付きの無料 Browser Chat で Capriole AI を試した](https://www.capriole.ai/ja) うえで、[完全なワークスペースと API アクセスのために Premium をサブスクライブ](https://www.capriole.ai/ja?view=api) できます。

## 計算を再現する方法

直接プロバイダーは入力と出力に別々の価格を公開します。このワークロードでは、計算式は次です。

```text
direct_cost = 4 × input_price_per_1M + 1 × output_price_per_1M
```

したがって Claude Fable 5 のコストは次です。

```text
4 × USD 10 + 1 × USD 50 = USD 90
```

OpenRouter は、選択したプロバイダーの推論料金に上乗せせずに請求すると説明しています。従量プランは、クレジットをカードで購入すると 5.5% の手数料（最低 USD 0.80）を掲載しています。表示推論レートでの現金計算は次です。

```text
openrouter_cash = inference_cost + max(USD 0.80, inference_cost × 0.055)
USD 90 + max(USD 0.80, USD 4.95) = USD 94.95
```

同じ算術で Gemini 3.1 Pro Preview は USD 21.10 になります。Gemini 3.8 Flash は、2026 年 12 月 31 日までの Google の導入時 Standard 料金で USD 6.75 です（4 × USD 0.75 + 1 × USD 3.75）。カード手数料の最低額 USD 0.80 を加えると、OpenRouter の合計は USD 7.55 です。

OpenRouter は同じモデルを異なるプロバイダーまたはサービス階層へルーティングでき、フォールバックはリクエストを処理するエンドポイントを変える場合があります。したがって表は、表示されている一致推論レートを比較します。すべてのデフォルト ルーティング設定からの請求を保証しません。

## Capriole が異なる単位を使う理由

Capriole の公開顧客残高は、各プロバイダーの入力・出力価格表をコピーしません。課金トークンと呼ばれる統一残高を差し引きます。

```text
charged_tokens = uncached_input + ceil(cached_input × 0.1) + output
```

キャッシュなし入力と出力は 100% で数えます。キャッシュ入力は 10% で数えます。この例にはキャッシュ入力がないため、400 万入力トークンと 100 万出力トークンは 500 万課金トークンを消費します。

課金トークンはアカウント残高の単位です。プロバイダーの入力トークンまたは出力トークン価格と同じものではありません。表は、各請求システムの下で固定ワークロードがいくらかかるかを比較します。価格単位が相互に置き換え可能だと主張しません。[Capriole AI の課金トークンの説明](/ja/articles/charged-tokens) は、追加の 3 例、丸め動作、Premium クォータ境界を提供します。

## USD 9 が API 残高以外に含むもの

直接 API と OpenRouter では、Capriole メンバーシップなしで推論に支払えます。この表は新規個人 Premium サブスクリプションを扱います。それ以外の Capriole API アクセスには、対象となる有効な個人または Team 権利が必要です。Team 価格はこの比較の外です。

USD 9 の Premium プランには次が含まれます。

- 対応する Premium モデル群の無制限 Browser Chat
- 毎月最初の 500 万 API 課金トークン
- 公開 API と維持されているコーディング エージェント統合へのアクセス
- モデル切り替え、ファイル、ウェブ検索、チャット ストレージ制御を備えた 1 つのブラウザ ワークスペース

サブスクライブ前に、サインアウト中の訪問者と Free ユーザーは、制限付き Browser Chat で GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon を試せます。その無料旗艦トライアルは、上の 3 モデル コスト表とは別です。

最先端モデル チャットとプログラム アクセスを一緒に欲しい対象ユーザーにとって、これが実務上の利点です。低い月額 1 つが日常のブラウザ ワークスペースと有用な API 許容量をカバーします。同じアカウントは [文書化された 10 のコーディング エージェント統合](/ja/articles/coding-agent-compatibility) でも動きます。

最初の 500 万トークンを、独立した API 製品として説明すべきではありません。支払いは完全な Premium バンドルを買います。別の 500 万課金トークンが必要な有効な個人 Premium メンバーは、USD 8 のチャージ パック 1 つを購入できます。

## 表が請求を予測しない場合

この例は、コストを実質的に変えうるいくつかの価格経路を除外しています。

- **キャッシュ**: プロバイダーはキャッシュ書き込みと読み取りに別々の価格を付けます。Capriole は課金トークン計算式でキャッシュ入力を 10% で数えます。
- **長いプロンプト**: Gemini 3.1 Pro Preview は、個別プロンプトが 200,000 トークンを超えるとより高いレートを課金します。
- **サービス階層とバッチ処理**: Free、Flex、Priority、Batch、または他のプロバイダー階層は、ここで使う有料 Standard レートと異なる場合があります。
- **OpenRouter ルーティング**: リクエストを処理するエンドポイントまたはフォールバックは、表で使った一致レートと異なる価格になる場合があります。
- **ツールと検索**: サーバー側ツール、grounding、検索は、リクエストまたは使用量課金を追加する場合があります。
- **出力が多いワークロード**: 表は入力対出力 80/20 分割を使います。出力が多いと、出力価格プレミアムが大きいモデルでは、直接と OpenRouter のコストがより速く上がります。
- **エンタープライズ条件**: ボリューム割引、非公開オファー、データ所在地、交渉済みコミットメントは、公開リスト価格を置き換える場合があります。

プロバイダーを選ぶ前に、想定するモデル、トークン構成、機能で再計算してください。
