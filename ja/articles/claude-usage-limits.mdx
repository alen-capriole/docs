Claude Pro と Max のユーザーが使用制限に達するのは、すべての有料 Claude プランに 5 時間のセッション制限と週間制限があり、claude.ai、Claude Desktop、Claude Code がすべて同じ枠を消費するためです。長いチャット、ツール、高いエフォート、大きなモデルほど枠を早く使います。主にチャットに使うなら、Capriole AI Premium は **月額 USD 8** で、**Claude Fable 5.1** と **Claude Opus 5.5** に加え、**GPT-6 Astra** と **Gemini 4 Argon** とのウェブチャットが無制限です。

コーディング エージェントを多用する作業向けに、同じアカウントには公式 API 価格より最大 92% 安い API も含まれます。

## Claude のプランと制限の比較

| プラン | 料金 | チャットの使用量 | Claude Fable 5.1 |
|---|---|---|---|
| Claude Free | USD 0 | 基本の利用枠。Sonnet と Haiku のみ | 利用不可 |
| Claude Pro | 月額 USD 20、年払いなら月額 USD 17 | 5 時間のセッションごとに Free の 5 倍以上、加えて週間制限 | プランの制限の対象外。API 料金の利用クレジットで支払い |
| Claude Max 5x | 月額 USD 100 | 5 時間のセッションごとに Pro の 5 倍、加えて週間制限 | 週間制限の最大 50% |
| Claude Max 20x | 月額 USD 200 | 5 時間のセッションごとに Pro の 20 倍、加えて週間制限 | 週間制限の最大 50% |
| Capriole AI Premium | 月額 USD 8 | 無制限のウェブチャット。1 日 200 メッセージのフェアユース上限あり | 無制限のウェブチャットに含まれる |

## Claude の使用制限の仕組み

Anthropic のヘルプセンターでは、有料プランの制限を 2 つ説明しています。

- **セッション制限。** 5 時間ごとにリセットされます。
- **週間制限。** すべてのモデルにまたがる制限で、アカウントごとに決まった時刻にリセットされます。

Anthropic は、月ごとの上限や特定のモデル・機能への制限など、ほかの方法で使用量を制限する場合もあるとしています。進捗は claude.ai の **Settings** → **Usage** で確認できます。

制限は共有です。claude.ai、Claude Desktop、Claude Code での使用量は同じ枠に数えられるため、Claude Code の長いセッションのあとは、チャットに使える余裕がほとんど残らないことがあります。週間制限はすべてのモデルにかかるため、別の Claude モデルに切り替えてもリセットされません。

## 思ったより早く制限に達する理由

Anthropic は、枠を多く使う要因として次を挙げています。

- 長く複雑な会話
- 選んだモデル
- 高いエフォート レベルと拡張思考
- 多くのトークンを使うツールとコネクタ
- コンテキストを占める大きなプロジェクト ファイル
- 自動コンテキスト管理が働く長いチャット

Fable 5.1 には独自のルールがあります。Pro では、Fable 5 と Fable 5.1 はプランの使用制限に含まれないため、Fable のメッセージはすべて標準の API 料金で請求される利用クレジットで動きます。Max では、Fable モデルは追加料金なしで週間制限の最大 50% まで使えます。

## 制限に達したときの Anthropic の推奨

1. **リセットを待つ。** セッション制限は 5 時間ごとにリセットされ、**Settings** → **Usage** でリセット時刻を確認できます。
2. **アップグレードする。** Anthropic は、Max 5x を頻繁に使うユーザー向け、Max 20x をほとんどの作業で毎日 Claude を使うユーザー向けとしています。新しいプランの制限はすぐに適用されます。
3. **利用クレジットをオンにする。** 制限に達したあとも、標準の API 料金で請求されるクレジットで作業を続けられます。月ごとの支出上限も設定できます。
4. **メッセージあたりの使用量を減らす。** 長い会話を続けずに新しい会話を始め、エフォート レベルを下げ、拡張思考と不要なツールをオフにし、プロジェクトの指示を短くします。

Claude Code の応答の途中で 5 時間の制限に達した場合、Claude Code は現在のステップを終えてから停止することがあります。Pro では、これは週間の使用期間ごとに最大 1 回です。

## USD 8 で Claude と無制限にウェブチャット

Capriole AI Premium は月額 USD 8 で、Claude Fable 5.1、Claude Opus 5.5、GPT-6 Astra、Gemini 4 Argon を含むすべての対応モデルでウェブチャットが無制限です。

Capriole AI のウェブチャットには、5 時間のセッション制限も週間制限もありません。ログイン中のウェブチャットには、1 アカウントあたり 1 日 200 メッセージのフェアユース上限があります。スクリプトによる自動化された乱用を防ぐためのもので、通常の利用ではこの上限を大きく下回ります。

Fable 5.1 に利用クレジットは不要です。すべてのモデルが同じ無制限のウェブチャットに含まれ、[会話の途中でモデルを切り替え](/ja/articles/switch-models-mid-chat)られます。たとえば、難しいステップだけ Claude Opus 5.5 から Claude Fable 5.1 に切り替えても、最初からやり直す必要はありません。

Premium には、GPT Image 2.5 と Nano Banana 2.1 による無料の画像生成、ファイルと Web 検索、プロジェクト、チャットのエクスポート、パーソナライズ、ストレージ制御も含まれます。

## コーディング エージェントを多用するなら API を使う

無制限のウェブチャットは、コーディング エージェントには適用されません。Claude Code などのエージェントには、Capriole AI の API キーを使ってください。エージェントのリクエストは、公式 API 価格より最大 92% 安い従量制の API 残高から引かれます。

| モデル | 公式 API 料金（100 万トークンあたり、入力 / 出力） | Capriole AI |
|---|---|---|
| Claude Fable 5.1 | USD 10 / USD 50 | 500 万トークンあたり USD 8 |
| Claude Opus 5.5 | USD 4 / USD 20 | 500 万トークンあたり USD 8 |
| GPT-6 Astra | USD 10 / USD 50 | 500 万トークンあたり USD 8 |

500 万トークンあたり USD 8 は、入力・出力とも 100 万トークンあたり USD 1.60 です。Premium には毎月 500 万 API トークンが含まれ、トップアップはどの対応モデルでも 500 万トークンあたり USD 8 です。[課金トークン](/ja/articles/charged-tokens)で説明しているとおり、キャッシュ入力は 10% で数えます。

Claude Code は、Capriole AI の Anthropic Messages エンドポイントで接続します。同じキーで、Codex を含む[ドキュメント化された 10 のコーディング エージェント](/ja/guides/one-api-key-coding-agents)を使えます。まずは [Claude Code のセットアップ](/ja/integrations/claude-code)から始めてください。

Claude Max には毎月の API クレジットが含まれますが、[Anthropic によると](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans)、対話型の Claude Code セッションや、プランの制限に達した後の追加使用には使えません。

## 手放すもの

Capriole AI は独立したワークスペースで、Anthropic とは提携していません。Claude アプリでもありません。Artifacts、コネクタ、メモリ、Claude in Chrome、Claude のデスクトップ アプリとモバイル アプリなど、Anthropic の製品にしかない機能は Capriole AI にはありません。Claude Code は、上記の API ルートで引き続き使えます。
