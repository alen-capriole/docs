マルチモデル AI チャットは、GPT、Claude、Gemini を 1 つのチャットで使えるサービスです。各サービスの違いが最も大きいのは、旗艦モデルの課金方法です。Capriole AI は**月額 USD 9** で、**GPT-6 Astra**、**Claude Fable 5.1**、**Claude Opus 5.5**、**Gemini 4 Argon** とのウェブチャットが無制限です。Magai、T3 Chat、Venice、OpenRouter は、旗艦モデルを使用量の予算、補充されるバケット、クレジット、従量課金で計量します。

Capriole AI には、公式 API 価格より最大 92% 安い API も含まれるため、同じアカウントでアプリもコーディング エージェントも動かせます。この比較は公開されているプランと機能を扱うもので、回答品質のテストではありません。

## 1 つの会話でモデルを切り替える

作業の途中でモデルを変えられることは、複数のアプリではなく 1 つのプラットフォームを使う一番の理由です。Capriole AI では、メニューから別のモデルを選ぶと、同じスレッドのまま次の回答がそのモデルから返ってきます。保存済みのファイルは、新しいモデルとストレージ モードが対応していれば引き継がれます。引き継がれるものと、Capriole AI が各社の形式の違いをどう調整するかは、[会話の途中でモデルを切り替える](/ja/articles/switch-models-mid-chat)で説明しています。

Magai の料金ページにも、スレッドを失わずにチャットの途中でモデルを切り替えられることが記載されています。T3 Chat の公式フィードバック ボードでは、会話の分岐とキーボードによるモデル切り替えが完了済みになっています。そのほかのワークスペース機能は [Capriole AI との比較](/ja/articles/capriole-ai-vs-t3-chat)で取り上げています。

## プライバシーとチャットの保存場所

ここで取り上げるどのプラットフォームも、最先端モデルへのリクエストは、OpenAI、Anthropic、Google などそのモデルを開発する企業か、そのモデルをホストするクラウド プラットフォームに送ります。違うのは、学習利用、ログ記録、そして履歴の保存場所です。

| | コンテンツの学習利用 | チャット履歴の保存場所 | そのほかに保持されるもの |
|---|---|---|---|
| Capriole AI | AI モデルの学習には使われない | 選択可能：アカウント（既定）、ブラウザのみ、保存しない | API はリクエストやレスポンスの内容を保持せず、トークン数などの使用量記録だけを残す |
| Magai | 作業内容がモデルの学習に使われることはないとしている | アカウントが有効な間は Magai のサーバー上 | サーバーとサービス プロバイダーは米国にある |
| T3 Chat | 自社モデルの学習はしない。可能な範囲でプロバイダーの学習もオプトアウト | FAQ に記載なし | 自分のプロバイダー キーを使う場合は、そのプロバイダーの設定が適用される |
| Venice | 確認したページには記載なし | 自分のデバイス | リクエストは保存されずに中継される。最先端モデルについては、プロバイダーがコンテンツを保存するものと考えるよう Venice は説明している |
| OpenRouter | データを学習に使わないとしている | Chatroom の会話はデバイスに残り、同期されない | モデルやトークン数などのリクエスト メタデータ。オプトインしない限りプロンプトはログに記録されないが、Safety Retention エンドポイントでは、乱用防止のために OpenRouter またはプロバイダーが保持する場合がある |

Capriole AI の **Local Storage** と **No Storage** モードでは履歴が当社のデータベースに保存されませんが、アップロードと画像作成には **Server Storage** が必要です。各モードで保持される内容は[プライバシーとデータ管理ガイド](/ja/guides/privacy-and-security)に、切り替え方は[チャット ストレージ ガイド](/ja/guides/chat-storage)にまとめています。

## ファイル、Web 検索、そのほかのワークスペース機能

Capriole AI のウェブチャットには、ファイルと Web 検索、独自の指示とファイルを持てる[プロジェクト](/ja/guides/projects)、チャットのエクスポート、パーソナライズが含まれます。GPT Image 2.6 と Nano Banana 2.1 による無料の画像生成も含まれます。必要なサインインとストレージの条件は[ファイル・画像生成・Web 検索のガイド](/ja/guides/files-web-search)で説明しています。

## 手放すもの

Capriole AI は個人と小規模チーム向けに作られています。Magai には組み込みエージェント、スケジュール タスクの実行、ほかのアプリとの連携があり、Magai と Venice は動画を生成できます。Capriole AI には、スケジュール タスク、アプリ連携、動画生成はありません。SAML シングル サインオンなどのエンタープライズ向け管理機能も提供していません。Capriole AI が提供するものとしないものは [LLM ゲートウェイのセキュリティ リスク](/ja/articles/llm-gateway-security)にまとめています。ウェブチャットは無制限ですが、API リクエストとコーディング エージェントは従量制の残高を使います。Premium では毎月 500 万トークンで、それを超えると 500 万トークンあたり USD 8 です。
