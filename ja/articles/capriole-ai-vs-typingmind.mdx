プロバイダー キーを別々に購入・管理するのではなく、旗艦モデルへのアクセスが最初から含まれたサービスを使いたいなら、**Capriole AI のほうがシンプルで、費用も抑えられます**。Premium は月額 USD 9 で、GPT-6.2 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Carbon とのウェブチャットが無制限になり、公式 API 価格より最大 92% 安い API アクセスと、10 のコーディング エージェント向けセットアップ ガイドも利用できます。どれも別々のプロバイダー アカウントは不要です。支払い前に、無料チャットで旗艦モデルを試せます。

TypingMind の個人ライセンスが買うのはインターフェイスであり、モデル アクセスではありません。ユーザーは引き続きプロバイダー アカウント、キー、残高、継続的なモデル使用量を供給します。

この比較では、2026 年 11 月 17 日に TypingMind の現行ドキュメント、プライバシー ポリシー、クラウド同期ページ、機能一覧、ライセンス ページを確認しました。両製品とも 1 つのインターフェイスで複数のモデル系統を見せられますが、アカウント所有権とデータフローの置き場所が異なります。

## Capriole はモデル アクセスを含む

Capriole はアクセス レイヤーの責任を負います。サインアウト中の訪問者と Free ユーザーは、まず無料のウェブチャットで対応旗艦モデルを試せます。Premium はその後、すべての対応モデルとのウェブチャットを無制限で提供します。ただし、スクリプトによる乱用を防ぐ 1 日 200 メッセージの[フェアユース上限](/ja/guides/plans-and-limits#「無制限」の意味)があります。公開 API とコーディング エージェント トラフィックは、含まれる毎月 5,000,000 課金 API トークンから引きます。

これにより、プロバイダー アカウントを開く、複数キーを保存する、複数残高に資金を入れる、複数の請求ページを確認する、といった管理手順が置き換わります。ブラウザ ワークスペース、API 利用枠、継続的に整備しているエージェント経路は、1 つの Capriole アカウントの下にあります。

TypingMind の個人製品は異なります。インターフェイスに支払い、プロバイダー API キーを追加し、選択したプロバイダーにモデル使用量を払い続けます。任意のクラウド ストレージは、含まれる容量を超えると追加コストになる場合があります。

たとえば、GPT-6.2 Astra で入力と出力の比率が 3:1 のチャットを月に 500 万トークン行うと、OpenAI の標準 API 料金で USD 80 になり、TypingMind のライセンスとは別に OpenAI から請求されます。Capriole AI では、このチャットは USD 9 の Premium プランに含まれます。

Capriole ユーザーに別々のプロバイダー キーは不要です。[1 つの AI サブスクリプション ガイド](/ja/articles/one-ai-subscription) は、含まれるアクセスと、無制限のウェブチャットと計量 API 作業の境界を説明します。

## Capriole は製品を変えずにストレージ選択肢を与える

Capriole は 3 つのチャット履歴の選択肢を提供します。Synced はアカウント履歴を保存します。Local は履歴を現在のブラウザに残します。No Storage は保存チャット履歴を残しません。どのモードでも、プロンプトは Capriole と選んだモデル プロバイダーへ送られます。

[チャットの保存ガイド](/ja/guides/chat-storage)では、同期する履歴、ブラウザー内の履歴、一時チャットの使い方を説明しています。

Server Storage を使うログイン済みアカウントでは、GPT Image 2.6、Nano Banana 2.1、Seedream 5.5 による無料の画像生成も利用できます。詳しくは [画像生成ガイド](/ja/guides/files-web-search) をご覧ください。

## 1 つのワークスペースは外部ツールへ続けられる

Capriole では、ワークスペース内の既存スレッド コンテキストを保ったまま、別の対応モデルでアクティブな会話を続けられます。同じアカウントはその後、OpenAI と Anthropic のプロトコル エンドポイント、および [ドキュメントのある 10 種類のコーディング エージェント経路](/ja/articles/coding-agent-compatibility) へ広がります。

Capriole AI は、ワークスペース、対応モデル アクセス、公開 API 利用枠、外部エージェント設定をまとめて提供します。

## Capriole の API は個人ワークスペースの一部

Capriole の公開エンドポイントは、OpenAI Chat Completions、OpenAI Responses、または Anthropic Messages を話すアプリケーションとエージェント向けです。それらの対応経路の背後に、1 つの Capriole キーと API 残高があります。

TypingMind Teams には、チーム ワークスペース向けの Custom API があります。個人の custom endpoints は逆方向に動きます。ユーザーが供給する互換モデル サービスを TypingMind が呼び出せるようにするものであり、外部モデル ゲートウェイを含むものではありません。

## BYOK はコストとセットアップをユーザーへ戻す

TypingMind は BYOK、セルフホスト、MCP、プラグイン、深いクライアントカスタマイズを提供します。それらの選択肢でも、プロバイダー アカウント、キー、残高、モデル請求はユーザーに残ります。Capriole は対応モデル アクセスを含み、1 つのアカウントの下でワークフローをウェブチャットから API とコーディング エージェント利用へ運びます。

## スタックを組み立てずに Capriole を使う

対応する最先端モデル、無制限の Premium ウェブチャット、含まれる API 利用枠、コーディング エージェント経路、ストレージ制御を、アクセス レイヤーを自分で組み立てずに欲しいときは、Capriole を選んでください。

[無料ウェブチャットを試す](https://www.capriole.ai/ja) と、先にプロバイダー アカウントを作ったり、インターフェイス ライセンスを買ったり、別々の API キーを供給したりせずに、対応旗艦モデルを使えます。さらに使いたい場合は、[USD 9 の Premium にアップグレードすると、無制限チャットと API キーを利用できます](https://www.capriole.ai/ja?view=api)。

Capriole AI は、TypingMind から独立して運営されているワークスペースです。
