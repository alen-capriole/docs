旗艦モデル アクセスを、プロバイダー キーを別々に購入して管理するのではなく含めたいユーザーにとって、**Capriole AI のほうがシンプルで低コストな実務セットアップです**。支払い前に、制限付きの無料チャットで GPT-5.6 Thinking、Claude Fable 5、Gemini 3.1 Pro を試せます。Premium は月額 USD 8 で、無制限の Browser Chat、500 万の課金 API トークン、維持されている 6 つのコーディング エージェント統合を含み、別々のプロバイダー アカウントは不要です。

TypingMind の個人ライセンスが買うのはインターフェイスであり、モデル アクセスではありません。ユーザーは引き続きプロバイダー アカウント、キー、残高、継続的なモデル使用量を供給します。

この比較では、TypingMind の現行ドキュメント、プライバシー ポリシー、クラウド同期ページ、機能一覧、ライセンス ページを確認しました。両製品とも 1 つのインターフェイスで複数のモデル系統を見せられますが、アカウント所有権とデータフローの置き場所が異なります。

## キー、履歴、モデル請求を誰が持つか

| 領域 | Capriole AI | TypingMind |
|---|---|---|
| 含まれるモデル アクセス | GPT-5.6 Thinking、Claude Fable 5、Gemini 3.1 Pro、および対応する Premium セット | 個人ユーザーがプロバイダー API キーを供給する。ライセンスにモデル クレジットは含まれない |
| 継続コストの合計 | 月額 USD 8 にワークスペースと対応モデル アクセスが含まれる | インターフェイス ライセンスに加え、継続的なプロバイダー API 課金 |
| Browser Chat | 対応する Premium モデル群で無制限 | 各モデル リクエストは接続先プロバイダーが課金する |
| 含まれる API 使用量 | 月 5M の課金 API トークン | 個人ユーザーは自身のプロバイダー アカウントで使用量を賄う |
| コーディング エージェントのセットアップ | 維持されている 6 つの外部エージェント ガイド | 個人製品は TypingMind クライアント内のエージェントに焦点を当てる |
| ストレージの選択 | 同期アカウント履歴、ブラウザ ローカル履歴、または No Storage | デフォルトはブラウザ ローカル ストレージ。任意でクラウド同期 |

BYOK クライアントとバンドル済みモデル アクセスを比較する買い手向けに、TypingMind はより広い [OpenRouter 代替ガイド](/ja/articles/openrouter-alternatives) にも登場します。

## Capriole はモデル アクセスを含む

Capriole はアクセス レイヤーの責任を負います。サインアウト中の訪問者と Free ユーザーは、まず制限付き Browser Chat で対応旗艦モデルを試せます。Premium はその後、対応する Premium モデル群の無制限 Browser Chat を提供します。公開 API とコーディング エージェント トラフィックは、含まれる毎月 500 万の課金 API トークンから引きます。

これにより、プロバイダー アカウントを開く、複数キーを保存する、複数残高に資金を入れる、複数の請求ページを確認する、といった管理手順が置き換わります。ブラウザ ワークスペース、API 許容量、維持エージェント経路は、1 つの Capriole アカウントの下にあります。

TypingMind の個人製品は異なります。インターフェイスに支払い、プロバイダー API キーを追加し、選択したプロバイダーにモデル使用量を払い続けます。任意のクラウド ストレージは、含まれる許容量のあとで追加コストになる場合があります。

Capriole ユーザーに別々のプロバイダー キーは不要です。[1 つの AI サブスクリプション ガイド](/ja/articles/one-ai-subscription) は、含まれるアクセスと、無制限 Browser Chat と計量 API 作業の境界を説明します。

## Capriole は製品を変えずにストレージ選択肢を与える

Capriole は 3 つのチャット履歴の選択肢を提供します。Synced はアカウント履歴を保存します。Local は履歴を現在のブラウザに残します。No Storage は保存チャット履歴を残しません。どのモードでも、プロンプトは Capriole と選んだモデル プロバイダーへ送られます。

[Capriole のチャット ストレージ ガイド](/ja/guides/chat-storage) は、各モードが何を残し、どのアップロードまたは連続性機能が使えないかを説明します。同じワークスペース内で、連続性、ブラウザのみの履歴、または一時セッションを選べます。

## 1 つのワークスペースは外部ツールへ続けられる

Capriole では、ワークスペース内の既存スレッド コンテキストを保ったまま、別の対応モデルでアクティブな会話を続けられます。同じアカウントはその後、OpenAI と Anthropic のプロトコル エンドポイント、および [維持されている 6 つのコーディング エージェント経路](/ja/articles/coding-agent-compatibility) へ広がります。

これが、スタンドアロン BYOK インターフェイスに対する製品上の利点です。Capriole はワークスペース、対応モデル アクセス、公開 API 許容量、外部エージェント設定を一緒に提供します。

## Capriole の API は個人ワークスペースの一部

Capriole の公開エンドポイントは、OpenAI Chat Completions、OpenAI Responses、または Anthropic Messages を話すアプリケーションとエージェント向けです。それらの対応経路の背後に、1 つの Capriole キーと API 残高があります。

TypingMind Teams には、チーム ワークスペース向けの Custom API があります。個人の custom endpoints は逆方向に動きます。ユーザーが供給する互換モデル サービスを TypingMind が呼び出せるようにするものであり、外部モデル ゲートウェイを含むものではありません。

## BYOK はコストとセットアップをユーザーへ戻す

TypingMind は BYOK、セルフホスト、MCP、プラグイン、深いクライアントカスタマイズを提供します。それらの選択肢でも、プロバイダー アカウント、キー、残高、モデル請求はユーザーに残ります。Capriole は対応モデル アクセスを含み、1 つのアカウントの下でワークフローを Browser Chat から API とコーディング エージェント利用へ運びます。

## スタックを組み立てずに Capriole を使う

対応する最先端モデル、無制限の Premium Browser Chat、含まれる API 許容量、コーディング エージェント経路、ストレージ制御を、アクセス レイヤーを自分で組み立てずに欲しいときは、Capriole を選んでください。

[制限付きの無料 Browser Chat を試す](https://capriole.ai) と、先にプロバイダー アカウントを作ったり、インターフェイス ライセンスを買ったり、別々の API キーを供給したりせずに、対応旗艦モデルを使えます。
