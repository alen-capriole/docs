**Capriole AI は月額 USD 8 で、GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon とのウェブチャットが無制限です**。API は公式 API 価格より最大 92% 安くなります。Magai は月額 USD 20 からで、プラン料金と同額の使用量が毎月付与され、GPT と Claude の最上位モデルは USD 40 の Pro と USD 200 の Ultra プランに限られます。

旗艦モデルとのチャットと API を最も安く使いたいなら、Capriole を選んでください。組み込みエージェント、スケジュール タスク、150 以上のアプリ連携、動画生成が必要なら、Magai を選んでください。

この比較では、Magai の料金ページ、モデル ページ、FAQ、プライバシー ポリシーを確認しました。

## 簡易比較

| 項目 | Capriole AI | Magai |
|---|---|---|
| 無料で始める | アカウントなしでウェブチャットを 1 日 5 メッセージ。無料アカウントでは毎月 50 万トークン分のウェブチャット | 無料プランやトライアルはなし。30 日間の返金保証 |
| GPT と Claude の最上位モデルの価格 | 月額 USD 8（Premium） | 月額 USD 40（Pro）または月額 USD 200（Ultra） |
| チャットの計量方法 | すべての対応モデルで無制限 | プラン料金と同じ月 USD 20、40、200 分の使用量。トップアップは USD 5、10、20 |
| 現在の旗艦モデル | GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon | GPT-6 Astra、Claude Opus 5.5、Gemini 4 Argon。Claude Fable 5.1 はモデル ページに掲載なし |
| デベロッパー API | OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。公式 API 価格より最大 92% 安い | 料金、モデル、FAQ の各ページに記載なし |
| コーディング エージェント | Claude Code や Codex を含む 10 種類のセットアップをドキュメント化 | 記載なし |
| 画像と動画 | GPT Image 2.5 と Nano Banana 2.1 による無料の画像生成。動画はなし | 多数のプロバイダーの画像・動画モデル。プランの使用量から消費 |
| エージェントと自動化 | 関連するチャットで共通の指示を使えるプロジェクト | 無制限のエージェント、100 回から無制限までのスケジュール タスク実行、150 以上の連携、MCP 接続 |
| チーム | Team: 月額 USD 70 で 5 シートと 5,000 万 API トークン | Standard では追加ユーザー 1 人あたり USD 20。Pro と Ultra は個別料金 |
| コンテンツの学習利用 | AI モデルの学習には使われない | どのモデルの学習にも使われない |

ログイン中の Capriole のチャットには、スクリプトによる乱用を防ぐため、1 アカウントあたり UTC 基準で 1 日 200 メッセージのフェアユース上限があります。通常の利用ではこの上限を大きく下回ります。

[無料でチャットを始める](https://www.capriole.ai/ja)ことも、[API キーを取得する](https://www.capriole.ai/ja?view=api)こともできます。

## 旗艦モデルとのチャットの料金

Magai はすべてのプランを金額ベースの使用量で計ります。Standard は月額 USD 20 で USD 20 分、Pro は USD 40 で USD 40 分、Ultra は USD 200 で USD 200 分の使用量を含みます。Magai によると、それでどこまで使えるかは選ぶモデルとツールによって変わります。上限に達したら、アップグレードするか、USD 5、10、20 単位でトップアップします。年払いでは 17% 節約できます。

Magai の Standard プランで使えるのは標準モデルだけです。プレミアム モデルには Pro または Ultra が必要です。Magai はプレミアム モデルを、GPT と Claude の最上位モデルと、実行コストが標準モデルの 3 倍以上かかるモデルと説明しています。

Capriole Premium は月額 USD 8 で、ウェブチャットに使用量のメーターはありません。GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon をはじめ、すべての対応モデルが無制限です。支払いの前に、アカウントなしで 1 日 5 メッセージまでチャットすることも、毎月 50 万トークン分のウェブチャットを使える無料アカウントに登録することもできます。

## モデル

Capriole の現在の旗艦モデルは、GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon です。ほかに GPT-6.1 Sol、GPT-6 Sol、GPT-6 Luna、Gemini 3.8 Flash、Grok 4.7、GLM 5.3 Flash、Kimi K3.1 Pro も提供しています。

Magai のモデル ページには、OpenAI、Anthropic、Google、xAI などのチャット モデルが掲載されており、GPT-6 Astra、Claude Opus 5.5、Gemini 4 Argon、Grok 4.7 も含まれます。Claude モデルは Claude Haiku 5.5、Claude Opus 5.5、Claude Sonnet 5.5 で、Claude Fable 5.1 はリストにありません。Magai は画像モデルと動画モデルも提供しています。Capriole は動画を生成しません。

## API とコーディング エージェント

Magai の FAQ によると、Magai がユーザーに代わって各プロバイダーの API を呼び出すため、プロバイダーのアカウントは不要です。料金、モデル、FAQ の各ページには、自分のコードから呼び出せるデベロッパー API の記載はありません。

Capriole には API が含まれています。1 つの API キーで OpenAI Chat Completions、OpenAI Responses、Anthropic Messages を使え、料金は公式 API 価格より最大 92% 安くなります。Premium には毎月 500 万 API トークンが含まれ、追加分は 500 万トークンあたり USD 8 です。計算は [Claude API の料金](/ja/articles/claude-api-pricing)と [OpenAI API の料金](/ja/articles/openai-api-pricing)のページで確認できます。

同じキーで、[Claude Code](/ja/integrations/claude-code) や [Codex](/ja/integrations/codex) を含む[ドキュメントのある 10 種類のコーディング エージェント](/ja/articles/coding-agent-compatibility)を動かせます。エージェントのリクエストは、無制限チャットではなく API 残高を使います。

## ワークスペースの機能

Magai はエージェントと自動化を中心に作られています。組み込みエージェントとカスタム エージェント、スケジュール タスクの実行（Standard は月 100 回、Pro は 1,000 回、Ultra は無制限）、150 以上の連携、MCP 接続、Canvas ドキュメント エディター、ChatGPT と Claude からのインポートを備えています。

Capriole はチャットと API に重点を置いています。ログイン中のアカウントは、Server Storage モードで GPT Image 2.5 と Nano Banana 2.1 による無料の画像生成を使えるほか、ファイルとウェブ検索、[プロジェクト](/ja/guides/projects)、チャットのエクスポート、パーソナライズも利用できます。

## プライバシーとストレージ

Magai の FAQ によると、プロンプト、ファイル、入力、出力がモデルの学習に使われることはありません。プライバシー ポリシーによると、チャット、画像、ファイルはアカウントが有効な間保存され、サーバーは米国にあります。

[プライバシーポリシー](/ja/legal/privacy)に記載のとおり、Capriole はチャット、ファイル、API のコンテンツを AI モデルの学習に使いません。チャット履歴の保存先は、アカウントへの同期、ブラウザ内への保存、まったく保存しない、から選べます。設定方法は[チャット ストレージ ガイド](/ja/guides/chat-storage)で確認できます。どのモードでも、リクエストは引き続き Capriole と選択したモデル プロバイダーを通ります。

## どちらを選ぶべきか

次のような場合は Capriole AI を選んでください。

- Claude Fable 5.1 を含む現在の旗艦モデル 4 つすべてと、月額 USD 8 で無制限にチャットしたい
- 公式 API 価格より最大 92% 安い、API とコーディング エージェント用のキーが欲しい
- 支払う前に旗艦モデルを無料で試したい

次のような場合は Magai を選んでください。

- 組み込みエージェント、スケジュール タスク、150 以上のアプリ連携が欲しい
- 同じワークスペースで動画を生成したい
- エージェントとプロンプトを共有するチーム向けに、シート単位のプランが欲しい

## よくある質問

### Capriole AI は Magai より安いですか？

はい。Capriole Premium は月額 USD 8 で、すべての対応モデルとのチャットが無制限です。GPT と Claude の最上位モデルを使える Magai の最も安いプランは月額 USD 40 の Pro で、USD 40 分の使用量が含まれます。

### Magai で Claude Fable 5.1 は使えますか？

Magai のモデル ページには掲載されていません。Claude モデルは Claude Haiku 5.5、Claude Opus 5.5、Claude Sonnet 5.5 です。Capriole では、Claude Fable 5.1 を無制限チャットでも API でも使えます。

### Magai に API はありますか？

Magai の料金、モデル、FAQ の各ページには、デベロッパー API の記載がありません。Capriole は Premium または Team で、OpenAI 互換と Anthropic 互換の API を提供しています。

### 画像と動画にはどちらが向いていますか？

動画が必要なら Magai です。Capriole はログイン中のアカウントに GPT Image 2.5 と Nano Banana 2.1 による無料の画像生成を提供しており、動画は生成しません。
