USD 20 以下でどの生成 AI の有料プランを選ぶべきかは、1 社のモデルだけで足りるか、すべての会社のモデルを使いたいかで変わります。Capriole AI Premium は**月額 USD 9** で、4 つの旗艦モデル、**GPT-6.2 Astra**、**Claude Fable 5.1**、**Claude Opus 5.5**、**Gemini 4 Carbon** のすべてと無制限にウェブチャットできます。一方、ChatGPT Plus、Claude Pro、Google AI Pro は USD 19.99〜USD 20 で、それぞれ 1 社のモデルだけを使えます。

Premium には毎月 500 万 API トークンが含まれます。ChatGPT Plus と Claude Pro には API の利用は含まれません。料金はすべて各社の公式ページに掲載された米国の月額料金です。

## どのプランが誰に向いているか

- **すべての会社のトップモデルを 1 つの料金で使いたい。** このリストで GPT-6.2 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Carbon を 1 つのサブスクリプションでカバーするのは Capriole AI Premium で、料金は USD 20 のプランの半額未満です。[会話の途中でモデルを切り替えれば](/ja/articles/switch-models-mid-chat)、同じスレッドで別の会社のモデルから 2 つ目の回答を得られます。
- **アプリも開発する、またはコーディング エージェントを使う。** Capriole AI Premium の API 利用枠は、OpenAI と Anthropic の API 形式と[ドキュメントのある 10 種類のコーディング エージェント](/ja/guides/one-api-key-coding-agents)で使えます。ほかのプランに含まれるものは表の API 列をご覧ください。

## Capriole AI の USD 9 で得られるもの

Premium では、GPT-6.2 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Carbon を含むすべての対応モデルとのウェブチャットが無制限です。

Premium には毎月 500 万 API トークンが含まれます。個人向けチャージは、どの対応モデルでも 500 万トークンあたり USD 8 です。[標準料金の比較](/ja/overview)では、公式 API 価格より最大 92% 安くなります。ファイルとウェブ検索、プロジェクト、チャットのエクスポート、ストレージ制御はワークスペースに組み込まれており、GPT Image 2.6、Nano Banana 2.1、Seedream 5.5 による[無料の画像生成](/ja/guides/files-web-search)も含まれます。Free、Premium、Team の内容は[プランと制限](/ja/guides/plans-and-limits)にすべて載っています。
