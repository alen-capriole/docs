USD 20 以下でどの生成 AI の有料プランを選ぶべきかは、1 社のモデルだけで足りるか、すべての会社のモデルを使いたいかで変わります。Capriole AI Premium は**月額 USD 9** で、現在の旗艦モデル 4 つ、**GPT-6 Astra**、**Claude Fable 5.1**、**Claude Opus 5.5**、**Gemini 4 Argon** のすべてと無制限にウェブチャットできます。一方、ChatGPT Plus、Claude Pro、Google AI Pro は USD 19.99〜USD 20 で、それぞれ 1 社のモデルだけを使えます。

Premium には毎月 500 万 API トークンも含まれ、公式 API 価格より最大 92% 安く使えます。ChatGPT Plus と Claude Pro には API の利用は含まれません。料金はすべて各社の公式ページに掲載された米国の月額料金です。

## どのプランが誰に向いているか

- **すべての会社の最高のモデルを 1 つの料金で使いたい。** このリストで GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon を 1 つのサブスクリプションでカバーするのは Capriole AI Premium で、料金は USD 20 のプランの半額未満です。[会話の途中でモデルを切り替えれば](/ja/articles/switch-models-mid-chat)、同じスレッドで別の会社のモデルから 2 つ目の回答を得られます。
- **アプリも開発する、またはコーディング エージェントを使う。** Capriole AI Premium の API 利用枠は、OpenAI と Anthropic の API 形式と[ドキュメント化された 10 のコーディング エージェント](/ja/guides/one-api-key-coding-agents)で使えます。ほかのプランに含まれるものは表の API 列をご覧ください。
- **日常的なチャットだけで十分。** ChatGPT の無料プランで足りるかもしれません。ChatGPT Go は USD 8 です。Capriole AI Premium は USD 9 で、4 つの旗艦モデルが含まれます。

## Capriole AI の USD 9 で得られるもの

Premium では、GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon を含むすべての対応モデルとのウェブチャットが無制限です。ログイン中のウェブチャットには、1 アカウントあたり 1 日 200 メッセージのフェアユース上限があります。スクリプトによる自動化された乱用を防ぐためのもので、通常の利用ではこの上限を大きく下回ります。

同じプランには、公式 API 価格より最大 92% 安い API も含まれます。毎月 500 万 API トークンが付き、それを超えるとどの対応モデルでも 500 万トークンあたり USD 8 です。ファイルと Web 検索、プロジェクト、チャットのエクスポート、ストレージ制御はワークスペースに組み込まれており、GPT Image 2.5 と Nano Banana 2.1 による無料の画像生成も含まれます。Free、Premium、Team の内容は[プランと制限](/ja/guides/plans-and-limits)にすべて載っています。

## 手放すもの

Capriole AI は独立したワークスペースで、OpenAI、Anthropic、Google とは提携していません。そのため、メモリ、ほかのアプリとのコネクタ、デスクトップ アプリとモバイル アプリ、Google AI Pro の 5 TB のストレージと Gmail、Google ドキュメント、Google スプレッドシートでの Gemini など、各社のアプリにしかない機能は使えません。Capriole AI には、音声会話モードも、動画や音楽の生成もありません。コーディング エージェントは無制限のチャットではなく従量制の API 残高を使うため、エージェントを多用すると、含まれる利用枠を超えた分は 500 万トークンあたり USD 8 かかります。
