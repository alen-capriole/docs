Capriole AI には 4 つの旗艦モデルがあります。OpenAI の GPT-6.2 Astra、Anthropic の Claude Fable 5.1 と Claude Opus 5.5、Google の Gemini 4 Carbon です。Premium なら月額 USD 9 で 4 つすべてとウェブチャットで無制限に会話でき、API は公式 API 価格より最大 92% 安く使えます。ウェブチャットは、別のモデルを選ぶまで GPT-6.2 Astra Thinking で始まります。以下の要約で、別のモデルの開発元がそのモデルをあなたの作業向けと説明していれば、そちらに切り替えてください。

### GPT-6.2 Astra

OpenAI は GPT-6.2 Astra を、最も難しいプロジェクトに向けた新しいフロンティア モデルと位置づけており、OpenAI の旗艦モデルとして GPT-6 Astra に代わります。OpenAI によると、スライド、スプレッドシート、ドキュメントは AI が書いたような印象が薄れ、テンプレートや分野ごとの慣例に沿うようになり、コードはよりクリーンに、フロントエンドはより良くなっています。OpenAI が示すコンテキスト ウィンドウは 105 万トークン、出力は最大 128,000 トークンで、API 価格は GPT-6 Astra より 20% 安くなっています。Capriole AI での GPT-6.2 Astra のコンテキスト ウィンドウは 87.2 万トークンです。別のモデルを選ぶまで **GPT-6.2 Astra Thinking** がウェブチャットの既定で、API では `openai-latest` が GPT-6.2 Astra を使います。

### Claude Fable 5.1

Anthropic は Claude Fable 5.1 を、高度な推論と長時間のエージェント作業向けに位置づけています。Anthropic によると、長時間のエージェント型コーディング、多段階のリサーチ、ドキュメント・スプレッドシート・スライドの作業で Claude Fable 5 より向上しています。Anthropic の評価では、速度は Claude Opus 5.5 より遅くなります。`claude-latest` は Claude Fable 5.1 を使います。Anthropic 自身の Pro プランでは、Fable 5.1 は使用制限の対象外で、利用クレジットで支払います。詳しくは [Claude の使用制限の解説](/ja/articles/claude-usage-limits)をご覧ください。

### Claude Opus 5.5

Anthropic は Claude Opus 5.5 を、長時間のエージェント型コーディングとナレッジワーク向けに、Fable 5.1 の公式価格の半分未満で提供しています。Anthropic は、ほとんどの作業を Opus 5.5 から始め、推論レベルを上げても Opus 5.5 で足りない場合に Fable 5.1 へ移ることを勧めています。Fable 5.1 と同じく思考は常にオンのため、Capriole AI の **Fast** は思考をオフにせず、推論レベルを下げます。

### Gemini 4 Carbon

Google は Gemini 4 Carbon を最も強力なモデルと呼び、複雑な多段階のコーディングとデバッグ、長時間のエージェント作業、科学的推論など、モデルの知能の限界が試されるタスク向けに作ったとしています。Carbon は 1 ターンあたりの思考トークンが Gemini 4 Argon より多いため、速度は遅く、使うトークンも多くなります。Google によると、難しいプロンプトでは数分かかることがあります。Google は、ソフトウェア開発とナレッジワークの大半には引き続き Argon が最適だとしています。Carbon の 100 万トークンのコンテキスト ウィンドウは、入力、思考、出力で共有されます。`google-latest` は Gemini 4 Carbon を使います。

## Thinking と Fast

ウェブチャットのほとんどのモデルには、2 つのプリセットがあります。メッセージ ボックスのモデル メニューの横で **Thinking** か **Fast** を選びます。

- **Thinking** は答える前により多く推論するため、複雑なタスクに向いています。Claude の Thinking プリセットは思考の要約を表示します。
- **Fast** は推論レベルを下げて、より速く返信します。

Thinking はより多くのトークンを使います。Premium と Team では、どちらを選んでもウェブチャットは無制限のままです。Free では、Thinking は毎月の枠をより多く使います。

| モデル | ウェブチャットのプリセット |
|---|---|
| GPT-6.2 Astra、GPT-6.2 Sol、GPT-6 Astra、GPT-6.1 Sol、GPT-6 Sol、GPT-6 Luna | **Thinking**（推論レベル中）と **Fast**（推論レベル低） |
| Claude Fable 5.1、Claude Opus 5.5 | 思考は常にオン。**Thinking** は推論レベル中、**Fast** は推論レベル低です。 |
| Gemini 4 Carbon、Gemini 4 Argon | Gemini 4 Carbon / Gemini 4 Argon では Thinking プリセットを使えます。**Fast** を選ぶと Gemini 3.8 Flash に切り替わります。 |
| Kimi K3.1 Pro | 常に思考するモデルです。**Thinking** は推論レベル高、**Fast** は推論レベル低を使います。 |
| GLM | **Fast** は GLM 5.3 Flash です。**Thinking** は以前の GLM 5.2（API では `zai/glm-5.2`）を使います。 |
| Grok 4.7 | プリセットは 1 つ |

ウェブチャットでは Thinking プリセットを選べます。API でより多くの推論が必要なときは、モデルの ID を呼び出し、リクエストで推論オプションを設定してください。

## チャットの途中でモデルを切り替える

モデル メニューから別のモデルを選び、次のメッセージを送ります。チャットは履歴を保ったまま、新しいモデルがそこから答えます。[チャットの途中でモデルを切り替える仕組み](/ja/articles/switch-models-mid-chat)。

最新のメッセージへの 2 つ目の回答を得るには、回答の下にある **再試行** を選び、別のモデルを選びます。新しい回答は元の回答と同じ場所に置き換わり、横の矢印で 2 つを切り替えられます。

**アカウント** → **設定** で **モデル自動切り替えを有効にする** をオンにすると、選んだモデルが混み合っているときに、Capriole AI が利用可能な別のモデルで答えることがあります。既定ではオフです。

## API のモデル ID

API のベース URL は `https://api.caprioletech.com` です。1 つのモデルに固定するには具体的なモデル ID を、各プロバイダーで当社が推奨する旗艦モデルに追従するには `*-latest` エイリアスを使います。

| エイリアス | 使うモデル | エンドポイント |
|---|---|---|
| `openai-latest` | `openai/gpt-6.2-astra` | Chat Completions、Responses |
| `claude-latest` | `anthropic/claude-fable-5-1`（Messages では `claude-fable-5-1`） | Chat Completions、Messages |
| `google-latest` | `google/gemini-4-carbon` | Chat Completions |

<Note>
2026 年 11 月 18 日から、`openai-latest` は GPT-6 Astra ではなく GPT-6.2 Astra を使います。GPT-6 Astra を使い続けるには、`openai/gpt-6-astra` を呼び出してください。
</Note>

<Note>
2026 年 11 月 17 日から、`google-latest` は Gemini 4 Argon ではなく Gemini 4 Carbon を使います。Chat Completions では、Carbon は Google の既定の思考レベル `medium` で思考し、当社のテストでは同じプロンプトで Argon の約 3〜4 倍の出力トークンを使いました。軽い呼び出しには、Google の `thinking_level` を `low` に設定する（`medium` と `high` も使えます）か、`google/gemini-4-argon` を呼び出してください。

<CodeGroup>
```bash curl
curl https://api.caprioletech.com/v1/chat/completions \
  -H "Authorization: Bearer YOUR_CAPRIOLE_AI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "google-latest",
    "messages": [{"role": "user", "content": "Hello"}],
    "extra_body": {"google": {"thinking_config": {"thinking_level": "low"}}}
  }'
```

```python OpenAI Python SDK
completion = client.chat.completions.create(
    model="google-latest",
    messages=[{"role": "user", "content": "Hello"}],
    extra_body={"extra_body": {"google": {"thinking_config": {"thinking_level": "low"}}}},
)
```
</CodeGroup>
</Note>

旗艦モデルの ID は `openai/gpt-6.2-astra`、`anthropic/claude-fable-5-1`、`anthropic/claude-opus-5-5`、`google/gemini-4-carbon` です。Anthropic Messages では、`claude-opus-5-5` のようにプレフィックスなしの Claude ID を使います。最新の一覧は `GET /v1/models` を呼び出すか、[モデル一覧](/ja/api-reference/endpoint/get)で確認してください。

Capriole AI は、どのモデルでも課金トークンを同じ方法で数えます。キャッシュなし入力に、キャッシュ入力の 10% と出力を足したものです。例は[課金トークンの説明](/ja/articles/charged-tokens)をご覧ください。

画像を作るには、モデル メニューで **画像** を選び、GPT Image 2.6、Nano Banana 2.1、Seedream 5.5 のいずれかを選びます。[画像生成ガイドを見る](/ja/guides/files-web-search)。

## よくある質問

### Capriole AI の既定のモデルは何ですか？

ゲストと新規アカウントのウェブチャットは GPT-6.2 Astra Thinking で始まります。モデルを選んだあとは、新しいチャットは最後に選んだモデルで始まり、保存済みのチャットは最後に使ったモデルで開きます。API では、`openai-latest` が GPT-6.2 Astra を使います。

### Capriole AI では旗艦モデルのほうが高くなりますか？

ウェブチャットではなりません。Premium と Team のチャットは、どの対応モデルでも無制限です。API ではどのモデルもトークンあたりの料金が同じ（500 万トークンあたり USD 8）なので、公式価格と比べた節約額は旗艦モデルで最も大きくなります。具体的な計算は [Claude API の料金](/ja/articles/claude-api-pricing)、[OpenAI API の料金](/ja/articles/openai-api-pricing)、[Gemini API の料金](/ja/articles/gemini-api-pricing)をご覧ください。

### OpenAI SDK で Claude や Gemini を使えますか？

はい。OpenAI Chat Completions は、`anthropic/claude-fable-5-1` や `google/gemini-4-carbon` を含むすべての公開モデル ID と、3 つのエイリアスを受け付けます。設定方法は [OpenAI と Anthropic の SDK ガイド](/ja/guides/openai-anthropic-sdks)で説明しています。

### API では推論の強度をどう設定しますか？

モデルの API ID を呼び出し、リクエストで推論オプションを設定してください。

### どの Claude モデルから始めればよいですか？

Anthropic は、ほとんどの作業を Claude Opus 5.5 から始め、高度な推論や長時間のエージェント作業には Claude Fable 5.1 に移ることを勧めています。[Claude と ChatGPT の比較](/ja/articles/claude-vs-chatgpt)では、両モデルを GPT-6.2 Astra と比べています。
