Capriole AI の Browser Chat は、アップロードした作業ファイルとウェブ上の最新情報を組み合わせられます。モデルに読ませたい資料を添付し、具体的な質問をし、答えが変化した内容に依存する場合は最新情報を求めてください。

同じワークスペースで、資料を別製品にコピーせずに GPT-6 Astra、Claude Fable 5.1、または Gemini 3.1 Pro で作業を続けられます。Premium は月額 USD 8 で、対応する Premium モデル群の Browser Chat が無制限になります。

ファイル アップロードには、デフォルトのアカウント同期ストレージを使う、サインイン済みチャットが必要です。ウェブ検索は Browser Chat のツールであり、質問が最新の公開情報を必要とするときにモデルが呼び出します。

## アップロード前にファイルを確認する

| ファイルの分類 | 対応例 | ファイルあたりの上限 |
|---|---|---:|
| 画像 | JPG、JPEG、PNG | 10 MB |
| PDF | PDF ドキュメント | 10 MB |
| テキストと構造化ファイル | TXT、Markdown、JSON、JSONL、HTML | 4 MB |
| Office ドキュメント | DOCX と PPTX | 4 MB |
| スプレッドシート | CSV、XLS、XLSX | 4 MB |

コンポーザーは複数ファイルを受け付けられますが、添付無制限という公開約束はありません。結合した大きなコンテキストは、選択したモデルの入力上限を超える場合があります。

Local と No Storage モードではファイル アップロードを受け付けません。会話のストレージ境界を変える前に、[チャット ストレージ ガイド](/ja/guides/chat-storage) を読んでください。

## ファイルを基にモデルへ作業させる

<Steps>
<Step title="同期チャットを開く">

[Capriole AI](https://capriole.ai) にサインインします。チャットがデフォルトのアカウント同期ストレージを使うよう、**Enable local storage** と **Enable No Storage** はオフのままにしてください。

</Step>

<Step title="ファイルを追加する">

コンポーザーで **Add photos and files** を選びます。ファイルをチャット領域にドラッグするか、クリップボードから貼り付けることもできます。

メッセージを送る前に、添付のアップロード完了を待ってください。Capriole は選択したモデル向けにアップロード ファイルを準備しているあいだ、処理ステータスを表示します。

</Step>

<Step title="ファイルだけでなく、作業内容を説明する">

モデルに何を調べ、どのような出力が役立つかを伝えてください。例:

```text
Read the attached spreadsheet. Identify the three largest month-over-month changes, explain which rows produced them, and return a compact table.
```

ドキュメントレビューでは、気になる節、判断、または不整合を指定してください。`summarize this` のような指示だけだと、モデルへの方向付けが少なくなります。

</Step>

<Step title="添付と照合して答えを確認する">

重要な数値、引用、行参照を元のファイルで確認してください。モデルごとにファイルとコンテキストの上限は異なり、変換されたドキュメントは視覚的な配置に依存するレイアウト詳細を失う場合があります。

</Step>
</Steps>

## 最新のウェブ情報を追加する

コンポーザーに通常の Web Search スイッチはありません。最近またはライブの公開情報に明らかに依存する質問をしてください。検索が必要だと判断したとき、モデルは Browser Chat の検索ツールを呼び出せます。

```text
Use the attached product brief as the baseline. Search for official changes announced in the last 30 days, list the sources, and explain which parts of the brief now need revision.
```

検索中、Thinking 領域に **Web searching** が表示されることがあります。検索がソース メタデータを返すと、応答にリンク結果を開く **Sources** コントロールが表示されます。

モデルはすべてのプロンプトで検索する必要はありません。最新ニュースや日付付きの事実を求めると必要性は明確になりますが、特定の結果、ソース数、検索プロバイダーは保証されません。

## ウェブ検索コンテキストで画像 URL を許可する

サインイン済みユーザーは **Account** → **Settings** を開き、**Enable web search images** を有効にできます。この設定は、利用可能な場合に通常の検索結果とあわせて画像 URL を返すことをウェブ検索に許可します。

画像生成の設定ではなく、すべての検索が画像を返す、または表示することも保証しません。画像結果を追加すると、モデルへ送る検索コンテキストが増え、トークン使用量が増える場合があります。

## Capriole がファイルの種類ごとに準備する方法

Capriole は 1 つのアップロード ワークフローを維持しつつ、その下のモデル入力を適応させます。画像はネイティブのマルチモーダル入力を使えます。一部の PDF とテキストに近いファイルも、モデルのネイティブ ファイル経路を使えます。その他の対応ドキュメントは、モデル呼び出し前にテキスト コンテキストへ変換されます。

この適応により、ユーザーが添付を毎回手作業で作り直さなくても、同じチャットを対応モデル間で移動できます。すべてのモデルがすべてのファイルをネイティブに読む、すべての視覚詳細を保持する、同じコンテキスト容量を持つ、という意味ではありません。

現在のモデルが結合コンテキストを受け付けられない場合は、添付数を減らす、大きなドキュメントを分割する、または今の質問に必要な節から始めてください。

## よくある問題を直す

| 問題 | 考えられる理由 | 次の操作 |
|---|---|---|
| 添付ボタンがない | チャットが Local または No Storage モードを使っている | デフォルトのアカウント同期ストレージに戻す |
| ドキュメントが拒否される | 画像でも PDF でもないファイルが 4 MB を超えている、または種類が非対応 | ファイルを分割、エクスポート、または対応形式に変換する |
| PDF または画像が拒否される | ファイルが 10 MB を超えている | アップロード前にファイル サイズを小さくする |
| メッセージをまだ送れない | 1 つ以上の添付がまだアップロード中 | アップロード完了を待つか、失敗した添付を削除する |
| **Sources** コントロールが出ない | モデルが検索しなかった、または正規化されたソースが返されなかった | 最新情報とソース リンクを明示的に求める |
| モデルがレイアウト詳細を見落とす | ファイルが変換された、またはモデルの解釈が異なる | 原本と照合し、視覚入力に向いたモデルを試す |

## ワークフローを 1 つのスレッドに保つ

次のメッセージの前に選択モデルを変えても、会話を作り直す必要はありません。別のモデルがスレッドを続けるときのコンテキストとストレージ境界は、[会話をやり直さずに AI モデルを切り替える](/ja/articles/switch-models-mid-chat) を読んでください。

[制限付きの無料 Browser Chat でこのワークフローを試す](https://capriole.ai)。無制限の Browser Chat が必要なときは Premium にアップグレードし、API とコーディング エージェントの作業にも同じ Capriole アカウントを使い続けてください。
