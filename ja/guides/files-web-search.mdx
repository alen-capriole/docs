Capriole AI のウェブチャットでは、質問に最新の情報が必要なときに、モデルがウェブを検索します。ログインして **Server Storage** を使うアカウントは、さらに GPT Image 2.6、Nano Banana 2.1、Seedream 5.5 で無料で画像を作成し、ファイル（画像と PDF は 10 MB まで、その他のドキュメントは 4 MB まで）を添付できます。

同じワークスペースで、資料を別製品にコピーせずに GPT-6.2 Astra、Claude Fable 5.1、Claude Opus 5.5、または Gemini 4 Carbon で作業を続けられます。Premium は月額 USD 9 で、すべての対応モデルとのウェブチャットが無制限になります。

## GPT Image 2.6、Nano Banana 2.1、Seedream 5.5 で画像を生成する

Capriole AI では、ログインして **Server Storage** を使う Free・Premium・Team アカウントが、ウェブチャットで **GPT Image 2.6**、**Nano Banana 2.1**、**Seedream 5.5** を無料で利用できます。**画像** モードでいずれかのモデルを選んで作成するか、会話中に **Text Agent** に依頼してください。画像生成自体は API トークン枠を消費しませんが、Text Agent のメッセージには通常のチャット制限が適用されます。

1. ログインし、**Server Storage** を使います。**アカウント** → **設定** で **ローカル保存を有効にする** と **No Storage を有効にする** をオフにします。
2. モデル メニューを開いて **画像** タブを選び、**GPT Image 2.6**、**Nano Banana 2.1**、**Seedream 5.5** のいずれかを選んで（**GPT Image 2.5** も引き続き選べます）、作りたい画像を説明します。
3. アスペクト比、**解像度**、**1～4 枚**の生成枚数を選んで送信します。比率は既定の **自動** と **1:1、21:9、16:9、3:2、4:3、9:16、2:3、3:4**、解像度は **1K、2K、4K** に対応します（Seedream 5.5 は **1K と 2K**）。**自動** では、編集のときは編集する画像の形を保ちます。新しい画像のときは、GPT Image は 1K ではプロンプトに合う形を選び、2K と 4K では正方形で生成します。Nano Banana 2.1 は正方形で生成します。
4. 会話内で完了を待ちます。保存した会話を開き直し、完成画像の表示、**Info** の確認、ダウンロードができます。画像 1 枚だけの応答では、**画像をコピー** でその画像をすぐにコピーできます。テキストもある応答や画像が複数ある応答では、**コピー** でメニューが開き、**テキストをコピー**（テキストがある場合）、各画像、すべてをまとめてコピーする **すべてコピー** から選べます。

画像を編集するには、**画像** モードでクリップ アイコン、貼り付け、ドラッグのいずれかで画像を添付します。1 メッセージにつき 10 枚まで、形式は PNG または JPEG、1 枚あたり 10 MB までです。続けて、変更したい内容を説明します。**@** を入力すると添付した画像の一覧が表示されます。画像には `@image1`、`@image2` のように順番で名前が付きます。生成した画像にマウスを重ねると **編集** ボタンが表示され、選ぶとその画像がすぐにコンポーザーに入るので、次の変更を説明できます。タッチ画面では、画像の **…** メニューに **画像を編集** と **画像をダウンロード** があります。GPT Image 2.6、GPT Image 2.5、Nano Banana 2.1、Seedream 5.5 はいずれも編集に対応しています。Capriole AI は選択したモデルを使います。

1 アカウントにつき同時に **4 枚まで**生成できます。編集した画像も新しい画像も、1 枚ごとにこの上限に数えられます。テキスト モードではタブを切り替えずに、Text Agent に画像の作成や、添付した画像またはチャット内で以前に生成した画像の変更を依頼できます。Text Agent は同じ生成サービスを使います。使う画像モデルは、あなたが指定したモデルです。指定がなければチャット内の最新の画像のモデルを使い、それもなければ既定の画像モデルである GPT Image 2.6（**画像** タブの先頭のモデル）を使います。

各モデルの公式な機能については [OpenAI のモデルドキュメント](https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst)、[Google のモデルドキュメント](https://ai.google.dev/gemini-api/docs/models/gemini-nano-banana-2.1)、[ByteDance Seed の Seedream 5.5 ページ](https://seed.bytedance.com/en/seedream5_5)をご覧ください。Capriole AI で利用できる機能は上記のとおりです。

## アップロード前にファイルを確認する

| ファイルの分類 | 対応例 | ファイルあたりの上限 |
|---|---|---:|
| 画像 | JPG、JPEG、PNG | 10 MB |
| PDF | PDF ドキュメント | 10 MB |
| テキストと構造化ファイル | TXT、Markdown、JSON、JSONL、HTML | 4 MB |
| Office ドキュメント | DOCX と PPTX | 4 MB |
| スプレッドシート | CSV、XLS、XLSX | 4 MB |

1 つのメッセージに最大 10 個のファイルを添付できます。複数のファイルを合わせたコンテキストが大きいと、選択したモデルの入力上限を超える場合があります。

会話のストレージ境界を変える前に、[チャット ストレージ ガイド](/ja/guides/chat-storage) を読んでください。

## ファイルを基にモデルへ作業させる

<Steps>
<Step title="同期チャットを開く">

[Capriole AI](https://www.capriole.ai/ja) にサインインします。チャットがデフォルトのアカウント同期ストレージを使うよう、**ローカル保存を有効にする** と **No Storage を有効にする** はオフのままにしてください。

</Step>

<Step title="ファイルを追加する">

コンポーザーで **写真とファイルを追加** を選びます。ファイルをチャット領域にドラッグするか、クリップボードから貼り付けることもできます。

メッセージを送る前に、添付のアップロード完了を待ってください。Capriole は選択したモデル向けにアップロード ファイルを準備しているあいだ、処理ステータスを表示します。

</Step>

<Step title="ファイルだけでなく、作業内容を説明する">

モデルに何を調べ、どのような出力が役立つかを伝えてください。例：

```text
Read the attached spreadsheet. Identify the three largest month-over-month changes, explain which rows produced them, and return a compact table.
```

ドキュメントレビューでは、気になる節、判断、または不整合を指定してください。`summarize this` のような指示だけだと、モデルへの方向付けが少なくなります。

</Step>

<Step title="添付と照合して答えを確認する">

重要な数値、引用、行参照を元のファイルで確認してください。モデルごとにファイルとコンテキストの上限は異なり、変換されたドキュメントは視覚的な配置に依存するレイアウト詳細を失う場合があります。

</Step>
</Steps>

## 最新のウェブ情報を追加する

最近またはライブの公開情報に明らかに依存する質問をしてください。検索が必要だと判断したとき、モデルはウェブチャットの検索ツールを呼び出せます。

```text
Use the attached product brief as the baseline. Search for official changes announced in the last 30 days, list the sources, and explain which parts of the brief now need revision.
```

検索中、Thinking 領域に、検索語に続けて **を検索しています** と表示されることがあります。検索がソース メタデータを返すと、応答にリンク結果を開く **ソース** コントロールが表示されます。

最新情報を調べるときは、質問に日付を入れ、出典のリンクを求めてください。

## ウェブ検索コンテキストで画像 URL を許可する

サインイン済みユーザーは **アカウント** → **設定** を開き、**ウェブ検索画像を有効にする** をオンにできます。この設定は、利用可能な場合に通常の検索結果とあわせて画像 URL を返すことをウェブ検索に許可します。

画像結果を追加すると、モデルへ送る検索コンテキストが増え、トークン使用量が増える場合があります。

## Capriole がファイルの種類ごとに準備する方法

Capriole は 1 つのアップロード ワークフローを維持しつつ、その下のモデル入力を適応させます。画像はネイティブのマルチモーダル入力を使えます。一部の PDF とテキストに近いファイルも、モデルのネイティブ ファイル経路を使えます。その他の対応ドキュメントは、モデル呼び出し前にテキスト コンテキストへ変換されます。

この適応により、ユーザーが添付を毎回手作業で作り直さなくても、同じチャットを対応モデル間で移動できます。

現在のモデルが結合コンテキストを受け付けられない場合は、添付数を減らす、大きなドキュメントを分割する、または今の質問に必要な節から始めてください。

## よくある問題を直す

| 問題 | 考えられる理由 | 次の操作 |
|---|---|---|
| 添付ボタンがない | チャットが Local または No Storage モードを使っている | デフォルトのアカウント同期ストレージに戻す |
| ドキュメントが拒否される | 画像でも PDF でもないファイルが 4 MB を超えている、または種類が非対応 | ファイルを分割、エクスポート、または対応形式に変換する |
| PDF または画像が拒否される | ファイルが 10 MB を超えている | アップロード前にファイル サイズを小さくする |
| メッセージをまだ送れない | 1 つ以上の添付がまだアップロード中 | アップロード完了を待つか、失敗した添付を削除する |
| **ソース** コントロールが出ない | モデルが検索しなかった、または正規化されたソースが返されなかった | 最新情報とソース リンクを明示的に求める |
| モデルがレイアウト詳細を見落とす | ファイルが変換された、またはモデルの解釈が異なる | 原本と照合し、視覚入力に向いたモデルを試す |

## ワークフローを 1 つのスレッドに保つ

次のメッセージの前に選択モデルを変えても、会話を作り直す必要はありません。別のモデルがスレッドを続けるときのコンテキストとストレージ境界は、[会話をやり直さずに AI モデルを切り替える](/ja/articles/switch-models-mid-chat) を読んでください。

[無料ウェブチャットでこのワークフローを試す](https://www.capriole.ai/ja)。無制限のウェブチャットが必要なときは Premium にアップグレードし、API とコーディング エージェントの作業にも同じ Capriole アカウントを使い続けてください。
