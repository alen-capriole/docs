Capriole AI Team は 5 シートで月額 USD 70 です。メンバー全員が GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon とウェブチャットで無制限に会話でき、チームはアプリやコーディング エージェント向けに毎月 5,000 万 API トークンを共有します。API は公式 API 価格より最大 92% 安く使えます。所有者は請求を 1 つにまとめ、メールでメンバーを招待し、各メンバーの API 利用を確認したり上限を設けたりできます。

## Team が向いている人

Team は、開発チームのように、請求を 1 つにまとめ、API トークンを共有し、誰が使っているかを把握したい小規模なグループに向いています。1 人で使うなら、月額 USD 8 の Premium で無制限のウェブチャットと自分専用の API 枠を利用できます。すべてのプランの比較は[プラン ガイド](/ja/guides/plans-and-limits)をご覧ください。

## Team に含まれるもの

| | Team |
|---|---|
| 料金 | 月額 USD 70 |
| シート | 所有者を含めて 5。保留中の招待もシートを使います。 |
| ウェブチャット | メンバー全員が、すべての対応モデルで無制限 |
| API トークン | 毎月 5,000 万、チームで共有 |
| チャージ | 5,000 万トークンあたり USD 80、まとめ買いで最大 10% 割引 |
| API キー | 各メンバーが自分で作成し、使用量はチームに請求 |
| 画像生成 | **Server Storage** を使うウェブチャットで無料 |

ログイン中のウェブチャットには、1 アカウントあたり 1 UTC 日 200 メッセージのフェアユース上限があります。スクリプトによる自動化された乱用を防ぐためのもので、通常の利用ではこの上限を大きく下回ります。上限はメンバーごとに別々です。

## 始める前に

- チームを作成すると、Premium プランが置き換わります。Premium を有料で契約している場合、サブスクリプションはすぐにキャンセルされ、返金されません。
- 各メンバーは、招待したメールアドレスで Capriole AI にサインアップまたはサインインします。
- Capriole Quant の特典アクセスやプロモーションの Premium はアカウントに残りますが、チームに参加しているあいだは使われません。

## チームを作成する

<Steps>
<Step title="Team プランを開く">

ログインし、サイドバー下部の自分の名前を選び、**料金** を選んでから **チーム用** を選びます。**アカウント** を開き、**Team** セクションで **チームを作成** を選んでも始められます。

</Step>

<Step title="購読する">

**購読する** を選びます。Premium を契約している場合は **Team を作成しますか？** ダイアログが開き、Premium サブスクリプションがすぐにキャンセルされ、返金されないことが説明されます。**続行** を選びます。

</Step>

<Step title="Stripe Checkout で支払う">

Stripe Checkout が開きます。支払い情報と、お持ちであればプロモーション コードを入力して支払います。

</Step>

<Step title="チームに名前を付ける">

Capriole AI が **アカウント** に戻り、**チームに名前を付ける** を開きます。名前を入力し、**保存** を選びます。

プランに **Team** と表示され、あなたがチームの所有者になります。

</Step>
</Steps>

## メンバーを招待する

<Steps>
<Step title="招待を送る">

**アカウント** → **Team** で **メンバーを招待** を選びます。メンバーの **メール** を入力し、**招待** を選びます。

Capriole AI が招待リンクをメールで送ります。招待はメンバー一覧に **保留中** と表示され、シートを 1 つ使います。**シート** には 5 つのうちいくつ使っているかが表示されます。

</Step>

<Step title="メンバーが承諾する">

メンバーはリンクを開き、招待されたメールアドレスでサインアップまたはサインインします。チームへの参加を確認するダイアログが表示されるので、**招待を承諾** を選ぶと有効プランが Team に切り替わります。参加しない場合は **辞退** を選びます。

すでにサインインしているメンバーには、**アカウント** → **Team** にも招待が表示されます。

</Step>
</Steps>

<Warning>
メンバーが Premium を有料で契約している場合、招待を承諾するとそのサブスクリプションはすぐにキャンセルされ、返金されません。
</Warning>

招待を取り消すには、メンバー一覧でその招待のメニューを開き、**招待をキャンセル** を選びます。

## メンバーを管理する

| 役割 | できること |
|---|---|
| **所有者** | 管理者ができることすべて。所有者は削除できず、所有権も移せません。 |
| **管理者** | チーム名の変更、メンバーの招待と削除、役割の変更、アラート トークンと上限トークンの設定、チームのチャージ購入、請求の管理 |
| **メンバー** | 無制限のウェブチャットと、チームに請求される API アクセスを使い、自分の API 使用量を確認 |

所有者と管理者には、各メンバーのメールアドレス、役割、Team の API 使用量が表示されます。Capriole AI がほかに何を保存し、誰が受け取るかは[プライバシー ガイド](/ja/guides/privacy-and-security)にまとめています。

役割を変えるには、メンバーのメニューを開いて **メンバー設定** を選び、**役割** を選んで **保存** を選びます。

メンバーを外すには、メニューを開いて **削除** を選び、確認します。そのメンバーはすぐにチームプランへのアクセスを失い、シートが空きます。

## API トークンを共有する

各メンバーは [API ページ](https://www.capriole.ai/ja?view=api)で自分のキーを作成します。チームに参加しているあいだ、すべての API リクエストはチームのトークンを使います。まず毎月含まれる 5,000 万、その次にチームでチャージしたトークンです。

API ページの **使用量** には、**含まれるチーム使用量** と **オンデマンドチーム使用量** が表示されます。所有者と管理者は **メンバー** で絞り込み、各メンバーのリクエストと課金トークンを確認できます。絞り込みについては [API キーと使用量ガイド](/ja/guides/api-keys-usage)で説明しています。

### アラート トークンと上限トークンを設定する

所有者と管理者は、**メンバー設定** でメンバーごとに 2 つの任意の上限を設定できます。どちらも直近 30 日間の課金トークンで数えます。

- **アラート tokens**：メンバーがこの量に達すると、Capriole AI がチームの所有者と管理者にメールで知らせます。
- **上限 tokens**：メンバーがこの量に達すると、使用量が上限を下回るか、あなたが上限を変えるまで、そのメンバーのチーム請求の API アクセスが止まります。

空欄にすると、アラートや上限はかかりません。ウェブチャットには影響しません。

## チームのチャージを購入する

所有者と管理者は、API ページで **チャージ** を選びます。1 パックは 5,000 万トークンで USD 80、一度に 1〜5 パック買えます。追加 1 パックごとに 2.5% 割引され、5 パック（2.5 億トークン）で最大 10% 割引になります。

## 名前の変更、請求、チームの終了

- **名前を変更**：**アカウント** → **Team** で、チーム名の横のメニューを開き、**名前を変更** を選びます。
- **請求**：所有者と管理者は **アカウント** で **サブスクリプションを管理** を選び、Stripe で支払い情報の更新、請求書の確認、解約ができます。
- **チームが終了すると**：各メンバーのアカウントは Free に戻ります。Capriole Quant の特典アクセスやプロモーションのアクセスがまだ有効なら、そちらに戻ります。メンバーが参加したときにキャンセルされた Premium サブスクリプションは復元されません。

## よくある質問

### Capriole AI Team の料金はいくらですか？

5 シートで月額 USD 70 です。メンバー全員がウェブチャットを無制限に使え、チームは毎月 5,000 万 API トークンを共有します。追加のトークンは 5,000 万あたり USD 80 です。

### チームに参加すると、Premium サブスクリプションはどうなりますか？

有料の Premium サブスクリプションはすぐにキャンセルされ、返金されません。Capriole Quant の特典アクセスやプロモーションのアクセスはアカウントに残りますが、チームに参加しているあいだは使われません。

### 保留中の招待もシートを使いますか？

はい。シートはメンバーと保留中の招待を合わせて数えるので、不要になった招待はキャンセルしてください。

### チームの所有権を移せますか？

いいえ。所有者はずっと所有者のままで、削除もできません。管理者は所有者と同じ管理・請求の権限を持ちます。

### チームのメンバーは 1 日のチャット上限を共有しますか？

いいえ。各メンバーはウェブチャットを無制限に使え、1 日のフェアユース上限はアカウントごとに別々に適用されます。
