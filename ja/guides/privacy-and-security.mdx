Capriole AI は、あなたのチャット、ファイル、API の内容を AI モデルの学習に使いません。チャット履歴の保存先は、アカウント、ブラウザのみ、保存しない、の 3 つから選べます。API はリクエストやレスポンスの内容を保持せず、トークン数などの使用量記録だけを残します。すべてのチャットをエクスポートでき、チャットはいつでも削除でき、アカウントも削除できます。チャットをまたいであなたについての事実を覚えるメモリは初期設定でオンになっていますが、いつでもオフにできます。

このガイドでは、データの扱いを要約します。全文は[プライバシーポリシー](/ja/legal/privacy)をご覧ください。プラン、制限、禁止されている利用については[利用規約](/ja/legal/terms)に定めています。

## コンテンツは学習に使われません

Capriole AI は、あなたのチャット、ファイル、API の内容を AI モデルの学習に使いません。

ただし、各リクエストは、それに答える AI モデル プロバイダー（OpenAI、Anthropic、Google、xAI、Z.ai、Moonshot AI、ByteDance）か、それらのモデルをホストするクラウド プラットフォームに送られます。そのプロバイダーは、自社の規約に基づいてリクエストを扱います。

## チャット履歴の保存先を選ぶ

| ストレージ モード | チャット履歴の保存先 | 選び方 |
|---|---|---|
| **Server Storage**（既定） | あなたのアカウント（Capriole AI のサーバー上） | 2 つのストレージ スイッチをどちらもオフのままにする |
| **Local Storage** | あなたのブラウザ（当社のデータベースには保存されません） | **ローカル保存を有効にする** をオンにする |
| **No Storage** | 保存されない | **No Storage を有効にする** をオンにする |

Server Storage を使うと、端末間でのチャットの同期、ファイルのアップロード、画像生成、メモリの利用ができます。

どちらのスイッチも **アカウント** → **設定** にあります。どのモードでも、メッセージは当社のサーバーを経由して、答えるモデルに届きます。また、Capriole AI は使用量記録を残します。応答を報告した場合は、どのモードでも、その応答と直前のあなたのメッセージが当社に届きます。各モードの詳細は[チャット ストレージ ガイド](/ja/guides/chat-storage)で説明しています。

<Warning>
**No Storage を有効にする** をオンにして確認すると、サーバーとこのブラウザのすべてのチャット履歴が完全に削除されます。
</Warning>

ゲストのチャットは当社のサーバーに保存されません。サインインしたときにアカウントへ保存できるよう、ブラウザのタブにコピーが残ります。

## Capriole AI が保持するデータ

| データ | 保持する内容 |
|---|---|
| アカウント | サインイン時のメールアドレス、名前、プロフィール画像。アカウントは Capriole Quant と共通です。 |
| チャット | メッセージ、添付ファイル、作成した画像、チャットのタイトル（ストレージ モードによる） |
| パーソナライズ | アカウントに追加した名前、仕事、指示 |
| メモリ | 共通メモリと各プロジェクトのメモリに入る、あなたについての短い事実。自分で追加したものと、**メモリ** がオンの間に Capriole AI がチャットから保存または更新したものです。 |
| プロジェクト | 名前、指示、追加したファイル |
| タグ | 名前、色、タグを付けたチャット |
| 音声入力 | なし。録音は文字起こしのために送られ、音声もテキストも保存されません。 |
| 報告 | 応答を報告したとき：その応答、直前のあなたのメッセージ、選んだ画像、選んだ理由と書き添えた詳細、モデル、ブラウザ、国などの技術情報。サインインしている場合はアカウントのメールアドレスも含みます。報告はメールで当社のサポート窓口に届きます。 |
| 使用量記録 | 各チャットと API リクエストの時刻、モデル、トークン数、ステータス、レイテンシ、コスト、IP アドレス。API リクエストでは使用したキーも記録します。メッセージの内容は含みません。 |
| 支払い | サブスクリプションの状態と請求用の識別子。支払いは Stripe が処理し、当社はカード番号を受け取りません。 |

## メモリ

Capriole AI のメモリは、住んでいる場所や好みの回答スタイルなど、あなたについての短い事実を保存し、以降のチャットで使います。メモリは初期設定でオンになっており、**アカウント** → **メモリ** でオフにできます。Capriole AI は返信のたびに、あなたが自分について述べた新しい事実を保存したり、保存済みの事実を更新したりすることがあり、内容は書いたときの言語のまま残ります。メモリを使うのは、ログインして Server Storage で保存されるチャットだけで、ウェブでもアプリでも同じです。Local Storage、No Storage、ゲストのチャットでは使われず、API でも使われません。

メモリはアカウントとともに当社のサーバーに保存され、2 種類の一覧があります。

| 一覧 | 管理する場所 | 使うチャット | 容量 |
|---|---|---|---|
| 共通メモリ | **アカウント** → **メモリ** | すべてのチャット。プロジェクト外のチャットは新しい事実をここに保存します。 | 最大 2,400 文字 |
| プロジェクトのメモリ | [プロジェクトの **メモリ** タブ](/ja/guides/projects#プロジェクトのメモリを使う) | そのプロジェクトのチャット（共通メモリと一緒に使います）。新しい事実はここに保存します。 | 各プロジェクト最大 1,200 文字 |

どちらの一覧でも、保存された内容をすべて確認したり、**メモリを追加** を選んだり、メモリを編集・削除したり、**すべて削除** を選んだりできます。**アカウント** → **メモリ** の **すべて削除** で消去されるのは共通メモリだけで、各プロジェクトのメモリはそれぞれのタブで消去します。どちらの一覧もウェブで管理し、アプリのチャットでも使われます。一覧がいっぱいになると、メモリを短くするか削除するまで、あなたも Capriole AI も追加できません。

**メモリ** をオフにすると、Capriole AI はメモリを使うことも更新することもやめます。一覧は残り、メモリの追加、編集、削除は引き続きできます。チャットやすべてのチャット履歴を削除してもメモリは残ります。プロジェクトを削除すると、そのメモリも削除されます。

## API が保持するデータ

API はリクエストや応答の内容を保存しません。Capriole AI は利用枠の管理、請求、サポートのために API キーと使用記録を保存します。ウェブチャットでは回答をパーソナライズできます。

## セキュリティ

Capriole AI は、暗号化された接続、非公開のファイルストレージ、スタッフのアクセス制限を採用しています。

主要なサーバーとデータベースはインドにあります。当社のプロバイダーは、米国を含むほかの国でもデータを処理します。

## チャットをエクスポートする

**アカウント** → **設定** で **チャット履歴をエクスポート** を選びます。すべてのチャットを Markdown ファイルにしたもの、添付したファイル、生成した画像に加えて、すべてのチャットをプログラムで読める形式でまとめた `conversations.json` を含む ZIP が手に入ります。プロジェクトの指示とファイルは `projects/` フォルダーに入り、`conversations.json` には各チャットが属するプロジェクトも記録されます。

履歴が多いと数分かかります。ダウンロードは 24 時間利用でき、有料プランが終わったあとでもエクスポートできます。

1 つのチャットだけをエクスポートするには、サイドバーでそのチャットのメニューを開き、**エクスポート** を選びます。プロジェクトはプロジェクトのメニューからエクスポートします。Local Storage のチャットは、当社のサーバーに保存されることなく、すぐにダウンロードされます。

## チャットやアカウントを削除する

- **1 つのチャット**：サイドバーでそのチャットのメニューを開き、**削除** を選びます。
- **すべてのチャット**：**アカウント** → **設定** で、**すべてのチャット履歴を削除** の横にある **すべて削除** を選びます。メモリは残り、プロジェクトとその指示、ファイル、メモリも残ります。
- **プロジェクト**：プロジェクトのメニューを開き、**削除** を選びます。その指示、ファイル、メモリ、チャットも一緒に削除されます。
- **メモリ**：**アカウント** → **メモリ** またはプロジェクトの **メモリ** タブで、メモリを 1 つずつ削除するか、**すべて削除** を選びます。
- **アカウント**：**アカウント** を開き、**アカウントを管理** を選んで、**セキュリティ** タブで **アカウントの削除** を選びます。有料サブスクリプションが有効な場合は、代わりに [info@capriole.ai](mailto:info@capriole.ai) にメールしてください。アカウントは Capriole Quant と共通のため、削除すると Capriole Quant にもサインインできなくなります。

チャット、すべてのチャット履歴、メモリ、またはプロジェクトを削除すると、当社のサーバーから完全に消去されます。削除したデータは、データベースのバックアップに最大 7 日間残ることがあります。Local Storage のチャットは、消去するまでブラウザに残ります。

## データを受け取る相手

| 受け取る相手 | 受け取る内容 |
|---|---|
| AI モデル プロバイダー | 各リクエストに必要なもの：メッセージ、ファイル、音声の録音、チャットの文脈、メモリ（オンの場合）、さらにタイムゾーンとそこから推定したおおよその位置 |
| インフラ プロバイダー | モデル プロバイダーへ送られる途中のリクエスト |
| 検索プロバイダー（Tavily など） | モデルが行う検索クエリ |
| 天気情報プロバイダー | 尋ねた場所。場所を指定しない場合は IP アドレス |
| サービス プロバイダー | Amazon Web Services（サーバー、データベース、ファイル）、Vercel（ウェブサイトのホスティングと分析）、Clerk（サインイン）、Stripe（ウェブでの支払い）、Apple・Google Play・RevenueCat（購入手続き）、Resend・Brevo（メール）、エラー監視ツール |
| Google と LinkedIn | 当社ウェブサイトのタグを通じたサイト訪問と広告の成果 |
| 所属する [Team](/ja/guides/team-plan) の所有者と管理者 | あなたのメールアドレス、役割、Team の API 使用量 |

Capriole AI はあなたの個人情報を販売しません。

## よくある質問

### Capriole AI はチャットを AI モデルの学習に使いますか？

いいえ。Capriole AI は、あなたのチャット、ファイル、API の内容を AI モデルの学習に使いません。モデル プロバイダーは各リクエストを受け取り、自社の規約に基づいて扱います。

### Capriole AI は API リクエストを保存しますか？

いいえ。API のリクエストやレスポンスの内容は保持せず、時刻、モデル、トークン数などの使用量記録だけを残します。

### チャットを保存せずに Capriole AI を使えますか？

はい。ページを離れるか更新すると消えるチャットにするには **No Storage を有効にする** を、履歴をブラウザだけに残すには **ローカル保存を有効にする** をオンにします。

### Capriole AI にはチャットをまたぐメモリがありますか？

はい。**メモリ** は初期設定でオンになっています。Capriole AI はログインした Server Storage のチャットで、あなたが自分について述べた短い事実を保存することがあり、以降のチャットで使います。各プロジェクトにも専用のメモリがあります。事実は 1 つずつ確認、追加、編集、削除でき、**メモリ** は **アカウント** → **メモリ** でいつでもオフにできます。

### Capriole AI のメモリを削除するには？

**アカウント** → **メモリ** で、メモリにポインターを合わせて **×** を選ぶか、**すべて削除** を選びます。プロジェクトのメモリは、そのプロジェクトの **メモリ** タブにあります。チャットを削除しても **メモリ** をオフにしても、保存済みのメモリは残ります。削除したメモリは、データベースのバックアップに最大 7 日間残ることがあります。

### Capriole AI のアカウントを削除するには？

**アカウント** を開き、**アカウントを管理** を選んで、**セキュリティ** タブで **アカウントの削除** を選びます。有料サブスクリプションが有効な場合は、代わりに [info@capriole.ai](mailto:info@capriole.ai) にメールしてください。2 つの製品は 1 つのアカウントを共有しているため、削除すると Capriole Quant にもサインインできなくなります。

### Capriole AI のデータはどこに保存されますか？

主要なサーバーとデータベースはインドにあります。当社のプロバイダーは、米国を含むほかの国でもデータを処理します。
