Capriole AI は、あなたのチャット、ファイル、API の内容を AI モデルの学習に使いません。チャット履歴の保存先は、アカウント、ブラウザのみ、保存しない、の 3 つから選べます。API はリクエストやレスポンスの内容を保持せず、トークン数などの使用量記録だけを残します。すべてのチャットをエクスポートでき、チャットはいつでも削除でき、アカウントの削除も依頼できます。

このガイドでは、データの扱いを要約します。全文は[プライバシーポリシー](/ja/legal/privacy)をご覧ください。

## コンテンツは学習に使われません

Capriole AI は、あなたのチャット、ファイル、API の内容を AI モデルの学習に使いません。

ただし、各リクエストは、それに答える AI モデル プロバイダー（OpenAI、Anthropic、Google、xAI、Z.ai、Moonshot AI）か、それらのモデルをホストするクラウド プラットフォームに送られます。そのプロバイダーは、自社の規約に基づいてリクエストを扱います。

## チャット履歴の保存先を選ぶ

| ストレージ モード | チャット履歴の保存先 | デバイス間の同期 | アップロードと画像作成 | 選び方 |
|---|---|---|---|---|
| **Server Storage**（既定） | あなたのアカウント（Capriole AI のサーバー上） | あり | 利用可能 | 2 つのストレージ スイッチをどちらもオフのままにする |
| **Local Storage** | あなたのブラウザ（当社のデータベースには保存されません） | なし | オフ | **ローカル保存を有効にする** をオンにする |
| **No Storage** | 保存されない | なし | オフ | **No Storage を有効にする** をオンにする |

どちらのスイッチも **アカウント** → **設定** にあります。どのモードでも、メッセージは当社のサーバーを経由して、答えるモデルに届きます。また、Capriole AI は使用量記録を残します。各モードの詳細は[チャット ストレージ ガイド](/ja/guides/chat-storage)で説明しています。

<Warning>
**No Storage を有効にする** をオンにして確認すると、サーバーとこのブラウザのすべてのチャット履歴が完全に削除されます。
</Warning>

ゲストのチャットは当社のサーバーに保存されません。サインインしたときにアカウントへ保存できるよう、ブラウザのタブにコピーが残ります。

## Capriole AI が保持するデータ

| データ | 保持する内容 |
|---|---|
| アカウント | サインイン時のメールアドレス、名前、プロフィール画像。アカウントは Capriole Quant と共通です。 |
| チャット | メッセージ、添付ファイル、作成した画像、チャットのタイトル（ストレージ モードによる） |
| パーソナライズ | アカウントに追加した名前、仕事、指示 |
| 音声入力 | なし。録音は文字起こしのために送られ、音声もテキストも保存されません。 |
| 使用量記録 | 各チャットと API リクエストの時刻、モデル、トークン数、ステータス、レイテンシ、コスト、IP アドレス。API リクエストでは使用したキーも記録します。メッセージの内容は含みません。 |
| 支払い | サブスクリプションの状態と請求用の識別子。支払いは Stripe が処理し、当社はカード番号を受け取りません。 |

## API が保持するデータ

API はリクエストやレスポンスの内容を保持しないため、API の会話履歴はありません。Capriole AI が保持するのは、API キーと、クォータ、請求、サポートのための各リクエストの使用量記録です。アカウントのパーソナライズは API には適用されません。

## セキュリティ

Capriole AI は、暗号化された接続、非公開のファイルストレージ、スタッフのアクセス制限を採用しています。完全に安全なシステムはありません。

主要なサーバーとデータベースはインドにあります。当社のプロバイダーは、米国を含むほかの国でもデータを処理します。

## チャットをエクスポートする

**アカウント** → **設定** で **チャット履歴をエクスポート** を選びます。すべてのチャットを Markdown ファイルにしたもの、添付したファイル、生成した画像に加えて、すべてのチャットをプログラムで読める形式でまとめた `conversations.json` を含む ZIP が手に入ります。

履歴が多いと数分かかります。ダウンロードは 24 時間利用でき、有料プランが終わったあとでもエクスポートできます。

1 つのチャットだけをエクスポートするには、サイドバーでそのチャットのメニューを開き、**エクスポート** を選びます。プロジェクトはプロジェクトのメニューからエクスポートします。Local Storage のチャットは、当社のサーバーに保存されることなく、すぐにダウンロードされます。

## チャットやアカウントを削除する

- **1 つのチャット**：サイドバーでそのチャットのメニューを開き、**削除** を選びます。
- **すべてのチャット**：**アカウント** → **設定** で、**すべてのチャット履歴を削除** の横にある **すべて削除** を選びます。
- **アカウント**：[info@capriole.ai](mailto:info@capriole.ai) にメールしてください。アカウントは Capriole Quant と共通のため、Capriole Quant にもサインインできなくなります。

チャットやすべてのチャット履歴を削除すると、当社のサーバーから完全に削除されます。削除したデータは、データベースのバックアップに最大 7 日間残ることがあります。Local Storage のチャットは、消去するまでブラウザに残ります。

## データを受け取る相手

| 受け取る相手 | 受け取る内容 |
|---|---|
| AI モデル プロバイダー | 各リクエストに必要なもの：メッセージ、ファイル、音声の録音、チャットの文脈、さらにタイムゾーンとそこから推定したおおよその位置 |
| インフラ プロバイダー | モデル プロバイダーへ送られる途中のリクエスト |
| 検索プロバイダー（Tavily など） | モデルが行う検索クエリ |
| サービス プロバイダー | Amazon Web Services（サーバー、データベース、ファイル）、Vercel（ウェブサイトのホスティングと分析）、Clerk（サインイン）、Stripe（支払い）、Resend（メール）、エラー監視ツール |
| Google と LinkedIn | 当社ウェブサイトのタグを通じたサイト訪問と広告の成果 |
| 所属する Team の所有者と管理者 | あなたのメールアドレス、役割、Team の API 使用量 |

Capriole AI はあなたの個人情報を販売しません。

## よくある質問

### Capriole AI はチャットを AI モデルの学習に使いますか？

いいえ。Capriole AI は、あなたのチャット、ファイル、API の内容を AI モデルの学習に使いません。モデル プロバイダーは各リクエストを受け取り、自社の規約に基づいて扱います。

### Capriole AI は API リクエストを保存しますか？

いいえ。API のリクエストやレスポンスの内容は保持せず、時刻、モデル、トークン数などの使用量記録だけを残します。

### チャットを保存せずに Capriole AI を使えますか？

はい。ページを離れるか更新すると消えるチャットにするには **No Storage を有効にする** を、履歴をブラウザだけに残すには **ローカル保存を有効にする** をオンにします。

### Capriole AI のアカウントを削除するには？

[info@capriole.ai](mailto:info@capriole.ai) にメールしてください。2 つの製品は 1 つのアカウントを共有しているため、削除すると Capriole Quant にもサインインできなくなります。

### Capriole AI のデータはどこに保存されますか？

主要なサーバーとデータベースはインドにあります。当社のプロバイダーは、米国を含むほかの国でもデータを処理します。
