Capriole AI Premium は月額 USD 8 で、GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon をはじめ、すべての対応モデルとウェブチャットで無制限に会話できます。アプリやコーディング エージェント向けに、公式 API 価格より最大 92% 安い API も含まれます。ウェブチャットはまず無料で試せます。アカウントなしなら 1 日 5 メッセージ、無料アカウントなら毎月 50 万トークンまで使えます。Team は月額 USD 70 で、5 シートと共有の API トークン プールが付きます。

## プランを比較する

| | ゲスト | Free | Premium | Team |
|---|---|---|---|---|
| 料金 | USD 0 | USD 0 | 月額 USD 8 | 5 シートで月額 USD 70 |
| アカウント | 不要 | 必要 | 必要 | メンバーごとに 1 つ |
| ウェブチャット | 1 日 5 メッセージ | 毎月 50 万トークン | 無制限 | メンバー全員が無制限 |
| ウェブチャットのモデル | すべての対応モデル | すべての対応モデル | すべての対応モデル | すべての対応モデル |
| 画像生成 | 利用不可 | 無料 | 無料 | 無料 |
| API とコーディング エージェント | 利用不可 | 利用不可 | 毎月 500 万トークン | 毎月 5,000 万トークンをチームで共有 |
| API のチャージ | 利用不可 | 利用不可 | 500 万トークンあたり USD 8 | 5,000 万トークンあたり USD 80 |
| チャット履歴 | ブラウザのタブ内にのみ保持 | 保存方法を選択可能 | 保存方法を選択可能 | 保存方法を選択可能 |

GPT Image 2.5 と Nano Banana 2.1 で画像を生成するには、**Server Storage** を使うログイン済みアカウントが必要です。[画像生成ガイドを見る](/ja/guides/files-web-search)。3 つのストレージ モードの違いは[チャット ストレージ ガイド](/ja/guides/chat-storage)で説明しています。

## 「無制限」の意味

Premium と Team のウェブチャットには、**Thinking** プリセットを含め、どの[対応モデル](/ja/guides/choose-a-model)にもトークンのメーターがありません。ログイン中のウェブチャットには、1 アカウントあたり 1 UTC 日 200 メッセージのフェアユース上限があります。スクリプトによる自動化された乱用を防ぐためのもので、通常の利用ではこの上限を大きく下回ります。

上限に達すると Capriole AI に通知が表示され、00:00 UTC にチャットを再開できます。この上限は API キーには適用されません。

Claude 自体の Pro と Max プランは仕組みが異なり、5 時間のセッション上限と週の上限があります。[Claude の使用制限の解説](/ja/articles/claude-usage-limits)で Capriole AI と比べています。

## API トークンを消費するもの

ウェブチャットと API は別々に数えます。

| 利用内容 | 消費するもの |
|---|---|
| Premium または Team のウェブチャット | なし。無制限です。 |
| Free のウェブチャット | 毎月 50 万トークンのチャット枠 |
| ウェブチャットでの画像生成 | なし。無料です。 |
| API リクエスト（API ページの **APIテスト環境** を含む） | API トークン |
| Codex や Claude Code などのコーディング エージェント | API トークン |

API トークンは課金トークンで数えます。キャッシュなし入力に、キャッシュ入力の 10% と出力を足したものです。数え方はどのモデルでも同じです。Thinking モデルはより多くのトークンを使います。計算例は[課金トークンの説明](/ja/articles/charged-tokens)をご覧ください。

毎月含まれるトークンが先に使われ、そのあとにチャージしたトークンが使われます。API キーには Premium か Team が必要です。Free では API ページに **サブスクライブすると API にアクセスできます。** と表示されます。

## API トークンを追加購入する

トークンが足りなくなったら、API ページで **チャージ** を選びます。複数のパックをまとめて買うと割安になります。

| | Premium のチャージ | Team のチャージ |
|---|---|---|
| 料金 | 500 万トークンあたり USD 8 | 5,000 万トークンあたり USD 80 |
| 1 回に買えるパック数 | 1〜11（500 万〜5,500 万トークン） | 1〜5（5,000 万〜2.5 億トークン） |
| まとめ買い割引 | 追加 1 パックごとに 1.5%、最大 15% 割引 | 追加 1 パックごとに 2.5%、最大 10% 割引 |
| 購入できる人 | Premium メンバー | Team の所有者と管理者 |

## Capriole Quant のサブスクライバー

Capriole AI は Capriole Investments が開発しています。同社の市場データプラットフォーム [Capriole Quant](https://quant.capriole.com/)（旧 Capriole Charts）は別の製品です。

対象となる Capriole Quant の有料プランには、追加料金なしで Capriole AI へのアクセスが含まれるため、別途サブスクリプションは必要ありません。アクセスは Quant プランが有効なあいだ続きます。Capriole Quant の 3 日間の無料トライアルに含まれるのはウェブチャットだけで、API アクセスは含まれません。

## プランの支払い

サイドバー下部の自分の名前を選び、**料金** を選んでから、Premium の **購読する** を選びます。**アカウント** ページの **アップグレード** からも同じプランを開けます。

支払いは Stripe が処理します。主要なクレジットカードとデビットカードに対応しており、チェックアウトで使える支払い方法は Stripe に表示されます。Premium と Team のチェックアウトではプロモーション コードを使えます。

いつでも解約できます。長期契約や解約手数料はありません。Premium は現在の請求期間の終わりまで有効で、その後アカウントは Free に戻ります。保存したチャットは残り、引き続きエクスポートできます。

プロモーションや引き換えコードで得た Premium は、解約の必要がありません。**アカウント** に表示される日付で終了し、更新されません。Team の所有者と管理者は、同じ **サブスクリプションを管理** ボタンで Team のサブスクリプションを管理します。シート、招待、共有トークンについては [Team プラン ガイド](/ja/guides/team-plan)で説明しています。

## よくある質問

### Capriole AI は本当に無制限ですか？

はい。Premium と Team のウェブチャットには、どの対応モデルにもトークンのメーターがなく、あるのはスクリプトによる乱用を防ぐ[フェアユース上限](#「無制限」の意味)だけです。API はトークンで数えます。

### Capriole AI は無料で使えますか？

はい。ゲストは[アカウントなしで](/ja/articles/ai-chat-without-login) 1 日 5 メッセージまで送れます。無料アカウントには毎月 50 万トークンのウェブチャットと無料の画像生成が含まれますが、API アクセスは含まれません。

### Premium には API が含まれますか？

はい。Premium には、アプリやコーディング エージェント向けに毎月 500 万 API トークンが含まれ、公式 API 価格より最大 92% 安く使えます。追加のトークンは 500 万あたり USD 8 です。

### Premium はどう解約しますか？

**アカウント** を開いて **サブスクリプションを管理** を選び、Stripe の請求ページで解約します。Premium は請求期間の終わりまで有効です。

### Capriole Quant を使っています。Premium は必要ですか？

いいえ。対象となる Capriole Quant の有料プランには、追加料金なしで Capriole AI へのアクセスが含まれます。

アカウントなしで[チャットを始める](https://www.capriole.ai/ja)か、月額 USD 8 の Premium で [API キーを取得](https://www.capriole.ai/ja?view=api)しましょう。
