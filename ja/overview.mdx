Capriole AI は Capriole Investments が開発しており、同社の市場データプラットフォーム [Capriole Quant](https://quant.capriole.com/)（旧 Capriole Charts）や投資ファンドとは別の製品です。有効な Capriole Quant サブスクライバーは、Capriole AI を無償で利用できます。

## USD 8 で無制限チャット

- Premium は月額 USD 8 で、GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon を含むすべての対応モデルでウェブチャットを無制限に使えます。
- 次の質問に別のモデルが向いているときは、同じチャットのままモデルを切り替えられます。
- ログイン中のウェブチャットには、1 アカウントあたり 1 日 200 メッセージのフェアユース上限があります。スクリプトによる自動化された乱用を防ぐためのもので、通常の利用ではこの上限を大きく下回ります。
- ゲストはアカウントなしで 1 日 5 メッセージまで試せます。無料アカウントでは、さらに毎月 50 万トークン分のウェブチャットを使えます。

[プランと制限を比較する](/ja/guides/plans-and-limits)か、[モデルを選ぶ](/ja/guides/choose-a-model)。

## 公式価格より最大 92% 安い API

- 1 つの API キーで、OpenAI Chat Completions、OpenAI Responses、Anthropic Messages の各クライアントに対応できます。
- Premium には毎月の API 枠が含まれ、トップアップはどの対応モデルでも 500 万トークンあたり USD 8 です。92% が公式価格からどう計算されるかは、[Claude API の料金](/ja/articles/claude-api-pricing)と [OpenAI API の料金](/ja/articles/openai-api-pricing)で確認できます。
- 同じキーで、Codex、Claude Code、GitHub Copilot CLI、OpenCode など、ドキュメントのある 10 種類のコーディング エージェントを動かせます。[1 つの API キーでコーディング エージェントを使う](/ja/guides/one-api-key-coding-agents)を参照してください。

まずは [API クイックスタート](/ja/quickstart)から始めましょう。

## 一度設定すれば継続して使えます

API またはコーディング エージェントを、各プロバイダーで推奨する旗艦モデルに Capriole AI が合わせ続けるようにしたい場合は、`openai-latest`、`claude-latest`、または `google-latest` を使ってください。

テスト、監査、または再現可能な実行で特定のモデル バージョンに固定する必要がある場合は、具体的なモデル ID を使ってください。

## そのほかの機能

ログインして **Server Storage** を使う Free・Premium・Team アカウントは、ウェブチャットで **GPT Image 2.5** と **Nano Banana 2.1** を使い、無料で画像を作成できます。ファイル、ウェブ検索、プロジェクト、チャットのエクスポート、ストレージ制御はワークスペースに組み込まれています。[画像生成ガイドを見る](/ja/guides/files-web-search)。
