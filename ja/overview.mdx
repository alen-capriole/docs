Capriole AI は、GPT-6 Astra、Claude Fable 5.1、Claude Opus 5.5、Gemini 4 Argon を複数のサブスクリプションなしで使いたい人と、それらすべてを 1 つの API キーで使いたい開発者やコーディング エージェントのユーザーのためのサービスです。月額 USD 8 の Premium メンバーシップ 1 つで両方をカバーします。ウェブチャットは無制限で、API は公式 API 価格より最大 92% 安く使えます。チャットと API は同じアカウントで使えますが、カウントは別々なので、チャットがアプリやコーディング エージェント用のトークンを消費することはありません。

Capriole AI は Capriole Investments が開発しており、同社の市場データプラットフォーム [Capriole Quant](https://quant.capriole.com/)（旧 Capriole Charts）や投資ファンドとは別の製品です。有効な Capriole Quant サブスクライバーは、Capriole AI を無償で利用できます。

## ひと目でわかる要点

| | Capriole AI |
|---|---|
| Premium | 月額 USD 8 で、すべての対応モデルとのウェブチャットが無制限。さらに毎月 500 万 API トークン付き |
| フェアユース | ログイン中のウェブチャットは 1 アカウントあたり 1 UTC 日 200 メッセージまで。スクリプトによる乱用を防ぐための上限で、通常の利用ではこれを大きく下回ります。[「無制限」の意味](/ja/guides/plans-and-limits#「無制限」の意味) |
| 無料とゲスト | ゲストは[アカウントなしで](/ja/articles/ai-chat-without-login) 1 日 5 メッセージまでウェブチャットを試せます。無料アカウントでは毎月 50 万トークン分のウェブチャットを使えますが、API は使えません |
| Team | 5 シートで月額 USD 70。メンバー全員のウェブチャットが無制限で、毎月 5,000 万 API トークンをチームで共有します。[Team プラン](/ja/guides/team-plan) |
| 旗艦モデル | GPT-6 Astra（OpenAI）、Claude Fable 5.1 と Claude Opus 5.5（Anthropic）、Gemini 4 Argon（Google） |
| API | Base URL は `https://api.caprioletech.com`。OpenAI Chat Completions、OpenAI Responses、Anthropic Messages と互換性があります |
| モデル エイリアス | `openai-latest` → GPT-6 Astra、`claude-latest` → Claude Fable 5.1、`google-latest` → Gemini 4 Argon |
| レート制限 | API キーごとに 1 分あたり 300 リクエスト |
| 92% の計算方法 | 出力 1 トークンにつき入力 3 トークンの比率では、500 万トークンのコストは GPT-6 Astra または Claude Fable 5.1 の公式価格で USD 100、Capriole AI では USD 8 です。[Claude API の料金](/ja/articles/claude-api-pricing)と [OpenAI API の料金](/ja/articles/openai-api-pricing)を参照してください |

## USD 8 で無制限チャット

**Thinking** プリセットも無制限です。次の質問に別のモデルが向いているときは、同じチャットのままモデルを切り替えられます。[プランと制限を比較する](/ja/guides/plans-and-limits)か、[モデルを選ぶ](/ja/guides/choose-a-model)。

## 公式価格より最大 92% 安い API

- チャージはどの対応モデルでも 500 万トークンあたり USD 8 で、複数パックをまとめて購入すると最大 15% 割引になります。
- 同じキーで、Codex、Claude Code、GitHub Copilot CLI、OpenCode など、ドキュメントのある 10 種類のコーディング エージェントを動かせます。[1 つの API キーでコーディング エージェントを使う](/ja/guides/one-api-key-coding-agents)を参照してください。
- 推奨の旗艦モデルが変わっても自動で追従させたいときはエイリアスを、テスト、監査、再現可能な実行で特定のバージョンが必要なときは具体的なモデル ID を使ってください。

まずは [API クイックスタート](/ja/quickstart)から始めましょう。
