## なぜ Capriole AI なのか

Capriole AI は、主要な AI モデルを 1 つの API で利用できます。

統合は 1 つ維持するだけで、必要に応じてモデルを切り替えられます。

- モデル アクセス用の API は 1 つ
- 対応モデルの切り替え時に統合を変更する必要はありません
- token パックによる、明確でシンプル、かつ大幅に低コストな価格設定

## 一度設定すれば継続して使えます

API またはコーディング エージェントを、各プロバイダーで推奨する旗艦モデルに Capriole AI が合わせ続けるようにしたい場合は、`openai-latest`、`claude-latest`、または `google-latest` を使ってください。

テスト、監査、または再現可能な実行で特定のモデル バージョンに固定する必要がある場合は、具体的なモデル ID を使ってください。

## 注意

有効な [Capriole Charts](https://capriole.com/charts/) サブスクライバーは、Capriole AI を無償で利用できます。
