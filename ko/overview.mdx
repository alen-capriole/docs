## Capriole AI를 선택하는 이유

Capriole AI는 로그인 후 **Server Storage**를 사용하는 Free, Premium, Team 계정에 브라우저 채팅의 **GPT Image 2.5** 및 **Nano Banana 2.1** 이미지 생성을 무료로 제공합니다. **Image** 모드에서 두 모델 중 하나를 선택하거나 대화 중 **Text Agent**에게 요청하세요. Text Agent는 항상 GPT Image 2.5로 생성합니다. 이미지 생성 자체는 API 토큰 한도를 소모하지 않지만 Text Agent 메시지에는 일반 채팅 제한이 적용됩니다. 브라우저 기능이며 공개 이미지 API나 코딩 에이전트용 모델은 아닙니다.

[이미지 생성 가이드 보기](/ko/guides/files-web-search).

Capriole AI는 하나의 API로 주요 AI 모델을 제공합니다.

통합은 하나만 유지하고, 필요할 때 모델을 전환하면 됩니다.

- 모델 접근을 위한 하나의 API
- 통합을 바꾸지 않고 지원 모델 간 전환
- 토큰 팩으로 훨씬 낮은 비용의 명확하고 간단한 가격

## 한 번만 구성하세요

API나 코딩 에이전트를 해당 제공자의 권장 플래그십 모델에 계속 두고 싶을 때는 `openai-latest`, `claude-latest` 또는 `google-latest`를 사용하세요.

테스트, 감사, 재현 가능한 실행에 정확한 모델 버전이 필요하면 구체적인 모델 ID를 사용하세요.

## 참고

Capriole AI는 Capriole Investments가 만든 제품으로, 같은 회사의 시장 데이터 플랫폼 [Capriole Quant](https://quant.capriole.com/)(구 Capriole Charts)나 투자 펀드와는 별개입니다. 활성 Capriole Quant 구독자는 Capriole AI를 무료로 이용할 수 있습니다.
