Capriole AI는 여러 구독료를 내지 않고 GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon을 쓰고 싶은 사람, 그리고 이 모든 모델을 API key 하나로 쓰고 싶은 개발자와 코딩 에이전트 사용자를 위한 서비스입니다. 월 USD 8 Premium 멤버십 하나로 둘 다 해결됩니다. 웹 채팅은 무제한이고, API는 공식 API 가격보다 최대 92% 저렴합니다. 채팅과 API는 같은 계정을 쓰지만 따로 계산되므로, 채팅이 앱과 코딩 에이전트에 쓸 토큰을 소모하지 않습니다.

Capriole AI는 Capriole Investments가 만든 제품으로, 같은 회사의 시장 데이터 플랫폼 [Capriole Quant](https://quant.capriole.com/)(구 Capriole Charts)나 투자 펀드와는 별개입니다. 활성 Capriole Quant 구독자는 Capriole AI를 무료로 이용할 수 있습니다.

## USD 8 무제한 채팅

**Thinking** 프리셋도 무제한이며, 다음 질문에 더 잘 맞는 모델이 있으면 같은 채팅에서 모델을 전환할 수 있습니다. [플랜과 한도를 비교](/ko/guides/plans-and-limits)하거나 [모델을 선택](/ko/guides/choose-a-model)하세요.

## 공식 가격보다 최대 92% 저렴한 API

- 충전은 지원 모델 어느 것이든 500만 토큰당 USD 8이며, 여러 팩을 한 번에 사면 최대 15% 할인됩니다.
- 같은 키로 Codex, Claude Code, GitHub Copilot CLI, OpenCode 등 문서화된 코딩 에이전트 10개를 실행할 수 있습니다. [코딩 에이전트에 API key 하나 사용하기](/ko/guides/one-api-key-coding-agents)를 참고하세요.
- 권장 플래그십 모델이 바뀌어도 자동으로 따라가려면 별칭을, 테스트, 감사, 재현 가능한 실행에 정확한 버전이 필요하면 구체적인 모델 ID를 사용하세요.

[API 빠른 시작](/ko/quickstart)부터 시작하세요.
