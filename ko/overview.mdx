Capriole AI는 Capriole Investments가 만든 제품으로, 같은 회사의 시장 데이터 플랫폼 [Capriole Quant](https://quant.capriole.com/)(구 Capriole Charts)나 투자 펀드와는 별개입니다. 활성 Capriole Quant 구독자는 Capriole AI를 무료로 이용할 수 있습니다.

## USD 8 무제한 채팅

- Premium은 월 USD 8이며, GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon을 포함한 모든 지원 모델로 웹 채팅을 무제한 이용할 수 있습니다.
- 다음 질문에 더 잘 맞는 모델이 있으면 같은 채팅에서 모델을 전환하세요.
- 로그인한 웹 채팅에는 계정당 하루 200개 메시지의 공정 사용 한도가 있습니다. 스크립트를 이용한 자동화된 남용을 막기 위한 것으로, 일반적인 사용은 이 한도에 훨씬 못 미칩니다.
- 게스트는 계정 없이 하루 5개 메시지를 써 볼 수 있습니다. 무료 계정은 여기에 매월 50만 토큰의 웹 채팅을 더합니다.

[플랜과 한도를 비교](/ko/guides/plans-and-limits)하거나 [모델을 선택](/ko/guides/choose-a-model)하세요.

## 공식 가격보다 최대 92% 저렴한 API

- API key 하나로 OpenAI Chat Completions, OpenAI Responses, Anthropic Messages 클라이언트를 모두 사용할 수 있습니다.
- Premium에는 월간 API 한도가 포함되며, 충전은 지원 모델 어느 것이든 500만 토큰당 USD 8입니다. 92%가 공식 가격에서 어떻게 계산되는지는 [Claude API 가격](/ko/articles/claude-api-pricing)과 [OpenAI API 가격](/ko/articles/openai-api-pricing)에서 확인하세요.
- 같은 키로 Codex, Claude Code, GitHub Copilot CLI, OpenCode 등 문서화된 코딩 에이전트 10개를 실행할 수 있습니다. [코딩 에이전트에 API key 하나 사용하기](/ko/guides/one-api-key-coding-agents)를 참고하세요.

[API 빠른 시작](/ko/quickstart)부터 시작하세요.

## 한 번만 구성하세요

API나 코딩 에이전트를 해당 제공자의 권장 플래그십 모델에 계속 두고 싶을 때는 `openai-latest`, `claude-latest` 또는 `google-latest`를 사용하세요.

테스트, 감사, 재현 가능한 실행에 정확한 모델 버전이 필요하면 구체적인 모델 ID를 사용하세요.

## 함께 제공되는 기능

로그인 후 **Server Storage**를 사용하는 Free, Premium, Team 계정은 웹 채팅에서 **GPT Image 2.5**와 **Nano Banana 2.1**로 이미지를 무료로 만들 수 있습니다. 파일, 웹 검색, 프로젝트, 채팅 내보내기, 저장 컨트롤이 작업 공간에 기본으로 들어 있습니다. [이미지 생성 가이드 보기](/ko/guides/files-web-search).
