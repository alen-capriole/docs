Anthropic의 Claude API는 **Claude Fable 5.1에 입력 토큰 100만당 USD 10, 출력 토큰 100만당 USD 50**을, **Claude Opus 5.5에 USD 4와 USD 20**을 청구합니다. 출력 토큰 1개당 입력 토큰 3개 비율로 계산하면, Anthropic 표준 요율에서 500만 토큰 비용은 Fable 5.1이 USD 100, Opus 5.5가 USD 40입니다.

Capriole AI Premium은 월 USD 8에 GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon과의 웹 채팅을 무제한으로 제공합니다. API는 Anthropic Messages 호환 엔드포인트로 두 Claude 모델을 모두 제공하며, 가격은 지원 모델 어느 것이든 500만 토큰당 USD 8로 공식 API 가격보다 최대 92% 저렴합니다. API key 하나로 직접 만든 앱과 Claude Code 같은 코딩 에이전트를 모두 사용할 수 있습니다.

## 100만 토큰당 Claude API 가격

Anthropic은 [Claude API 가격 페이지](https://platform.claude.com/docs/en/about-claude/pricing)에 다음 표준 요율을 게시합니다. 모든 가격은 100만 토큰당 USD 기준입니다.

| 모델 | API 모델 ID | 입력 | 출력 | 캐시 읽기 | 5분 캐시 쓰기 | 1시간 캐시 쓰기 |
|---|---|---:|---:|---:|---:|---:|
| Claude Fable 5.1 | `claude-fable-5-1` | USD 10 | USD 50 | USD 0.25 | USD 12.50 | USD 20 |
| Claude Opus 5.5 | `claude-opus-5-5` | USD 4 | USD 20 | USD 0.20 | USD 5 | USD 8 |

같은 페이지에는 이 요율을 바꾸는 규칙도 나와 있습니다.

- **Batch API**: 비동기 배치는 입력과 출력 모두 50% 저렴합니다. Fable 5.1은 USD 5와 USD 25, Opus 5.5는 USD 2와 USD 10입니다.
- **긴 컨텍스트**: 두 모델 모두 100만 토큰 컨텍스트 창 전체를 표준 요율로 제공합니다.
- **미국 전용 추론**: `inference_geo`를 `"us"`로 설정하면 모든 토큰 가격에 1.1을 곱합니다.
- **Fast 모드**: Fast 모드의 Opus 5.5는 입력 USD 8, 출력 USD 40이며, Fast 모드는 Batch API와 함께 쓸 수 없습니다.

## 100만 토큰과 500만 토큰의 비용

다음 예시는 표준 요율, 캐싱 없음, 출력 토큰 1개당 입력 토큰 3개를 기준으로 합니다.

```text
official_cost = input_millions × input_price + output_millions × output_price
```

| 토큰 | 입력 / 출력 | Claude Fable 5.1 | Claude Opus 5.5 | Capriole AI, 두 모델 모두 |
|---|---|---:|---:|---:|
| 100만 | 75만 / 25만 | USD 20 | USD 8 | USD 1.60 |
| 500만 | 375만 / 125만 | USD 100 | USD 40 | **USD 8** |

Fable 5.1에서 500만 토큰은 3.75 × USD 10 + 1.25 × USD 50 = USD 100이므로, Capriole의 USD 8은 92% 저렴합니다. Opus 5.5에서는 같은 워크로드가 USD 40이므로 USD 8은 80% 저렴합니다. Capriole은 API 토큰을 500만 단위 팩으로 판매하며, 100만 토큰 금액은 비교를 위해 팩의 5분의 1로 표시한 값입니다.

Anthropic은 출력 가격을 입력의 5배로 책정합니다. Capriole은 입력과 출력을 같은 요율로 계산하므로, 절감 폭은 실제 입력과 출력 비율에 따라 달라집니다. 예를 들어 입력 토큰만 500만 개를 써도 Fable 5.1은 USD 50, Opus 5.5는 USD 20입니다.

[무료로 채팅을 시작하거나](https://www.capriole.ai/ko) [API key를 받으세요](https://www.capriole.ai/ko?view=api).

## 캐싱과 배치가 비교를 바꾸는 방식

- **캐시 읽기**: Anthropic은 캐시된 토큰 100만당 Fable 5.1에 USD 0.25, Opus 5.5에 USD 0.20을 청구합니다. Capriole은 캐시된 입력을 10%로 계산하며, 이는 캐시된 토큰 100만당 USD 0.16에 해당합니다. 공식은 [과금 토큰 설명](/ko/articles/charged-tokens)에서 확인하세요.
- **캐시 쓰기**: Anthropic은 5분 쓰기에 입력의 1.25배, 1시간 쓰기에 입력의 2배를 청구합니다. Capriole은 캐시 쓰기를 일반 입력으로 계산합니다.
- **배치**: Anthropic 배치 요율에서 500만 토큰 예시는 Fable 5.1이 USD 50, Opus 5.5가 USD 20입니다. Capriole에는 배치 엔드포인트가 없지만, 이 워크로드에서도 USD 8은 각각 84%, 60% 저렴합니다.

OpenRouter의 credit 수수료까지 포함한 500만 토큰 테스트는 [AI API 비용 비교](/ko/articles/ai-api-cost-comparison)를 참고하세요.

## Capriole의 Messages API로 Claude 호출하기

Capriole의 API는 Anthropic Messages와 호환됩니다. Anthropic SDK나 다른 Messages 클라이언트를 `https://api.caprioletech.com`으로 지정하고 `POST /v1/messages`를 호출하세요.

- `claude-latest`는 Claude Fable 5.1을 선택하므로, 구성이 현재 권장 Claude 모델을 따라갑니다.
- `claude-fable-5-1`과 `claude-opus-5-5`는 모델을 명시적으로 선택합니다.
- 키는 Bearer 토큰으로 보내세요. Anthropic SDK에서는 `auth_token`으로 전달합니다.

```python
import os

from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com",
)

message = client.messages.create(
    model="claude-latest",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Summarize this pull request."}],
)
print(message.content[0].text)
```

같은 키는 `/v1/chat/completions`의 OpenAI Chat Completions에서도 작동하며, 여기서도 `claude-latest`를 쓸 수 있습니다. 키마다 분당 300개 요청을 보낼 수 있습니다. 허용되는 모든 Claude 모델 ID는 [Messages 레퍼런스](/ko/api-reference/endpoint/messages)에서, Capriole 키로 Claude Code를 실행하는 방법은 [Claude Code 설정](/ko/integrations/claude-code)에서 확인하세요.

## 월 USD 8에 포함되는 것

- GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon을 비롯한 모든 지원 모델과의 무제한 웹 채팅. 로그인한 채팅에는 스크립트를 이용한 남용을 막기 위해 계정당 UTC 기준 하루 200개 메시지의 공정 사용 한도가 있으며, 일반적인 사용은 이 한도에 훨씬 못 미칩니다.
- 앱과 코딩 에이전트에 쓰는 월 500만 API 토큰.
- 추가 API 토큰은 500만당 USD 8이며, 한 번에 1~11개 팩을 구매할 수 있고 여러 팩을 사면 최대 15% 할인됩니다.
- GPT Image 2.5와 Nano Banana 2.1 무료 이미지 생성, 파일과 웹 검색, 프로젝트, 채팅 내보내기, [문서화된 코딩 에이전트 10개](/ko/articles/coding-agent-compatibility).

API key를 만들려면 Premium 또는 Team이 필요합니다. Team은 월 USD 70이며 좌석 5개와 API 토큰 5,000만이 포함됩니다. 계정 없이도 하루 5개 메시지까지 웹 채팅을 써 볼 수 있고, 무료 계정은 API 접근 없이 매월 50만 토큰의 웹 채팅을 받습니다.

Batch API를 비롯해 Messages와 토큰 계산 이외의 기능, 미국 전용 추론, 또는 Anthropic과의 직접 계약이 필요하다면 Anthropic을 직접 이용하세요.

## 자주 묻는 질문

### Claude API 비용은 얼마인가요?

Claude Fable 5.1은 입력 토큰 100만당 USD 10, 출력 토큰 100만당 USD 50입니다. Claude Opus 5.5는 USD 4와 USD 20입니다. 배치 요청은 절반 가격입니다.

### Claude Opus 5.5가 Claude Fable 5.1보다 저렴한가요?

예. Anthropic API에서 Opus 5.5는 Fable 5.1보다 토큰당 60% 저렴합니다. Capriole AI에서는 두 모델 모두 500만 토큰당 같은 USD 8입니다.

### Capriole AI에서 `claude-latest`는 무엇을 뜻하나요?

`claude-latest`는 Claude Fable 5.1을 가리킵니다. `/v1/messages`와 `/v1/chat/completions`에서 작동합니다.

### Capriole AI 키로 Claude Code를 쓸 수 있나요?

예. `ANTHROPIC_BASE_URL`을 `https://api.caprioletech.com`으로, `ANTHROPIC_AUTH_TOKEN`을 Capriole 키로 설정하세요. 전체 구성은 [Claude Code 설정](/ko/integrations/claude-code)에 있습니다.

### 무제한 채팅에 API 사용량도 포함되나요?

아니요. 무제한은 웹 채팅에 적용됩니다. API와 코딩 에이전트 요청은 API 토큰 잔액을 사용합니다.
