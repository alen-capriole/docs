Claude Pro와 Max 사용자가 사용량 한도에 걸리는 이유는 모든 유료 Claude 플랜에 5시간 세션 한도와 주간 한도가 있고, claude.ai, Claude Desktop, Claude Code가 모두 이 한도를 함께 쓰기 때문입니다. 긴 채팅, 도구, 높은 effort, 큰 모델은 허용량을 더 빨리 소모합니다. 주로 채팅만 한다면 Capriole AI Premium이 **월 USD 8**에 **Claude Fable 5.1**, **Claude Opus 5.5**는 물론 **GPT-6 Astra**, **Gemini 4 Argon**까지 웹 채팅을 무제한으로 제공합니다.

코딩 에이전트를 많이 쓴다면, 같은 계정에 공식 API 가격보다 최대 92% 저렴한 API도 포함되어 있습니다.

| 플랜 | 가격 | 채팅 사용량 | Claude Fable 5.1 |
|---|---|---|---|
| Claude Free | USD 0 | 기본 허용량. Sonnet과 Haiku만 | 사용 불가 |
| Claude Pro | 월 USD 20, 연간 결제 시 월 USD 17 | 5시간 세션당 Free의 최소 5배, 주간 한도 추가 | 플랜 한도 밖. API 요금의 사용량 크레딧으로 결제 |
| Claude Max 5x | 월 USD 100 | 5시간 세션당 Pro의 5배, 주간 한도 추가 | 주간 한도의 최대 50% |
| Claude Max 20x | 월 USD 200 | 5시간 세션당 Pro의 20배, 주간 한도 추가 | 주간 한도의 최대 50% |
| Capriole AI Premium | 월 USD 8 | 웹 채팅 무제한. 하루 200개 메시지의 공정 사용 한도 적용 | 무제한 웹 채팅에 포함 |

## Claude 사용량 한도의 작동 방식

Anthropic 도움말 센터는 유료 플랜의 두 가지 한도를 설명합니다.

- 5시간마다 초기화되는 **세션 한도**.
- 모든 모델에 걸친 **주간 한도**. 계정에 지정된 고정 시각에 초기화됩니다.

Anthropic은 월간 한도나 특정 모델·기능 제한처럼 다른 방식으로도 사용량을 제한할 수 있다고 말합니다. 진행 상황은 claude.ai의 **Settings** → **Usage**에서 확인할 수 있습니다.

한도는 공유됩니다. claude.ai, Claude Desktop, Claude Code의 사용량이 같은 허용량에서 차감되므로, 긴 Claude Code 세션 뒤에는 채팅에 쓸 여유가 거의 남지 않을 수 있습니다. 주간 한도는 모든 모델에 적용되므로 다른 Claude 모델로 바꿔도 초기화되지 않습니다.

## 예상보다 빨리 한도에 걸리는 이유

Anthropic은 허용량을 더 많이 쓰는 요인을 다음과 같이 나열합니다.

- 길고 복잡한 대화
- 선택한 모델
- 높은 effort 수준과 extended thinking
- 토큰을 많이 쓰는 도구와 커넥터
- 컨텍스트를 차지하는 큰 프로젝트 파일
- 자동 컨텍스트 관리를 일으키는 긴 채팅

Fable 5.1에는 별도 규칙이 있습니다. Pro에서는 Fable 5와 Fable 5.1이 플랜 사용량 한도에 포함되지 않으므로, 모든 Fable 메시지가 표준 API 요금으로 청구되는 사용량 크레딧으로 실행됩니다. Max에서는 Fable 모델이 추가 비용 없이 주간 한도의 최대 50%까지 사용할 수 있습니다.

## 한도에 걸렸을 때 Anthropic이 제안하는 방법

1. **초기화를 기다리세요.** 세션 한도는 5시간마다 초기화되며, **Settings** → **Usage**에서 초기화 시각을 확인할 수 있습니다.
2. **업그레이드하세요.** Anthropic은 Max 5x를 Claude를 자주 쓰는 사용자에게, Max 20x를 대부분의 작업에 Claude를 매일 쓰는 사용자에게 적합한 플랜으로 소개합니다. 새 플랜의 한도는 바로 적용됩니다.
3. **사용량 크레딧을 켜세요.** 크레딧을 쓰면 한도에 도달한 뒤에도 계속 작업할 수 있으며, 표준 API 요금으로 청구됩니다. 월 지출 상한을 정할 수 있습니다.
4. **메시지당 사용량을 줄이세요.** 긴 대화를 이어가는 대신 새 대화를 시작하고, effort 수준을 낮추고, extended thinking과 필요 없는 도구를 끄고, 프로젝트 지침을 짧게 줄이세요.

Claude Code 응답 도중 5시간 한도에 도달하면, Claude Code는 멈추기 전에 현재 단계를 마칠 수 있습니다. Pro에서는 이 동작이 주간 사용 기간마다 최대 한 번만 일어납니다.

## USD 8에 Claude 웹 채팅 무제한

Capriole AI Premium은 월 USD 8로 Claude Fable 5.1, Claude Opus 5.5, GPT-6 Astra, Gemini 4 Argon을 포함한 모든 지원 모델의 웹 채팅을 무제한 제공합니다.

Capriole AI 웹 채팅에는 5시간 세션도, 주간 한도도 없습니다. 로그인한 웹 채팅에는 계정당 하루 200개 메시지의 공정 사용 한도가 있습니다. 스크립트를 이용한 자동화된 남용을 막기 위한 것으로, 일반적인 사용은 이 한도에 훨씬 못 미칩니다.

Fable 5.1에는 사용량 크레딧이 필요하지 않습니다. 모든 모델이 같은 무제한 웹 채팅에 포함되며, [대화 중 모델을 전환](/ko/articles/switch-models-mid-chat)할 수 있습니다. 예를 들어 더 어려운 단계에서 Claude Opus 5.5를 Claude Fable 5.1로 바꿔도 처음부터 다시 시작할 필요가 없습니다.

Premium에는 GPT Image 2.5와 Nano Banana 2.1 무료 이미지 생성, 파일과 웹 검색, 프로젝트, 채팅 내보내기, 개인화, 저장 컨트롤도 포함됩니다.

## 코딩 에이전트를 많이 쓴다면: API 경로

무제한 웹 채팅은 코딩 에이전트에 적용되지 않습니다. Claude Code와 다른 에이전트에는 Capriole AI API key를 사용하세요. 에이전트 요청은 공식 API 가격보다 최대 92% 저렴한, 측정되는 API 잔액에서 차감됩니다.

| 모델 | 100만 토큰당 공식 API 가격 (입력 / 출력) | Capriole AI |
|---|---|---|
| Claude Fable 5.1 | USD 10 / USD 50 | 500만 토큰당 USD 8 |
| Claude Opus 5.5 | USD 4 / USD 20 | 500만 토큰당 USD 8 |
| GPT-6 Astra | USD 10 / USD 50 | 500만 토큰당 USD 8 |

500만 토큰당 USD 8은 입력과 출력 모두 100만 토큰당 USD 1.60입니다. Premium에는 월 500만 API 토큰이 포함되고, 충전은 모든 지원 모델에서 500만 토큰당 USD 8입니다. [과금 토큰](/ko/articles/charged-tokens)에서 설명하듯 캐시된 입력은 10%로 계산됩니다.

Claude Code는 Capriole AI의 Anthropic Messages 엔드포인트로 연결됩니다. 같은 키로 Codex를 포함한 [문서화된 코딩 에이전트 10개](/ko/guides/one-api-key-coding-agents)를 사용할 수 있습니다. [Claude Code 설정](/ko/integrations/claude-code)부터 시작하세요.

Claude Max에는 월간 API 크레딧이 포함되지만, [Anthropic에 따르면](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans) 이 크레딧은 대화형 Claude Code 세션이나 플랜 한도에 도달한 뒤의 추가 사용량에는 쓸 수 없습니다.

## 포기하는 것

Capriole AI는 Anthropic과 제휴 관계가 없는 독립 작업 공간입니다. Claude 앱이 아닙니다. Artifacts, 커넥터, 메모리, Claude in Chrome, Claude 데스크톱 및 모바일 앱처럼 Anthropic 제품에만 있는 기능은 Capriole AI에 포함되지 않습니다. Claude Code는 위의 API 경로로 계속 사용할 수 있습니다.
