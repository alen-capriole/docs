Capriole AI는 여러 AI 구독을 USD 9 멤버십 하나로 대체합니다. **GPT-6.2 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Carbon**과의 무제한 웹 채팅에 더해, 공식 API 가격보다 최대 92% 저렴한 API 접근을 제공합니다. 로그인하지 않은 방문자와 Free 사용자는 결제 전에 무료 웹 채팅에서 같은 플래그십 모델을 써 볼 수 있습니다.

Premium은 지원되는 Premium 모델 세트의 무제한 웹 채팅에 **월 USD 9**입니다. **월 500만 과금 API 토큰**, 코딩 에이전트 10개의 설정 가이드, 모델 전환, 파일, 웹 검색, 여러 채팅에 걸친 메모리, 명시적 채팅 저장 컨트롤도 포함합니다.

그 결과, 여러 구독, 인터페이스, 기록, 제공자 키, 잔액 대신 계정 하나로 지원되는 최첨단 모델을 쓸 수 있습니다.

## 문제는 월 청구서보다 큽니다

여러 AI 제품을 쓰면 보통 여러 브라우저 탭, 청구 페이지, 기록, 인터페이스, 컨트롤 세트가 생깁니다. 사용량을 재는 방식도 제품마다 다릅니다. 예를 들어 Claude Pro와 Max에서는 채팅과 Claude Code가 [5시간 및 주간 한도](/ko/articles/claude-usage-limits)를 함께 씁니다. 한 제품에서 시작한 작업이 나중에 다른 모델이 필요할 수 있습니다. 그러면 이동이 작은 마이그레이션이 됩니다. 유용한 컨텍스트를 복사하고, 파일을 다시 첨부하고, 작업을 다시 설명하고, 다음 인터페이스가 어떤 컨트롤을 노출하는지 배웁니다.

API 작업은 제공자 계정, 키, 잔액, 모델 이름, 호환되지 않는 요청 형식을 더합니다. 코딩 에이전트는 또 다른 구성 계층을 더합니다. 각 단계가 따로는 어렵지 않지만, 모두 합치면 모델을 고르는 일이 계정 관리 업무가 됩니다.

Capriole AI는 공통 부분을 하나의 작업 공간으로 가져옵니다. 지원 모델과 채팅하고, 대화 안에서 모델을 바꾸고, 파일이나 웹 검색으로 작업하고, 스레드를 같은 인터페이스에 둘 수 있습니다. 제품이 그 전환 뒤의 프로토콜과 컨텍스트 차이를 처리합니다.

## 한 대화, 다른 모델 강점

다른 모델 계열은 같은 작업의 다른 부분에 유용합니다. 스레드는 연구로 시작해 신중한 글쓰기로 이동하고 코드나 구조화된 분석으로 끝날 수 있습니다. 제품이 따로 나뉘어 있으면 그 사이에서 컨텍스트를 옮기는 일은 사용자 몫이 됩니다.

Capriole은 선택한 모델이 바뀌는 동안 대화를 하나의 작업 공간에 남깁니다. 보이는 동작은 모델 선택입니다. 그 아래에서 메시지 형식, 컨텍스트 제한, reasoning 제어, 파일, 도구, 스트리밍 이벤트, 토큰 회계, 오류가 모두 다른 처리가 필요할 수 있습니다.

Capriole은 그 적응을 제품의 일부로 유지하므로, 선택한 모델을 바꿔도 사용자가 스레드나 통합을 다시 만들 필요가 없습니다.

Capriole은 지원되는 API 및 에이전트 워크플로에 latest 모델 별칭도 제공합니다. 사용자가 모든 정확한 모델 식별자를 즉시 업데이트하지 않고도 구성이 제공자 계열의 Capriole 권장 현재 모델을 따르게 합니다.

## 같은 계정으로 브라우저 밖에서도 작업을 이어갈 수 있습니다

자격 있는 유료 접근은 웹 채팅뿐 아니라 Capriole의 공개 API도 잠금 해제합니다. [API 빠른 시작](/ko/quickstart)이 첫 요청을 다루고, 유지 중인 가이드가 코딩 에이전트 10개를 다룹니다. [Codex](/ko/integrations/codex), [Claude Code](/ko/integrations/claude-code), [GitHub Copilot CLI](/ko/integrations/github-copilot-cli), [OpenCode](/ko/integrations/opencode), [OpenClaw](/ko/integrations/openclaw), [Kilo Code](/ko/integrations/kilo-code), [Cline](/ko/integrations/cline), [Qwen Code](/ko/integrations/qwen-code), [Crush](/ko/integrations/crush), [Pi](/ko/integrations/pi)입니다.

각 클라이언트는 여전히 자체 능력과 기대를 가집니다. 이점은 지원 클라이언트가 각 계열마다 별도의 모델 제공자 설정 없이 하나의 Capriole 계정과 호환 API 경로를 사용할 수 있다는 것입니다.

## 채팅 기록이 어디에 있을지 선택하기

모든 대화가 같은 저장 정책을 받을 필요는 없습니다.

| 모드 | 채팅 기록이 남는 곳 |
|---|---|
| Synced | Capriole 계정 저장소 |
| Local | 이 브라우저의 로컬 저장소 |
| No Storage | 현재 페이지 세션만 |

기본 계정 저장소를 사용하면 기기 간에 채팅을 동기화하고 파일을 업로드할 수 있습니다.

Local 기록은 해당 브라우저의 사이트 데이터를 지울 때까지 새로 고침 후에도 남습니다. No Storage 기록은 페이지가 새로 고쳐지거나 사용자가 떠나면 사라지고, 켜면 기존 서버 및 로컬 채팅 기록을 삭제하기 전에 먼저 확인을 요청합니다.

세 모드 모두 각 요청을 Capriole과 선택한 모델 서비스로 보냅니다. 민감하거나 규제된 데이터를 사용하기 전에 [채팅 저장 가이드](/ko/guides/chat-storage)를 읽으세요.

Server Storage를 사용하는 로그인 계정에는 GPT Image 2.6, Nano Banana 2.1, Seedream 5.5 무료 이미지 생성도 포함됩니다. 자세한 내용은 [이미지 생성 가이드](/ko/guides/files-web-search)를 참고하세요.
