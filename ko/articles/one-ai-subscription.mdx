Capriole AI는 별도의 AI 구독이 만드는 일상 마찰을 하나의 저비용 작업 공간으로 대체합니다. 로그아웃 방문자와 Free 사용자는 결제 전에 제한된 Browser Chat에서 **GPT-6 Astra, Claude Fable 5.1, Gemini 3.1 Pro**를 써 볼 수 있습니다.

Premium은 지원되는 Premium 모델 세트의 무제한 Browser Chat에 **월 USD 8**입니다. **월 500만 과금 API 토큰**, 유지 중인 코딩 에이전트 통합 여섯 개, 모델 전환, 파일, 웹 검색, 명시적 채팅 저장 컨트롤도 포함합니다.

결과는 여러 구독, 인터페이스, 기록, 제공자 키, 잔액 대신 지원 최첨단 모델을 위한 계정 하나입니다.

## 문제는 월 청구서보다 큽니다

여러 AI 제품을 쓰면 보통 여러 브라우저 탭, 청구 페이지, 기록, 인터페이스, 컨트롤 세트가 생깁니다. 한 제품에서 시작한 작업이 나중에 다른 모델이 필요할 수 있습니다. 그러면 이동이 작은 마이그레이션이 됩니다. 유용한 컨텍스트를 복사하고, 파일을 다시 첨부하고, 작업을 다시 설명하고, 다음 인터페이스가 어떤 컨트롤을 노출하는지 배웁니다.

API 작업은 제공자 계정, 키, 잔액, 모델 이름, 호환되지 않는 요청 형식을 더합니다. 코딩 에이전트는 또 다른 구성 계층을 더합니다. 각 단계는 개별적으로 어렵지 않지만, 함께면 모델 선택이 계정 관리가 됩니다.

Capriole AI는 공통 부분을 하나의 작업 공간으로 가져옵니다. 지원 모델과 채팅하고, 대화 안에서 모델을 바꾸고, 파일이나 웹 검색으로 작업하고, 스레드를 같은 인터페이스에 둘 수 있습니다. 제품이 그 전환 뒤의 프로토콜과 컨텍스트 차이를 처리합니다.

## USD 8 멤버십 하나가 대체하는 것

| 플랜의 부분 | 포함되는 것 | 중요한 경계 |
|---|---|---|
| Premium Browser Chat | 지원되는 Premium 모델 세트의 무제한 채팅 | 지원되는 일상 작업에서 하나의 Capriole 작업 공간이 별도의 제공자 채팅 인터페이스를 대체합니다 |
| 월간 API 허용량 | 500만 과금 API 토큰 | API 사용량은 허용량을 소비합니다. 무제한이 아닙니다 |
| API top-up | 추가 토큰 팩을 구매할 수 있음 | Top-up은 월간 구독과 별개입니다 |
| 코딩 에이전트 | Capriole API key를 문서화된 통합과 사용할 수 있음 | 지원은 유지 중인 프로토콜 및 모델 경로로 제한됩니다 |
| 무료 접근 | 업그레이드 전 제한된 Browser Chat | 무료 접근에는 공개 API가 포함되지 않습니다 |

Capriole은 같은 작업 공간 안에서 OpenAI, Anthropic, Google, xAI, Z.AI, Moonshot AI의 현재 지원 모델을 유지하며, 위에 이름 붙인 플래그십 세트를 포함합니다.

브라우저와 API는 다른 사용량 모델을 가집니다. Premium Browser Chat에는 사용자가 관리할 메시지당 토큰 잔액이 없습니다. API 요청은 측정됩니다. 프로그래밍 워크로드가 일반 채팅 사용을 훨씬 넘을 수 있기 때문입니다.

플랜은 매일 채팅하면서 가끔 또는 중간 정도의 API 또는 코딩 에이전트 접근이 필요한 사람에게 맞습니다. 두 허용량은 분명하게 남습니다. Premium에서 Browser Chat은 무제한이고, 자동화 작업은 보이는 과금 토큰 잔액을 사용합니다.

## 한 대화, 다른 모델 강점

다른 모델 계열은 같은 작업의 다른 부분에 유용합니다. 스레드는 연구로 시작해 신중한 글쓰기로 이동하고 코드나 구조화된 분석으로 끝날 수 있습니다. 별도 제품은 사용자가 그 사이를 컨텍스트를 나르게 합니다.

Capriole은 선택한 모델이 바뀌는 동안 대화를 하나의 작업 공간에 남깁니다. 보이는 동작은 모델 선택입니다. 그 아래에서 메시지 형식, 컨텍스트 제한, reasoning 제어, 파일, 도구, 스트리밍 이벤트, 토큰 회계, 오류가 모두 다른 처리가 필요할 수 있습니다.

Capriole은 그 적응을 제품의 일부로 유지하므로, 선택한 모델을 바꿔도 사용자가 스레드나 통합을 다시 만들 필요가 없습니다.

Capriole은 지원되는 API 및 에이전트 워크플로에 latest 모델 별칭도 제공합니다. 사용자가 모든 정확한 모델 식별자를 즉시 업데이트하지 않고도 구성이 제공자 계열의 Capriole 권장 현재 모델을 따르게 합니다.

## 같은 계정이 브라우저를 떠날 수 있습니다

자격 있는 유료 접근은 Browser Chat뿐 아니라 Capriole의 공개 API도 잠금 해제합니다. [API 빠른 시작](/ko/quickstart)이 첫 요청을 다루고, 유지 중인 가이드가 코딩 에이전트 여섯 개를 지원합니다. [Codex](/ko/integrations/codex), [Claude Code](/ko/integrations/claude-code), [Kilo Code](/ko/integrations/kilo-code), [GitHub Copilot CLI](/ko/integrations/github-copilot-cli), [OpenCode](/ko/integrations/opencode), [OpenClaw](/ko/integrations/openclaw)입니다.

이것이 모든 코딩 에이전트를 같게 만들지는 않습니다. 각 클라이언트는 여전히 자체 능력과 기대를 가집니다. 이점은 지원 클라이언트가 각 계열마다 별도의 모델 제공자 설정 없이 하나의 Capriole 계정과 호환 API 경로를 사용할 수 있다는 것입니다.

## 채팅 기록이 어디에 있을지 선택하기

모든 대화가 같은 저장 정책을 받을 필요는 없습니다.

| 모드 | 채팅 기록이 남는 곳 | 기기 간 | 업로드 |
|---|---|---|---|
| Synced | Capriole 계정 저장소 | 예 | 사용 가능 |
| Local | 이 브라우저의 로컬 저장소 | 아니요 | 비활성화 |
| No Storage | 현재 페이지 세션의 메모리만 | 아니요 | 비활성화 |

Local 기록은 해당 브라우저의 사이트 데이터를 지울 때까지 새로 고침 후에도 남습니다. No Storage 기록은 페이지가 새로 고쳐지거나 사용자가 떠나면 사라지고, 켜면 기존 서버 및 로컬 채팅 기록을 삭제하기 전에 먼저 확인을 요청합니다.

세 모드 모두 각 요청을 Capriole과 선택한 모델 서비스로 보냅니다. 채팅 기록 지속성을 제어하며, 운영 기록 없음을 약속하거나 선택한 제공자의 데이터 정책을 대체하지 않습니다. 민감하거나 규제된 데이터를 사용하기 전에 [채팅 저장 가이드](/ko/guides/chat-storage)를 읽으세요.
