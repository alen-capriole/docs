OpenAI API는 새 플래그십인 **GPT-6.2 Astra에 입력 토큰 100만당 USD 8, 출력 토큰 100만당 USD 40**을 청구하며, 캐시된 입력은 USD 0.40입니다. GPT-6 Astra의 USD 10과 USD 50보다 20% 낮은 가격입니다. GPT-6.2 Sol, GPT-6.1 Sol, GPT-6 Sol은 USD 2와 USD 10, GPT-6 Luna는 USD 0.10과 USD 0.50입니다. 출력 토큰 1개당 입력 토큰 3개 비율로 계산하면, OpenAI 표준 요율에서 500만 토큰 비용은 GPT-6.2 Astra가 USD 80, GPT-6 Astra가 USD 100입니다.

Capriole AI Premium은 월 USD 9에 GPT-6.2 Astra, Claude Fable 5.2, Claude Opus 5.5, Gemini 4 Carbon과의 웹 채팅을 무제한으로 제공합니다. API는 OpenAI Responses와 Chat Completions로 GPT-6.2 Astra를 제공합니다. 개인 Premium에는 매월 API 토큰 5,000,000개가 포함됩니다. 추가 토큰 5,000,000개는 USD 8이며 모든 지원 모델에 사용할 수 있습니다. 공식 API 가격 대비 최대 92% 저렴합니다. API 키 하나로 직접 만든 앱과 Codex 같은 코딩 에이전트를 모두 사용할 수 있습니다.

## 100만 토큰당 OpenAI API 가격

OpenAI는 [API 가격 페이지](https://developers.openai.com/api/docs/pricing)에 다음 표준 요율을 게시합니다. 모든 가격은 입력 토큰 27만 2,000개 이하 프롬프트 기준이며, 100만 토큰당 USD입니다.

| 모델 | API 모델 ID | 입력 | 캐시된 입력 | 캐시 쓰기(30분) | 캐시 쓰기(12시간) | 출력 |
|---|---|---:|---:|---:|---:|---:|
| GPT-6.2 Astra | `gpt-6.2-astra` | USD 8 | USD 0.40 | USD 10 | USD 20 | USD 40 |
| GPT-6.2 Sol | `gpt-6.2-sol` | USD 2 | USD 0.10 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Astra | `gpt-6-astra` | USD 10 | USD 1 | USD 12.50 | USD 25 | USD 50 |
| GPT-6.1 Sol | `gpt-6.1-sol` | USD 2 | USD 0.10 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Sol | `gpt-6-sol` | USD 2 | USD 0.20 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Luna | `gpt-6-luna` | USD 0.10 | USD 0.01 | USD 0.125 | USD 0.25 | USD 0.50 |

OpenAI의 가격 페이지와 모델 페이지에는 이 요율을 바꾸는 규칙도 나와 있습니다.

- **Batch와 Flex**: 둘 다 표준 요율의 50%입니다. Batch에서 GPT-6.2 Astra는 입력 USD 4, 출력 USD 20이고, GPT-6 Astra는 USD 5와 USD 25입니다. OpenAI의 Flex 가격에는 GPT-6.2 Astra와 GPT-6.2 Sol이 나와 있지 않습니다.
- **긴 프롬프트**: 입력 토큰이 27만 2,000개를 넘는 요청은 요청 전체에 입력 및 캐시 요율의 2배, 출력 요율의 1.5배가 적용됩니다.
- **Fast 모드**: 표준 요율의 2배입니다. Fast 모드의 GPT-6.2 Astra는 입력 USD 16, 출력 USD 80입니다.
- **지역 처리**: 사용할 수 있는 경우 10%가 추가됩니다.

## 100만 토큰과 500만 토큰의 비용

다음 예시는 표준 요율, 캐싱 없음, 27만 2,000 토큰 미만 프롬프트, 출력 토큰 1개당 입력 토큰 3개를 기준으로 합니다. Capriole AI의 API 토큰 잔액이 충분하면 예시의 사용량은 추가 결제 없이 잔액에서 차감됩니다.

```text
official_cost = input_millions × input_price + output_millions × output_price
```

| 토큰 | 입력 / 출력 | GPT-6.2 Astra | GPT-6 Astra | GPT-6.2 Sol, GPT-6.1 Sol 또는 GPT-6 Sol | GPT-6 Luna | Capriole AI 개인용 API 충전 |
|---|---|---:|---:|---:|---:|---:|
| 100만 | 75만 / 25만 | USD 16 | USD 20 | USD 4 | USD 0.20 | USD 1.60 |
| 500만 | 375만 / 125만 | USD 80 | USD 100 | USD 20 | USD 1 | **USD 8** |

GPT-6.2 Astra에서 5,000,000 토큰은 3.75 × USD 8 + 1.25 × USD 40 = USD 80이므로, 개인 Premium의 추가 충전 가격 USD 8은 90% 저렴합니다. GPT-6 Astra에서는 같은 워크로드가 USD 100이고, USD 8은 92% 저렴합니다. Sol 모델에서는 USD 8이 60% 저렴합니다. 같은 사용량에서 OpenAI의 GPT-6 Luna 공식 요금은 USD 1입니다. Capriole은 API 토큰을 5,000,000 단위 팩으로 판매하며, 1,000,000 토큰 금액은 비교를 위해 팩의 5분의 1로 표시한 값입니다.

Capriole의 과금 토큰 공식에는 긴 프롬프트 구간이 없으므로, 30만 토큰 프롬프트도 짧은 프롬프트와 같은 토큰당 요율로 계산됩니다.

[무료로 채팅을 시작하거나](https://www.capriole.ai/ko) [API 키를 받으세요](https://www.capriole.ai/ko?view=api).

## 캐싱과 배치가 비교를 바꾸는 방식

- **캐시된 입력**: OpenAI는 캐시된 토큰 100만당 GPT-6.2 Astra에서 USD 0.40, GPT-6.2 Sol과 GPT-6.1 Sol에서 USD 0.10을 청구하며 이는 각 입력 요율의 5%입니다. GPT-6 Astra에서는 입력 요율의 10%인 USD 1을 청구합니다. Capriole은 모든 모델에서 캐시된 입력을 10%로 계산하며, 이는 캐시된 토큰 100만당 개인 Premium 충전 가격 기준 USD 0.16에 해당합니다. 공식은 [과금 토큰 설명](/ko/articles/charged-tokens)에서 확인하세요.
- **캐시 쓰기**: OpenAI는 30분 캐시 쓰기에 입력의 1.25배, 12시간 캐시 쓰기에 2.5배를 청구합니다. Capriole은 캐시 쓰기를 포함해 캐시되지 않은 모든 입력 토큰을 일반 요율로 계산합니다.
- **Batch와 Flex**: 절반 가격이면 5,000,000 토큰 GPT-6.2 Astra 예시는 USD 40입니다. 개인 Premium에서 토큰 5,000,000개를 추가로 충전하는 가격은 USD 8이며 위 요금보다 80% 저렴합니다.

OpenRouter의 크레딧 수수료까지 포함한 500만 토큰 테스트는 [AI API 비용 비교](/ko/articles/ai-api-cost-comparison)를 참고하세요. Claude Fable 5.2와 Opus 5.5는 [Claude API 가격](/ko/articles/claude-api-pricing), Gemini 4 Carbon과 Argon은 [Gemini API 가격](/ko/articles/gemini-api-pricing)에서 확인할 수 있습니다.

## Capriole API로 GPT-6.2 Astra 호출하기

Capriole의 API는 `POST /v1/responses`의 OpenAI Responses, `POST /v1/chat/completions`의 OpenAI Chat Completions와 호환됩니다. OpenAI SDK의 base URL을 `https://api.caprioletech.com/v1`로 설정하세요.

- `openai-latest`는 GPT-6.2 Astra를 선택하므로, 구성이 현재 권장 OpenAI 모델을 따라갑니다.
- Responses에서는 `gpt-6.2-astra` 같은 기본 ID와 `openai/gpt-6.2-astra` 같은 접두사 ID가 같은 모델을 선택합니다.
- Chat Completions는 `openai-latest`와 `GET /v1/models`가 반환하는 모델 ID를 받습니다.

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com/v1",
)

response = client.responses.create(
    model="openai-latest",
    input="Write a release note for this change.",
)
print(response.output_text)
```

키마다 분당 300개 요청을 보낼 수 있습니다. 허용되는 모든 모델 ID는 [Responses 레퍼런스](/ko/api-reference/endpoint/responses)와 [Chat Completions 레퍼런스](/ko/api-reference/endpoint/chat-completions)에서, Capriole 키로 Codex를 실행하는 방법은 [Codex 설정](/ko/integrations/codex)에서 확인하세요.

## 자주 묻는 질문

### GPT-6.2 Astra 비용은 얼마인가요?

GPT-6.2 Astra는 입력 토큰 100만당 USD 8, 캐시된 입력 토큰 100만당 USD 0.40, 출력 토큰 100만당 USD 40입니다. GPT-6 Astra는 USD 10, USD 1, USD 50입니다. Batch 요청은 절반 가격입니다.

### 가장 저렴한 GPT-6 모델은 무엇인가요?

GPT-6 Luna입니다. 입력 토큰 100만당 USD 0.10, 출력 토큰 100만당 USD 0.50입니다.

### OpenAI는 긴 프롬프트에 더 많이 청구하나요?

예. 입력 토큰이 27만 2,000개를 넘는 요청은 요청 전체에 입력 및 캐시 요율의 2배, 출력 요율의 1.5배를 냅니다.

### Capriole AI에서 `openai-latest`는 무엇을 뜻하나요?

`openai-latest`는 2026년 11월 18일부터 GPT-6.2 Astra를 가리킵니다. `/v1/responses`와 `/v1/chat/completions`에서 작동합니다.

### Capriole AI 키로 Codex를 쓸 수 있나요?

예. Codex는 사용자 지정 모델 제공자를 통해 Responses API로 연결됩니다. 전체 구성은 [Codex 설정](/ko/integrations/codex)에 있습니다.
