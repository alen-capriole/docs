USD 20 이하 AI 구독 중 무엇이 가장 좋은지는 한 회사의 모델만 원하는지, 모든 회사의 모델을 원하는지에 따라 달라집니다. Capriole AI Premium은 **월 USD 9**에 현재 플래그십 4종인 **GPT-6 Astra**, **Claude Fable 5.1**, **Claude Opus 5.5**, **Gemini 4 Argon** 모두와 웹 채팅을 무제한으로 제공합니다. ChatGPT Plus, Claude Pro, Google AI Pro는 각각 한 회사의 모델만 제공하며 USD 19.99~USD 20입니다.

Premium에는 매월 500만 API 토큰이 포함됩니다. ChatGPT Plus와 Claude Pro에는 API 사용량이 포함되지 않습니다. 모든 가격은 각 회사 공식 페이지에 표시된 미국 월간 가격입니다.

표에 넣지 않은 관련 플랜이 두 개 있습니다. Google AI Plus에는 Gemini 4 Argon이 아니라 Gemini 3.6 Flash가 나와 있으며, 확인 당시 Google 플랜 페이지에 미국 가격이 표시되지 않았습니다. T3 Chat은 안정적인 공개 가격 페이지를 유지하지 않으므로, 가격을 인용하는 대신 [Capriole AI와의 비교](/ko/articles/capriole-ai-vs-t3-chat)에서 사용량 버킷의 작동 방식을 설명합니다. [멀티 모델 AI 채팅 플랫폼](/ko/articles/multi-model-ai-chat-platforms)은 가격 외의 측면에서도 Capriole AI를 Magai, T3 Chat, Venice, OpenRouter와 비교합니다.

## 누구에게 어떤 플랜이 맞을까

- **모든 회사의 최고 모델을 하나의 가격으로 쓰고 싶다면.** 이 목록에서 GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon을 구독 하나로 모두 쓸 수 있는 플랜은 Capriole AI Premium이며, 가격은 USD 20 플랜의 절반도 되지 않습니다. 같은 스레드에서 다른 회사 모델의 두 번째 답변을 받으려면 [대화 중에 모델을 전환](/ko/articles/switch-models-mid-chat)하세요.
- **앱을 만들거나 코딩 에이전트도 쓴다면.** Capriole AI Premium의 API 허용량은 OpenAI 및 Anthropic API 형식과 [문서화된 코딩 에이전트 10개](/ko/guides/one-api-key-coding-agents)에서 쓸 수 있습니다. 다른 플랜에 포함된 내용은 표의 API 열에서 확인하세요.
- **일상적인 채팅만 필요하다면.** ChatGPT 무료 플랜으로 충분할 수 있습니다. ChatGPT Go는 USD 8입니다. Capriole AI Premium은 USD 9이며 플래그십 모델 4종이 포함됩니다.

## Capriole AI에서 USD 9로 받는 것

Premium은 GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon을 비롯한 모든 지원 모델로 웹 채팅을 무제한 제공합니다. 로그인한 웹 채팅에는 계정당 하루 200개 메시지의 공정 사용 한도가 있습니다. 스크립트를 이용한 자동화된 남용을 막기 위한 것으로, 일반적인 사용은 이 한도에 훨씬 못 미칩니다.

Premium에는 매월 500만 API 토큰이 포함됩니다. 개인용 충전은 지원 모델에 관계없이 500만 토큰당 USD 8이며, [표준 요금 비교](/ko/overview)에서는 공식 API 가격보다 최대 92% 저렴합니다. 파일과 웹 검색, 프로젝트, 채팅 내보내기, 저장 컨트롤이 작업 공간에 들어 있으며, GPT Image 2.6과 Nano Banana 2.1 무료 이미지 생성도 함께 제공됩니다. [플랜과 한도](/ko/guides/plans-and-limits)에 Free, Premium, Team의 전체 내용이 나와 있습니다.

## 포기하는 것

Capriole AI는 OpenAI, Anthropic, Google과 제휴하지 않은 독립적인 작업 공간이므로, 메모리, 다른 앱 커넥터, 자체 데스크톱 및 모바일 앱, 그리고 Google AI Pro의 5 TB 저장 공간과 Gmail, Docs, Sheets의 Gemini처럼 그들의 앱에만 있는 기능은 그 앱에서만 쓸 수 있습니다. Capriole AI에는 음성 대화 모드도, 동영상이나 음악 생성도 없습니다. 코딩 에이전트는 무제한 채팅이 아니라 측정되는 API 잔액을 쓰므로, 에이전트 작업이 많으면 포함된 허용량을 넘는 부분에 500만 토큰당 USD 8이 듭니다.
