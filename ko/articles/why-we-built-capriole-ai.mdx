Capriole AI는 최첨단 모델 채팅, 공개 API 허용량, 지원 코딩 에이전트를 위한 통합 작업 공간입니다. 로그아웃 방문자와 Free 사용자는 구독 전에 GPT-6 Astra, Claude Fable 5.1, Gemini 3.1 Pro를 써 볼 수 있습니다. USD 8 Premium은 무제한 Browser Chat, 500만 과금 API 토큰, 유지 중인 에이전트 통합 여섯 개를 추가합니다.

시작은 우리가 Capriole Charts에 AI 기능을 더하던 때였습니다.

우리는 최첨단 모델에 대한 믿을 수 있는 접근이 필요했고, 자체 작업에 충분할 만큼 설정을 안정적으로 만드는 데 오랜 시간을 썼습니다. 안정적으로 동작한 뒤에는 같은 접근 계층이 Charts 밖에서도 유용할 수 있다는 것이 보였습니다.

ChatGPT, Claude, Gemini를 쓰는 일은 보통 세 제품을 방문하는 일이었습니다. 각기 구독, 인터페이스, 기록, 대화를 다루는 방식이 있었습니다. API 접근은 또 다른 계정과 잔액 세트를 더했습니다. 코딩 에이전트는 더 많은 키와 구성을 가져왔습니다.

우리는 그 인프라를 자체 제품으로 제공하기로 했습니다.

첫 AI 경험은 Charts 안에 있었습니다. 작업이 커지면서 일반 채팅과 모델 접근 계층이 분명히 더 넓은 용도를 가졌습니다. 우리는 그 작업 공간을 Capriole AI로 분리했고, Charts는 자체 제품 맥락에 묶인 AI 기능을 유지했습니다.

## 별도 제품의 비용

매달 여러 회사에 비용을 내는 일은 비쌉니다. 관리하는 일도 지루합니다.

질문이 한 채팅에서 시작해, 다른 모델이 더 유용한 지점에 도달할 수 있습니다. 이동은 프롬프트를 복사하고, 여전히 말이 되는 컨텍스트 부분을 가져가고, 다른 인터페이스에 익숙해지는 일이었습니다. 시간을 아끼도록 만들어진 제품을 사용자가 조율해야 했습니다.

Capriole AI는 지원 최첨단 모델을 하나의 웹 채팅에 둡니다. 한 모델로 대화를 시작하고, 새 제품을 열거나 스레드를 다시 만들지 않고 다른 모델로 바꿀 수 있습니다. 파일, 웹 검색, 채팅 기록, 모델 선택은 같은 작업 공간에 남습니다.

## 다른 모델이 하나의 제품처럼 느껴지게 만들기

모든 모델 제공자에게는 자체 가정이 있습니다. 메시지 형식이 다릅니다. 컨텍스트 제한과 reasoning 제어가 다릅니다. 파일, 도구, 스트리밍 이벤트, 토큰 회계, 오류 응답은 모두 자체 처리가 필요합니다.

공식 AI 제품은 자체 모델만 잘 동작하게 하면 됩니다. Capriole AI는 여러 제공자의 선도 모델이 한 대화 안에서 일관되게 동작하게 해야 합니다.

모델 선택기는 작업의 가장 작은 부분이었습니다. 우리는 프로토콜 어댑터, 모델 별칭, 컨텍스트 관리, 스트리밍 동작, 자동 fallback, 오류 처리를 만들고 계속 다듬었습니다. 새 모델 릴리스는 같은 인터페이스에 들어가기 전에 또 한 번의 호환성 작업이 필요한 경우가 많습니다.

차이는 실제 요청에서 드러납니다. 한 모델 계열은 OpenAI Responses 이벤트를 쓰고, 다른 계열은 Anthropic Messages를 기대할 수 있습니다. 토큰 사용량과 오류는 다른 형태로 도착합니다. 긴 스레드는 다음 모델이 안전하게 이어가기 전에 컨텍스트를 압축해야 할 수 있습니다. 모델 전환이 대수롭지 않게 느껴지려면 그 경우들이 함께 동작해야 합니다.

그 작업의 대부분은 인터페이스 뒤에 남습니다. 사용자는 대화 중간에 ChatGPT 모델에서 Claude 또는 Gemini로 바꾸고 같은 스레드에서 이어갈 수 있습니다.

같은 Capriole AI 계정이 Browser Chat, 공개 API, 유지 중인 코딩 에이전트 통합 여섯 개에 걸쳐 있습니다. [Codex](/ko/integrations/codex), [Claude Code](/ko/integrations/claude-code), [Kilo Code](/ko/integrations/kilo-code), [GitHub Copilot CLI](/ko/integrations/github-copilot-cli), [OpenCode](/ko/integrations/opencode), [OpenClaw](/ko/integrations/openclaw)입니다. Latest 모델 별칭은 제공자별 모델 이름을 추적하지 않고도 지원되는 API 및 에이전트 구성을 단순화합니다. 우리는 호환 프로토콜 경로를 처리하므로, 에이전트를 연결하는 일이 또 다른 제공자 통합 프로젝트가 되지 않습니다.

## 일상 사용을 위한 멤버십 가격

우리는 비싼 AI 멤버십 모음을 부담 없는 계정 하나로 바꾸려고 Capriole AI를 만들었습니다.

Premium은 **월 USD 8**입니다. 지원되는 Premium 모델 세트의 무제한 Browser Chat을 포함합니다. 지켜볼 Browser Chat credit 잔액이 없고, 모델을 바꿀 때마다 차감되는 별도 허용량도 없습니다.

Premium 회원은 **매달 500만 과금 API 토큰**도 받으며, 추가 사용량은 top-up으로 제공됩니다. 우리의 [날짜가 있는 비용 비교](/ko/articles/ai-api-cost-comparison)에서 Capriole은 테스트한 세 모델 워크로드 각각에 USD 8입니다. 직접 유료 Standard 가격은 USD 15에서 USD 90이고, OpenRouter는 게시된 credit 구매 수수료 후 USD 15.83에서 USD 94.95입니다.

테스트는 가능한 모든 워크로드가 아니라 하나의 고정 토큰 구성을 사용합니다. 그래도 우리가 멤버십을 이렇게 만든 이유는 보여 줍니다. 검증된 더 낮은 API 합계가 추론만 사는 것이 아니라 완전한 작업 공간 안에 들어 있습니다.

따라서 하나의 계정이 일상 사고에 쓰는 채팅과 구축에 쓰는 API를 커버할 수 있습니다. Premium에서 브라우저는 무제한으로 남고, API는 명확하고 보이는 사용량 잔액을 유지합니다.

## 개인정보는 제품 안의 선택이어야 합니다

저장된 연구 스레드와 민감한 자료가 있는 대화는 같은 저장 정책이 필요하지 않습니다.

| 모드 | 지속성 | 주요 트레이드오프 |
|---|---|---|
| Synced | 기기 간에 사용할 수 있는 계정 기록 | 연속성을 위해 채팅과 업로드 파일 상태가 저장됨 |
| Local | 현재 브라우저만 | 기기 간 기록 없음. 업로드 비활성화 |
| No Storage | 현재 페이지 세션만 | 새로 고치거나 떠나면 채팅이 사라짐. 업로드 비활성화 |

No Storage를 켜면 기존 서버 및 로컬 채팅 기록을 삭제하기 전에 먼저 확인을 요청합니다. 모든 모드는 여전히 요청을 Capriole과 선택한 모델 서비스로 보냅니다. 기록 지속성을 바꾸며, 모델 요청 경로는 바꾸지 않습니다. [채팅 저장 가이드](/ko/guides/chat-storage)가 전체 경계를 설명합니다.

우리는 개인정보를 작업 공간 안의 컨트롤로 만들었고, 각 선택의 결과를 그 옆에 설명합니다.

## 우리가 더 쉽게 만들고 싶었던 것

Capriole AI는 강한 모델에 접근하면서 AI 접근을 또 다른 관리 일로 만들고 싶지 않은 사람을 위한 것입니다.

목표가 작업에 맞는 모델을 쓰는 것뿐일 때 여러 비싼 멤버십은 거의 의미가 없습니다. 그 모델이 바뀌어도 유용한 대화는 이어질 수 있어야 합니다. 코딩 에이전트는 매번 같은 제공자 설정을 다시 만들지 않고 연결되어야 합니다.

우리는 돈을 아끼고, 설정을 줄이고, 작업이 바뀔 때 모델 선택을 열어 두는 하나의 작업 공간을 원했습니다. 별도의 구독, 키, 기록, 인터페이스가 방해가 되던 때 우리가 갖고 싶었던 제품이 지금 Capriole입니다.

이런 작업 공간과 더 넓은 모델 게이트웨이 사이에서 결정 중이라면, [Capriole AI와 OpenRouter 비교](/ko/articles/capriole-ai-vs-openrouter)가 각 제품이 맞는 곳을 설명합니다.

[Capriole AI를 열고](https://capriole.ai) 제한된 무료 채팅에서 현재 플래그십 세트를 써 볼 수 있습니다. 무제한 Browser Chat, 포함된 API 잔액, 같은 계정 아래 유지 중인 코딩 에이전트 경로가 필요하면 USD 8 Premium으로 업그레이드하세요. 개발자는 [API 빠른 시작](/ko/quickstart)으로 이어갈 수 있습니다.
