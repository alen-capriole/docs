멀티 모델 AI 채팅 플랫폼은 GPT, Claude, Gemini를 한 채팅에 모아 주며, 가장 크게 다른 점은 플래그십 모델에 요금을 매기는 방식입니다. Capriole AI는 **월 USD 8**에 **GPT-6 Astra**, **Claude Fable 5.1**, **Claude Opus 5.5**, **Gemini 4 Argon**과의 웹 채팅을 무제한으로 제공합니다. Magai, T3 Chat, Venice, OpenRouter는 플래그십 모델을 사용량 예산, 다시 채워지는 버킷, 크레딧 또는 종량제 가격으로 측정합니다.

Capriole AI에는 공식 API 가격보다 최대 92% 저렴한 API도 포함되어 있어, 같은 계정으로 앱과 코딩 에이전트도 실행할 수 있습니다. 이 비교는 공개된 플랜과 기능을 다루며, 답변 품질을 테스트한 것은 아닙니다.

[OpenAI](/ko/articles/openai-api-pricing)와 [Claude](/ko/articles/claude-api-pricing) API 가격 페이지에서 보듯 플래그십 모델은 각 회사의 자체 API에서 가장 비싸며, 그래서 나머지 네 제품은 이 모델들의 사용량을 측정합니다. [USD 20 이하 AI 구독](/ko/articles/ai-subscriptions-under-20) 페이지는 각 회사의 자체 플랜인 ChatGPT Plus, Claude Pro, Google AI Pro를 이 가격 비교에 더합니다.

## 한 대화에서 모델 전환하기

작업 도중 모델을 바꿀 수 있다는 점이 여러 앱 대신 한 플랫폼을 쓰는 가장 큰 이유입니다. Capriole AI에서는 메뉴에서 다른 모델을 고르면 같은 스레드에서 다음 답변을 그 모델이 하며, 새 모델과 저장 방식이 지원하면 저장된 파일도 함께 이어집니다. [대화 중 모델 전환](/ko/articles/switch-models-mid-chat)에서 무엇이 이어지고 Capriole AI가 회사별 형식 사이에서 무엇을 맞춰 주는지 설명합니다.

Magai의 가격 페이지에도 흐름을 잃지 않고 대화 중에 모델을 전환하는 기능이 나와 있습니다. T3 Chat의 공식 피드백 보드는 대화 분기와 키보드 모델 전환기를 완료로 표시합니다. 작업 공간의 나머지 부분은 [Capriole AI와의 비교](/ko/articles/capriole-ai-vs-t3-chat)에서 다룹니다.

## 개인정보와 채팅 보관 위치

여기 나온 모든 플랫폼은 최첨단 모델 요청을 OpenAI, Anthropic, Google처럼 해당 모델을 만드는 회사나 그 모델을 호스팅하는 클라우드 플랫폼으로 보냅니다. 다른 점은 학습, 로그 기록, 그리고 기록이 보관되는 위치입니다.

| | 콘텐츠의 학습 사용 | 채팅 기록 보관 위치 | 그 밖에 보관하는 것 |
|---|---|---|---|
| Capriole AI | AI 모델 학습에 사용하지 않음 | 직접 선택: 계정(기본값), 브라우저에만, 또는 저장 안 함 | API는 요청과 응답 내용을 보관하지 않고, 토큰 수 같은 사용 기록만 남김 |
| Magai | 작업 내용이 어떤 모델 학습에도 쓰이지 않는다고 밝힘 | 계정이 활성 상태인 동안 Magai 서버에 보관 | 서버와 서비스 제공업체는 미국에 있음 |
| T3 Chat | 자체 모델을 학습하지 않으며, 가능한 경우 제공자 학습에서 옵트아웃함 | FAQ에 명시되어 있지 않음 | 자체 제공자 키를 쓰면 해당 제공자의 설정이 적용됨 |
| Venice | 확인한 페이지에 명시되어 있지 않음 | 기기에 보관 | 요청은 저장되지 않고 전달됨. 최첨단 모델은 제공자가 콘텐츠를 저장한다고 가정하라고 Venice가 안내함 |
| OpenRouter | 사용자 데이터로 학습하지 않는다고 밝힘 | Chatroom 대화는 기기에 남고 동기화되지 않음 | 모델, 토큰 수 같은 요청 메타데이터. 직접 동의하지 않으면 프롬프트는 기록되지 않지만, Safety Retention 엔드포인트에서는 남용 방지를 위해 OpenRouter나 제공자가 보관할 수 있음 |

Capriole AI의 **Local Storage**와 **No Storage** 모드는 기록을 Capriole AI 데이터베이스에 저장하지 않지만, 업로드와 이미지 생성에는 **Server Storage**가 필요합니다. [개인정보와 데이터 관리 가이드](/ko/guides/privacy-and-security)에 모드별로 보관되는 정보가 나와 있고, [채팅 저장 방식 가이드](/ko/guides/chat-storage)에서 전환 방법을 설명합니다.

## 파일, 웹 검색, 그 밖의 작업 공간 기능

Capriole AI 웹 채팅에는 파일과 웹 검색, 자체 지침과 파일을 갖는 [프로젝트](/ko/guides/projects), 채팅 내보내기, 개인화가 포함됩니다. GPT Image 2.5와 Nano Banana 2.1 무료 이미지 생성도 함께 제공되며, 로그인과 저장 방식 요건은 [파일, 이미지, 웹 검색 가이드](/ko/guides/files-web-search)에서 다룹니다.

## 포기하는 것

Capriole AI는 개인과 소규모 팀을 위해 만들어졌습니다. Magai에는 내장 에이전트, 예약 작업 실행, 다른 앱과의 통합이 있고 Magai와 Venice는 동영상을 생성합니다. Capriole AI에는 예약 작업, 앱 통합, 동영상 생성이 없습니다. SAML 싱글 사인온 같은 엔터프라이즈 관리 기능도 제공하지 않습니다. Capriole AI가 제공하는 것과 제공하지 않는 것은 [LLM 게이트웨이 보안 위험](/ko/articles/llm-gateway-security)에 정리되어 있습니다. 웹 채팅은 무제한이지만 API 요청과 코딩 에이전트는 측정되는 잔액을 씁니다. Premium에서는 매월 500만 토큰이 제공되고, 이후에는 500만 토큰당 USD 8입니다.
