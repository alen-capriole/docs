예, 계정을 만들지 않고도 **GPT-6 Astra**, **Claude Fable 5.1**, **Claude Opus 5.5**, **Gemini 4 Argon**과 채팅할 수 있습니다. [Capriole AI](https://www.capriole.ai/ko)를 열고 모델을 고른 다음, 게스트로 하루 최대 5개 메시지를 보내세요. 무료 계정은 매월 50만 토큰의 웹 채팅을 더하고, Premium은 **월 USD 8**에 웹 채팅이 무제한입니다.

Premium에는 공식 API 가격보다 최대 92% 저렴한 API도 포함되어 있어, 같은 계정으로 앱과 코딩 에이전트를 실행할 수 있습니다.

| 모델 | 모든 지원 웹 채팅 모델 | 모든 지원 웹 채팅 모델 | 모든 지원 웹 채팅 모델 |

‘모든 지원 웹 채팅 모델’은 체험용 모델이 아니라 전체 모델 메뉴를 뜻합니다. GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon과 xAI, Z.ai, Moonshot AI의 모델이 포함됩니다.

## 계정 없이 채팅 시작하기

1. [www.capriole.ai](https://www.capriole.ai/ko)를 엽니다.
2. 모델 메뉴를 열고 모델을 선택합니다. 나머지 모델은 **더 많은 모델**에 있습니다.
3. **무엇이든 물어보세요**에 입력하고 보냅니다.
4. 채팅을 유지하려면 **로그인**을 선택하고 같은 탭에서 로그인하거나 가입합니다.

그러면 채팅이 모든 메시지를 그대로 담은 채 계정의 저장된 채팅으로 열립니다. 저장해도 사용량에 포함되지 않습니다.

## 무료 계정이 더하는 것

무료 계정은 하루 게스트 한도 대신 모든 지원 모델에서 매월 50만 토큰의 웹 채팅을 제공합니다. 토큰 사용량은 모델과 대화에 따라 다르며, thinking 모델과 긴 채팅은 더 많이 사용합니다.

로그인하면 파일 업로드, GPT Image 2.5와 Nano Banana 2.1 무료 이미지 생성, [프로젝트](/ko/guides/projects)도 사용할 수 있습니다. 셋 다 기본값인 **Server Storage**가 필요합니다. 다른 저장 방식은 [채팅 저장 가이드](/ko/guides/chat-storage)에서 설명합니다.

무료 계정에는 API 접근이 포함되지 않습니다.

## Premium이 더하는 것

Premium은 월 USD 8입니다.

- **무제한 웹 채팅.** GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon을 포함한 모든 지원 모델에서 쓸 수 있습니다.
- **공식 가격보다 최대 92% 저렴한 API.** Premium에는 월 500만 API 토큰이 포함되고, 충전은 모든 지원 모델에서 500만 토큰당 USD 8입니다. 키 하나로 Codex와 Claude Code를 포함한 [문서화된 코딩 에이전트 10개](/ko/guides/one-api-key-coding-agents)를 사용할 수 있습니다.

게스트, Free, Premium, Team은 [플랜과 한도](/ko/guides/plans-and-limits)에서 한눈에 비교할 수 있습니다.

## 알아 둘 한도

- **게스트 한도는 IP 주소별로 계산됩니다.** 같은 네트워크의 사용자는 하루 5개 메시지를 함께 씁니다.
- **게스트는 파일 업로드, 이미지 생성, 프로젝트를 사용할 수 없습니다.** 사용하려면 로그인하세요.
- **게스트 채팅은 같은 탭에서 로그인하기 전까지 계정에 저장되지 않습니다.**
- **계정 유무와 관계없이 요청은 Capriole AI와 선택한 모델의 제공자를 거칩니다.** 민감한 자료를 공유하기 전에 [개인정보와 데이터 관리](/ko/guides/privacy-and-security)를 읽으세요.

## 다른 AI 채팅 앱의 로그아웃 사용 방식

- **ChatGPT.** OpenAI에 따르면 지원 국가에서는 계정 없이 ChatGPT를 사용할 수 있습니다. 로그아웃 상태에서는 한 번에 대화 하나만 할 수 있고, 채팅은 저장되지 않습니다. OpenAI 모델 가이드에 따르면 로그아웃 사용자는 GPT-5.6 Sol을 쓸 수 없으며, GPT-6 Astra 기반의 Chat 옵션인 GPT-6 Pro에는 Pro, Business 또는 Enterprise 플랜이 필요합니다.
- **Gemini.** Google에 따르면 Gemini 웹 앱의 일부 기능은 로그인 없이 작동합니다. 다른 기능과 활동 저장에는 Google 계정이 필요합니다.
- **Claude.** Anthropic 도움말 센터에 따르면 새 Claude 계정은 지원 지역의 전화번호를 인증해야 하며, 이 단계는 건너뛸 수 없습니다.

Capriole AI에서는 계정 없이 브라우저 탭 하나로 GPT, Claude, Gemini 모델을 쓸 수 있습니다.
