Google의 Gemini API는 **Gemini 4 Argon에 입력 토큰 100만당 USD 2, 출력 토큰 100만당 USD 10**을 청구합니다. 이는 2026년 11월 30일까지 적용되는 출시 기념 가격이며, 2026년 12월 1일부터 Argon은 **USD 4와 USD 20**입니다. 출력 토큰 1개당 입력 토큰 3개 비율로 계산하면, Google 표준 요율에서 500만 토큰 비용은 출시 기념 가격으로 USD 20, 12월 1일부터 USD 40입니다.

Capriole AI Premium은 월 USD 8에 GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon과의 웹 채팅을 무제한으로 제공합니다. API는 OpenAI Chat Completions로 Gemini 4 Argon을 제공하며, 가격은 지원 모델 어느 것이든 500만 토큰당 USD 8로 공식 API 가격보다 최대 92% 저렴합니다. 다만 Google은 Argon을 GPT-6 Astra와 Claude Fable 5.1보다 낮게 책정하므로 Argon에서는 절감 폭이 더 작습니다. 출시 기념 가격 기준 60%, 12월 1일부터 80%입니다. API key 하나로 직접 만든 앱과 코딩 에이전트를 모두 사용할 수 있습니다.

## 100만 토큰당 Gemini API 가격

Google은 [Gemini Developer API 가격 페이지](https://ai.google.dev/gemini-api/docs/pricing)에 다음 유료 등급 요율을 공개합니다. 모든 가격은 100만 토큰당 USD이며, 출력 가격에는 사고 토큰이 포함됩니다.

| 모델 | API 모델 ID | 기간 | 입력 | 캐시된 입력 | 출력 |
|---|---|---|---:|---:|---:|
| Gemini 4 Argon | `gemini-4-argon` | 2026년 11월 30일까지 | USD 2 | USD 0.10 | USD 10 |
| Gemini 4 Argon | `gemini-4-argon` | 2026년 12월 1일부터 | USD 4 | USD 0.20 | USD 20 |
| Gemini 3.8 Flash | `gemini-3.8-flash` | 2026년 12월 31일까지 | USD 0.75 | USD 0.075 | USD 3.75 |
| Gemini 3.8 Flash | `gemini-3.8-flash` | 2027년 1월 1일부터 | USD 1.50 | USD 0.15 | USD 7.50 |

같은 페이지에는 이 요율을 바꾸는 규칙도 나와 있습니다.

- **Batch와 Flex**: 둘 다 표준 요율의 절반입니다. Gemini 4 Argon은 11월 30일까지 입력 USD 1·출력 USD 5, 이후 USD 2·USD 10입니다.
- **Priority**: Gemini 4 Argon은 11월 30일까지 입력 USD 3.60·출력 USD 18, 이후 USD 7.20·USD 36입니다.
- **캐싱**: Gemini 4 Argon은 암시적 캐싱만 지원하며, 4,096토큰 이상인 프롬프트에서는 기본으로 켜집니다. 명시적 캐싱은 지원하지 않습니다.
- **무료 등급**: Gemini 3.8 Flash에는 무료 등급이 있지만 Gemini 4 Argon에는 없습니다.
- **Google 검색 그라운딩**: 매월 검색 요청 5,000건까지 무료이며 Gemini 3 이후 모델이 함께 씁니다. 그 이후에는 1,000건당 USD 14입니다.

두 모델 모두 긴 프롬프트에 대한 별도 요율은 나와 있지 않습니다.

## 100만 토큰과 500만 토큰의 비용

아래 예시는 표준 요율, 캐싱 없음, 출력 토큰 1개당 입력 토큰 3개 비율을 기준으로 합니다.

```text
official_cost = input_millions × input_price + output_millions × output_price
```

| 토큰 | 입력 / 출력 | Gemini 4 Argon (11월 30일까지) | Gemini 4 Argon (12월 1일부터) | Capriole AI (모든 모델) |
|---|---|---:|---:|---:|
| 100만 | 75만 / 25만 | USD 4 | USD 8 | USD 1.60 |
| 500만 | 375만 / 125만 | USD 20 | USD 40 | **USD 8** |

출시 기념 가격에서 Gemini 4 Argon의 500만 토큰은 3.75 × USD 2 + 1.25 × USD 10 = USD 20이므로, Capriole의 USD 8은 60% 저렴합니다. 12월 1일부터는 같은 워크로드가 USD 40이므로 USD 8은 80% 저렴합니다. 92%라는 수치는 [GPT-6 Astra](/ko/articles/openai-api-pricing)와 [Claude Fable 5.1](/ko/articles/claude-api-pricing)처럼 USD 10과 USD 50으로 책정된 모델에 해당합니다. Capriole은 API 토큰을 500만 단위 팩으로 판매하며, 100만 토큰 금액은 비교를 위해 팩의 5분의 1로 표시한 값입니다.

Gemini 3.8 Flash는 같은 500만 토큰이 2026년 12월 31일까지 USD 7.50으로, Capriole의 USD 8보다 조금 저렴합니다. 2027년 1월 1일부터는 USD 15이므로 USD 8은 47% 저렴합니다.

Google은 사고 토큰을 포함한 출력 가격을 입력의 5배로 책정합니다. Capriole은 입력과 출력을 같은 요율로 계산하므로, 절감 폭은 실제 입력과 출력 비율에 따라 달라집니다. 예를 들어 입력 토큰만 500만 개를 쓰면 Argon은 출시 기념 가격으로 USD 10, 12월 1일부터 USD 20입니다.

[무료로 채팅을 시작하거나](https://www.capriole.ai/ko) [API key를 받으세요](https://www.capriole.ai/ko?view=api).

## 캐싱과 배치가 비교를 바꾸는 방식

- **캐시된 입력**: Google은 Argon의 캐시된 토큰 100만당 11월 30일까지 USD 0.10, 12월 1일부터 USD 0.20을 청구합니다. Capriole은 응답에 보고된 캐시 입력을 10%로 계산하므로, 캐시된 토큰 100만당 USD 0.16에 해당합니다. 11월 30일까지는 Google의 캐시 요율이 더 낮고, 12월 1일부터는 Capriole이 더 낮습니다. 계산식은 [과금 토큰 설명](/ko/articles/charged-tokens)에 있습니다.
- **Batch와 Flex**: 절반 가격이면 Argon 500만 토큰 예시는 11월 30일까지 USD 10, 12월 1일부터 USD 20입니다. Capriole에는 배치 엔드포인트가 없지만, 이 워크로드에서도 USD 8은 각각 20%, 60% 저렴합니다.

OpenRouter의 credit 수수료까지 포함한 500만 토큰 테스트는 [AI API 비용 비교](/ko/articles/ai-api-cost-comparison)를 참고하세요.

## Capriole API로 Gemini 4 Argon 호출하기

Capriole은 `POST /v1/chat/completions`의 OpenAI Chat Completions로 Gemini 모델을 제공합니다. OpenAI SDK의 base URL을 `https://api.caprioletech.com/v1`로 설정하세요.

- `google-latest`는 Gemini 4 Argon을 선택하므로, 설정이 현재 권장되는 Google 모델을 따라갑니다.
- `google/gemini-4-argon`과 `google/gemini-3.8-flash`는 모델을 명시적으로 선택합니다.
- Responses와 Messages 엔드포인트는 Gemini 모델을 받지 않습니다.

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com/v1",
)

completion = client.chat.completions.create(
    model="google-latest",
    messages=[{"role": "user", "content": "Explain this stack trace."}],
)
print(completion.choices[0].message.content)
```

긴 추론에는 `stream=True`로 응답을 스트리밍하세요. 스트리밍하지 않으면 요청이 약 2분 뒤 시간 초과될 수 있습니다. 키마다 분당 300개 요청을 보낼 수 있습니다. 사용 가능한 모델 ID는 [Chat Completions 레퍼런스](/ko/api-reference/endpoint/chat-completions)에서, Gemini 4 Argon과 GPT-6 Astra, Claude 비교는 [어떤 AI 모델을 쓸까](/ko/guides/choose-a-model)에서 확인하세요.

## 자주 묻는 질문

### Gemini API 비용은 얼마인가요?

Gemini 4 Argon은 2026년 11월 30일까지 입력 토큰 100만당 USD 2, 출력 토큰 100만당 USD 10이며, 이후에는 USD 4와 USD 20입니다. Gemini 3.8 Flash는 2026년 12월 31일까지 USD 0.75와 USD 3.75, 이후에는 USD 1.50과 USD 7.50입니다. 배치 요청은 절반 가격입니다.

### Gemini 4 Argon을 무료로 쓸 수 있나요?

Google의 무료 등급에는 Gemini 4 Argon이 포함되지 않습니다. Capriole AI에서는 계정 없이 웹 채팅으로 하루 5개 메시지까지 써 볼 수 있고, Premium이면 웹 채팅이 무제한입니다.

### Capriole AI에서 `google-latest`는 무엇을 뜻하나요?

`google-latest`는 Gemini 4 Argon을 가리킵니다. Gemini 모델을 제공하는 엔드포인트인 `/v1/chat/completions`에서 쓸 수 있습니다.

### 무제한 채팅에 API 사용량도 포함되나요?

아니요. 무제한은 웹 채팅에 적용됩니다. API와 코딩 에이전트 요청은 API 토큰 잔액을 사용합니다.
