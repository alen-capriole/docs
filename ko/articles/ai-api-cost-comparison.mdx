OpenRouter는 각 제공자의 정가로 과금하고 카드로 Standard 크레딧을 구매할 때 5.5% 수수료를 더합니다. Capriole AI 개인 Premium 구독료는 **월 USD 9**이며 아래 예시에 필요한 API 토큰 5,000,000개가 포함됩니다. 같은 모델은 유료 Standard 정가에서 **USD 6.75에서 USD 90**이고, 계산된 OpenRouter 현금 합계는 게시된 크레딧 구매 수수료 후 **USD 7.55에서 USD 94.95**입니다. USD 9 플랜인 Premium에는 네 가지 플래그십 모델인 GPT-6.2 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Carbon과의 무제한 웹 채팅도 포함됩니다.

Gemini 3.8 Flash로 같은 양을 사용하면 공식 API는 USD 6.75, OpenRouter는 크레딧 구매 수수료를 포함해 USD 7.55입니다. USD 9 Premium 구독에는 무제한 웹 채팅도 포함됩니다.

이는 재현 가능한 비교이며, 모든 경우에 통하는 가격 보장이 아닙니다. 토큰 구성을 일정하게 유지하고 인용한 공개 가격을 사용합니다. 2026년 11월 18일에 요금을 확인했습니다.

## 500만 토큰 비용은 API마다 얼마인가요?

입력 400만·출력 100만 토큰 기준으로 GPT-6 Astra와 Claude Fable 5.1은 공식 API에서 USD 90, OpenRouter에서 USD 94.95이고, GPT-6.2 Astra는 각각 USD 72와 USD 75.96입니다. Capriole AI의 API 토큰 잔액이 충분하면 예시의 사용량은 추가 결제 없이 잔액에서 차감됩니다. 개인 Premium에서 토큰 5,000,000개를 추가로 충전하는 가격은 USD 8입니다.

표는 청구되는 토큰 수를 같게 맞춘 것이며, 원문 텍스트나 실제 작업 내용이 같다는 뜻은 아닙니다. 토크나이저는 모델 계열마다 다릅니다. 시나리오는 요청 100개이며, 각각 캐시되지 않은 입력 토큰 40,000개와 출력 토큰 10,000개를 사용해 모든 프롬프트를 OpenAI와 Google의 긴 프롬프트 가격 임계값 아래로 유지합니다. [Claude](/ko/articles/claude-api-pricing), [OpenAI](/ko/articles/openai-api-pricing), [Gemini](/ko/articles/gemini-api-pricing) API 가격 페이지는 이와 달리 출력 토큰 1개당 입력 토큰 3개 비율로 계산하므로 500만 토큰 합계가 더 높게 나옵니다. 예를 들어 GPT-6 Astra는 USD 100입니다. 캐시 읽기 및 쓰기, 도구, 무료 티어, 대체 서비스 티어, 배치 처리, 세금, 계정별 할인은 제외합니다.

## 계산을 재현하는 방법

직접 제공자는 입력과 출력에 별도의 가격을 게시합니다. 이 워크로드의 공식은 다음과 같습니다.

```text
direct_cost = 4 × input_price_per_1M + 1 × output_price_per_1M
```

따라서 GPT-6 Astra, Claude Fable 5.1, Claude Fable 5 비용은 다음과 같습니다.

```text
4 × USD 10 + 1 × USD 50 = USD 90
```

OpenRouter는 선택한 제공자의 추론 가격을 마크업 없이 전달한다고 말합니다. Standard 플랜은 크레딧을 카드로 구매할 때 5.5% 수수료와 USD 0.80 최소 금액을 나열합니다. 표시된 추론 요율에서 현금 계산은 다음과 같습니다.

```text
openrouter_cash = inference_cost + max(USD 0.80, inference_cost × 0.055)
USD 90 + max(USD 0.80, USD 4.95) = USD 94.95
```

같은 계산으로 GPT-6.2 Astra는 USD 75.96(직접 API는 4 × USD 8 + 1 × USD 40 = USD 72), Claude Opus 5.5는 USD 37.98, Gemini 4 Carbon, Gemini 4 Argon, GPT-6.2 Sol은 USD 18.99, Gemini 3.1 Pro Preview는 USD 21.10이 나옵니다. Gemini 3.8 Flash는 2026년 12월 31일까지 적용되는 Google Standard 출시 요금으로 USD 6.75입니다(4 × USD 0.75 + 1 × USD 3.75). 카드 결제 최소 수수료 USD 0.80을 더하면 OpenRouter는 총 USD 7.55입니다.

Gemini 3.1 Pro Preview의 입력 및 출력 토큰 1,000,000개당 요율로 계산하면 공식 API 비용은 4 × USD 2 + 1 × USD 12 = USD 20입니다. OpenRouter에서도 추론 비용은 USD 20이고 카드로 크레딧을 구매할 때 수수료 USD 1.10이 추가됩니다.

OpenRouter는 같은 모델을 다른 제공자나 서비스 티어로 라우팅할 수 있고, 대체 경로가 요청을 처리하는 엔드포인트를 바꿀 수 있습니다. 따라서 표는 표시된 일치 추론 요율을 비교하며, 모든 기본 라우팅 구성의 청구서를 보장하지 않습니다.

## Capriole이 다른 단위를 쓰는 이유

Capriole AI는 과금 토큰으로 API 사용량을 계산합니다. 각 요청은 다음 공식에 따라 같은 잔액에서 차감됩니다.

```text
charged_tokens = uncached_input + ceil(cached_input × 0.1) + output
```

캐시되지 않은 입력과 출력은 100%로 계산됩니다. 캐시된 입력은 10%로 계산됩니다. 예시에는 캐시된 입력이 없으므로 입력 토큰 400만과 출력 토큰 100만이 과금 토큰 500만을 소비합니다.

Capriole은 과금 토큰을 잔액에서 차감합니다. 표에는 개인 Premium 신규 구독료와 예시의 사용량에 대해 공식 API 및 OpenRouter가 청구하는 금액이 나와 있습니다. [Capriole AI 과금 토큰 설명](/ko/articles/charged-tokens)은 추가 예시 세 개, 올림 방식, Premium 할당량 경계를 제공합니다.

## USD 9이 API 잔액 외에 포함하는 것

월 USD 9인 Capriole AI Premium에는 웹 워크스페이스와 매월 5M API 토큰이 포함됩니다. Team 멤버는 공유 API 잔액을 사용합니다.

USD 9 Premium 플랜에는 다음이 포함됩니다.

- 지원되는 Premium 모델 세트의 무제한 웹 채팅, 스크립트 남용을 막는 하루 200개 메시지의 [공정 사용 한도](/ko/guides/plans-and-limits#무제한의-의미) 적용
- 월간 첫 500만 API 과금 토큰
- 공개 API와 유지 중인 코딩 에이전트 통합 접근
- 모델 전환, 파일, 웹 검색, 채팅 저장 컨트롤이 있는 하나의 브라우저 작업 공간

구독 전에 로그인하지 않은 방문자와 Free 사용자는 무료 웹 채팅에서 GPT-6.2 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Carbon을 써 볼 수 있습니다. 그 무료 플래그십 체험은 위의 API 비용 표와 별개입니다.

최첨단 모델 채팅과 API 접근을 함께 원한다면 USD 9로 브라우저 작업 공간과 매월 500만 API 토큰을 모두 이용할 수 있습니다. 같은 계정은 [문서화된 코딩 에이전트 통합 10개](/ko/articles/coding-agent-compatibility)와도 동작합니다.

추가 5,000,000 과금 토큰이 필요한 활성 개인 Premium 회원은 USD 8 충전 팩 하나를 구매할 수 있습니다.

## 요청 비용은 어떤 요인에 따라 달라지나요?

예시는 비용을 실질적으로 바꿀 수 있는 여러 가격 경로를 제외합니다.

- **캐싱**: 제공자는 캐시 쓰기와 읽기를 따로 가격 책정합니다. Capriole은 과금 토큰 공식에서 캐시된 입력을 10%로 계산합니다.
- **긴 프롬프트**: OpenAI는 요청의 입력 토큰이 272,000개를 넘으면 GPT-6.2 Astra, GPT-6 Astra, GPT-6.2 Sol에 더 높은 요율을 청구하고, Google은 프롬프트가 200,000 토큰을 초과하면 Gemini 3.1 Pro Preview에 더 높은 요율을 청구합니다.
- **서비스 티어와 배치 처리**: Free, Flex, Priority, Batch 또는 다른 제공자 티어는 여기서 사용한 유료 Standard 요율과 다를 수 있습니다.
- **OpenRouter 라우팅**: 요청을 처리하는 엔드포인트나 대체 경로는 표에서 사용한 일치 요율과 다른 가격을 가질 수 있습니다.
- **도구와 검색**: 서버 측 도구, grounding, 검색은 요청 또는 사용량 요금을 더할 수 있습니다.
- **출력 비중이 큰 워크로드**: 표는 80/20 입력 대 출력 분할을 사용합니다. 출력이 더 많으면 출력 가격 프리미엄이 큰 모델에서 직접 및 OpenRouter 비용이 더 빨리 올라갑니다.
- **엔터프라이즈 조건**: 볼륨 할인, 비공개 제안, 데이터 레지던시, 협상된 약정은 공개 정가를 대체할 수 있습니다.

제공자를 선택하기 전에 예상 모델, 토큰 구성, 기능으로 다시 계산하세요.
