최첨단 모델 채팅, API 접근, 코딩 에이전트를 하나의 예측 가능한 작업 공간에서 원하는 사용자를 위해 **Capriole AI는 무제한 채팅과 잔액이 보이는 API를 분리해 제공합니다**. USD 9 Premium 플랜은 GPT-6.2 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Carbon과의 무제한 웹 채팅, 공식 API 가격보다 최대 92% 저렴한 API 접근, 코딩 에이전트 10개의 설정 가이드를 제공합니다. 로그인하지 않은 방문자와 Free 사용자는 플래그십 모델을 먼저 써 볼 수 있습니다.

Poe는 무제한 웹 채팅과 잔액이 보이는 포함 API를 따로 나누지 않고, 해당되는 모든 제품 활동에서 컴퓨트 포인트를 차감합니다.

이번 비교를 위해 2026년 11월 17일에 Poe의 구매 FAQ, 일반 FAQ, 개인정보 처리방침, 크리에이터 문서를 확인했습니다. 두 제품 모두 다중 모델 채팅과 개발자 접근을 제공하지만, 사용량과 저장 규칙이 다릅니다.

## 빠른 비교

| 영역 | Capriole AI | Poe |
|---|---|---|
| 현재 플래그십 접근 | 한 작업 공간의 GPT-6.2 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Carbon | 공식 및 사용자 생성 봇 또는 앱으로 접근이 구성됨 |
| 결제가 포함하는 것 | USD 9 Premium에 무제한 웹 채팅과 월 500만 과금 API 토큰 포함 | 유료 활동이 선택한 모델과 동작에 따라 컴퓨트 포인트를 소비함 |
| 사용량 예측 가능성 | Premium 웹 채팅은 무제한이며, API와 에이전트 사용량에는 보이는 월간 잔액이 있음 | 포인트 사용량은 모델, 컨텍스트, 파일, 검색, 활동에 따라 달라짐 |
| 공개 프로토콜 | OpenAI Chat Completions, OpenAI Responses, Anthropic Messages | OpenAI Chat Completions, OpenAI Responses, Claude 모델용 Anthropic Messages |
| 코딩 에이전트 경로 | Capriole이 유지하는 코딩 에이전트 10개의 설정 가이드 | 여러 코딩 클라이언트의 공식 설정 문서 |
| 채팅 저장 | Synced, 브라우저 로컬 또는 No Storage 기록 모드 | 기본은 비공개 채팅이며 공식 봇에는 임시 채팅 |

게이트웨이, 채팅 제품, BYOK 클라이언트의 더 넓은 시각은 [OpenRouter 대안 가이드](/ko/articles/openrouter-alternatives)를 확인하세요. Capriole AI를 [TypingMind](/ko/articles/capriole-ai-vs-typingmind), [Magai](/ko/articles/capriole-ai-vs-magai), [Venice](/ko/articles/capriole-ai-vs-venice), [ChatGPT Plus](/ko/articles/chatgpt-plus-alternative)와 비교한 글도 있습니다.

## Capriole이 더 나은 일상 작업 공간인 이유

Capriole은 봇 마켓플레이스가 아니라 완전한 작업 계정에서 시작합니다. 로그인하지 않은 방문자와 Free 사용자는 무료 웹 채팅에서 지원 플래그십 모델을 써 볼 수 있습니다. Premium은 여러 제공자 계정을 관리하라고 요구하지 않고 무제한 웹 채팅, 월간 API 허용량, 유지 중인 외부 도구 경로를 추가합니다.

파일, 웹 검색, 기록, 모델 전환은 한 인터페이스에 남습니다. 작업은 웹 채팅의 문서로 시작해, 같은 스레드에서 다른 지원 모델로 이어가고, 같은 Capriole 계정을 통해 애플리케이션이나 코딩 에이전트로 이동할 수 있습니다.

Server Storage를 사용하는 로그인 계정에는 GPT Image 2.6, Nano Banana 2.1, Seedream 5.5 무료 이미지 생성도 포함됩니다. 자세한 내용은 [이미지 생성 가이드](/ko/guides/files-web-search)를 참고하세요.

## 채팅과 API 사용량의 예측 가능한 분리

Poe 구독은 플랜에 따라 일별 또는 월별 일정으로 컴퓨트 포인트를 발급합니다. 플랜이 달리 말하지 않는 한 사용하지 않은 포인트는 일반적으로 이월되지 않으며, 소비량은 선택한 모델과 활동에 따라 바뀝니다.

구독자와 API 사용자는 추가 포인트를 살 수 있습니다. Poe는 현재 API 추가 포인트를 100만 포인트당 USD 30부터 판매하며, 구매한 추가 포인트는 1년 동안 사용할 수 있습니다.

Poe 포인트와 Capriole 과금 API 토큰은 직접 비교할 수 없습니다. 다른 시스템을 측정합니다. 모델 비용, 컨텍스트 길이, 파일, 검색, 수행 중인 활동이 Poe 잔액이 얼마나 빨리 쓰이는지를 바꿀 수 있습니다.

Capriole Premium은 더 단순하게 나눕니다. 웹 채팅은 지원되는 모든 모델에서 [무제한](/ko/guides/plans-and-limits#무제한의-의미)입니다. 프로그래밍 작업은 포함된 월 500만 과금 API 토큰에 대해 측정되고, 충전은 따로 판매됩니다. 코딩 에이전트 트래픽은 API 트래픽으로 계산됩니다.

[하나의 AI 구독 가이드](/ko/articles/one-ai-subscription)가 그 경계를 더 자세히 설명합니다. 사용자는 얼마나 많은 프로그래밍 작업을 실행할지 결정하기 전에 웹 채팅 약속과 API 잔액을 볼 수 있습니다.

## 프로토콜은 겹치고, 번들은 겹치지 않습니다

Capriole은 이미 OpenAI Chat Completions, OpenAI Responses 또는 Anthropic Messages 형식을 쓰는 클라이언트를 위한 프로토콜 엔드포인트를 노출합니다. 공개 엔드포인트가 외부 애플리케이션이나 에이전트가 호출하는 제품 표면입니다.

코딩 에이전트에 Capriole은 [설정 경로 10개](/ko/articles/coding-agent-compatibility)를 유지합니다. 에이전트는 자체 도구를 로컬에서 계속 실행합니다. Capriole은 지원 모델 프로토콜과 계정 잔액을 제공합니다.

Poe는 Chat Completions 및 Responses 엔드포인트와 Claude 모델용 Anthropic Messages 엔드포인트를 노출합니다. Claude Code와 여러 OpenAI 호환 코딩 클라이언트의 설정 문서도 게시합니다.

Capriole의 차이는 그 개발자 경로를 둘러싼 완전한 USD 9 번들입니다. 무제한 Premium 웹 채팅, 월 500만 과금 API 토큰, Capriole이 유지하는 코딩 에이전트 10개의 설정 가이드, 명시적 작업 공간 저장 컨트롤입니다. Poe는 자격 있는 채팅과 API 활동에 같은 포인트 잔액을 사용하므로, 빈번한 웹 채팅과 코딩 에이전트 작업이 같은 측정 시스템에서 가져갑니다.

## Capriole에서 저장 컨트롤은 계속 보입니다

Capriole은 채팅 기록 지속성을 Account 설정에 바로 둡니다. Synced 모드는 계정 기록을 저장합니다. Local 모드는 현재 브라우저에 기록을 둡니다. No Storage 모드는 저장된 채팅 기록을 유지하지 않습니다. [채팅 저장 가이드](/ko/guides/chat-storage)에서 파일 업로드에 사용하는 기본 동기화 모드를 선택하는 방법을 확인하세요.

저장 설정에서 기록을 보관할 위치를 정합니다. 각 요청은 Capriole AI를 거쳐 처리를 담당하는 모델 제공업체나 클라우드 플랫폼으로 전달됩니다.

## 크리에이터 마켓플레이스는 다른 구매입니다

Poe는 봇 탐색, 게시, Canvas 앱을 중심에 둡니다. Capriole은 사용자 자신의 작업을 중심에 둡니다. 최첨단 모델 접근을 사는 사람에게 Capriole AI는 무제한 웹 채팅, 보이는 API 허용량, 코딩 에이전트 통합, 저장 컨트롤을 하나의 플랜에 담아 제공합니다.

## 워크플로를 Capriole로 가져오기

지원 최첨단 모델, 무제한 Premium 웹 채팅, 명확한 월간 API 허용량, 문서화된 에이전트 경로 10개, 저장 컨트롤을 하나의 계정에서 원하면 Capriole을 선택하세요.

[무료 웹 채팅을 써 보거나](https://www.capriole.ai/ko) [USD 9 Premium으로 업그레이드해 무제한 채팅과 API 키를 받으세요](https://www.capriole.ai/ko?view=api). [저장 가이드](/ko/guides/chat-storage)는 같은 Capriole 작업 공간이 기록을 유지하는 방식을 보여 줍니다.

Capriole AI는 독립적인 워크스페이스이며 Poe 소속이 아닙니다.
