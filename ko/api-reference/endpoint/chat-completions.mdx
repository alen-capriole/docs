애플리케이션, SDK 또는 게이트웨이가 OpenAI Chat Completions 요청 및 응답 형식을 기대할 때 이 엔드포인트를 사용하세요.

`model`과 `messages`가 있는 표준 Chat Completions 페이로드를 보내세요. Capriole AI는 업스트림 전달 전에 latest 별칭을 선택한 제공자 모델 ID로 해석하고, `messages`, `tools`, `tool_choice`, `response_format`, `stream` 같은 호환 필드를 전달하며, 업스트림 JSON 또는 SSE 스트림을 아래에 설명한 GLM SSE 보정과 하트비트 주석을 제외하고 그대로 반환합니다. 스트리밍 요청의 경우 Capriole AI는 전달 전에 `stream_options.include_usage=true`를 설정해 사용량을 기록할 수 있게 합니다.

일부 `model="zai/glm-5.3-flash"` SSE 응답에서 Capriole AI는 델타의 빈 레거시 `function_call={"name":"","arguments":""}` 필드만 제거합니다. 완전한 함수 호출과 일부만 담긴 함수 호출, `tool_calls`, 텍스트, 사용량은 유지됩니다. 이 예외는 비스트리밍 응답이나 다른 모델에 적용되지 않습니다.

`POST /v1/chat/completions`는 `openai-latest`, `claude-latest`, `google-latest`와 `GET /v1/models`가 반환하는 구체적인 공개 모델 ID를 받습니다. 해당 제공자에서 Capriole AI가 권장하는 플래그십 모델을 쓰려면 latest 별칭을 사용하세요.

latest 별칭은 모델 ID 대신 입력하는 약칭입니다. 사용량은 해석된 모델 기준으로 기록되며, 응답 본문의 모델 이름은 선택한 호환 엔드포인트의 표기 방식을 그대로 따릅니다.

## Kimi K3.1 Pro

Kimi K3.1 Pro는 `temperature`를 1, `top_p`를 0.95로 고정합니다. 이 모델에서는 `temperature`, `top_p`, `n`, `presence_penalty`, `frequency_penalty`를 생략하고, 지침은 `developer`가 아닌 `system` 역할로 보내세요.

## Gemini 4 Carbon

`google-latest`는 `google/gemini-4-carbon`으로 해석됩니다. 이 엔드포인트는 요청의 나머지 부분을 그대로 전달하므로, Gemini 4 Carbon은 Google의 기본 수준인 `medium`으로 추론합니다. 우리 테스트에서는 같은 프롬프트에 Gemini 4 Argon보다 출력 토큰을 약 3~4배 썼습니다. OpenAI의 `reasoning_effort`로는 Carbon의 추론 수준이 바뀌지 않습니다. 수준을 설정하려면 Google의 필드를 `low`, `medium`, `high` 중 하나로 보내세요.

```json
"extra_body": {"google": {"thinking_config": {"thinking_level": "low"}}}
```

OpenAI Python SDK에서는 `extra_body={"extra_body": {"google": {"thinking_config": {"thinking_level": "low"}}}}`를 전달하세요. Google은 Carbon에서 어려운 프롬프트는 몇 분이 걸릴 수 있다고 안내하므로, [긴 작업](#긴-작업)에 설명된 대로 스트리밍하세요. 기다리는 시간을 줄이려면 `thinking_level`을 `low`로 설정하거나 `google/gemini-4-argon`을 사용하세요.

## 웹 검색

이 엔드포인트는 웹 검색을 제공하지 않습니다. Grok 모델에서 `web_search_options` 또는 `search_parameters` 필드가 null이 아닌 요청은 HTTP 400으로 실패합니다.

```json
{
  "detail": "Web search is not supported for xai/grok-4.7 on /v1/chat/completions. Use POST /v1/responses with tools: [{\"type\": \"web_search\"}]."
}
```

클라이언트가 정의한 함수 도구는 이름이 `web_search`여도 그대로 전달됩니다. GPT 또는 Grok으로 웹을 검색하려면 [`POST /v1/responses`](/ko/api-reference/endpoint/responses)에서 `"tools": [{"type": "web_search"}]`를 사용하세요.

## 긴 작업

긴 추론 같은 긴 작업에는 `"stream": true`를 설정하세요. 스트리밍을 사용하지 않으면 약 2분 후 연결이 시간 초과될 수 있습니다. 스트림이 모델을 기다리는 동안 Capriole AI는 15초마다 SSE `: heartbeat` 주석을 보내며, 스트리밍하는 `google/*` 요청은 첫 토큰을 최대 20분까지 기다릴 수 있습니다. 모델이 60초 안에 응답하지 않으면 200 응답이 이미 시작된 상태이므로, 이후의 업스트림 오류는 `error` 객체가 담긴 마지막 SSE 이벤트 하나로 전달됩니다.
