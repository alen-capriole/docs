Capriole AI API 키 하나로 Cline에서 GPT-6.2 Astra, Claude Fable 5.2, Opus 5.5, Gemini 4 Carbon 모델을 공식 API 가격보다 최대 92% 저렴하게 사용할 수 있습니다.

## Cline이란

Cline은 터미널과 VS Code를 위한 오픈 소스 코딩 에이전트입니다. Cline의 OpenAI Compatible 제공자는 Chat Completions를 통해 모델 요청을 Capriole AI로 보냅니다.

## 사전 준비

시작하기 전에 다음이 있는지 확인하세요.

- Capriole AI 계정([여기에서 가입](https://www.capriole.ai/ko))
- Premium 플랜(월 USD 9, 무제한 웹 채팅 포함) 또는 Team 플랜. API 키를 만들려면 둘 중 하나가 필요합니다([구독하기](https://www.capriole.ai/ko?view=api))
- Capriole AI API 키([키 받기](https://www.capriole.ai/ko?view=api))

## 설치

npm으로 Cline CLI를 설치하세요.

```bash
npm install -g cline
```

설치를 확인하세요.

```bash
cline --version
```

## 구성

### 모델 검증

Cline CLI 3.0.73 버전은 아래 구성으로 지원 모델 섹션의 모든 모델에서 Capriole AI를 통한 파일 읽기, 파일 쓰기, 최종 답변 검사를 통과합니다.

Capriole AI를 제공자로 저장하세요.

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
cline auth -p openai-compatible \
  -k "$CAPRIOLE_AI_API_KEY" \
  -b "https://api.caprioletech.com/v1" \
  -m claude-latest
```

각 설정의 역할은 다음과 같습니다.

- `-p openai-compatible`은 키를 Bearer 토큰으로 보내는 Cline의 OpenAI Compatible 제공자를 사용합니다.
- `-b`는 Base URL입니다. Cline이 `/chat/completions`를 직접 추가하므로 `/v1`을 포함합니다.
- `-m`은 기본 모델입니다.

Cline은 이 값을 `~/.cline`에 저장하므로 `cline auth`는 한 번만 실행하면 됩니다.

VS Code 확장에서는 Cline 설정을 열고 **OpenAI Compatible**을 선택한 다음, 같은 Base URL, API 키, 모델 ID를 입력하세요.

## Cline 실행

프로젝트 디렉터리에서 Cline을 시작하세요.

```bash
cline
```

일회성 작업은 프롬프트를 전달하세요. 해당 실행에서 다른 모델을 쓰려면 `-m`을 사용하세요.

```bash
cline -m moonshot/kimi-k3 "Explain this repository."
```

## 지원 모델

모든 모델이 Chat Completions를 사용합니다.

| 모델 | 모델 ID |
| --- | --- |
| OpenAI latest | `openai-latest` |
| GPT-6.2 Sol | `openai/gpt-6.2-sol` |
| Claude latest | `claude-latest` |
| Opus 5.5 | `anthropic/claude-opus-5-5` |
| Google latest | `google-latest` |
| Gemini 4 Carbon | `google/gemini-4-carbon` |
| Gemini 4 Argon | `google/gemini-4-argon` |
| Gemini 4 Neon | `google/gemini-4-neon` |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` |
| Grok 4.7 | `xai/grok-4.7` |
| GLM 5.3 Flash | `zai/glm-5.3-flash` |
| Kimi K3.1 Pro | `moonshot/kimi-k3.1-pro` |
| Kimi K3 | `moonshot/kimi-k3` |

`openai-latest`, `claude-latest`, `google-latest`는 항상 각 계열의 최신 플래그십 모델을 가리킵니다. 현재는 GPT-6.2 Astra, Claude Fable 5.2, Gemini 4 Carbon입니다. `GET https://api.caprioletech.com/v1/models`는 모든 모델 ID를 나열합니다.

## 문제 해결

### Cline이 인증 오류를 반환하는 이유는 무엇인가요?

현재 Capriole AI API 키로 `cline auth`를 다시 실행하세요.

### Claude 모델이 `Unsupported chat model_key`로 실패하는 이유는 무엇인가요?

Chat Completions에서는 `anthropic/claude-opus-5-5`처럼 `anthropic/` 접두사가 붙은 Claude ID를 사용하세요. `claude-opus-5-5` 같은 접두사 없는 ID는 Anthropic Messages용입니다.

### 요청이 엔드포인트 오류로 실패하는 이유는 무엇인가요?

Base URL이 `https://api.caprioletech.com/v1`인지 확인하세요.

## 참고

- Cline는 로컬에서 코딩 도구를 실행하며, 모델 요청은 Capriole AI가 처리합니다.
- Gemini 4 Carbon은 Gemini 4 Argon보다 오래 추론하므로 턴마다 시간이 더 걸리고 토큰도 더 쓸 수 있습니다. 더 빠른 응답이 필요하면 `google/gemini-4-argon`을 사용하세요.
- 같은 키를 다른 코딩 에이전트에서도 쓰려면 [코딩 에이전트에 API 키 하나 사용하기](/ko/guides/one-api-key-coding-agents) 가이드를 참고하세요.
- 공식 참고: [Cline CLI](https://docs.cline.bot/cline-cli/overview), [Cline OpenAI Compatible 제공자](https://docs.cline.bot/provider-config/openai-compatible).
