Capriole AI API key 하나로 Kilo Code에서 GPT-6 Astra, Claude Fable 5.1, Opus 5.5 모델을 공식 API 가격보다 최대 92% 저렴하게 사용할 수 있습니다.

## Kilo Code란

Kilo Code는 VS Code와 터미널을 위한 AI 코딩 에이전트입니다. 이 구성은 Capriole AI를 하나의 사용자 지정 제공자로 추가합니다. 제공자의 각 모델은 Capriole AI가 해당 모델 계열에 제공하는 API 프로토콜을 사용합니다.

## 사전 준비

시작하기 전에 다음이 있는지 확인하세요.

- Capriole AI 계정([여기에서 가입](https://www.capriole.ai/ko))
- Premium 플랜(월 USD 8, 무제한 웹 채팅 포함) 또는 Team 플랜. API key를 만들려면 둘 중 하나가 필요합니다([구독하기](https://www.capriole.ai/ko?view=api))
- Capriole AI API key([키 받기](https://www.capriole.ai/ko?view=api))

## 설치

### Kilo CLI

```bash
npm install -g @kilocode/cli
```

설치를 확인하세요.

```bash
kilo --version
```

### VS Code 확장

VS Code의 확장 보기에서 Kilo Code를 설치하세요. 확장은 CLI와 같은 전역 구성 파일을 읽습니다.

## 구성

### 모델 검증

Kilo CLI 7.8.15 버전은 아래 구성으로 지원 모델 섹션의 모든 모델에서 Capriole AI를 통한 파일 읽기, 파일 쓰기, 최종 답변 검사를 통과합니다.

`~/.config/kilo/kilo.jsonc`를 만들거나 업데이트하세요.

```jsonc
{
  "$schema": "https://app.kilo.ai/config.json",
  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
        }
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          },
          "tool_call": true
        },
        "openai/gpt-6.1-sol": {
          "name": "GPT-6.1 Sol",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          },
          "tool_call": true
        },
        "claude-latest": {
          "name": "Claude latest",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          },
          "tool_call": true
        },
        "claude-opus-5-5": {
          "name": "Opus 5.5",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          },
          "tool_call": true
        },
        "google/gemini-3.8-flash": {
          "name": "Gemini 3.8 Flash",
          "limit": {
            "context": 1048576,

          },

        },
        "xai/grok-4.7": {
          "name": "Grok 4.7",
          "limit": {
            "context": 500000,
            "output": 128000
          },
          "tool_call": true
        },
        "zai/glm-5.3-flash": {
          "name": "GLM 5.3 Flash",
          "limit": {
            "context": 1000000,
            "output": 128000
          },
          "tool_call": true
        },
        "moonshot/kimi-k3.1-pro": {
          "name": "Kimi K3.1 Pro",
          "limit": {
            "context": 1048576,
            "output": 131072
          },
          "tool_call": true
        },
        "moonshot/kimi-k3": {
          "name": "Kimi K3",
          "limit": {
            "context": 1048576,
            "output": 131072
          },
          "tool_call": true
        }
      }
    }
  }
}
```

각 설정의 역할은 다음과 같습니다.

- `npm: "@ai-sdk/openai-compatible"`은 제공자의 기본 패키지이므로 Gemini, Grok, GLM, Kimi는 Chat Completions를 사용합니다.
- 각 GPT 모델은 `provider.npm`을 Responses API를 사용하는 `@ai-sdk/openai`로 재정의합니다. 각 Claude 모델은 Anthropic Messages를 사용하는 `@ai-sdk/anthropic`으로 재정의합니다.
- `{env:CAPRIOLE_AI_API_KEY}`는 환경 변수에서 키를 읽습니다. `Authorization` 헤더는 모든 패키지에서 키를 Bearer 토큰으로 보냅니다. 이 헤더가 없으면 Anthropic 패키지가 키를 `x-api-key` 헤더로 보내는데, Capriole AI는 이를 받지 않습니다.
- `tool_call: true`는 모델이 Kilo의 도구를 호출할 수 있게 합니다.
- `limit`은 각 모델의 컨텍스트 창과 출력 한도를 설정합니다. 이 값이 없으면 Kilo는 두 값을 모두 `0`으로 처리해 긴 세션을 압축하지 않습니다.

이 제공자는 전역 구성에 두세요. Kilo는 프로젝트 수준 구성의 `{env:...}` 참조를 해석하지 않습니다.

파일을 수정한 뒤 `kilo config check`를 실행하세요.

## Kilo Code 실행

API key를 설정한 다음 프로젝트 디렉터리에서 Kilo를 시작하세요.

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo
```

특정 모델로 시작하세요.

```bash
kilo -m capriole-ai/openai-latest
```

일회성 요청은 `kilo run`에 프롬프트를 전달하세요.

```bash
kilo run -m capriole-ai/claude-latest "Explain this repository."
```

## 지원 모델

모델 참조는 `capriole-ai/<model-id>` 형식을 사용합니다.

| 모델 | 모델 ID | 프로토콜 |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest`와 `claude-latest`는 항상 각 계열의 최신 플래그십 모델을 가리킵니다. 현재는 GPT-6 Astra와 Claude Fable 5.1입니다.

## 문제 해결

### Kilo Code가 인증 오류를 반환하는 이유는 무엇인가요?

`kilo`를 실행하기 전에 같은 셸에서 `CAPRIOLE_AI_API_KEY`를 내보냈는지, 제공자가 프로젝트 구성이 아니라 `~/.config/kilo/kilo.jsonc`에 있는지 확인하세요.

### Claude 요청이 `Unsupported Claude Messages model`로 실패하는 이유는 무엇인가요?

`@ai-sdk/anthropic`을 사용하는 Claude 모델에는 `claude-opus-5-5` 같은 접두사 없는 Claude ID가 필요합니다. `anthropic/` 접두사가 붙은 ID는 Chat Completions용입니다.

### Kilo Code가 모델이 없다고 표시하는 이유는 무엇인가요?

선택한 모델이 `capriole-ai/<model-id>` 형식을 사용하는지, `provider.capriole-ai.models`에 일치하는 항목이 있는지 확인하세요. `kilo models capriole-ai`를 실행하면 Kilo가 불러온 모델 목록을 볼 수 있습니다.

### 도구 사용이 실패하는 이유는 무엇인가요?

모델 항목에 `"tool_call": true`가 포함되어 있는지 확인하세요.

## 참고

- Kilo Code는 사용자 컴퓨터에서 코딩 도구를 실행합니다. Capriole AI는 모델 요청만 처리합니다.
- 다른 Capriole AI 모델을 추가하려면 같은 계열 모델의 항목을 복사하고 ID를 바꾸세요. `GET https://api.caprioletech.com/v1/models`는 모든 모델 ID를 나열합니다.
- 같은 key를 다른 코딩 에이전트에서도 쓰려면 [코딩 에이전트에 API key 하나 사용하기](/ko/guides/one-api-key-coding-agents) 가이드를 참고하세요.
- 공식 참고: [Kilo CLI](https://kilo.ai/docs/cli), [Kilo custom models](https://kilo.ai/docs/code-with-ai/agents/custom-models), [Kilo settings](https://kilo.ai/docs/getting-started/settings), [OpenCode providers](https://opencode.ai/docs/providers).
