## OpenCode란

OpenCode는 터미널 인터페이스, 데스크톱 앱, IDE 확장으로 제공되는 오픈 소스 AI 코딩 에이전트입니다. 이 구성은 Capriole AI를 하나의 사용자 지정 제공자로 추가합니다. 제공자의 각 모델은 Capriole AI가 해당 모델 계열에 제공하는 API 프로토콜을 사용합니다.

## 사전 준비

시작하기 전에 다음이 있는지 확인하세요.

- Capriole AI 계정([여기에서 가입](https://capriole.ai))
- Capriole AI API key([키 받기](https://capriole.ai?view=api))

## 설치

공식 설치 스크립트로 OpenCode를 설치하세요.

```bash
curl -fsSL https://opencode.ai/install | bash
```

또는 npm으로 설치하세요.

```bash
npm install -g opencode-ai
```

설치를 확인하세요.

```bash
opencode --version
```

## 구성

### 모델 검증

OpenCode 1.19.3 버전은 아래 구성으로 지원 모델 섹션의 모든 모델에서 Capriole AI를 통한 파일 읽기, 파일 쓰기, 최종 답변 검사를 통과합니다.

`~/.config/opencode/opencode.json`을 만들거나 업데이트하세요.

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
        }
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "openai/gpt-6.1-sol": {
          "name": "GPT-6.1 Sol",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "claude-latest": {
          "name": "Claude latest",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "claude-opus-5-5": {
          "name": "Opus 5.5",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "google/gemini-3.8-flash": {
          "name": "Gemini 3.8 Flash",
          "limit": {
            "context": 1048576,
            "output": 65536
          }
        },
        "xai/grok-4.7": {
          "name": "Grok 4.7",
          "limit": {
            "context": 500000,
            "output": 128000
          }
        },
        "zai/glm-5.3-flash": {
          "name": "GLM 5.3 Flash",
          "limit": {
            "context": 1000000,
            "output": 128000
          }
        },
        "moonshot/kimi-k3": {
          "name": "Kimi K3",
          "limit": {
            "context": 1048576,
            "output": 131072
          }
        }
      }
    }
  }
}
```

각 설정의 역할은 다음과 같습니다.

- `npm: "@ai-sdk/openai-compatible"`은 제공자의 기본 패키지이므로 Gemini, Grok, GLM, Kimi는 Chat Completions를 사용합니다.
- 각 GPT 모델은 `provider.npm`을 Responses API를 사용하는 `@ai-sdk/openai`로 재정의합니다. 각 Claude 모델은 Anthropic Messages를 사용하는 `@ai-sdk/anthropic`으로 재정의합니다.
- `baseURL`에는 모든 패키지에서 `/v1`이 포함됩니다.
- `{env:CAPRIOLE_AI_API_KEY}`는 환경 변수에서 키를 읽습니다. `Authorization` 헤더는 모든 패키지에서 키를 Bearer 토큰으로 보냅니다. 이 헤더가 없으면 Anthropic 패키지가 키를 `x-api-key` 헤더로 보내는데, Capriole AI는 이를 받지 않습니다.
- `limit`은 OpenCode에 각 모델의 컨텍스트 창과 출력 한도를 알려 주어, OpenCode가 컨텍스트를 추적하고 제때 세션을 압축할 수 있게 합니다.
- `small_model`은 OpenCode가 세션 제목 생성 같은 가벼운 작업에 사용하는 모델입니다.

## OpenCode 실행

API key를 설정한 다음 프로젝트 디렉터리에서 OpenCode를 시작하세요.

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
opencode
```

`/models`로 모델을 전환하세요. 비대화형으로 실행하려면 `opencode run`을 사용하세요.

```bash
opencode run -m capriole-ai/claude-latest "Explain this repository."
```

## 지원 모델

모델 참조는 `capriole-ai/<model-id>` 형식을 사용합니다.

| 모델 | 모델 ID | 프로토콜 |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest`와 `claude-latest`는 항상 각 계열의 최신 플래그십 모델을 가리킵니다.

## 문제 해결

### OpenCode가 인증 오류를 반환하는 이유는 무엇인가요?

OpenCode를 시작하기 전에 같은 셸에서 `CAPRIOLE_AI_API_KEY`를 내보냈는지, `options.headers` 아래에 `Authorization` 헤더가 있는지 확인하세요.

### Claude 요청이 `Unsupported Claude Messages model`로 실패하는 이유는 무엇인가요?

`@ai-sdk/anthropic`을 사용하는 Claude 모델에는 `claude-opus-5-5` 같은 접두사 없는 Claude ID가 필요합니다. `anthropic/` 접두사가 붙은 ID는 Chat Completions용입니다.

### GPT 요청이 실패하는 이유는 무엇인가요?

각 GPT 모델에 `"provider": { "npm": "@ai-sdk/openai" }`가 있어 요청이 Responses API를 사용하는지 확인하세요.

### Capriole AI 모델이 나타나지 않는 이유는 무엇인가요?

모델 참조가 `capriole-ai/moonshot/kimi-k3`처럼 `capriole-ai/<model-id>` 형식인지, `disabled_providers`가 `capriole-ai`를 차단하지 않는지 확인하세요.

### 구성 변경이 적용되지 않는 이유는 무엇인가요?

프로젝트 수준 `opencode.json` 또는 `OPENCODE_CONFIG` 재정의가 있는지 확인한 다음 OpenCode를 다시 시작하세요.

### 제공자 패키지 오류가 나타나는 이유는 무엇인가요?

`~/.cache/opencode`를 지우고 OpenCode를 다시 시작해 제공자 패키지를 다시 설치하게 하세요.

## 참고

- 키는 환경 변수에 두세요. `opencode.json`에 붙여 넣지 마세요.
- 다른 Capriole AI 모델을 추가하려면 같은 계열 모델의 항목을 복사하고 ID를 바꾸세요. `GET https://api.caprioletech.com/v1/models`는 모든 모델 ID를 나열합니다.
