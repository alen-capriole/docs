## GitHub Copilot CLI란

GitHub Copilot CLI는 터미널용 GitHub 코딩 에이전트입니다. BYOK(bring-your-own-key) 모드는 환경 변수로 설정한 제공자에게 모델 요청을 보냅니다. 이 구성은 그 제공자를 Capriole AI로 지정합니다.

## 사전 준비

시작하기 전에 다음이 있는지 확인하세요.

- Capriole AI 계정([여기에서 가입](https://capriole.ai))
- Capriole AI API key([키 받기](https://capriole.ai?view=api))

## 설치

npm으로 GitHub Copilot CLI를 설치하세요.

```bash
npm install -g @github/copilot
```

설치를 확인하세요.

```bash
copilot --version
```

`COPILOT_PROVIDER_BASE_URL`이 설정되어 있으면 GitHub에 로그인할 필요가 없습니다.

## 구성

### 모델 검증

GitHub Copilot CLI 1.0.100 버전은 아래 프로필로 지원 모델 섹션의 모든 모델에서 Capriole AI를 통한 파일 읽기, 파일 쓰기, 최종 답변 검사를 통과합니다.

Copilot CLI는 한 번에 하나의 제공자만 사용하므로 원하는 모델 계열의 프로필을 선택하세요. 각 프로필은 모델 값 두 개를 설정합니다.

- `COPILOT_PROVIDER_WIRE_MODEL`은 Copilot이 보내는 Capriole AI 모델 ID입니다.
- `COPILOT_PROVIDER_MODEL_ID`는 Copilot이 알고 있는 모델입니다. Copilot은 이 값으로 도구, 프롬프트, 토큰 한도를 정합니다.

### GPT 모델

GPT 모델은 Responses API를 사용합니다.

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.caprioletech.com/v1"
export COPILOT_PROVIDER_API_KEY="$CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_WIRE_API="responses"
export COPILOT_PROVIDER_MODEL_ID="gpt-6-astra"
export COPILOT_PROVIDER_WIRE_MODEL="openai-latest"
```

GPT-6.1 Sol에는 `COPILOT_PROVIDER_MODEL_ID="gpt-6.1-sol"`과 `COPILOT_PROVIDER_WIRE_MODEL="openai/gpt-6.1-sol"`을 설정하세요.

### Claude 모델

Claude 모델은 Anthropic Messages를 사용합니다.

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_TYPE="anthropic"
export COPILOT_PROVIDER_BASE_URL="https://api.caprioletech.com"
export COPILOT_PROVIDER_BEARER_TOKEN="$CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_MODEL_ID="claude-opus-4.6"
export COPILOT_PROVIDER_WIRE_MODEL="claude-latest"
```

Opus 5.5에는 `COPILOT_PROVIDER_WIRE_MODEL="claude-opus-5-5"`를 설정하세요.

- `COPILOT_PROVIDER_BEARER_TOKEN`은 키를 Bearer 토큰으로 보냅니다. `COPILOT_PROVIDER_API_KEY`를 쓰면 키가 `x-api-key` 헤더로 전송되는데, Capriole AI는 이를 받지 않습니다.
- Copilot이 `/v1/messages`를 직접 추가하므로 Base URL에는 `/v1`이 없습니다.
- `COPILOT_PROVIDER_MODEL_ID="claude-opus-4.6"`을 유지하세요. `claude-sonnet-4` 같은 이전 프로필을 쓰면 Copilot이 thinking 예산을 보내고, Opus 5.5는 `requires adaptive thinking`으로 이를 거부합니다.

### Gemini, Grok, GLM, Kimi 모델

이 모델은 Chat Completions를 사용합니다.

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_TYPE="openai"
export COPILOT_PROVIDER_BASE_URL="https://api.caprioletech.com/v1"
export COPILOT_PROVIDER_API_KEY="$CAPRIOLE_AI_API_KEY"
export COPILOT_PROVIDER_WIRE_API="completions"
export COPILOT_PROVIDER_MODEL_ID="claude-sonnet-4"
export COPILOT_PROVIDER_WIRE_MODEL="moonshot/kimi-k3"
```

다른 모델은 `COPILOT_PROVIDER_WIRE_MODEL`을 `google/gemini-3.8-flash`, `xai/grok-4.7` 또는 `zai/glm-5.3-flash`로 바꾸세요.

`COPILOT_PROVIDER_MODEL_ID="claude-sonnet-4"`를 유지하세요. `gpt-5.4` 같은 GPT 프로필을 쓰면 Copilot이 이 모델들이 거부하는 도구 유형을 보냅니다.

프로필을 계속 사용하려면 해당 줄을 `~/.zshrc` 또는 `~/.bashrc`에 추가한 다음 새 터미널을 여세요.

## GitHub Copilot CLI 실행

프로젝트 디렉터리에서 Copilot CLI를 시작하세요.

```bash
copilot
```

비대화형으로 실행하려면 `-p`로 프롬프트를 전달하세요.

```bash
copilot -p "Explain this repository." --allow-all-tools
```

## 지원 모델

| 모델 | `COPILOT_PROVIDER_WIRE_MODEL` | `COPILOT_PROVIDER_MODEL_ID` | 프로토콜 |
| --- | --- | --- | --- |
| OpenAI latest | `openai-latest` | `gpt-6-astra` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | `gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | `claude-opus-4.6` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | `claude-opus-4.6` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | `claude-sonnet-4` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | `claude-sonnet-4` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | `claude-sonnet-4` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | `claude-sonnet-4` | Chat Completions |

`openai-latest`와 `claude-latest`는 항상 각 계열의 최신 플래그십 모델을 가리킵니다.

## 문제 해결

### Copilot CLI가 인증 오류를 반환하는 이유는 무엇인가요?

같은 셸에서 `CAPRIOLE_AI_API_KEY`를 내보냈는지 확인하세요. Claude 모델에는 `COPILOT_PROVIDER_API_KEY`가 아니라 `COPILOT_PROVIDER_BEARER_TOKEN`을 사용하세요.

### 요청이 엔드포인트 오류로 실패하는 이유는 무엇인가요?

GPT, Gemini, Grok, GLM, Kimi 모델에서 `COPILOT_PROVIDER_BASE_URL`은 `https://api.caprioletech.com/v1`입니다. Claude 모델에서는 `/v1` 없는 `https://api.caprioletech.com`입니다.

### Opus 5.5가 `requires adaptive thinking`으로 실패하는 이유는 무엇인가요?

`COPILOT_PROVIDER_MODEL_ID="claude-opus-4.6"`을 설정하세요.

### Gemini, Grok, GLM, Kimi 요청이 도구 오류로 실패하는 이유는 무엇인가요?

`COPILOT_PROVIDER_MODEL_ID="claude-sonnet-4"`를 설정하세요. GPT 프로필은 OpenAI 모델만 받는 도구 유형을 보냅니다.

## 참고

- Copilot CLI는 사용자 컴퓨터에서 코딩 도구를 실행합니다. Capriole AI는 모델 요청만 처리합니다.
- 모든 BYOK 환경 변수를 보려면 `copilot help providers`를 실행하세요.
- 공식 참고: [Install GitHub Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/set-up-copilot-cli/install-copilot-cli), [Use BYOK models in Copilot CLI](https://docs.github.com/en/copilot/how-tos/copilot-cli/customize-copilot/use-byok-models).
