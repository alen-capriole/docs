Capriole AI Browser Chat은 업로드한 업무 파일과 웹의 최신 정보를 결합할 수 있습니다. 모델이 읽어야 할 자료를 첨부하고 구체적인 질문을 하세요. 답이 달라진 내용에 달려 있으면 최신 정보를 요청하세요.

같은 작업 공간에서 GPT-5.6 Thinking, Claude Fable 5 또는 Gemini 3.1 Pro로 작업을 이어갈 수 있어, 자료를 다른 제품에 복사할 필요가 없습니다. Premium은 월 USD 8이며, 지원되는 Premium 모델 세트에서 Browser Chat을 무제한으로 사용할 수 있습니다.

파일 업로드는 기본 계정 동기화 저장소를 사용하는 로그인 채팅이 필요합니다. 웹 검색은 질문에 최신 공개 정보가 필요할 때 모델이 호출하는 Browser Chat 도구입니다.

## 업로드 전에 파일 확인하기

| 파일 범주 | 지원 예시 | 파일당 제한 |
|---|---|---:|
| 이미지 | JPG, JPEG, PNG | 10 MB |
| PDF | PDF 문서 | 10 MB |
| 텍스트 및 구조화 파일 | TXT, Markdown, JSON, JSONL, HTML | 4 MB |
| Office 문서 | DOCX 및 PPTX | 4 MB |
| 스프레드시트 | CSV, XLS, XLSX | 4 MB |

작성기는 여러 파일을 받을 수 있지만, 첨부 수 무제한을 공개 약속하지는 않습니다. 합친 큰 컨텍스트는 선택한 모델의 입력 제한을 여전히 넘을 수 있습니다.

Local 및 No Storage 모드는 파일 업로드를 받지 않습니다. 대화의 저장 경계를 바꾸기 전에 [채팅 저장 가이드](/ko/guides/chat-storage)를 확인하세요.

## 파일이 작업의 기준이 되도록 요청하기

<Steps>
<Step title="동기화 채팅 열기">

[Capriole AI](https://capriole.ai)에 로그인하세요. 채팅이 기본 계정 동기화 저장소를 사용하도록 **Enable local storage**와 **Enable No Storage**를 꺼 두세요.

</Step>

<Step title="파일 추가하기">

작성기에서 **Add photos and files**를 선택하세요. 파일을 채팅 영역으로 끌어다 놓거나 클립보드에서 붙여넣을 수도 있습니다.

메시지를 보내기 전에 첨부 업로드가 끝날 때까지 기다리세요. Capriole은 선택한 모델을 위해 업로드 파일을 준비하는 동안 처리 상태를 표시합니다.

</Step>

<Step title="파일만이 아니라 작업을 설명하기">

모델이 무엇을 살펴보고 어떤 출력이 유용한지 알려 주세요. 예를 들면 다음과 같습니다.

```text
Read the attached spreadsheet. Identify the three largest month-over-month changes, explain which rows produced them, and return a compact table.
```

문서 검토에서는 관심 있는 섹션, 결정, 불일치를 지정하세요. `summarize this` 같은 짧은 요청은 모델에 방향이 더 적습니다.

</Step>

<Step title="첨부 파일과 답 대조하기">

원본 파일에서 중요한 숫자, 인용, 행 참조를 확인하세요. 모델마다 파일 및 컨텍스트 제한이 다르고, 변환된 문서는 시각적 위치에 의존하는 레이아웃 세부 정보를 잃을 수 있습니다.

</Step>
</Steps>

## 최신 웹 정보 추가하기

작성기에는 일반적인 Web Search 스위치가 없습니다. 최근 또는 실시간 공개 정보에 분명히 의존하는 질문을 하세요. 모델이 검색이 필요하다고 판단하면 Browser Chat 검색 도구를 호출할 수 있습니다.

```text
Use the attached product brief as the baseline. Search for official changes announced in the last 30 days, list the sources, and explain which parts of the brief now need revision.
```

검색 중 Thinking 영역에 **Web searching**이 표시될 수 있습니다. 검색이 출처 메타데이터를 반환하면 응답에 연결된 결과를 여는 **Sources** 컨트롤이 나타납니다.

모델이 모든 프롬프트에 검색할 필요는 없습니다. 최신 뉴스나 날짜가 있는 사실을 요청하면 필요성은 더 분명해지지만, 특정 결과, 출처 수, 검색 제공자를 보장하지는 않습니다.

## 웹 검색 컨텍스트에서 이미지 URL 허용하기

로그인한 사용자는 **Account** → **Settings**를 열고 **Enable web search images**를 켤 수 있습니다. 이 설정은 사용 가능할 때 일반 검색 결과와 함께 이미지 URL을 웹 검색이 반환하도록 허용합니다.

이미지 생성 설정이 아니며, 모든 검색이 이미지를 반환하거나 표시한다고 보장하지 않습니다. 이미지 결과를 추가하면 모델로 보내는 검색 컨텍스트가 늘어나고 토큰 사용이 증가할 수 있습니다.

## Capriole이 다른 파일을 준비하는 방식

Capriole은 하나의 업로드 워크플로를 유지하면서 그 아래 모델 입력을 맞춥니다. 이미지는 네이티브 멀티모달 입력을 사용할 수 있습니다. 일부 PDF와 텍스트형 파일도 모델의 네이티브 파일 경로를 사용할 수 있습니다. 다른 지원 문서는 모델 호출 전에 텍스트 컨텍스트로 변환됩니다.

이 적응 덕분에 같은 채팅이 지원 모델 사이를 이동할 때 사용자가 모든 첨부를 수동으로 다시 만들 필요가 없습니다. 모든 모델이 모든 파일을 네이티브로 읽거나, 모든 시각 세부 정보를 보존하거나, 같은 컨텍스트 용량을 갖는다는 뜻은 아닙니다.

현재 모델이 합친 컨텍스트를 받을 수 없으면 첨부 수를 줄이거나, 큰 문서를 나누거나, 당면 질문에 필요한 섹션부터 시작하세요.

## 흔한 문제 해결하기

| 문제 | 가능한 이유 | 다음 조치 |
|---|---|---|
| 첨부 버튼이 없음 | 채팅이 Local 또는 No Storage 모드를 사용함 | 기본 계정 동기화 저장소로 돌아가기 |
| 문서가 거부됨 | 이미지가 아닌, PDF가 아닌 파일이 4 MB를 초과하거나 형식이 지원되지 않음 | 파일을 나누거나, 내보내거나, 지원 형식으로 변환하기 |
| PDF 또는 이미지가 거부됨 | 파일이 10 MB를 초과함 | 업로드 전에 파일 크기를 줄이기 |
| 메시지를 아직 보낼 수 없음 | 하나 이상의 첨부가 아직 업로드 중임 | 업로드 완료를 기다리거나 실패한 첨부를 제거하기 |
| **Sources** 컨트롤이 나타나지 않음 | 모델이 검색하지 않았거나 정규화된 출처가 반환되지 않음 | 최신 정보와 출처 링크를 명시적으로 요청하기 |
| 모델이 레이아웃 세부 정보를 놓침 | 파일이 변환되었거나 모델이 다르게 해석함 | 원본과 대조하고 시각 입력에 맞는 모델을 시도하기 |

## 작업을 한 스레드에 유지하기

다음 메시지를 보내기 전에 선택한 모델을 바꿔도 대화를 다시 만들 필요가 없습니다. 다른 모델이 스레드를 이어갈 때 적용되는 컨텍스트와 저장 경계는 [대화를 다시 시작하지 않고 AI 모델 전환하기](/ko/articles/switch-models-mid-chat)를 확인하세요.

[제한된 무료 Browser Chat에서 이 워크플로를 사용해 보세요](https://capriole.ai). 무제한 Browser Chat이 필요하면 Premium으로 업그레이드한 뒤, 같은 Capriole 계정으로 API와 코딩 에이전트 작업을 이어가세요.
