Capriole AI Team은 월 USD 70에 좌석 5개를 제공합니다. 모든 멤버가 GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon과 웹 채팅을 무제한으로 하고, 팀은 앱과 코딩 에이전트에 쓰는 API 토큰을 매월 5,000만 개 공유합니다. API는 공식 API 가격보다 최대 92% 저렴합니다. 소유자는 청구서 하나로 결제하고, 이메일로 멤버를 초대하며, 멤버별 API 사용량을 확인하거나 제한할 수 있습니다.

## Team이 맞는 경우

Team은 개발팀처럼 청구서 하나, 공유 API 토큰, 누가 얼마나 쓰는지 보는 화면이 필요한 소규모 그룹에 맞습니다. 혼자 쓴다면 월 USD 8 Premium으로 무제한 웹 채팅과 자체 API 허용량을 받을 수 있습니다. 모든 플랜 비교는 [플랜 가이드](/ko/guides/plans-and-limits)에 있습니다.

## Team에 포함된 것

| | Team |
|---|---|
| 가격 | 월 USD 70 |
| 좌석 | 소유자를 포함해 5개. 대기 중인 초대도 좌석을 차지합니다. |
| 웹 채팅 | 모든 멤버가 모든 지원 모델로 무제한 |
| API 토큰 | 매월 5,000만 개, 팀 공유 |
| 충전 | 5,000만 토큰당 USD 80, 여러 팩 구매 시 최대 10% 할인 |
| API key | 멤버마다 직접 만들고, 사용량은 팀에 청구 |
| 이미지 생성 | **Server Storage**를 쓰는 웹 채팅에서 무료 |

로그인한 웹 채팅에는 계정당 UTC 기준 하루 200개 메시지의 공정 사용 한도가 있습니다. 스크립트를 이용한 자동화된 남용을 막기 위한 것으로, 일반적인 사용은 이 한도에 훨씬 못 미칩니다. 한도는 멤버마다 따로 적용됩니다.

## 시작하기 전에

- 팀을 만들면 현재 Premium 플랜이 교체됩니다. 유료 Premium을 쓰고 있다면 구독은 즉시 취소되며 환불되지 않습니다.
- 각 멤버는 초대받은 이메일 주소로 Capriole AI에 가입하거나 로그인합니다.
- Capriole Quant로 받은 무료 이용 권한이나 프로모션 Premium은 계정에 남지만, 팀에 속해 있는 동안에는 사용되지 않습니다.

## 팀 만들기

<Steps>
<Step title="Team 플랜 열기">

로그인한 다음 사이드바 하단에서 이름을 선택하고 **요금**을 선택한 뒤 **팀용**을 선택하세요. **계정**을 열고 **Team** 섹션에서 **팀 만들기**를 선택해도 됩니다.

</Step>

<Step title="구독하기">

**구독**을 선택하세요. Premium을 쓰고 있다면 **Team을 만들까요?** 대화 상자가 Premium 구독이 즉시 취소되며 환불되지 않는다고 안내합니다. **계속**을 선택하세요.

</Step>

<Step title="Stripe Checkout에서 결제하기">

Stripe Checkout이 열립니다. 결제 정보와, 있다면 프로모션 코드를 입력한 다음 결제하세요.

</Step>

<Step title="팀 이름 정하기">

Capriole AI가 다시 **계정**으로 안내하고 **팀 이름 지정**을 엽니다. 이름을 입력하고 **저장**을 선택하세요.

이제 플랜에 **Team**이 표시되고, 본인이 팀 소유자가 됩니다.

</Step>
</Steps>

## 멤버 초대하기

<Steps>
<Step title="초대 보내기">

**계정** → **Team**에서 **멤버 초대**를 선택하세요. 멤버의 **이메일**을 입력하고 **초대**를 선택하세요.

Capriole AI가 초대 링크를 이메일로 보냅니다. 초대는 멤버 목록에 **대기 중**으로 표시되며 좌석 하나를 차지합니다. **좌석**에는 5개 중 몇 개를 쓰고 있는지 표시됩니다.

</Step>

<Step title="멤버가 수락하기">

멤버는 링크를 열고, 초대받은 이메일로 가입하거나 로그인합니다. 팀에 참여할지 묻는 대화 상자가 나타나면 **초대 수락**을 선택해 활성 플랜을 Team으로 바꾸거나 **거절**을 선택합니다.

이미 로그인한 멤버는 **계정** → **Team**에서도 초대를 볼 수 있습니다.

</Step>
</Steps>

<Warning>
멤버가 유료 Premium을 쓰고 있다면, 초대를 수락하는 즉시 그 구독이 환불 없이 취소됩니다.
</Warning>

초대를 철회하려면 멤버 목록에서 해당 초대의 메뉴를 열고 **초대 취소**를 선택하세요.

## 멤버 관리하기

| 역할 | 할 수 있는 일 |
|---|---|
| **소유자** | 관리자가 할 수 있는 모든 일. 소유자는 제거할 수 없고, 소유권은 이전할 수 없습니다. |
| **관리자** | 팀 이름 변경, 멤버 초대와 제거, 역할 변경, 알림 토큰과 한도 토큰 설정, 팀 충전 구매, 결제 관리 |
| **멤버** | 무제한 웹 채팅과 팀에 청구되는 API 사용, 본인 API 사용량 확인 |

소유자와 관리자는 각 멤버의 이메일, 역할, Team API 사용량을 볼 수 있습니다. Capriole AI가 그 밖에 무엇을 보관하고 누가 받는지는 [개인정보 가이드](/ko/guides/privacy-and-security)에 정리되어 있습니다.

역할을 바꾸려면 멤버의 메뉴를 열고 **멤버 설정**을 선택한 다음 **역할**을 고르고 **저장**을 선택하세요.

멤버를 제거하려면 메뉴를 열고 **제거**를 선택한 다음 확인하세요. 그 멤버는 즉시 팀 플랜 이용 권한을 잃고, 좌석 하나가 비워집니다.

## API 토큰 공유하기

멤버는 각자 [API 페이지](https://www.capriole.ai/ko?view=api)에서 자기 키를 만듭니다. 팀에 속해 있는 동안 모든 API 요청은 팀 토큰을 씁니다. 먼저 매월 포함된 5,000만 토큰을 쓰고, 그다음 팀 충전 토큰을 씁니다.

API 페이지의 **사용량**에는 **포함 팀 사용량**과 **온디맨드 팀 사용량**이 표시됩니다. 소유자와 관리자는 **멤버**로 필터링해 사람별 요청과 과금 토큰을 볼 수 있습니다. 필터는 [API keys와 사용량 가이드](/ko/guides/api-keys-usage)에서 설명합니다.

### 알림 토큰과 한도 토큰 설정하기

소유자와 관리자는 **멤버 설정**에서 멤버마다 선택 사항인 한도 두 가지를 정할 수 있습니다. 둘 다 직전 30일 동안의 과금 토큰을 기준으로 합니다.

- **알림 tokens**: 멤버가 이 양에 도달하면 Capriole AI가 팀 소유자와 관리자에게 이메일을 보냅니다.
- **한도 tokens**: 멤버가 이 양에 도달하면, 사용량이 한도 아래로 내려가거나 한도를 바꿀 때까지 그 멤버의 팀 청구 API 사용이 중단됩니다.

알림이나 한도를 두지 않으려면 칸을 비워 두세요. 웹 채팅에는 영향이 없습니다.

## 팀 충전 구매하기

소유자와 관리자는 API 페이지에서 **충전**을 선택합니다. 팩 하나는 5,000만 토큰에 USD 80이며, 한 번에 1~5팩을 살 수 있습니다. 추가 팩마다 2.5%씩 할인되어, 5팩(2억 5,000만 토큰)이면 최대 10% 할인됩니다.

## 이름 변경, 결제, 팀 종료

- **이름 변경**: **계정** → **Team**에서 팀 이름 옆 메뉴를 열고 **이름 변경**을 선택합니다.
- **결제**: 소유자와 관리자는 **계정**에서 **구독 관리**를 선택해 Stripe에서 결제 정보를 바꾸거나, 청구서를 보거나, 구독을 취소합니다.
- **팀이 끝나면**: 각 멤버의 계정은 Free로 돌아가거나, 아직 유효한 Capriole Quant 무료 이용 권한 또는 프로모션 이용 권한으로 돌아갑니다. 멤버가 팀에 참여할 때 취소된 Premium 구독은 복구되지 않습니다.

## 자주 묻는 질문

### Capriole AI Team은 얼마인가요?

좌석 5개에 월 USD 70입니다. 모든 멤버가 웹 채팅을 무제한으로 쓰고, 팀은 API 토큰을 매월 5,000만 개 공유합니다. 추가 토큰은 5,000만 토큰당 USD 80입니다.

### 팀에 참여하면 Premium 구독은 어떻게 되나요?

유료 Premium 구독은 즉시 취소되며 환불되지 않습니다. Capriole Quant 무료 이용 권한이나 프로모션 이용 권한은 계정에 남지만, 팀에 속해 있는 동안에는 사용되지 않습니다.

### 대기 중인 초대도 좌석을 차지하나요?

네. 좌석은 멤버와 대기 중인 초대를 모두 세므로, 더 이상 필요 없는 초대는 취소하세요.

### 팀 소유권을 이전할 수 있나요?

아니요. 소유자는 계속 소유자로 남고 제거할 수 없습니다. 관리자는 소유자와 같은 관리 및 결제 권한을 가집니다.

### 팀 멤버가 일일 채팅 한도를 함께 쓰나요?

아니요. 멤버마다 웹 채팅이 무제한이고, 하루 공정 사용 한도는 계정마다 따로 적용됩니다.
