Capriole AI Premium은 월 USD 8이며, GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon을 비롯한 모든 지원 모델로 웹 채팅을 무제한 이용할 수 있습니다. 앱과 코딩 에이전트에 쓰는 API도 포함되며, 공식 API 가격보다 최대 92% 저렴합니다. 웹 채팅은 먼저 무료로 써 볼 수 있습니다. 계정 없이 하루 5개 메시지, 무료 계정으로는 매월 50만 토큰입니다. Team은 월 USD 70에 좌석 5개와 공유 API 토큰 풀을 제공합니다.

## 무제한의 의미

Premium과 Team 웹 채팅에는 **Thinking** 프리셋을 포함해 어떤 [지원 모델](/ko/guides/choose-a-model)에도 토큰 계량기가 없습니다. 로그인한 웹 채팅에는 계정당 UTC 기준 하루 200개 메시지의 공정 사용 한도가 있습니다. 스크립트를 이용한 자동화된 남용을 막기 위한 것으로, 일반적인 사용은 이 한도에 훨씬 못 미칩니다.

한도에 도달하면 Capriole AI가 알림을 표시하고, 채팅은 UTC 00:00에 다시 가능해집니다. 이 한도는 API key에는 적용되지 않습니다.

Claude 자체의 Pro와 Max 플랜은 방식이 달라서 5시간 세션 한도와 주간 한도가 있습니다. [Claude 사용량 한도 정리](/ko/articles/claude-usage-limits)에서 Capriole AI와 비교합니다.

## API 토큰을 쓰는 활동

웹 채팅과 API는 따로 계산됩니다.

| 활동 | 사용하는 것 |
|---|---|
| Premium 또는 Team의 웹 채팅 | 없음. 무제한입니다. |
| Free의 웹 채팅 | 매월 50만 토큰의 채팅 허용량 |
| 웹 채팅의 이미지 생성 | 없음. 무료입니다. |
| API 페이지의 **API 테스트 환경**을 포함한 API 요청 | API 토큰 |
| Codex, Claude Code 같은 코딩 에이전트 | API 토큰 |

API 토큰은 과금 토큰으로 계산합니다. 캐시되지 않은 입력, 캐시된 입력의 10%, 출력을 더한 값입니다. 계산 방식은 모든 모델에서 같습니다. Thinking 모델은 토큰을 더 많이 씁니다. [과금 토큰 설명](/ko/articles/charged-tokens)에 계산 예시가 있습니다.

매월 포함된 토큰을 먼저 쓰고, 그다음 충전한 토큰을 씁니다. API key에는 Premium 또는 Team이 필요합니다. Free에서는 API 페이지에 **구독하면 API에 액세스할 수 있습니다.**라는 문구가 표시됩니다.

## API 토큰 추가 구매하기

토큰이 더 필요하면 API 페이지에서 **충전**을 선택하세요. 여러 팩을 한 번에 사면 가격이 낮아집니다.

| | Premium 충전 | Team 충전 |
|---|---|---|
| 가격 | 500만 토큰당 USD 8 | 5,000만 토큰당 USD 80 |
| 1회 구매 팩 수 | 1~11팩(500만~5,500만 토큰) | 1~5팩(5,000만~2억 5,000만 토큰) |
| 여러 팩 할인 | 추가 팩마다 1.5%, 최대 15% 할인 | 추가 팩마다 2.5%, 최대 10% 할인 |
| 구매 가능 대상 | Premium 회원 | Team 소유자와 관리자 |

## Capriole Quant 구독자

Capriole AI는 Capriole Investments가 만듭니다. 같은 회사의 시장 데이터 플랫폼 [Capriole Quant](https://quant.capriole.com/)(구 Capriole Charts)는 별개 제품입니다.

자격 요건을 갖춘 유료 Capriole Quant 플랜에는 추가 비용 없이 Capriole AI 이용 권한이 포함되므로 따로 구독할 필요가 없습니다. 이 권한은 Quant 플랜이 활성인 동안 유지됩니다. Capriole Quant 3일 무료 체험에는 웹 채팅만 포함되며 API 접근은 포함되지 않습니다.

## 플랜 결제하기

사이드바 하단에서 이름을 선택하고 **요금**을 선택한 다음, Premium에서 **구독**을 선택하세요. **계정** 페이지의 **업그레이드**를 선택해도 같은 플랜이 열립니다.

결제는 Stripe가 처리합니다. 주요 신용카드와 체크카드를 지원하며, 결제 화면에서 쓸 수 있는 결제 수단은 Stripe가 표시합니다. Premium과 Team 결제에는 프로모션 코드를 쓸 수 있습니다.

## 자주 묻는 질문

### Capriole AI는 정말 무제한인가요?

네, Premium과 Team의 웹 채팅은 그렇습니다. 어떤 지원 모델에도 토큰 계량기가 없고, 스크립트 남용을 막는 [공정 사용 한도](#무제한의-의미)만 있습니다. API는 토큰으로 계산됩니다.

### Capriole AI를 무료로 쓸 수 있나요?

네. 게스트는 [계정 없이](/ko/articles/ai-chat-without-login) 하루 5개 메시지를 보낼 수 있습니다. 무료 계정에는 매월 50만 토큰의 웹 채팅과 무료 이미지 생성이 포함되지만, API 접근은 포함되지 않습니다.

### Premium에 API가 포함되나요?

네. Premium에는 앱과 코딩 에이전트에 쓰는 API 토큰이 매월 500만 개 포함되며, 공식 API 가격보다 최대 92% 저렴합니다. 추가 토큰은 500만 토큰당 USD 8입니다.

### Premium은 어떻게 취소하나요?

**계정**을 열고 **구독 관리**를 선택한 다음 Stripe 결제 관리 페이지에서 취소하세요. Premium은 결제 기간이 끝날 때까지 유지됩니다.

### Capriole Quant를 쓰고 있습니다. Premium이 필요한가요?

아니요. 자격 요건을 갖춘 유료 Capriole Quant 플랜에는 추가 비용 없이 Capriole AI 이용 권한이 포함됩니다.
