Capriole AI에는 세 가지 채팅 기록 동작이 있습니다. 기본 계정 동기화 기록을 쓰려면 두 저장 스위치를 모두 끄세요. 브라우저 전용 기록에는 **로컬 저장 사용**을 켜세요. 페이지를 떠나거나 새로 고치면 사라지는 임시 세션에는 **No Storage 사용**을 켜세요.

이 컨트롤은 최첨단 모델 채팅, 대화 중 모델 전환, 파일, 웹 검색을 지원하는 같은 작업 공간에 들어 있습니다. 로그인하지 않은 방문자와 Free 사용자는 결제 전에 현재 플래그십 세트를 써 볼 수 있습니다. Premium은 월 USD 9이며, 지원되는 Premium 모델 세트에서 웹 채팅을 무제한으로 사용할 수 있습니다.

이 설정을 바꾸려면 로그인해야 합니다.

## 세 동작 비교하기

| 계정 설정의 선택 | 채팅 기록 보관 위치 | 새로 고침 후 |
|---|---|---|
| 두 저장 스위치 모두 끔 | Capriole 계정 기록 | 저장된 스레드를 다시 열 수 있음 |
| **로컬 저장 사용** 켬 | 현재 브라우저 데이터 | 브라우저 데이터를 지울 때까지 스레드가 유지됨 |
| **No Storage 사용** 켬 | 현재 세션 | 페이지를 새로 고치거나 떠나면 세션이 끝납니다. |

기본 계정 저장소를 사용하면 기기 간에 채팅을 동기화하고 파일을 업로드할 수 있습니다.

이 설정은 Capriole 채팅 기록 지속성을 제어합니다. 각 요청은 Capriole AI를 거쳐 처리를 담당하는 모델 제공업체나 클라우드 플랫폼으로 전달됩니다.

## 저장 설정 열기

<Steps>
<Step title="Capriole AI에 로그인하기">

[Capriole AI](https://www.capriole.ai/ko)를 열고 로그인하세요.

</Step>

<Step title="계정 열기">

Capriole AI 사이드바 하단에서 아바타 또는 이름을 선택한 다음 메뉴에서 **계정**을 선택하세요. **설정** 섹션으로 스크롤하세요.

**No Storage 사용**이 **로컬 저장 사용** 위에 표시됩니다.

</Step>
</Steps>

## 계정 동기화 기록 유지하기

**No Storage 사용**과 **로컬 저장 사용**을 꺼 두세요.

새 채팅 기록은 계정에 저장되고, 기기 간에 동기화될 수 있으며, 저장된 업로드를 사용할 수 있습니다. 다른 브라우저나 기기에서 다시 열 작업에 이 동작을 선택하세요.

다른 저장 모드가 켜져 있으면 끄세요.

## 이 브라우저에 기록 유지하기

**로컬 저장 사용**을 켜세요.

활성 저장 동작이 브라우저 전용 기록으로 바뀝니다. 대화는 현재 브라우저에서 사용할 수 있고 기록 목록에도 나타날 수 있습니다.

<Warning>
이 브라우저의 사이트 데이터를 지우면 로컬 대화가 삭제됩니다.
</Warning>

새 작업에 기본 계정 동기화 저장소를 쓰려면 **로컬 저장 사용**을 끄세요.

## No Storage 세션 시작하기

<Steps>
<Step title="No Storage 켜기">

**계정** → **설정**에서 **No Storage 사용**을 켜세요.

Capriole은 **모든 채팅을 삭제할까요?** 제목의 대화 상자를 엽니다.

</Step>

<Step title="삭제 확인하기">

<Warning>
확인하면 서버와 이 브라우저에 저장된 모든 채팅 기록이 영구 삭제됩니다.
</Warning>

No Storage 모드로 전환하려면 **삭제**를, 기존 대화를 유지하려면 **취소**를 선택하세요.

</Step>

<Step title="임시 채팅 사용하기">

현재 대화는 활성 페이지 세션에만 존재하며, 페이지를 떠나거나 새로 고치면 사라집니다.

새 채팅이 다시 기본 계정 동기화 기록을 사용하게 하려면 **No Storage 사용**을 끄세요.

새 대화를 다시 이 브라우저에 저장하려면 **No Storage 사용**을 끈 다음 **로컬 저장 사용**을 켜세요.

</Step>
</Steps>

## 결과에 따라 선택하기

| 필요한 것 | 선택 |
|---|---|
| 계정을 따라 기기 간에 이어지는 프로젝트와 태그 | 기본 동기화 저장소 |
| 계정에 채팅을 저장하지 않고 한 브라우저에만 기록 | **로컬 저장 사용** |
| 저장된 채팅 기록이 없는 일회성 세션 | **No Storage 사용** |
| 파일 업로드 | 기본 동기화 저장소 |
| 이미지 생성 | 기본 동기화 저장소 |
| 여러 채팅에 걸친 메모리 | 기본 동기화 저장소 |
| 브라우저 데이터를 지워도 남는 스레드 | 기본 동기화 저장소 |

모델을 바꿔도 저장 설정은 덮어쓰지 않습니다. [모델 전환 글](/ko/articles/switch-models-mid-chat)은 지원 모델이 활성 대화 안에서 다음 턴을 처리하는 방식을 설명합니다.

기본 동기화 저장소는 웹 채팅 첨부에도 필요합니다. [파일과 웹 검색 가이드](/ko/guides/files-web-search)에서 지원 형식, 크기 제한, 출처 확인을 다룹니다.

기본 동기화 저장소를 사용하는 로그인 계정에는 GPT Image 2.6, Nano Banana 2.1, Seedream 5.5 무료 이미지 생성도 포함됩니다. 자세한 내용은 [이미지 생성 가이드](/ko/guides/files-web-search)를 참고하세요.

메모리에도 기본 동기화 저장소가 필요합니다. **로컬 저장 사용** 또는 **No Storage 사용**이 켜져 있는 동안에는 채팅이 메모리를 사용하지도 업데이트하지도 않으며, 둘 중 하나를 켜거나 채팅을 삭제해도 저장된 메모리는 남습니다. 메모리에 저장되는 내용과 삭제 방법은 [개인정보 가이드](/ko/guides/privacy-and-security#메모리)에서 설명합니다.

## 자주 묻는 질문

### Local 모드에 기록 목록이 있나요?

있습니다. 현재 브라우저는 로컬 스레드를 나열, 검색, 이름 변경, 고정, 삭제할 수 있습니다.

### 파일 업로드는 어떤 저장 모드에서 사용할 수 있나요?

기본 계정 저장소를 사용하면 기기 간에 채팅을 동기화하고 파일을 업로드할 수 있습니다.

### 임시 채팅은 언제 끝나나요?

페이지를 떠나거나 새로 고치면 해당 임시 세션이 끝납니다.

### 기존 채팅을 유지하려면 어떻게 하나요?

확인 창에서 **취소**를 선택하면 기존 채팅이 유지됩니다. 확인하면 서버와 이 브라우저에 저장된 모든 채팅 기록이 영구 삭제됩니다.

### 각 요청은 어디에서 처리되나요?

저장 설정에서 기록을 보관할 위치를 정합니다. 각 요청은 Capriole AI를 거쳐 처리를 담당하는 모델 제공업체나 클라우드 플랫폼으로 전달됩니다.

## 선택을 한 작업 공간 안에 두기

Capriole에서는 AI 제품을 바꾸거나 다른 인터페이스에서 대화를 다시 만들지 않고 저장 경계를 바꿀 수 있습니다. [무료 웹 채팅에서 플래그십 모델을 써 보세요](https://www.capriole.ai/ko). 무제한 웹 채팅과 전체 작업 공간이 필요하면 Premium으로 업그레이드하세요.
