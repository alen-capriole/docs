Capriole AI에는 세 가지 채팅 기록 동작이 있습니다. 기본 계정 동기화 기록을 쓰려면 두 저장 스위치를 모두 끄세요. 브라우저 전용 기록에는 **Enable local storage**를 켜세요. 페이지를 떠나거나 새로 고치면 사라지는 임시 세션에는 **Enable No Storage**를 켜세요.

이 컨트롤은 최첨단 모델 채팅, 대화 중 모델 전환, 파일, 웹 검색을 지원하는 같은 작업 공간에 들어 있습니다. 로그아웃 방문자와 Free 사용자는 결제 전에 현재 플래그십 세트를 써 볼 수 있습니다. Premium은 월 USD 8이며, 지원되는 Premium 모델 세트에서 Browser Chat을 무제한으로 사용할 수 있습니다.

이 설정을 바꾸려면 로그인해야 합니다.

## 세 동작 비교하기

| Account 설정의 선택 | 채팅 기록 보관 위치 | 기기 간 기록 | 업로드 | 새로 고침 후 |
|---|---|---|---|---|
| 두 저장 스위치 모두 끔 | Capriole 계정 기록 | 사용 가능 | 사용 가능 | 저장된 스레드를 다시 열 수 있음 |
| **Enable local storage** 켬 | 현재 브라우저 데이터 | 사용 불가 | 비활성화 | 브라우저 데이터를 지울 때까지 스레드가 유지됨 |
| **Enable No Storage** 켬 | 채팅 기록으로 보관되지 않음 | 사용 불가 | 비활성화 | 현재 세션이 사라짐 |

이 설정은 Capriole 채팅 기록 지속성을 제어합니다. 모델 요청은 여전히 Capriole과 선택한 추론 제공자를 거칩니다. 설정이 일반적인 규정 준수나 운영 기록 없음을 약속하지는 않습니다.

## 저장 설정 열기

<Steps>
<Step title="Capriole AI에 로그인하기">

[Capriole AI](https://capriole.ai)를 열고 로그인하세요. 로그아웃 방문자는 저장 스위치 상태가 바뀌지 않습니다.

</Step>

<Step title="Account 열기">

Capriole AI 사이드바 하단에서 아바타 또는 이름을 선택한 다음 메뉴에서 **Account**를 선택하세요. **Settings** 섹션으로 스크롤하세요.

**Enable No Storage**가 **Enable local storage** 위에 표시됩니다.

</Step>
</Steps>

## 계정 동기화 기록 유지하기

**Enable No Storage**와 **Enable local storage**를 꺼 두세요.

새 채팅 기록은 계정에 저장되고, 기기 간에 동기화될 수 있으며, 저장된 업로드를 사용할 수 있습니다. 다른 브라우저나 기기에서 다시 열 작업에 이 동작을 선택하세요.

다른 저장 모드가 켜져 있으면 끄세요. 의도적으로 삭제했거나 브라우저 데이터에서 사라진 채팅은 설정을 되돌려도 다시 만들 수 없습니다.

## 이 브라우저에 기록 유지하기

**Enable local storage**를 켜세요.

활성 저장 동작이 브라우저 전용 기록으로 바뀝니다. 대화는 현재 브라우저에서 사용할 수 있고 기록 목록에도 나타날 수 있습니다. 다른 기기로 동기화되지 않으며 파일 업로드는 비활성화됩니다.

<Warning>
이 브라우저의 사이트 데이터를 지우면 로컬 대화가 삭제됩니다. Capriole은 계정 저장소에서 브라우저 전용 기록을 복원할 수 없습니다.
</Warning>

새 작업에 기본 계정 동기화 저장소를 쓰려면 **Enable local storage**를 끄세요.

## No Storage 세션 시작하기

<Warning>
No Storage를 켜면 서버와 이 브라우저의 모든 대화 기록이 영구 삭제됩니다. 계속하기 전에 확인 내용을 읽으세요.
</Warning>

<Steps>
<Step title="No Storage 켜기">

**Account** → **Settings**에서 **Enable No Storage**를 켜세요.

Capriole은 **Delete all chats?** 제목의 대화 상자를 엽니다. 아직 설정은 바뀌지 않았습니다.

</Step>

<Step title="삭제 확인하기">

저장된 서버 및 브라우저 기록을 제거하고 No Storage 모드로 들어가려면 **Delete**를 선택하세요. 기존 대화를 유지해야 하면 **Cancel**을 선택하세요.

삭제 후 사이드바에서 채팅 기록과 검색 섹션이 사라집니다. No Storage가 켜져 있는 동안 **Enable local storage**는 비활성화됩니다.

</Step>

<Step title="임시 채팅 사용하기">

파일을 첨부하지 않고 메시지를 보내세요. 현재 대화는 활성 페이지 세션에만 존재하며, 페이지를 떠나거나 새로 고치면 사라집니다.

새 채팅이 다시 기본 계정 동기화 기록을 사용하게 하려면 **Enable No Storage**를 끄세요. 이전에 삭제한 대화는 돌아오지 않습니다.

</Step>
</Steps>

## 결과에 따라 선택하기

| 필요한 것 | 선택 |
|---|---|
| 계정을 따라 기기 간에 이어지는 프로젝트 | 기본 동기화 저장소 |
| 계정에 채팅을 저장하지 않고 한 브라우저에만 기록 | **Enable local storage** |
| 저장된 채팅 기록이 없는 일회성 세션 | **Enable No Storage** |
| 파일 업로드 | 기본 동기화 저장소 |
| 브라우저 데이터를 지워도 남는 스레드 | 기본 동기화 저장소 |

모델을 바꿔도 저장 설정은 덮어쓰지 않습니다. [모델 전환 글](/ko/articles/switch-models-mid-chat)은 지원 모델이 활성 대화 안에서 다음 턴을 처리하는 방식을 설명합니다.

기본 동기화 저장소는 Browser Chat 첨부에도 필요합니다. [파일과 웹 검색 가이드](/ko/guides/files-web-search)에서 지원 형식, 크기 제한, 출처 확인을 다룹니다.

## 자주 묻는 질문

### Local 모드에 기록 목록이 있나요?

있습니다. 현재 브라우저는 로컬 스레드를 나열, 검색, 이름 변경, 고정, 삭제할 수 있습니다. 다른 브라우저나 기기는 볼 수 없습니다.

### Local 또는 No Storage 모드에서 파일을 업로드할 수 있나요?

없습니다. 파일 업로드에는 기본 계정 동기화 저장소가 필요합니다.

### No Storage는 새로 고침 후에도 현재 채팅을 유지하나요?

아닙니다. 페이지를 떠나거나 새로 고치면 해당 임시 세션이 끝납니다.

### No Storage를 켤 때 삭제한 채팅을 복구할 수 있나요?

없습니다. 확인은 서버와 브라우저 채팅 기록을 영구 삭제합니다.

### 이 설정이 모델 제공자가 요청을 받는 것을 막나요?

아닙니다. Capriole 작업 공간 안의 채팅 기록을 제어합니다. 추론을 위해 요청은 여전히 Capriole과 선택한 모델 제공자에 도달해야 합니다.

## 선택을 한 작업 공간 안에 두기

Capriole에서는 AI 제품을 바꾸거나 다른 인터페이스에서 대화를 다시 만들지 않고 저장 경계를 바꿀 수 있습니다. [제한된 무료 Browser Chat에서 플래그십 모델을 써 보세요](https://capriole.ai). 무제한 Browser Chat과 전체 작업 공간이 필요하면 Premium으로 업그레이드하세요.
