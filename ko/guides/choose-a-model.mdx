Capriole AI에는 플래그십 모델 4개가 있습니다. OpenAI의 GPT-6 Astra, Anthropic의 Claude Fable 5.1과 Claude Opus 5.5, Google의 Gemini 4 Argon입니다. Premium은 월 USD 8로 네 모델 모두와 웹 채팅을 무제한으로 할 수 있고, API는 공식 API 가격보다 최대 92% 저렴합니다. 웹 채팅은 GPT-6 Astra Thinking으로 시작합니다. 아래 요약에서 다른 모델의 제공사가 그 모델을 내 작업에 맞게 만들었다고 설명하면 그 모델로 전환하세요.

| [Claude Fable 5.1](https://platform.claude.com/docs/en/models/fable-5-1/overview) (Anthropic) | 까다로운 추론과 장기 에이전트 작업 | 100만 토큰 | USD 10 / USD 50 |
| [Claude Opus 5.5](https://platform.claude.com/docs/en/models/opus-5-5/overview) (Anthropic) | 오래 실행되는 에이전트 코딩과 지식 작업 | 100만 토큰 | USD 4 / USD 20 |

Capriole AI에서는 이 표의 모든 모델을 Premium과 Team 웹 채팅에서 무제한으로 쓸 수 있습니다. API에서는 토큰 가격이 모든 모델에서 같습니다. 500만 토큰당 USD 8입니다.

### GPT-6 Astra

OpenAI는 GPT-6 Astra를 가장 까다로운 작업을 위한 가장 뛰어난 모델이라고 부릅니다. OpenAI가 밝힌 컨텍스트 창은 105만 토큰이고, 출력은 최대 128,000토큰입니다. Capriole AI에서는 **GPT-6 Astra Thinking**이 웹 채팅 기본값이며, API에서는 `openai-latest`가 GPT-6 Astra를 사용합니다.

### Claude Fable 5.1

Anthropic은 Claude Fable 5.1을 까다로운 추론과 장기 에이전트 작업용으로 내세웁니다. Anthropic에 따르면 Claude Fable 5보다 오래 실행되는 에이전트 코딩, 여러 단계의 리서치, 문서·스프레드시트·슬라이드 작업이 나아졌습니다. Anthropic은 이 모델을 Claude Opus 5.5보다 느리다고 평가합니다. `claude-latest`는 Claude Fable 5.1을 사용합니다.

### Claude Opus 5.5

Anthropic은 Claude Opus 5.5를 오래 실행되는 에이전트 코딩과 지식 작업용으로 만들었고, 공식 가격은 Fable 5.1의 절반도 되지 않습니다. Anthropic은 대부분의 작업을 Opus 5.5로 시작하고, 추론 강도를 높인 Opus 5.5로도 부족할 때 Fable 5.1로 옮기라고 권장합니다. 이 모델은 추론이 항상 켜져 있으므로, Capriole AI에서 **Fast**는 추론을 끄는 대신 추론 강도를 낮춥니다.

### Gemini 4 Argon

Google은 Gemini 4 Argon을 가장 어려운 문제를 풀도록 만든 가장 뛰어난 모델이라고 부릅니다. Google에 따르면 복잡한 코딩, 에이전트, 수학, 과학 작업에서 더 오래 추론할 수 있습니다. 100만 토큰 컨텍스트 창은 입력, 추론, 출력이 함께 씁니다. `google-latest`는 Gemini 4 Argon을 사용합니다.

## Thinking과 Fast

웹 채팅의 모델 대부분은 프리셋 두 개가 한 쌍으로 제공됩니다. 메시지 입력창의 모델 메뉴 옆에서 **Thinking** 또는 **Fast**를 선택하세요.

- **Thinking**은 답하기 전에 더 많이 추론하므로 복잡한 작업에 맞습니다. Claude Thinking 프리셋은 추론 요약을 보여 줍니다.
- **Fast**는 추론 강도를 낮춰 더 빨리 답합니다.

Thinking은 토큰을 더 많이 씁니다. Premium과 Team에서는 어느 쪽이든 웹 채팅이 무제한입니다. Free에서는 Thinking이 월간 허용량을 더 많이 씁니다.

| 모델 | 웹 채팅 프리셋 |
|---|---|
| GPT-6 Astra, GPT-6.1 Sol, GPT-6 Sol, GPT-6 Luna, Claude Fable 5.1 | **Thinking**(추론 강도 중간)과 **Fast**(추론 강도 낮음) |
| Claude Opus 5.5 | 추론이 항상 켜져 있습니다. **Fast**는 추론 강도를 낮춥니다. |
| Gemini 4 Argon | 웹 채팅에는 **Thinking** 프리셋만 있습니다. **Fast**를 선택하면 채팅이 Gemini 3.8 Flash로 전환됩니다. |
| Kimi K3.1 Pro | 항상 추론합니다. **Thinking**은 높은 추론 강도, **Fast**는 낮은 추론 강도를 씁니다. |
| GLM | **Fast**는 GLM 5.3 Flash입니다. **Thinking**은 이전 모델인 GLM 5.2(API에서는 `zai/glm-5.2`)를 사용합니다. |
| Grok 4.7 | 프리셋 하나 |

Thinking 프리셋은 웹 채팅 전용입니다. API에서 더 많은 추론이 필요하면 모델 ID를 호출하고 요청에서 추론 옵션을 설정하세요.

## 채팅 중간에 모델 전환하기

모델 메뉴에서 다른 모델을 고르고 다음 메시지를 보내세요. 채팅 기록은 그대로 유지되고, 새 모델이 거기서부터 답합니다. [대화 중 모델 전환 방식](/ko/articles/switch-models-mid-chat)을 참고하세요.

**계정** → **설정**에서 **모델 자동 전환 사용**을 켜 두면, 선택한 모델에 수요가 몰릴 때 Capriole AI가 사용 가능한 다른 모델로 답할 수 있습니다. 기본값은 꺼짐입니다.

## API 모델 ID

API 기본 URL은 `https://api.caprioletech.com`입니다. 모델 하나를 고정하려면 구체적인 모델 ID를, 제공사별 권장 플래그십을 따라가려면 `*-latest` 별칭을 쓰세요.

| 별칭 | 사용 모델 | 엔드포인트 |
|---|---|---|
| `openai-latest` | `openai/gpt-6-astra` | Chat Completions, Responses |
| `claude-latest` | `anthropic/claude-fable-5-1`(Messages에서는 `claude-fable-5-1`) | Chat Completions, Messages |
| `google-latest` | `google/gemini-4-argon` | Chat Completions |

플래그십 ID는 `openai/gpt-6-astra`, `anthropic/claude-fable-5-1`, `anthropic/claude-opus-5-5`, `google/gemini-4-argon`입니다. Anthropic Messages에서는 `claude-opus-5-5`처럼 접두사 없는 Claude ID를 쓰세요. 최신 목록은 `GET /v1/models`를 호출하거나 [모델 목록](/ko/api-reference/endpoint/get)에서 확인하세요.

Capriole AI는 모든 모델에서 과금 토큰을 같은 방식으로 계산합니다. 캐시되지 않은 입력, 캐시된 입력의 10%, 출력을 더한 값입니다. [과금 토큰 설명](/ko/articles/charged-tokens)에 예시가 있습니다.

그림이 필요하면 모델 메뉴에서 **이미지**를 선택하고 GPT Image 2.5 또는 Nano Banana 2.1을 고르세요. 이미지 모델은 웹 채팅에서만 작동합니다. [이미지 생성 가이드 보기](/ko/guides/files-web-search).

## 자주 묻는 질문

### Capriole AI는 기본으로 어떤 모델을 쓰나요?

웹 채팅은 GPT-6 Astra Thinking으로 시작합니다. API에서는 `openai-latest`가 GPT-6 Astra를 사용합니다.

### Capriole AI에서 플래그십 모델은 더 비싼가요?

웹 채팅에서는 아닙니다. Premium과 Team 채팅은 모든 지원 모델에서 무제한입니다. API에서는 모든 모델의 토큰 가격이 500만 토큰당 USD 8로 같으므로, 공식 가격 대비 절감 폭은 플래그십에서 가장 큽니다.

### OpenAI SDK로 Claude나 Gemini를 쓸 수 있나요?

네. OpenAI Chat Completions는 `anthropic/claude-fable-5-1`, `google/gemini-4-argon`을 포함한 모든 공개 모델 ID와 별칭 세 개를 받습니다. 설정 방법은 [OpenAI 및 Anthropic SDK 가이드](/ko/guides/openai-anthropic-sdks)에 있습니다.

### Thinking 프리셋을 API에서 쓸 수 있나요?

아니요. 웹 채팅 전용입니다. 모델의 API ID를 호출하고 요청에서 추론 옵션을 설정하세요.

### 어떤 Claude 모델로 시작해야 하나요?

Anthropic은 대부분의 작업을 Claude Opus 5.5로 시작하고, 까다로운 추론과 장기 에이전트 작업에는 Claude Fable 5.1로 옮기라고 권장합니다.
