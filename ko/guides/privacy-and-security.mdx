Capriole AI는 채팅, 파일, API 콘텐츠를 AI 모델 학습에 사용하지 않습니다. 채팅 기록을 어디에 둘지는 직접 고릅니다. 계정에 저장하거나, 브라우저에만 두거나, 아예 저장하지 않을 수 있습니다. API는 요청과 응답 내용을 보관하지 않고, 토큰 수 같은 사용 기록만 남깁니다. 모든 채팅을 내보낼 수 있고, 언제든 채팅을 삭제할 수 있으며, 계정 삭제를 요청할 수 있습니다.

이 가이드는 데이터 처리 방식을 요약합니다. 전체 내용은 [개인정보 처리방침](/ko/legal/privacy)에 있습니다.

## 콘텐츠는 학습에 쓰이지 않습니다

Capriole AI는 채팅, 파일, API 콘텐츠를 AI 모델 학습에 사용하지 않습니다.

다만 각 요청은 답변하는 AI 모델 제공사, 즉 OpenAI, Anthropic, Google, xAI, Z.ai, Moonshot AI 또는 이들의 모델을 호스팅하는 클라우드 플랫폼으로 전달됩니다. 해당 제공사는 자체 약관에 따라 요청을 처리합니다.

## 채팅 기록 보관 위치 선택하기

| 저장 방식 | 채팅 기록 보관 위치 | 기기 간 동기화 | 업로드와 이미지 생성 | 선택 방법 |
|---|---|---|---|---|
| **Server Storage**(기본값) | 내 계정, Capriole AI 서버 | 예 | 사용 가능 | 저장 스위치 두 개를 모두 끔 |
| **Local Storage** | 브라우저. Capriole AI 데이터베이스에는 저장되지 않음 | 아니요 | 꺼짐 | **로컬 저장 사용**을 켬 |
| **No Storage** | 저장되지 않음 | 아니요 | 꺼짐 | **No Storage 사용**을 켬 |

두 스위치는 모두 **계정** → **설정**에 있습니다. 어떤 방식이든 메시지는 Capriole AI 서버를 거쳐 답변하는 모델로 전달되며, Capriole AI는 사용 기록을 남깁니다. 각 방식은 [채팅 저장 방식 가이드](/ko/guides/chat-storage)에서 자세히 설명합니다.

<Warning>
**No Storage 사용**을 켜고 확인하면 서버와 이 브라우저의 모든 채팅 기록이 영구 삭제됩니다.
</Warning>

게스트 채팅은 서버에 저장되지 않습니다. 로그인하면 계정에 저장할 수 있도록 브라우저 탭에 사본이 남습니다.

## Capriole AI가 보관하는 정보

| 데이터 | 보관하는 내용 |
|---|---|
| 계정 | 로그인할 때 받은 이메일 주소, 이름, 프로필 사진. 계정은 Capriole Quant와 공유됩니다. |
| 채팅 | 저장 방식에 따라 메시지, 첨부 파일, 생성한 이미지, 채팅 제목 |
| 개인화 | 계정에 입력한 이름, 하는 일, 지침 |
| 음성 입력 | 없음. 녹음은 오디오나 텍스트를 저장하지 않고 받아쓰기용으로 전송됩니다. |
| 사용 기록 | 각 채팅과 API 요청의 시간, 모델, 토큰 수, 상태, 지연 시간, 비용, IP 주소, 그리고 API 요청에 사용된 키. 메시지 내용은 없음. |
| 결제 | 구독 상태와 결제 식별자. 결제는 Stripe가 처리하며, Capriole AI는 카드 번호를 받지 않습니다. |

## API가 보관하는 정보

API는 요청이나 응답 내용을 보관하지 않으므로 API 대화 기록이 없습니다. Capriole AI는 할당량, 결제, 지원을 위해 API key와 요청별 사용 기록을 보관합니다. 계정 개인화는 API에 적용되지 않습니다.

## 보안

Capriole AI는 암호화된 연결, 비공개 파일 저장소, 제한된 직원 접근을 사용합니다. 완벽하게 안전한 시스템은 없습니다.

주 서버와 데이터베이스는 인도에 있습니다. 협력 업체는 미국을 비롯한 다른 국가에서도 데이터를 처리합니다.

## 채팅 내보내기

**계정** → **설정**에서 **채팅 기록 내보내기**를 선택하세요. 모든 채팅이 각각 Markdown 파일로 담긴 ZIP을 받습니다. 첨부한 파일, 생성한 이미지, 그리고 프로그램이 읽을 수 있는 형식으로 모든 채팅을 담은 `conversations.json`도 함께 들어 있습니다.

기록이 많으면 몇 분 걸립니다. 다운로드는 24시간 동안 유지되며, 유료 플랜이 끝난 뒤에도 내보낼 수 있습니다.

채팅 하나만 내보내려면 사이드바에서 그 채팅의 메뉴를 열고 **내보내기**를 선택하세요. 프로젝트는 프로젝트 메뉴에서 내보냅니다. Local Storage 채팅은 서버에 저장되지 않고 바로 다운로드됩니다.

## 채팅 또는 계정 삭제하기

- **채팅 하나**: 사이드바에서 채팅의 메뉴를 열고 **삭제**를 선택합니다.
- **모든 채팅**: **계정** → **설정**에서 **모든 채팅 기록 삭제** 옆의 **모두 삭제**를 선택합니다.
- **내 계정**: [info@capriole.ai](mailto:info@capriole.ai)로 이메일을 보내세요. 계정은 Capriole Quant와 공유되므로 Capriole Quant 로그인도 함께 끝납니다.

채팅이나 전체 채팅 기록을 삭제하면 서버에서 영구적으로 제거됩니다. 삭제된 데이터는 데이터베이스 백업에 최대 7일 동안 남을 수 있습니다. Local Storage 채팅은 직접 지울 때까지 브라우저에 남습니다.

## 사용자의 권리

거주 지역에 따라 개인정보에 접근하거나 정정, 삭제, 이전을 요청하거나 일부 사용에 이의를 제기할 권리가 있을 수 있습니다. 권리를 행사하려면 [info@capriole.ai](mailto:info@capriole.ai)로 이메일을 보내세요. 호주 정보위원회 사무국(Office of the Australian Information Commissioner)이나 거주 지역의 개인정보 보호 기관에 민원을 제기할 수도 있습니다.

## 자주 묻는 질문

### Capriole AI는 내 채팅으로 AI 모델을 학습하나요?

아니요. Capriole AI는 채팅, 파일, API 콘텐츠를 AI 모델 학습에 사용하지 않습니다. 모델 제공사는 각 요청을 받아 자체 약관에 따라 처리합니다.

### Capriole AI는 API 요청을 저장하나요?

아니요. API 요청이나 응답 내용은 보관하지 않고, 시간, 모델, 토큰 수 같은 사용 기록만 남깁니다.

### 채팅을 저장하지 않고 Capriole AI를 쓸 수 있나요?

네. 페이지를 떠나거나 새로 고치면 사라지는 채팅을 원하면 **No Storage 사용**을, 브라우저에만 기록을 남기려면 **로컬 저장 사용**을 켜세요.

### Capriole AI 계정은 어떻게 삭제하나요?

[info@capriole.ai](mailto:info@capriole.ai)로 이메일을 보내세요. 두 제품이 계정 하나를 공유하므로, 계정을 삭제하면 Capriole Quant 로그인도 함께 끝납니다.

### Capriole AI 데이터는 어디에 저장되나요?

주 서버와 데이터베이스는 인도에 있습니다. 협력 업체는 미국을 비롯한 다른 국가에서도 데이터를 처리합니다.
