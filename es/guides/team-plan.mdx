Capriole AI Team cuesta USD 70 al mes por 5 plazas. Cada miembro tiene chat web ilimitado con GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5 y Gemini 4 Argon, y el equipo comparte 50 millones de tokens de API al mes para aplicaciones y agentes de programación, hasta un 92% por debajo de los precios oficiales de las API. El propietario paga una sola factura, invita a los miembros por correo y puede seguir o limitar el uso de la API de cada miembro.

## Para quién es Team

Team encaja con grupos pequeños, como un equipo de desarrollo, que quieren una sola factura, tokens de API compartidos y saber quién los usa. Si trabajas solo, Premium cubre el chat web ilimitado y su propia asignación de API por USD 8 al mes. La [guía de planes](/es/guides/plans-and-limits) compara todos los planes.

| | Team |

| Plazas | 5, incluido el propietario. Las invitaciones pendientes también ocupan una plaza. |
| Chat web | Ilimitado para cada miembro en todos los modelos compatibles |

El chat web con sesión iniciada tiene un límite de uso justo de 200 mensajes por cuenta por día UTC. Sirve para frenar el abuso automatizado mediante scripts; el uso normal queda muy por debajo. Cada miembro tiene su propio límite.

## Antes de empezar

- Crear un equipo reemplaza tu plan Premium. Si pagas Premium, la suscripción se cancela de inmediato y no se reembolsa.
- Cada miembro se registra o inicia sesión en Capriole AI con la dirección de correo a la que lo invitas.
- El acceso incluido con Capriole Quant o el Premium promocional se mantienen en tu cuenta, pero no se usan mientras estás en un equipo.

## Crea un equipo

<Steps>
<Step title="Abre el plan Team">

Inicia sesión, selecciona tu nombre en la parte inferior de la barra lateral, elige **Precios** y luego selecciona **Para mi equipo**. También puedes abrir **Cuenta** y seleccionar **Crear equipo** en la sección **Team**.

</Step>

<Step title="Suscríbete">

Selecciona **Suscribirse**. Si tienes Premium, un diálogo **¿Crear un Team?** explica que tu suscripción Premium se cancelará de inmediato y no se reembolsará. Selecciona **Continuar**.

</Step>

<Step title="Paga en Stripe Checkout">

Se abre Stripe Checkout. Introduce tus datos de pago y, si tienes uno, un código promocional; después paga.

</Step>

<Step title="Ponle nombre a tu equipo">

Capriole AI te devuelve a **Cuenta** y abre **Ponle nombre a tu equipo**. Escribe un nombre y selecciona **Guardar**.

Tu plan ahora muestra **Team** y eres el propietario del equipo.

</Step>
</Steps>

## Invita a miembros

<Steps>
<Step title="Envía la invitación">

En **Cuenta** → **Team**, selecciona **Invitar miembro**. Escribe el **Correo** del miembro y selecciona **Invitar**.

Capriole AI le envía por correo un enlace de invitación. La invitación aparece como **Pendiente** en tu lista de miembros y ocupa una plaza. **Plazas** muestra cuántas de las 5 están en uso.

</Step>

<Step title="El miembro acepta">

El miembro abre el enlace y se registra, o inicia sesión con el correo invitado. Un diálogo le pide que se una a tu equipo. Selecciona **Aceptar invitación**, que cambia su plan activo a Team, o **Rechazar**.

Si el miembro ya tiene la sesión iniciada, también ve la invitación en **Cuenta** → **Team**.

</Step>
</Steps>

<Warning>
Si el miembro paga Premium, aceptar la invitación cancela esa suscripción de inmediato y sin reembolso.
</Warning>

Para retirar una invitación, abre su menú en la lista de miembros y elige **Cancelar invitación**.

## Gestiona los miembros

| Rol | Qué puede hacer el rol |
|---|---|
| **Propietario** | Todo lo que puede hacer un administrador. El propietario no se puede quitar y la propiedad no se puede transferir. |
| **Administrador** | Renombrar el equipo, invitar y quitar miembros, cambiar roles, definir los tokens de alerta y de tope, comprar recargas del equipo y gestionar la facturación |
| **Miembro** | Usar el chat web ilimitado y el acceso a la API facturado al equipo, y ver su propio uso de la API |

Para cambiar un rol, abre el menú del miembro, elige **Ajustes del miembro**, escoge un **Rol** y selecciona **Guardar**.

Para quitar a alguien, abre su menú, elige **Quitar** y confirma. El miembro pierde de inmediato el acceso al plan del equipo y su plaza queda libre.

## Comparte los tokens de API

Cada miembro crea sus propias claves en la [página de API](https://www.capriole.ai/es?view=api). Mientras estás en un equipo, cada solicitud a la API usa los tokens del equipo: primero los 50M incluidos cada mes y después los tokens de recarga del equipo.

En la página de API, **Uso** muestra **Uso incluido del equipo** y **Uso bajo demanda del equipo**. Los propietarios y administradores pueden filtrar por **Miembro** para ver las solicitudes y los tokens cobrados de cada persona. La [guía de claves API y uso](/es/guides/api-keys-usage) explica los filtros.

### Define los tokens de alerta y de tope

Los propietarios y administradores pueden definir dos límites opcionales para cada miembro en **Ajustes del miembro**. Ambos cuentan los tokens cobrados en un periodo móvil de 30 días.

- **Tokens de alerta**: cuando el miembro llega a esta cantidad, Capriole AI envía un correo a los propietarios y administradores del equipo.
- **Tokens de tope**: cuando el miembro llega a esta cantidad, su acceso a la API facturado al equipo se detiene hasta que su uso baje del tope o lo cambies.

Deja un campo vacío si no quieres alerta o tope. El chat web no se ve afectado.

## Compra recargas del equipo

Los propietarios y administradores seleccionan **Recargar** en la página de API. Un paquete cuesta USD 80 por 50M de tokens, y puedes comprar de 1 a 5 paquetes a la vez. Cada paquete adicional suma un 2.5% de descuento, hasta un 10% con 5 paquetes (250M de tokens).

## Renombrar, facturación y fin del equipo

- **Renombrar**: en **Cuenta** → **Team**, abre el menú junto al nombre del equipo y elige **Renombrar**.
- **Facturación**: los propietarios y administradores seleccionan **Administrar suscripción** en **Cuenta** para actualizar los datos de pago, ver facturas o cancelar en Stripe.
- **Cuando el equipo termina**: la cuenta de cada miembro vuelve a Free, o al acceso incluido con Capriole Quant o al acceso promocional que siga activo. Las suscripciones Premium canceladas cuando los miembros se unieron no se restauran.

## Preguntas frecuentes

### ¿Cuánto cuesta Capriole AI Team?

USD 70 al mes por 5 plazas. Cada miembro tiene chat web ilimitado y el equipo comparte 50 millones de tokens de API al mes. Los tokens adicionales cuestan USD 80 por cada 50 millones.

### ¿Qué pasa con mi suscripción Premium cuando me uno a un equipo?

Una suscripción Premium de pago se cancela de inmediato y no se reembolsa. El acceso incluido con Capriole Quant o el acceso promocional se mantiene en tu cuenta, pero no se usa mientras estás en el equipo.

### ¿Una invitación pendiente ocupa una plaza?

Sí. Las plazas cuentan los miembros y las invitaciones pendientes, así que cancela las invitaciones que ya no necesites.

### ¿Puedo transferir la propiedad del equipo?

No. El propietario sigue siendo el propietario y no se puede quitar. Los administradores comparten los permisos de gestión y facturación del propietario.

### ¿Los miembros del equipo comparten el límite diario de chat?

No. Cada miembro tiene chat web ilimitado, y el límite de uso justo de 200 mensajes por día UTC se aplica a cada cuenta por separado.
