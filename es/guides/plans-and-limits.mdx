Capriole AI Premium cuesta USD 9 al mes e incluye chat web ilimitado con GPT-6.2 Astra, Claude Fable 5.2, Claude Opus 5.5, Gemini 4 Carbon y todos los demás modelos compatibles. También incluye 5M de tokens de API al mes para tus aplicaciones y agentes de programación. Puedes probar el chat web gratis primero: 5 mensajes al día sin cuenta, o 500,000 tokens al mes con una cuenta gratuita. Team cuesta USD 70 al mes por 5 plazas y un fondo compartido de tokens de API.

El precio de las nuevas suscripciones web es de USD 9 al mes. Las suscripciones web de USD 8 se renuevan a ese precio mientras sigan activas.

## Qué significa ilimitado

El chat web de Premium y Team no tiene contador de tokens en ningún [modelo compatible](/es/guides/choose-a-model), incluidos los modos **Thinking**, ni límites de cinco horas ni semanales.

El anillo del cuadro de mensaje muestra cuánto contexto del modelo ha usado el chat. Selecciónalo para ver **Contexto (antes de la compactación)** y, en Free, cuánto te queda de la asignación de este mes. Para ocultar el anillo, desactiva **Mostrar uso** en **Cuenta** → **Ajustes**.

Los planes Pro y Max de Claude funcionan de otra forma, con un límite por sesión de cinco horas y un límite semanal. [Límites de uso de Claude](/es/articles/claude-usage-limits) los compara con Capriole AI.

## Qué consume tokens de API

El chat web y la API se cuentan por separado.

| Actividad | Qué consume |
|---|---|
| Chat web en Premium o Team | Nada. Es ilimitado. |
| Chat web en Free | Tu asignación mensual de 500,000 tokens de chat |
| Generación de imágenes en el chat web | Nada. Es gratis. |
| Solicitudes a la API, incluido el **Entorno de pruebas** de la página de API | Tokens de API |
| Agentes de programación como Codex y Claude Code | Tokens de API |

Los tokens de API se cuentan como tokens cobrados: la entrada no cacheada, más el 10% de la entrada cacheada, más la salida. El cálculo es el mismo en todos los modelos. Los modelos Thinking consumen más tokens. [Tokens cobrados explicados](/es/articles/charged-tokens) incluye ejemplos resueltos.

Primero se usan los tokens mensuales incluidos y después los tokens de recarga. Una clave API requiere Premium o Team; en Free, la página de API muestra **Suscríbete para acceder a la API.**

### Hasta 3 cuentas gratuitas por dirección IP

Cada dirección IP admite hasta 3 cuentas gratuitas, además de las cuentas de pago y Team.

Cuando se usan más de 3 cuentas gratuitas desde una misma dirección IP:

- El chat gratuito se detiene en las cuentas adicionales.
- Enviamos un correo a cada cuenta adicional. 48 horas después, eliminamos las cuentas adicionales y conservamos las 3 más usadas.
- Para conservar una cuenta adicional, pásala a un plan de pago.

Si tú, tu familia o tu equipo necesitan más de 3 cuentas, te pedimos que pases a una cuenta de pago. También puede que un [plan Team](/es/guides/team-plan) de Capriole AI te resulte más eficiente.

Para eliminar una cuenta tú mismo: inicia sesión, haz clic en **Cuenta**, selecciona **Administrar cuenta** > **Seguridad** y haz clic en **Eliminar cuenta**.

Si las cuentas pertenecen a personas distintas, escribe a [info@capriole.ai](mailto:info@capriole.ai) y te ayudaremos con gusto.

## Paga un plan

Selecciona tu nombre en la parte inferior de la barra lateral, elige **Precios** y luego selecciona **Suscribirse** en Premium. En la página **Cuenta**, **Mejorar** abre los mismos planes.

Stripe procesa los pagos. Se aceptan las principales tarjetas de crédito y débito, y Stripe muestra los métodos de pago disponibles para tu compra. El pago de Premium y Team acepta códigos promocionales. En la app para Android, Google Play procesa el pago.

## Preguntas frecuentes

### ¿Capriole AI es realmente ilimitado?

Sí. Los planes de pago incluyen chat web ilimitado con todos los modelos compatibles, sin límites de cinco horas ni semanales.

### ¿Puedo usar Capriole AI gratis?

Sí. Los invitados pueden enviar 5 mensajes al día [sin cuenta](/es/articles/ai-chat-without-login). Una cuenta gratuita incluye 500,000 tokens mensuales de chat web y generación gratuita de imágenes con Server Storage.

### ¿Premium incluye la API?

Sí. Premium incluye 5 millones de tokens de API al mes para aplicaciones y agentes de programación. Las recargas personales cuestan USD 8 por 5 millones de tokens, hasta un 92% menos que los precios oficiales de las API en la [comparación de tarifas estándar](/es/overview).

### ¿Cómo cancelo Premium?

Abre **Cuenta**, selecciona **Administrar suscripción** y cancela en la página de facturación de Stripe. Premium sigue activo hasta el final del periodo de facturación. Si te suscribiste en la app para Android, cancélala en Google Play.

### Tengo Capriole Quant. ¿Necesito Premium?

No. Los planes de pago de Capriole Quant que cumplen los requisitos incluyen acceso a Capriole AI sin costo adicional.

### ¿Hay una app de Capriole AI?

Sí. Capriole AI tiene una app para Android en [Google Play](https://play.google.com/store/apps/details?id=com.capriole.ai). Inicia sesión o crea una cuenta gratuita para usarla. Premium funciona en la web y en la app, y los chats guardados con Server Storage aparecen en ambas. La app para iPhone llegará pronto.
