Capriole AI Premium cuesta USD 8 al mes e incluye chat web ilimitado con GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, Gemini 4 Argon y todos los demás modelos compatibles. También incluye una API que cuesta hasta un 92% menos que los precios oficiales de las API, para tus aplicaciones y agentes de programación. Puedes probar el chat web gratis primero: 5 mensajes al día sin cuenta, o 500.000 tokens al mes con una cuenta gratuita. Team cuesta USD 70 al mes por 5 plazas y un fondo compartido de tokens de API.

## Qué significa ilimitado

El chat web de Premium y Team no tiene contador de tokens en ningún [modelo compatible](/es/guides/choose-a-model), incluidos los modos **Thinking**. El chat web con sesión iniciada tiene un límite de uso justo de 200 mensajes por cuenta por día UTC: sirve para frenar el abuso automatizado mediante scripts, y el uso normal queda muy por debajo.

Si llegas al límite, Capriole AI muestra un aviso y el chat se reanuda a las 00:00 UTC. El límite no se aplica a las claves API.

Los planes Pro y Max de Claude funcionan de otra forma, con un límite por sesión de cinco horas y un límite semanal. [Límites de uso de Claude](/es/articles/claude-usage-limits) los compara con Capriole AI.

## Qué consume tokens de API

El chat web y la API se cuentan por separado.

| Actividad | Qué consume |
|---|---|
| Chat web en Premium o Team | Nada. Es ilimitado. |
| Chat web en Free | Tu asignación mensual de 500.000 tokens de chat |
| Generación de imágenes en el chat web | Nada. Es gratis. |
| Solicitudes a la API, incluido el **Entorno de pruebas** de la página de API | Tokens de API |
| Agentes de programación como Codex y Claude Code | Tokens de API |

Los tokens de API se cuentan como tokens cobrados: la entrada no cacheada, más el 10% de la entrada cacheada, más la salida. El cálculo es el mismo en todos los modelos. Los modelos Thinking consumen más tokens. [Tokens cobrados explicados](/es/articles/charged-tokens) incluye ejemplos resueltos.

Primero se usan los tokens mensuales incluidos y después los tokens de recarga. Una clave API requiere Premium o Team; en Free, la página de API muestra **Suscríbete para acceder a la API.**

Capriole AI está desarrollado por Capriole Investments. Su plataforma de datos de mercado, [Capriole Quant](https://quant.capriole.com/) (antes Capriole Charts), es un producto independiente.

Los planes de pago de Capriole Quant que cumplen los requisitos incluyen acceso a Capriole AI sin costo adicional, así que no necesitas otra suscripción. ## Paga un plan

Selecciona tu nombre en la parte inferior de la barra lateral, elige **Precios** y luego selecciona **Suscribirse** en Premium. En la página **Cuenta**, **Mejorar** abre los mismos planes.

Stripe procesa los pagos. Se aceptan las principales tarjetas de crédito y débito, y Stripe muestra los métodos de pago disponibles para tu compra. El pago de Premium y Team acepta códigos promocionales.

## Preguntas frecuentes

### ¿Capriole AI es realmente ilimitado?

Sí, para el chat web en Premium y Team: no hay contador de tokens en ningún modelo compatible, solo el [límite de uso justo](#qué-significa-ilimitado) contra el abuso mediante scripts. La API se cuenta en tokens.

### ¿Puedo usar Capriole AI gratis?

Sí. Los invitados pueden enviar 5 mensajes al día [sin cuenta](/es/articles/ai-chat-without-login). Una cuenta gratuita incluye 500.000 tokens de chat web al mes y generación de imágenes gratis, pero no acceso a la API.

### ¿Premium incluye la API?

Sí. Premium incluye 5 millones de tokens de API al mes para aplicaciones y agentes de programación, hasta un 92% por debajo de los precios oficiales de las API. Los tokens adicionales cuestan USD 8 por cada 5 millones.

### ¿Cómo cancelo Premium?

Abre **Cuenta**, selecciona **Administrar suscripción** y cancela en la página de facturación de Stripe. Premium sigue activo hasta el final del periodo de facturación.

### Tengo Capriole Quant. ¿Necesito Premium?

No. Los planes de pago de Capriole Quant que cumplen los requisitos incluyen acceso a Capriole AI sin costo adicional.
