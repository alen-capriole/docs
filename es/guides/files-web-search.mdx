En el chat web de Capriole AI, el modelo busca en la web cuando tu pregunta necesita información actual. Las cuentas con sesión iniciada que usan **Server Storage** también pueden crear imágenes gratis con GPT Image 2.6, Nano Banana 2.1 y Seedream 5.5 y adjuntar archivos (imágenes y PDF de hasta 10 MB, otros documentos de hasta 4 MB).

El mismo espacio de trabajo puede continuar la tarea con GPT-6.2 Astra, Claude Fable 5.2, Claude Opus 5.5 o Gemini 4 Carbon sin copiar el material a productos separados. Premium cuesta USD 9 al mes y hace ilimitado el chat web con todos los modelos compatibles.

## Crea imágenes con GPT Image 2.6, Nano Banana 2.1 y Seedream 5.5

Capriole AI ofrece generación gratuita con **GPT Image 2.6**, **Nano Banana 2.1** y **Seedream 5.5** en el chat web para cuentas Free, Premium y Team con sesión iniciada y **Server Storage**. Elige cualquiera de estos modelos en el modo **Imagen** o pídeselo al **Text Agent** durante la conversación. La generación de imágenes no consume la asignación de tokens de API; los mensajes del Text Agent siguen los límites normales del chat.

1. Inicia sesión y usa **Server Storage**: en **Cuenta** → **Ajustes**, desactiva **Activar almacenamiento local** y **Activar No Storage**.
2. Abre el selector de modelos, elige la pestaña **Imagen** y selecciona **GPT Image 2.6**, **Nano Banana 2.1** o **Seedream 5.5** (**GPT Image 2.5** sigue disponible). Describe la imagen.
3. Elige la relación de aspecto, **Resolución** y un lote de **1–4 imágenes**; después envía la solicitud. Las relaciones son **Auto** (la predeterminada) y **1:1, 21:9, 16:9, 3:2, 4:3, 9:16, 2:3 y 3:4**, con resoluciones **1K, 2K y 4K**, o **1K y 2K** con Seedream 5.5. Con **Auto**, una edición conserva la forma de la imagen editada. En una imagen nueva, GPT Image elige una forma acorde con el prompt en 1K y crea una imagen cuadrada en 2K y 4K, y Nano Banana 2.1 crea una imagen cuadrada.
4. Espera a que termine en la conversación. Puedes volver a abrir la conversación guardada, ver cada imagen terminada, consultar **Info** o descargarla. En una respuesta que solo es una imagen, **Copiar imagen** la copia al instante. Si la respuesta también tiene texto o tiene varias imágenes, **Copiar** abre un menú con **Copiar texto** (si hay texto), cada imagen y **Copiar todo**, que copia todo junto.

Para editar imágenes, adjúntalas en el modo **Imagen** con el clip, pegándolas o arrastrándolas: hasta 10 por mensaje, PNG o JPEG, de hasta 10 MB cada una. Después describe el cambio. Escribe **@** para ver la lista de imágenes adjuntas, que se nombran por su posición: `@image1`, `@image2`, etc. Al pasar el cursor sobre una imagen generada, aparece el botón **Editar**, que la coloca al instante en el cuadro de mensaje para que describas el siguiente cambio. En pantallas táctiles, el menú **…** de la imagen tiene **Editar imagen** y **Descargar imagen**. GPT Image 2.6, GPT Image 2.5, Nano Banana 2.1 y Seedream 5.5 editan imágenes, y Capriole AI usa el modelo que hayas seleccionado.

Cada cuenta puede tener hasta **cuatro imágenes activas**. Cada imagen, editada o nueva, cuenta para ese límite. En el modo **Texto** puedes pedirle al Text Agent que cree una imagen, o que cambie una imagen adjunta o una generada antes en el chat, sin cambiar de pestaña; el Text Agent usa el mismo servicio. Usa el modelo de imagen que nombres; si no nombras ninguno, el modelo de la última imagen del chat; y si no hay ninguna, el modelo de imagen predeterminado, GPT Image 2.6, el primero de la pestaña **Imagen**.

Consulta las capacidades oficiales de cada modelo en la [documentación de OpenAI](https://developers.openai.com/api/docs/models/gpt-image-2.6-sunburst), la [documentación de Google](https://ai.google.dev/gemini-api/docs/models/gemini-nano-banana-2.1) y la [página de Seedream 5.5 de ByteDance Seed](https://seed.bytedance.com/en/seedream5_5). Las funciones disponibles en Capriole AI se describen arriba.

## Revisa el archivo antes de subirlo

| Categoría de archivo | Ejemplos compatibles | Límite por archivo |
|---|---|---:|
| Imágenes | JPG, JPEG, PNG | 10 MB |
| PDF | Documentos PDF | 10 MB |
| Texto y archivos estructurados | TXT, Markdown, JSON, JSONL, HTML | 4 MB |
| Documentos de Office | DOCX y PPTX | 4 MB |
| Hojas de cálculo | CSV, XLS, XLSX | 4 MB |

Puedes adjuntar hasta 10 archivos por mensaje. Un contexto combinado grande aún puede superar los límites de entrada del modelo seleccionado.

Usa la [guía de almacenamiento del chat](/es/guides/chat-storage) antes de cambiar el límite de almacenamiento de una conversación.

## Pide a un modelo que trabaje a partir de un archivo

<Steps>
<Step title="Abre un chat sincronizado">

Inicia sesión en [Capriole AI](https://www.capriole.ai/es). Deja **Activar almacenamiento local** y **Activar No Storage** desactivados para que el chat use el almacenamiento sincronizado de la cuenta por defecto.

</Step>

<Step title="Añade el archivo">

Elige **Añadir fotos y archivos** en el cuadro de mensaje. También puedes arrastrar archivos al área del chat o pegar un archivo desde el portapapeles.

Espera a que el adjunto termine de subirse antes de enviar el mensaje. Capriole muestra un estado de procesamiento mientras prepara los archivos subidos para el modelo seleccionado.

</Step>

<Step title="Describe el trabajo, no solo el archivo">

Dile al modelo qué debe inspeccionar y qué salida sería útil. Por ejemplo:

```text
Read the attached spreadsheet. Identify the three largest month-over-month changes, explain which rows produced them, and return a compact table.
```

Para una revisión de documento, nombra la sección, la decisión o la inconsistencia que te importa. Una petición suelta como `summarize this` le da menos dirección al modelo.

</Step>

<Step title="Contrasta la respuesta con el adjunto">

Confirma números importantes, citas y referencias de filas en el archivo original. Los modelos tienen límites distintos de archivo y de contexto, y los documentos convertidos pueden perder detalles de maquetación que dependen de la posición visual.

</Step>
</Steps>

## Añade información web actual

Formula una pregunta que dependa claramente de información pública reciente o en vivo. El modelo puede llamar a la herramienta de búsqueda de Browser Chat cuando decida que hace falta una búsqueda.

```text
Use the attached product brief as the baseline. Search for official changes announced in the last 30 days, list the sources, and explain which parts of the brief now need revision.
```

Durante una búsqueda, el área Thinking puede mostrar **Buscando** seguido de la consulta de búsqueda. Cuando la búsqueda devuelve metadatos de fuente, la respuesta expone un control **Fuentes** que abre los resultados enlazados.

Para obtener información actual, indica la fecha en tu pregunta y pide enlaces a las fuentes.

## Permite URLs de imágenes en el contexto de búsqueda web

Los usuarios con sesión iniciada pueden abrir **Cuenta** → **Ajustes** y activar **Activar imágenes de búsqueda web**. Este ajuste permite que la búsqueda web devuelva URLs de imágenes junto con los resultados normales cuando estén disponibles.

Añadir resultados de imagen puede aumentar el contexto de búsqueda enviado al modelo y puede aumentar el uso de tokens.

## Cómo Capriole prepara distintos archivos

Capriole mantiene un solo flujo de subida y adapta por debajo la entrada del modelo. Las imágenes pueden usar entrada multimodal nativa. Algunos PDF y archivos de tipo texto también pueden usar la ruta nativa de archivos de un modelo. Otros documentos compatibles se convierten en contexto de texto antes de la llamada al modelo.

Esa adaptación permite que el mismo chat se mueva entre modelos compatibles sin pedirte que reconstruyas cada adjunto a mano.

Si el modelo actual no puede aceptar el contexto combinado, reduce el número de adjuntos, divide un documento grande o empieza por la sección necesaria para la pregunta inmediata.

## Corrige problemas habituales

| Problema | Motivo probable | Siguiente acción |
|---|---|---|
| Falta el botón de adjuntar | El chat usa el modo Local o No Storage | Vuelve al almacenamiento sincronizado de la cuenta por defecto |
| Se rechaza un documento | Un archivo que no es imagen ni PDF supera 4 MB o el tipo no es compatible | Divide, exporta o convierte el archivo a un formato compatible |
| Se rechaza un PDF o una imagen | El archivo supera 10 MB | Reduce el tamaño del archivo antes de subirlo |
| El mensaje aún no se puede enviar | Uno o más adjuntos siguen subiéndose | Espera a que termine la subida o quita el adjunto fallido |
| No aparece el control Fuentes | El modelo no buscó o no se devolvieron fuentes normalizadas | Pide de forma explícita información actual y enlaces de fuente |
| Un modelo pierde detalles de maquetación | El archivo se convirtió o el modelo lo interpretó de otra forma | Contrástalo con el original y prueba un modelo adecuado para entrada visual |
