Capriole AI reemplaza la fricción cotidiana de las suscripciones de IA separadas con un espacio de trabajo de bajo costo. Los visitantes sin sesión y los usuarios Free pueden probar **GPT-6 Astra, Claude Fable 5.1 y Gemini 3.1 Pro** en el chat limitado del navegador antes de pagar.

Premium cuesta **USD 8 al mes** por chat ilimitado del navegador en el conjunto de modelos Premium compatible. También incluye **5 millones de tokens cobrados de API al mes**, seis integraciones mantenidas de agentes de programación, cambio de modelo, archivos, búsqueda web y controles explícitos de almacenamiento del chat.

El resultado es una cuenta para modelos de frontera compatibles en lugar de varias suscripciones, interfaces, historiales, claves de proveedor y saldos.

## El problema es más grande que la factura mensual

Usar varios productos de IA suele significar varias pestañas del navegador, páginas de facturación, historiales, interfaces y conjuntos de controles. Una tarea que empieza en un producto puede necesitar un modelo distinto después. Moverla se convierte entonces en una migración pequeña: copiar el contexto útil, volver a adjuntar archivos, explicar la tarea otra vez y aprender qué controles expone la siguiente interfaz.

El trabajo de API añade cuentas de proveedor, claves, saldos, nombres de modelo y formatos de solicitud incompatibles. Los agentes de programación añaden otra capa de configuración. Ninguno de estos pasos es difícil por sí solo, pero juntos convierten la elección de modelo en administración de cuentas.

Capriole AI reúne las partes comunes en un espacio de trabajo. Puedes chatear con un modelo compatible, cambiar de modelo dentro de la conversación, trabajar con archivos o búsqueda web y mantener el hilo en la misma interfaz. El producto gestiona las diferencias de protocolo y de contexto detrás de ese cambio.

El plan encaja con alguien que chatea cada día y también necesita acceso ocasional o moderado a la API o a agentes de programación. Los dos cupos se mantienen claros: el chat del navegador es ilimitado en Premium, mientras que el trabajo automatizado usa el saldo visible de tokens cobrados.

## Una conversación, distintas fortalezas de modelo

Las distintas familias de modelo son útiles para distintas partes de la misma tarea. Un hilo puede empezar con investigación, pasar a una escritura cuidadosa y terminar con código o análisis estructurado. Los productos separados hacen que el usuario lleve el contexto entre ellos.

Capriole deja que la conversación se quede en un espacio de trabajo mientras cambia el modelo seleccionado. La acción visible es una elección de modelo. Por debajo, los formatos de mensaje, los límites de contexto, los controles de reasoning, los archivos, las herramientas, los eventos streaming, la contabilidad de tokens y los errores pueden necesitar cada uno un tratamiento distinto.

Capriole mantiene esa adaptación como parte del producto, así que cambiar el modelo seleccionado no hace que el usuario reconstruya el hilo o la integración.

Capriole también ofrece alias de modelo latest para flujos compatibles de API y de agentes. Permiten que una configuración siga el modelo actual recomendado de Capriole para una familia de proveedor sin exigir que el usuario actualice de inmediato cada identificador exacto de modelo.

## La misma cuenta puede salir del navegador

El acceso de pago elegible desbloquea la API pública de Capriole además del chat del navegador. El [inicio rápido de la API](/es/quickstart) cubre la primera solicitud, mientras que las guías mantenidas admiten seis agentes de programación: [Codex](/es/integrations/codex), [Claude Code](/es/integrations/claude-code), [Kilo Code](/es/integrations/kilo-code), [GitHub Copilot CLI](/es/integrations/github-copilot-cli), [OpenCode](/es/integrations/opencode) y [OpenClaw](/es/integrations/openclaw).

Esto no hace que todos los agentes de programación sean idénticos. Cada cliente sigue teniendo sus propias capacidades y expectativas. El beneficio es que los clientes compatibles pueden usar una cuenta de Capriole y rutas de API compatibles en lugar de requerir una configuración de proveedor de modelo separada para cada familia.

## Elige dónde vive el historial del chat

No toda conversación merece la misma política de almacenamiento.

| Modo | Dónde permanece el historial del chat | Entre dispositivos | Subidas |
|---|---|---|---|
| Synced | Almacenamiento de la cuenta de Capriole | Sí | Disponible |
| Local | Almacenamiento local de este navegador | No | Deshabilitado |
| No Storage | Memoria solo para la sesión actual de la página | No | Deshabilitado |

El historial Local sobrevive a una actualización hasta que se borren los datos del sitio de ese navegador. El historial de No Storage se pierde cuando la página se actualiza o el usuario sale, y activarlo pide primero confirmación antes de eliminar el historial de chat existente del servidor y local.

Los tres modos siguen enviando cada solicitud a través de Capriole y el servicio de modelo seleccionado. Controlan la persistencia del historial de chat; no prometen cero registros operativos ni reemplazan la política de datos del proveedor seleccionado. Lee la [guía de almacenamiento del chat](/es/guides/chat-storage) antes de usar datos sensibles o regulados.
