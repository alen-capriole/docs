## Cómo funcionan los límites de uso de Claude

El centro de ayuda de Anthropic describe dos límites en los planes de pago:

- **Un límite por sesión** que se restablece cada cinco horas.
- **Un límite semanal** para todos los modelos, que se restablece a una hora fija asignada a tu cuenta.

Anthropic indica que también puede limitar el uso de otras formas, como topes mensuales o límites en modelos y funciones concretos. Puedes ver tu progreso en **Settings** → **Usage** en claude.ai.

Los límites son compartidos. El uso en claude.ai, Claude Desktop y Claude Code cuenta para la misma asignación, así que una sesión larga de Claude Code puede dejar poco margen para el chat. Cambiar a otro modelo de Claude no la restablece, porque el límite semanal abarca todos los modelos.

## Por qué llegas al límite antes de lo esperado

Anthropic enumera lo que consume más de tu asignación:

- las conversaciones largas y complejas
- el modelo que eliges
- los niveles de esfuerzo más altos y el pensamiento extendido
- las herramientas y los conectores, que usan muchos tokens
- los archivos grandes de proyecto, que ocupan contexto
- los chats largos que activan la gestión automática del contexto

Fable 5.1 añade su propia regla. En Pro, Fable 5 y Fable 5.1 no forman parte de los límites de uso del plan, así que cada mensaje de Fable se paga con créditos de uso facturados a las tarifas estándar de la API. En Max, los modelos Fable pueden usar hasta el 50% de tus límites semanales sin costo adicional.

## Qué sugiere Anthropic cuando llegas a un límite

1. **Espera al restablecimiento.** El límite por sesión se restablece cada cinco horas, y **Settings** → **Usage** muestra cuándo.
2. **Cambia a un plan superior.** Anthropic describe Max 5x como ideal para quienes usan Claude con frecuencia, y Max 20x como ideal para quienes lo usan a diario en la mayoría de sus tareas. Los límites de un plan nuevo se aplican de inmediato.
3. **Activa los créditos de uso.** Los créditos te permiten seguir trabajando después de llegar a un límite, facturados a las tarifas estándar de la API. Puedes fijar un tope de gasto mensual.
4. **Gasta menos por mensaje.** Empieza una conversación nueva en lugar de alargar una larga, baja el nivel de esfuerzo, desactiva el pensamiento extendido y las herramientas innecesarias, y acorta las instrucciones del proyecto.

Si llegas al límite de cinco horas en mitad de una respuesta de Claude Code, Claude Code puede terminar el paso actual antes de detenerse. En Pro, eso ocurre como máximo una vez por periodo de uso semanal.

## Uso intensivo de agentes de programación: la vía de la API

El chat web ilimitado no cubre los agentes de programación. Para Claude Code y otros agentes, usa una clave API de Capriole AI. Las solicitudes de los agentes consumen un saldo medido de API que cuesta hasta un 92% menos que los precios oficiales de las API.

| Modelo | Precio oficial de API por 1M de tokens (entrada / salida) | Capriole AI |
|---|---|---|
| Claude Fable 5.1 | USD 10 / USD 50 | USD 8 por 5M de tokens |
| Claude Opus 5.5 | USD 4 / USD 20 | USD 8 por 5M de tokens |
| GPT-6 Astra | USD 10 / USD 50 | USD 8 por 5M de tokens |

USD 8 por 5M de tokens equivale a USD 1.60 por millón, tanto de entrada como de salida. Premium incluye 5M de tokens de API al mes, y las recargas cuestan USD 8 por 5M de tokens de cualquier modelo compatible. La entrada cacheada cuenta al 10%, como explica el artículo sobre [tokens cobrados](/es/articles/charged-tokens).

Claude Code se conecta a través del endpoint de Anthropic Messages de Capriole AI. La misma clave funciona con [10 agentes de programación documentados](/es/guides/one-api-key-coding-agents), entre ellos Codex. Empieza con la [configuración de Claude Code](/es/integrations/claude-code).

Claude Max incluye créditos mensuales de API, pero [Anthropic indica](https://support.claude.com/en/articles/17154008-monthly-api-credits-for-max-and-team-plans) que no cubren las sesiones interactivas de Claude Code ni el uso adicional después de alcanzar los límites del plan.

## A qué renuncias

Capriole AI es un espacio de trabajo independiente, no afiliado a Anthropic. No es la app de Claude. Las funciones que solo existen en los productos de Anthropic, como Artifacts, los conectores, la memoria, Claude in Chrome y las apps de escritorio y móviles de Claude, no forman parte de Capriole AI. Claude Code sigue funcionando a través de la vía de la API descrita arriba.
