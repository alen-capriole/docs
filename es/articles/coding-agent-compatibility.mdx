Una cuenta de Capriole AI puede conectar Codex, Claude Code, Kilo Code, GitHub Copilot CLI, OpenCode y OpenClaw. Premium cuesta USD 8 al mes, incluye 5 millones de tokens cobrados de API y también ofrece chat ilimitado del navegador con el conjunto de modelos Premium compatible.

Cada cliente conserva el formato de transmisión que espera. Capriole mantiene rutas de OpenAI Responses, Chat Completions compatible con OpenAI y Anthropic Messages para las integraciones documentadas.

“Compatible con OpenAI” por sí solo no describe el soporte moderno de agentes de programación.

## Por qué importan las rutas mantenidas

Capriole quita la configuración repetida de proveedor detrás de estos clientes. Una membresía suministra la cuenta, el saldo de API, la gestión de claves, los alias de modelo latest y la configuración exacta específica de cada cliente. No necesitas una cuenta, clave, saldo y página de facturación de proveedor separados para cada familia de modelo compatible.

El resultado es una ruta documentada desde el espacio de trabajo del navegador hasta el trabajo en el repositorio. El chat permanece ilimitado en Premium, mientras que el tráfico de agentes de programación usa el saldo visible de 5 millones de tokens cobrados al mes.

## Seis agentes, varios protocolos

Los agentes de programación pueden parecer similares en el prompt, pero sus clientes de modelo no son intercambiables.

| Agente de programación | Ruta mantenida de Capriole | Punto de partida recomendado |
|---|---|---|
| Codex | OpenAI Responses | [`openai-latest`](/es/integrations/codex) |
| Claude Code | Anthropic Messages | [`claude-latest`](/es/integrations/claude-code) |
| Kilo Code | Chat Completions compatible con OpenAI | [`openai-latest`](/es/integrations/kilo-code) |
| GitHub Copilot CLI | Chat Completions, Responses o Messages | [Elige una ruta de protocolo documentada](/es/integrations/github-copilot-cli) |
| OpenCode | OpenAI Responses, Chat Completions o Anthropic Messages | [Elige una ruta de proveedor documentada](/es/integrations/opencode) |
| OpenClaw | OpenAI Responses, Anthropic Messages o chat compatible | [Elige una ruta de proveedor documentada](/es/integrations/openclaw) |

La misma cuenta y el mismo saldo de API están detrás de estas integraciones. La forma de la solicitud sigue al cliente.

Codex envía solicitudes de Responses. Claude Code envía solicitudes de Anthropic Messages y puede usar preflight de recuento de tokens cuando el proveedor seleccionado lo admite. Kilo Code usa Chat Completions. GitHub Copilot CLI, OpenCode y OpenClaw se pueden configurar con distintas rutas de protocolo o de proveedor, así que su configuración depende de la familia de modelo y del protocolo que elijas.

Capriole conserva esas distinciones. Su ruta pública Responses no se convierte en secreto a Chat Completions, y su ruta Messages no se reescribe como una respuesta de OpenAI.

## Por qué es útil una sola clave

Sin una capa de acceso compartida, probar varios agentes de programación suele significar repetir el mismo trabajo administrativo:

- crear o mantener cuentas con distintos proveedores de modelo;
- añadir datos de facturación y saldos en varios lugares;
- guardar varias claves API;
- aprender qué nombre de modelo y Base URL espera cada cliente;
- volver a revisar cada configuración cuando cambia un modelo preferido.

Capriole reduce esa configuración a una cuenta y una clave API de Capriole. Las guías de integración proporcionan la Base URL exacta, el selector de modelo y los campos específicos del cliente.

Los agentes conservan sus propias interfaces, sistemas de herramientas, modelos de permisos y comportamiento de ejecución local. Capriole suministra el acceso al modelo; cada agente de programación sigue decidiendo cómo editar archivos, ejecutar herramientas y presentar el resultado.

## Los alias latest reducen el mantenimiento

Las versiones de modelo se mueven rápido. Una configuración atada a un ID de modelo concreto es útil para trabajo reproducible, pero también necesita actualizaciones manuales cuando quieres el valor por defecto compatible más reciente.

Capriole ofrece alias mantenidos para las rutas públicas compatibles:

- `openai-latest` para la ruta OpenAI mantenida;
- `claude-latest` para la ruta Claude mantenida;
- `google-latest` en las rutas de chat públicas compatibles.

El alias se resuelve antes del envío a upstream y de la contabilidad de uso. El agente de programación envía el selector estable; Capriole registra el modelo resuelto que gestionó la solicitud.

Los IDs de modelo concretos siguen siendo útiles cuando una versión exacta importa para una auditoría, una prueba o un proyecto de larga duración. “Latest” es una conveniencia, no un sustituto de fijar la versión.

## Qué se ha probado

La configuración mantenida sigue rutas y pruebas reales de cliente.

La validación local cubre los seis clientes a través de sus configuraciones documentadas. Las pruebas incluyen prompts básicos y flujos de interacción con herramientas compatibles.

Hay límites específicos de cliente. Codex permanece en los modelos mantenidos de OpenAI Responses; seleccionar un modelo Claude en Capriole no lo convierte en un modelo compatible con Codex. Claude Code usa la ruta de Claude Messages. Kilo Code usa Chat Completions. GitHub Copilot CLI, OpenCode y OpenClaw ofrecen más opciones, pero su configuración debe seguir coincidiendo con el protocolo seleccionado.

Las guías de integración enlazadas en la tabla son la fuente de verdad para los campos actuales y los selectores compatibles.

Lee [cómo Capriole comprueba la compatibilidad de API con varios modelos](/es/articles/unified-model-api#cómo-comprobamos-la-compatibilidad) para la diferencia entre la cobertura de una ruta y un pase real de agente de programación.

## El chat del navegador y los agentes de programación resuelven partes distintas del trabajo

La investigación, el borrador, los archivos, la búsqueda web y los cambios de modelo a mitad de conversación pueden quedarse en el espacio de trabajo del navegador. Cuando la tarea necesita contexto del repositorio, herramientas locales o cambios de archivos, un agente de programación puede usar la misma cuenta de Capriole.

Capriole conecta ambas superficies a la misma cuenta. Una membresía Premium cuesta actualmente **USD 8 al mes**, incluye chat ilimitado del navegador en el conjunto de modelos Premium compatible y añade **5 millones de tokens cobrados de API cada mes**. El uso de agentes de programación es uso de API, así que toma de ese saldo medido en lugar del cupo ilimitado del chat del navegador.

El plan mantiene las dos cargas de trabajo separadas. El chat cotidiano del navegador es ilimitado en Premium, mientras que las cargas de trabajo programáticas y de agentes usan tokens cobrados de API visibles, con recargas disponibles cuando haga falta.

## Elige primero el agente y luego sigue su protocolo

Usa Codex cuando su flujo OpenAI basado en Responses encaje con el trabajo. Usa Claude Code cuando quieras su cliente nativo de Anthropic. Kilo Code ofrece un flujo de IDE o terminal sobre Chat Completions. GitHub Copilot CLI, OpenCode y OpenClaw ofrecen más opciones de protocolo.

Cada cliente documentado obtiene una ruta mantenida hacia los modelos compatibles con ese protocolo.

[Prueba GPT-5.6 Thinking, Claude Fable 5 o Gemini 3.1 Pro en el chat limitado gratuito del navegador](https://capriole.ai) y pasa a Premium cuando estés listo para crear una clave API. Empieza con la [guía de una clave para agentes de programación](/es/guides/one-api-key-coding-agents) para el flujo compartido y luego abre la página de integración del agente que uses.
