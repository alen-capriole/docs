---
title: "Chat"
description: "Crea una respuesta de texto a partir de un modelo."
openapi: "api-reference/openapi.json POST /v1/chat"
---

Usa este endpoint para enviar una entrada de texto plano a un modelo y recibir una respuesta de texto plano. Esta ruta nativa de Capriole no es streaming; usa Chat Completions, Responses o Messages cuando tu cliente necesite un flujo SSE.

`POST /v1/chat` acepta `openai-latest`, `claude-latest`, `google-latest` y los IDs de modelo concretos públicos que devuelve `GET /v1/models`. Usa un alias latest para que Capriole AI elija nuestro modelo insignia recomendado para ese proveedor. Usa un ID de modelo concreto cuando importe fijar la versión.

GPT-6 Astra ofrece dos modos en Web Chat: Thinking (`medium`, predeterminado) y Fast (`low`). Los dos modos de GPT-5.6 están en Other Models. La API pública usa `openai-latest` u `openai/gpt-6-astra`, no el ID Thinking exclusivo del navegador. Este endpoint Chat nativo usa el modo `low` de Astra; Responses y Chat Completions conservan las opciones de razonamiento del cliente.

El chat web de Capriole AI y la API pública son superficies de producto distintas. En el chat web, Fable 5.1 y Fable 5.1 Thinking son los modos principales de Anthropic, mientras que Fable 5, Fable 5 Thinking, Opus 5 y Opus 5 Thinking aparecen en Other Models. La API pública no expone los presets de thinking del chat web como IDs de modelo separados; para solicitudes de la Chat API de Claude, usa `claude-latest` o un ID público concreto de Claude como `anthropic/claude-fable-5-1`, `anthropic/claude-fable-5`, `anthropic/claude-opus-5` o `anthropic/claude-sonnet-4-6`. Las integraciones existentes de Opus 4.8, Opus 4.7 y Opus 4.6 siguen siendo compatibles.
