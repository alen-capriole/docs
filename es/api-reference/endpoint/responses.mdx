title: "Responses"
description: "Crea salida compatible con OpenAI Responses con los modelos Responses de Capriole AI."

---

Usa este endpoint cuando tu aplicación, SDK o agente espere el formato de solicitud y respuesta de OpenAI Responses.

Envía un payload estándar de Responses con `model` e `input`. Capriole AI resuelve los alias latest al ID de modelo de upstream seleccionado antes del envío a upstream, reenvía campos compatibles como `instructions`, `tools`, `reasoning`, `previous_response_id` y `stream`, y devuelve el JSON o el flujo SSE de upstream sin cambios.

`POST /v1/responses` acepta `openai-latest`, `openai/gpt-6-astra`, `openai/gpt-6.1-sol`, `openai/gpt-6-sol`, `openai/gpt-6-luna`, `openai/gpt-5.6-terra`, `openai/gpt-5.6-luna` y `openai/gpt-5.5`. Usa `openai-latest` para que Capriole AI elija nuestro modelo insignia recomendado de OpenAI Responses.

También puedes enviar ID nativos de OpenAI sin el prefijo `openai/`, como `gpt-6-astra`. Los ID nativos y los que llevan prefijo se resuelven a la misma entrada de modelo para el enrutamiento, los precios y la cuota.

Este endpoint también acepta los modelos Grok `xai/grok-4.7`, `xai/grok-4.6` y `xai/grok-4.5`. Envía siempre los ID de Grok con el prefijo `xai/`; un ID sin prefijo como `grok-4.7` se trata como un ID nativo de OpenAI y se rechaza. Las solicitudes de Grok se reenvían a la propia API de Responses de xAI sin conversión de formato.

Los demás modelos no son compatibles en este endpoint: `claude-latest`, `google-latest`, los IDs de modelos Claude y Gemini como `anthropic/claude-fable-5-1` y `google/gemini-4-argon`, y los modelos GLM y Kimi (`zai/glm-5.3-flash`, `zai/glm-5.2`, `moonshot/kimi-k3.1-pro` y `moonshot/kimi-k3`). Usa `POST /v1/chat/completions` cuando quieras un solo endpoint compatible con OpenAI que pueda llamar a todos los modelos públicos.

## Búsqueda web

Añade la herramienta integrada `web_search` para que los modelos GPT o Grok busquen en la web:

```bash
curl https://api.caprioletech.com/v1/responses \
  -X POST \
  -H "Authorization: Bearer YOUR_CAPRIOLE_AI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "xai/grok-4.7",
    "input": "Summarize the latest AI news.",
    "tools": [{"type": "web_search"}],
    "stream": true
  }'
```

La búsqueda web añade los resultados obtenidos a los tokens de entrada de la solicitud, por lo que una respuesta con búsqueda puede usar muchos más tokens de entrada que el prompt por sí solo.

`POST /v1/chat/completions` no ofrece búsqueda web.

## Tareas largas

Para tareas largas, como búsqueda web o razonamiento extenso, establece `"stream": true`. Sin streaming, la conexión puede agotar el tiempo de espera después de unos 2 minutos.
