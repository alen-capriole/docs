## Qué es OpenCode

OpenCode es un agente de programación de IA de código abierto disponible como interfaz de terminal, app de escritorio y extensión de IDE. Esta configuración añade Capriole AI como un único proveedor personalizado. Cada uno de sus modelos usa el protocolo de API que Capriole AI sirve para esa familia de modelos.

## Requisitos previos

Antes de empezar, asegúrate de tener:

- Una cuenta de Capriole AI ([Regístrate aquí](https://capriole.ai))
- Una clave API de Capriole AI ([Obtén tu clave](https://capriole.ai?view=api))

## Instalación

Instala OpenCode con el script de instalación oficial:

```bash
curl -fsSL https://opencode.ai/install | bash
```

O instálalo con npm:

```bash
npm install -g opencode-ai
```

Verifica la instalación:

```bash
opencode --version
```

## Configuración

### Validación de modelos

OpenCode 1.19.3 supera una prueba de lectura de archivos, escritura de archivos y respuesta final a través de Capriole AI con todos los modelos de la sección Modelos compatibles, usando la configuración siguiente.

Crea o actualiza `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "capriole-ai/claude-latest",
  "small_model": "capriole-ai/zai/glm-5.3-flash",
  "provider": {
    "capriole-ai": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Capriole AI",
      "options": {
        "baseURL": "https://api.caprioletech.com/v1",
        "apiKey": "{env:CAPRIOLE_AI_API_KEY}",
        "headers": {
          "Authorization": "Bearer {env:CAPRIOLE_AI_API_KEY}"
        }
      },
      "models": {
        "openai-latest": {
          "name": "OpenAI latest",
          "provider": {
            "npm": "@ai-sdk/openai"
          },
          "limit": {
            "context": 1050000,
            "output": 128000
          },
          "options": {
            "forceReasoning": true
          }
        },
        "openai/gpt-6.1-sol": {

          "provider": {
            "npm": "@ai-sdk/openai"
          },

        },
        "claude-latest": {
          "name": "Claude latest",
          "provider": {
            "npm": "@ai-sdk/anthropic"
          },
          "limit": {

        "xai/grok-4.7": {

            "context": 500000,
            "output": 128000

          "name": "GLM 5.3 Flash",

        "moonshot/kimi-k3.1-pro": {
          "name": "Kimi K3.1 Pro",
          "limit": {
            "context": 1048576,
            "output": 131072
          }
        },
        "moonshot/kimi-k3": {
          "name": "Kimi K3",
          "limit": {
            "context": 1048576,
            "output": 131072
          }
        }
      }
    }
  }
}
```

Qué hace cada ajuste:

- `npm: "@ai-sdk/openai-compatible"` es el paquete por defecto del proveedor, así que Gemini, Grok, GLM y Kimi usan Chat Completions.
- Cada modelo GPT sustituye `provider.npm` por `@ai-sdk/openai`, que usa la API Responses. Cada modelo Claude lo sustituye por `@ai-sdk/anthropic`, que usa Anthropic Messages.
- `baseURL` incluye `/v1` para todos los paquetes.
- `{env:CAPRIOLE_AI_API_KEY}` lee tu clave del entorno. La cabecera `Authorization` la envía como token Bearer con todos los paquetes. Sin ella, el paquete de Anthropic envía la clave en una cabecera `x-api-key`, que Capriole AI no acepta.
- `limit` indica a OpenCode la ventana de contexto y el límite de salida de cada modelo, para que pueda controlar el contexto y compactar la sesión a tiempo.
- `small_model` es el modelo que OpenCode usa para tareas ligeras, como los títulos de sesión.

## Ejecutar OpenCode

Define tu clave API y luego inicia OpenCode desde el directorio de tu proyecto:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
opencode
```

Usa `/models` para cambiar de modelo. Para una ejecución no interactiva, usa `opencode run`:

```bash
opencode run -m capriole-ai/claude-latest "Explain this repository."
```

## Modelos compatibles

Las referencias de modelo usan el formato `capriole-ai/<model-id>`.

| Modelo | ID de modelo | Protocolo |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` y `claude-latest` siempre apuntan a nuestro modelo insignia más reciente de cada familia.

## Solución de problemas

### ¿Por qué OpenCode devuelve un error de autenticación?

Confirma que `CAPRIOLE_AI_API_KEY` está exportada en el mismo shell antes de iniciar OpenCode y que la cabecera `Authorization` está presente en `options.headers`.

### ¿Por qué las solicitudes de Claude fallan con `Unsupported Claude Messages model`?

Los modelos Claude que usan `@ai-sdk/anthropic` necesitan los IDs de Claude sin prefijo, como `claude-opus-5-5`. Los IDs con el prefijo `anthropic/` son para Chat Completions.

### ¿Por qué fallan las solicitudes de GPT?

Confirma que cada modelo GPT tiene `"provider": { "npm": "@ai-sdk/openai" }`, para que sus solicitudes usen la API Responses.

### ¿Por qué no aparecen los modelos de Capriole AI?

Confirma que la referencia de modelo usa `capriole-ai/<model-id>`, como `capriole-ai/moonshot/kimi-k3`, y que `disabled_providers` no bloquea `capriole-ai`.

### ¿Por qué no se aplican los cambios de configuración?

Comprueba si hay un `opencode.json` a nivel de proyecto o una anulación con `OPENCODE_CONFIG` y luego reinicia OpenCode.

### ¿Por qué aparecen errores de paquetes de proveedor?

Borra `~/.cache/opencode` y reinicia OpenCode para que reinstale los paquetes de proveedor.

## Notas

- Mantén tu clave en el entorno. No la pegues en `opencode.json`.
- Para añadir otro modelo de Capriole AI, copia la entrada de un modelo de la misma familia y cambia el ID. `GET https://api.caprioletech.com/v1/models` devuelve la lista de todos los IDs de modelo.
- Referencias oficiales: [instalación de OpenCode](https://opencode.ai/docs), [configuración de OpenCode](https://opencode.ai/docs/config), [proveedores de OpenCode](https://opencode.ai/docs/providers), [modelos de OpenCode](https://opencode.ai/docs/models) y [solución de problemas de OpenCode](https://opencode.ai/docs/troubleshooting).
