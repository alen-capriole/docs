Con una sola clave API de Capriole AI, usas GPT-6 Astra, Claude Fable 5.1 y Opus 5.5 en Qwen Code pagando hasta un 92% menos que los precios oficiales de la API.

## Qué es Qwen Code

Qwen Code es un agente de programación de código abierto para la terminal. Su ajuste `modelProviders` enumera los modelos que puedes usar y el protocolo de API de cada uno. Esta configuración añade modelos de Capriole AI a esa lista.

## Requisitos previos

Antes de empezar, asegúrate de tener:

- Una cuenta de Capriole AI ([Regístrate aquí](https://www.capriole.ai/es))
- Un plan Premium (USD 8 al mes, también incluye chat web ilimitado) o un plan Team, necesario para la clave API ([Suscríbete](https://www.capriole.ai/es?view=api))
- Una clave API de Capriole AI ([Obtén tu clave](https://www.capriole.ai/es?view=api))

## Instalación

Instala Qwen Code con npm (Node.js 22 o posterior):

```bash
npm install -g @qwen-code/qwen-code@latest
```

O instálalo con Homebrew:

```bash
brew install qwen-code
```

Verifica la instalación:

```bash
qwen --version
```

Qué hace cada ajuste:

- Los modelos dentro de `openai` usan Chat Completions. Los modelos GPT añaden `wireApi: "responses"` para usar la API Responses.
- Los modelos dentro de `anthropic` usan Anthropic Messages. Su `baseUrl` no lleva `/v1`.
- `envKey` indica la variable de entorno que contiene tu clave. Qwen Code envía la clave a Capriole AI como token Bearer.
- `contextWindowSize` indica a Qwen Code la ventana de contexto de cada modelo.
- `security.auth.selectedType` y `model.name` definen el modelo por defecto. `/model` actualiza ambos cuando cambias de modelo.

## Ejecutar Qwen Code

Inicia Qwen Code desde el directorio de tu proyecto:

```bash
qwen
```

Cambia de modelo con `/model`. Para una ejecución puntual, pasa el prompt, el modelo y el tipo de autenticación de su grupo:

```bash
qwen "Explain this repository." -m claude-latest --auth-type anthropic
```

## Solución de problemas

### ¿Por qué Qwen Code devuelve un error de autenticación?

Confirma que `~/.qwen/.env` define `CAPRIOLE_AI_API_KEY` o exporta la variable en el mismo shell.

### ¿Por qué un modelo falla con un error de protocolo?

Ejecuta el modelo con el tipo de autenticación de su grupo: `--auth-type openai` para los modelos dentro de `openai` y `--auth-type anthropic` para los modelos dentro de `anthropic`. `/model` lo configura por ti.

### ¿Por qué las solicitudes de Claude fallan con `Unsupported Claude Messages model`?

Los modelos Claude dentro de `anthropic` necesitan los IDs de Claude sin prefijo, como `claude-opus-5-5`.

## Notas

- Guarda tu clave en `~/.qwen/.env`, no en `settings.json`.
- Para añadir otro modelo de Capriole AI, copia la entrada de un modelo de la misma familia y cambia el ID. `GET https://api.caprioletech.com/v1/models` devuelve la lista de todos los IDs de modelo.
- Para usar la misma clave en tus otros agentes de programación, consulta [Usa una sola clave API con agentes de programación](/es/guides/one-api-key-coding-agents).
- Referencias oficiales: [Qwen Code](https://github.com/QwenLM/qwen-code) y [proveedores de modelos de Qwen Code](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/model-providers/).
