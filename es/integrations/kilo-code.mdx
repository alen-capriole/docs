## Qué es Kilo Code

Kilo Code es un agente de programación de IA para VS Code y la terminal. Esta configuración añade Capriole AI como un único proveedor personalizado. Cada uno de sus modelos usa el protocolo de API que Capriole AI sirve para esa familia de modelos.

## Requisitos previos

Antes de empezar, asegúrate de tener:

- Una cuenta de Capriole AI ([Regístrate aquí](https://capriole.ai))
- Una clave API de Capriole AI ([Obtén tu clave](https://capriole.ai?view=api))

## Instalación

### Kilo CLI

```bash
npm install -g @kilocode/cli
```

Verifica la instalación:

```bash
kilo --version
```

### Extensión de VS Code

Instala Kilo Code desde la vista Extensions de VS Code. La extensión lee el mismo archivo de configuración global que la CLI.

Qué hace cada ajuste:

- `npm: "@ai-sdk/openai-compatible"` es el paquete por defecto del proveedor, así que Gemini, Grok, GLM y Kimi usan Chat Completions.
- Cada modelo GPT sustituye `provider.npm` por `@ai-sdk/openai`, que usa la API Responses. Cada modelo Claude lo sustituye por `@ai-sdk/anthropic`, que usa Anthropic Messages.
- `{env:CAPRIOLE_AI_API_KEY}` lee tu clave del entorno. La cabecera `Authorization` la envía como token Bearer con todos los paquetes. Sin ella, el paquete de Anthropic envía la clave en una cabecera `x-api-key`, que Capriole AI no acepta.
- `tool_call: true` permite que el modelo llame a las herramientas de Kilo.
- `limit` define la ventana de contexto y el límite de salida de cada modelo. Sin él, Kilo trata ambos como `0` y no compacta las sesiones largas.

Mantén este proveedor en tu configuración global. Kilo no resuelve las referencias `{env:...}` en una configuración a nivel de proyecto.

Ejecuta `kilo config check` después de editar el archivo.

## Ejecutar Kilo Code

Define tu clave API y luego inicia Kilo desde el directorio de tu proyecto:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
kilo
```

Inicia con un modelo concreto:

```bash
kilo -m capriole-ai/openai-latest
```

Para una solicitud puntual, pasa un prompt a `kilo run`:

```bash
kilo run -m capriole-ai/claude-latest "Explain this repository."
```

## Modelos compatibles

Las referencias de modelo usan el formato `capriole-ai/<model-id>`.

| Modelo | ID de modelo | Protocolo |
| --- | --- | --- |
| OpenAI latest | `openai-latest` | Responses |
| GPT-6.1 Sol | `openai/gpt-6.1-sol` | Responses |
| Claude latest | `claude-latest` | Anthropic Messages |
| Opus 5.5 | `claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `moonshot/kimi-k3` | Chat Completions |

`openai-latest` y `claude-latest` siempre apuntan a nuestro modelo insignia más reciente de cada familia.

## Solución de problemas

### ¿Por qué Kilo Code devuelve un error de autenticación?

Confirma que `CAPRIOLE_AI_API_KEY` está exportada en el mismo shell antes de ejecutar `kilo` y que el proveedor está en `~/.config/kilo/kilo.jsonc`, no en una configuración de proyecto.

### ¿Por qué las solicitudes de Claude fallan con `Unsupported Claude Messages model`?

Los modelos Claude que usan `@ai-sdk/anthropic` necesitan los IDs de Claude sin prefijo, como `claude-opus-5-5`. Los IDs con el prefijo `anthropic/` son para Chat Completions.

### ¿Por qué Kilo Code indica que falta el modelo?

Confirma que el modelo seleccionado usa el formato `capriole-ai/<model-id>` y que `provider.capriole-ai.models` tiene una entrada que coincide. Ejecuta `kilo models capriole-ai` para ver los modelos que Kilo ha cargado.

### ¿Por qué falla el uso de herramientas?

Confirma que la entrada del modelo incluye `"tool_call": true`.

## Notas

- Kilo Code ejecuta las herramientas de programación en tu equipo. Capriole AI solo gestiona las solicitudes de modelo.
- Para añadir otro modelo de Capriole AI, copia la entrada de un modelo de la misma familia y cambia el ID. `GET https://api.caprioletech.com/v1/models` devuelve la lista de todos los IDs de modelo.
- Referencias oficiales: [Kilo CLI](https://kilo.ai/docs/cli), [modelos personalizados de Kilo](https://kilo.ai/docs/code-with-ai/agents/custom-models), [ajustes de Kilo](https://kilo.ai/docs/getting-started/settings) y [proveedores de OpenCode](https://opencode.ai/docs/providers).
