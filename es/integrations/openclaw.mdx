## Qué es OpenClaw

OpenClaw es un asistente de IA personal y gateway de código abierto, autoalojado, que conecta canales de chat como WhatsApp, Slack, Discord, Telegram, iMessage y WebChat con agentes de IA. Puede enviar solicitudes de modelo compatibles a través de Capriole AI al configurar proveedores de modelo personalizados compatibles con OpenAI y Anthropic.

## Requisitos previos

Antes de empezar, asegúrate de tener:

- Una cuenta de Capriole AI ([Regístrate aquí](https://capriole.ai))
- Una clave API de Capriole AI ([Obtén tu clave](https://capriole.ai?view=api))

## Instalación

```bash
curl -fsSL https://openclaw.ai/install.sh | bash -s -- --no-onboard
```

## Configuración

Configura el proveedor GPT:

```bash
export CUSTOM_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
export CAPRIOLE_OPENAI_BASE_URL="https://api.caprioletech.com/v1"

openclaw onboard --non-interactive \
  --accept-risk \
  --mode local \
  --auth-choice custom-api-key \
  --custom-base-url "$CAPRIOLE_OPENAI_BASE_URL" \
  --custom-model-id "openai-latest" \
  --custom-provider-id "capriole-ai-openai" \
  --custom-compatibility openai \
  --secret-input-mode ref \
  --gateway-port 18789 \
  --gateway-bind loopback \
  --skip-channels \
  --skip-search \
  --skip-skills \
  --skip-health \

openclaw config set models.providers.capriole-ai-openai.request.auth \

openclaw config set models.providers.capriole-ai-openai.api \
```

## Ejecutar OpenClaw

Inicia el gateway:

```bash
export CUSTOM_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
openclaw gateway --force --port 18789
```

Abre la TUI en otra terminal:

```bash
export CUSTOM_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
openclaw tui
```

## Solución de problemas

### ¿Por qué fallan las solicitudes de GPT?

Confirma que `models.providers.capriole-ai-openai.api` está definido como `"openai-responses"` y que `baseUrl` es `https://api.caprioletech.com/v1`.

### ¿Por qué fallan las solicitudes de Grok, GLM o Kimi?

Confirma que `models.providers.capriole-ai-compatible.api` está definido como `"openai-completions"` y que `baseUrl` es `https://api.caprioletech.com/v1`.

### ¿Por qué fallan las solicitudes de Anthropic?

Confirma que `models.providers.capriole-ai-anthropic.api` está definido como `"anthropic-messages"` y que el `baseUrl` de Anthropic es `https://api.caprioletech.com` sin `/v1`.

### ¿Por qué falla la autenticación?

Exporta `CUSTOM_API_KEY` en la terminal que inicia `openclaw gateway` y en la terminal que inicia `openclaw tui`.

### ¿Por qué OpenClaw indica que un modelo no está permitido o no está disponible?

Ejecuta `openclaw models list` y luego confirma que el modelo seleccionado y cualquier lista de permitidos de `agents.defaults.models` incluyen la referencia de modelo de Capriole AI, como `capriole-ai-openai/openai-latest`, `capriole-ai-compatible/xai/grok-4.5`, `capriole-ai-compatible/moonshot/kimi-k3` o `capriole-ai-anthropic/claude-latest`.

Si un modelo de Capriole AI aparece como ausente, actualiza la entrada del modelo con el objeto completo que se muestra arriba. Las versiones actuales de OpenClaw necesitan más que `id` y `name` para los modelos de proveedores personalizados.

### ¿Por qué no arranca el gateway?

Ejecuta `openclaw status`, `openclaw gateway status`, `openclaw logs --follow` y `openclaw doctor`. Corrige problemas de esquema, de `gateway.mode` o de servicio antes de reintentar.

### ¿Por qué falla el puerto `18789`?

Elige otro puerto local y usa el mismo puerto para el gateway y la configuración del cliente. En instalaciones en modo servicio, ejecuta `openclaw doctor --fix` o `openclaw gateway install --force` después de cambiar el puerto.

## Notas

- Los proveedores personalizados de OpenClaw requieren que el modo de API del proveedor coincida con la familia de endpoints de Capriole AI.
- OpenClaw 2026.4.21 completa flujos de trabajo de la herramienta local `exec` con Grok 4.5, GLM 5.2 y Kimi K3 a través de `openai-completions`.
- Capriole AI gestiona la solicitud de modelo. OpenClaw puede seguir dando forma al comportamiento final del asistente a través de su gateway, canales y ajustes de agente.
- Referencias oficiales: [OpenClaw install](https://docs.openclaw.ai/install), [OpenClaw custom providers](https://docs.openclaw.ai/gateway/config-tools), [OpenClaw model providers](https://documentation.openclaw.ai/concepts/model-providers) y [OpenClaw troubleshooting](https://docs.openclaw.ai/gateway/troubleshooting).
