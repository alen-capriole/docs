## Qué es OpenClaw

OpenClaw es un asistente personal de IA y gateway de código abierto y autoalojado. Conecta canales de chat como WhatsApp, Slack, Discord, Telegram, iMessage y WebChat con agentes de IA. Esta configuración añade Capriole AI como tres proveedores de modelos personalizados, uno por cada protocolo de API que Capriole AI sirve.

## Requisitos previos

Antes de empezar, asegúrate de tener:

- Una cuenta de Capriole AI ([Regístrate aquí](https://capriole.ai))
- Una clave API de Capriole AI ([Obtén tu clave](https://capriole.ai?view=api))

## Instalación

Instala OpenClaw con el script de instalación oficial:

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```

Después completa la configuración inicial propia de OpenClaw:

```bash
openclaw onboard
```

Qué hace cada ajuste:

- `capriole-ai-openai` envía los modelos GPT a la API Responses. `capriole-ai-anthropic` envía los modelos Claude a Anthropic Messages. `capriole-ai-compatible` envía los modelos Gemini, Grok, GLM y Kimi a Chat Completions.
- `${CAPRIOLE_AI_API_KEY}` lee tu clave del entorno.
- `request.auth` con `authorization-bearer` hace que el proveedor de Anthropic envíe la clave como token Bearer. Sin él, la clave va en una cabecera `x-api-key`, que Capriole AI no acepta.
- El `baseUrl` de Anthropic no lleva `/v1`, porque OpenClaw añade `/v1/messages` por su cuenta.
- `reasoning` es `false` para Opus 5.5. Cuando es `true`, OpenClaw envía un presupuesto de thinking y Opus 5.5 lo rechaza con `requires adaptive thinking`.
- `contextWindow` y `maxTokens` indican a OpenClaw los límites de cada modelo.
- `agents.defaults.models` es la lista de modelos que pueden usar los agentes. `agents.defaults.model.primary` es el modelo por defecto.

## Ejecutar OpenClaw

Exporta tu clave en cada terminal desde la que inicies OpenClaw:

```bash
export CAPRIOLE_AI_API_KEY="YOUR_CAPRIOLE_AI_API_KEY"
```

Inicia el gateway:

```bash
openclaw gateway
```

Abre la interfaz de terminal en otra terminal:

```bash
openclaw tui
```

Para una ejecución local puntual sin el gateway:

```bash
openclaw agent --local --session-id capriole-test --message "Summarize the files in my workspace."
```

## Modelos compatibles

Las referencias de modelo usan el formato `<provider-id>/<model-id>`.

| Modelo | Referencia de modelo | Protocolo |
| --- | --- | --- |
| OpenAI latest | `capriole-ai-openai/openai-latest` | Responses |
| GPT-6.1 Sol | `capriole-ai-openai/openai/gpt-6.1-sol` | Responses |
| Claude latest | `capriole-ai-anthropic/claude-latest` | Anthropic Messages |
| Opus 5.5 | `capriole-ai-anthropic/claude-opus-5-5` | Anthropic Messages |
| Gemini 3.8 Flash | `capriole-ai-compatible/google/gemini-3.8-flash` | Chat Completions |
| Grok 4.7 | `capriole-ai-compatible/xai/grok-4.7` | Chat Completions |
| GLM 5.3 Flash | `capriole-ai-compatible/zai/glm-5.3-flash` | Chat Completions |
| Kimi K3.1 Pro | `capriole-ai-compatible/moonshot/kimi-k3.1-pro` | Chat Completions |
| Kimi K3 | `capriole-ai-compatible/moonshot/kimi-k3` | Chat Completions |

`openai-latest` y `claude-latest` siempre apuntan a nuestro modelo insignia más reciente de cada familia.

## Solución de problemas

### ¿Por qué falla la autenticación?

Exporta `CAPRIOLE_AI_API_KEY` en la terminal que inicia `openclaw gateway` u `openclaw agent`. OpenClaw muestra `missing env var` cuando la variable no está definida.

### ¿Por qué Opus 5.5 falla con `requires adaptive thinking`?

Define `reasoning` como `false` para `claude-opus-5-5`.

### ¿Por qué OpenClaw indica que un modelo no está permitido o que falta?

Ejecuta `openclaw models list`. Confirma que la referencia de modelo está en `agents.defaults.models` y que la entrada del modelo tiene el objeto completo mostrado arriba, no solo `id` y `name`.

### ¿Por qué una sesión nueva empieza con una conversación de configuración?

Es la configuración inicial del espacio de trabajo que OpenClaw hace en la primera ejecución, no un problema de Capriole AI. Complétala una vez en `openclaw tui` o vuelve a ejecutar `openclaw onboard`.

### ¿Por qué no arranca el gateway?

Ejecuta `openclaw status`, `openclaw gateway status`, `openclaw logs --follow` y `openclaw doctor`.

## Notas

- Para añadir otro modelo de Capriole AI, copia la entrada de un modelo de la misma familia, cambia el ID y añade su referencia a `agents.defaults.models`. `GET https://api.caprioletech.com/v1/models` devuelve la lista de todos los IDs de modelo.
