## Qué es Claude Code

Claude Code es la herramienta de programación agéntica de Anthropic para leer bases de código, editar archivos, ejecutar comandos e integrarse con herramientas de desarrollo. Esta configuración dirige Claude Code a Capriole AI mediante sus ajustes de gateway: el endpoint de la API, el token de autenticación y el modelo de cada alias.

## Requisitos previos

Antes de empezar, asegúrate de tener:

- Una cuenta de Capriole AI ([Regístrate aquí](https://capriole.ai))
- Una clave API de Capriole AI ([Obtén tu clave](https://capriole.ai?view=api))

## Instalación

Instala Claude Code con el instalador nativo oficial:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

O instálalo con Homebrew:

```bash
brew install --cask claude-code
```

O instálalo con npm (Node.js 22 o posterior):

```bash
npm install -g @anthropic-ai/claude-code
```

Verifica la instalación:

```bash
claude --version
```

## Configuración

### Validación de modelos

Claude Code 2.1.304 supera una prueba de lectura de archivos, escritura de archivos y respuesta final a través de Capriole AI con todos los modelos de la sección Modelos compatibles, usando la configuración siguiente.

Crea o actualiza `~/.claude/settings.json`:

```json
{
  "model": "claude-fable-5-1",
  "env": {
    "ANTHROPIC_BASE_URL": "https://api.caprioletech.com",
    "ANTHROPIC_AUTH_TOKEN": "YOUR_CAPRIOLE_AI_API_KEY",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "claude-opus-5-5",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "claude-fable-5-1",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "claude-sonnet-4-6"
  }
}
```

Qué hace cada ajuste:

- `model` es el modelo por defecto para las sesiones nuevas. El modelo que eliges con `/model` se guarda y se usa la próxima vez.
- `ANTHROPIC_BASE_URL` envía las solicitudes a Capriole AI. No añadas `/v1`; Claude Code añade `/v1/messages` por su cuenta.
- `ANTHROPIC_AUTH_TOKEN` envía tu clave como token Bearer, que es lo que Capriole AI exige.
- Los tres valores `ANTHROPIC_DEFAULT_*_MODEL` asignan los alias `opus`, `sonnet` y `haiku` a modelos que Capriole AI sirve. `haiku` es el modelo que Claude Code usa para tareas rápidas en segundo plano.

Para una configuración de shell de una sola vez, exporta el endpoint y el token, y luego pasa el modelo:

```bash
export ANTHROPIC_BASE_URL="https://api.caprioletech.com"
export ANTHROPIC_AUTH_TOKEN="YOUR_CAPRIOLE_AI_API_KEY"
claude --model claude-fable-5-1
```

## Ejecutar Claude Code

Inicia Claude Code desde el directorio de tu proyecto:

```bash
claude
```

Cambia de modelo dentro de una sesión con `/model`, por ejemplo `/model opus` para Opus 5.5. Para una ejecución no interactiva, usa el modo print:

```bash
claude -p "Explain this repository."
```

## Modelos compatibles

Claude Code usa el protocolo Anthropic Messages, así que admite los modelos Claude de Capriole AI:

- `claude-fable-5-1` (Fable 5.1, el modelo por defecto recomendado)
- `claude-opus-5-5` (Opus 5.5)
- `claude-fable-5`
- `claude-opus-5`
- `claude-opus-4-8`
- `claude-opus-4-7`
- `claude-opus-4-6`
- `claude-sonnet-4-6`
- `claude-latest`, que siempre apunta a nuestro modelo insignia de Claude más reciente (actualmente Fable 5.1)

Claude Code no reconoce `claude-latest` como nombre de modelo, así que le asigna una ventana de contexto de 200K. Usa un ID concreto como `claude-fable-5-1` para obtener la ventana de contexto completa del modelo.

## Solución de problemas

### ¿Por qué Claude Code devuelve un error de autenticación?

Usa `ANTHROPIC_AUTH_TOKEN`, no `ANTHROPIC_API_KEY`. `ANTHROPIC_API_KEY` envía la clave en una cabecera `x-api-key`, y Capriole AI solo acepta un token Bearer.

### ¿Por qué las solicitudes fallan con errores de endpoint?

Confirma que `ANTHROPIC_BASE_URL` es `https://api.caprioletech.com` sin `/v1`.

### ¿Por qué Claude Code vuelve a otro modelo cada vez que se inicia?

Elimina `ANTHROPIC_MODEL` de tus ajustes y de tu shell. Si está definida, Claude Code vuelve a ese modelo en el siguiente inicio en lugar del modelo que guardaste con `/model`.

### ¿Por qué falla `/model opus` o `/model sonnet`?

Mantén los tres valores `ANTHROPIC_DEFAULT_*_MODEL`. Sin ellos, Claude Code envía los modelos a los que Anthropic asigna cada alias. Por ejemplo, `sonnet` solicita `claude-sonnet-5-5`, que Capriole AI no sirve, y la solicitud falla con `Unsupported Claude Messages model`.

### ¿Por qué Claude Code no usa mi nivel de esfuerzo?

Claude Code guarda el nivel de esfuerzo por separado para cada modelo. Elígelo con `/effort` mientras el modelo está activo. Un `effortLevel` de nivel superior en tus ajustes de usuario no se aplica a Opus 5.5.

### ¿Por qué falla el recuento de tokens?

Capriole AI reenvía `/v1/messages/count_tokens` al upstream seleccionado. Si ese upstream no admite el recuento de tokens, Claude Code estima el recuento en su lugar y la sesión sigue funcionando.

## Notas

- `~/.claude/settings.json` se aplica a tu cuenta de usuario en todos los proyectos. Sustituye `YOUR_CAPRIOLE_AI_API_KEY` por tu clave API de Capriole AI.
- Los modelos Gemini, Grok, GLM y Kimi no funcionan en Claude Code, porque solo habla el protocolo Anthropic Messages. Para esos modelos, usa OpenCode, Kilo Code u otro agente multiprotocolo.
- Referencias oficiales: [instalación de Claude Code](https://code.claude.com/docs/en/setup), [configuración de modelos](https://code.claude.com/docs/en/model-config) y [configuración de un gateway LLM](https://code.claude.com/docs/en/llm-gateway-connect).
