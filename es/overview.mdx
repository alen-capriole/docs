## Chat ilimitado por USD 8

- Premium cuesta USD 8 al mes e incluye chat web ilimitado con todos los modelos compatibles, entre ellos GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5 y Gemini 4 Argon.
- Cambia de modelo en el mismo chat cuando otro modelo se adapte mejor a la siguiente pregunta.
- El chat web con sesión iniciada tiene un límite de uso justo de 200 mensajes por cuenta al día. Sirve para frenar el abuso automatizado mediante scripts; el uso normal queda muy por debajo.
- Los invitados pueden probar 5 mensajes al día sin cuenta. Una cuenta gratuita suma 500.000 tokens de chat web al mes.

[Compara planes y límites](/es/guides/plans-and-limits) o [elige un modelo](/es/guides/choose-a-model).

## API hasta un 92% por debajo de los precios oficiales

- Una sola clave API funciona con clientes de OpenAI Chat Completions, OpenAI Responses y Anthropic Messages.
- Premium incluye una asignación mensual de API, y las recargas cuestan USD 8 por 5M de tokens de cualquier modelo compatible. [Precios de la API de Claude](/es/articles/claude-api-pricing) y [Precios de la API de OpenAI](/es/articles/openai-api-pricing) muestran cómo se calcula el 92% a partir de los precios oficiales.
- La misma clave funciona con 10 agentes de programación documentados, como Codex, Claude Code, GitHub Copilot CLI y OpenCode. Consulta [una sola clave API para agentes de programación](/es/guides/one-api-key-coding-agents).

Empieza con el [inicio rápido de la API](/es/quickstart).

## Configura una vez

Usa `openai-latest`, `claude-latest` o `google-latest` cuando quieras que Capriole AI mantenga tu API o agente de programación en nuestro modelo insignia recomendado para ese proveedor.

Usa un ID de modelo concreto cuando necesites una versión exacta para pruebas, auditorías o ejecuciones reproducibles.
