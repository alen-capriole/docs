Capriole AI es para quienes quieren GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5 y Gemini 4 Argon sin pagar varias suscripciones, y para desarrolladores y usuarios de agentes de programación que quieren una sola clave API para todos ellos. La membresía Premium de USD 8 cubre ambas cosas: chat web ilimitado y una API hasta un 92% por debajo de los precios oficiales de las API. El chat y la API comparten una cuenta, pero se cuentan por separado, así que chatear nunca gasta los tokens con los que funcionan tus aplicaciones y agentes de programación.

## Chat ilimitado por USD 8

El chat ilimitado también incluye los modos **Thinking**, y puedes cambiar de modelo en el mismo chat cuando otro se adapte mejor a la siguiente pregunta. [Compara planes y límites](/es/guides/plans-and-limits) o [elige un modelo](/es/guides/choose-a-model).

## API hasta un 92% por debajo de los precios oficiales

- Las recargas cuestan USD 8 por 5M de tokens de cualquier modelo compatible, con hasta un 15% de descuento si compras varios paquetes a la vez.
- La misma clave funciona con 10 agentes de programación documentados, como Codex, Claude Code, GitHub Copilot CLI y OpenCode. Consulta [una sola clave API para agentes de programación](/es/guides/one-api-key-coding-agents).
- Usa un alias para seguir en el modelo insignia recomendado aunque cambie, o un ID de modelo concreto cuando tus pruebas, auditorías o ejecuciones reproducibles necesiten una versión exacta.

Empieza con el [inicio rápido de la API](/es/quickstart).
