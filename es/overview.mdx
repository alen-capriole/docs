## Por qué Capriole AI

Capriole AI también ofrece generación gratuita con **GPT Image 2** en el chat web para cuentas Free, Premium y Team con sesión iniciada y **Server Storage**. Usa el modo **Image** o pídeselo al **Text Agent** durante la conversación. La generación de imágenes no consume la asignación de tokens de API; los mensajes del Text Agent siguen los límites normales del chat. Es una función del navegador, no una API pública de imágenes ni un modelo para agentes de programación.

[Consulta la guía de generación de imágenes](/es/guides/files-web-search).

Capriole AI te da una sola API para los modelos de IA líderes.

Mantén una integración y cambia entre modelos cuando lo necesites.

- Una API para acceder a los modelos
- Cambia entre los modelos compatibles sin modificar tu integración
- Precios claros y simples con paquetes de tokens a un costo mucho menor

## Configura una vez

Usa `openai-latest`, `claude-latest` o `google-latest` cuando quieras que Capriole AI mantenga tu API o agente de programación en nuestro modelo insignia recomendado para ese proveedor.

Usa un ID de modelo concreto cuando necesites una versión exacta para pruebas, auditorías o ejecuciones reproducibles.

## Nota

Los suscriptores activos de [Capriole Charts](https://capriole.com/charts/) reciben acceso gratuito a Capriole AI.
