Capriole AI is made by Capriole Investments, whose market-data platform [Capriole Quant](https://quant.capriole.com/) (formerly Capriole Charts) and investment fund are separate from Capriole AI. Active Capriole Quant subscribers receive complimentary Capriole AI access.

## Unlimited chat for USD 8

- Premium costs USD 8 a month and includes unlimited web chat on every supported model, including GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, and Gemini 4 Argon.
- Switch models in the same chat when one model suits the next question better.
- Signed-in web chat has a fair-use limit of 200 messages per account per day. It stops scripted, automated abuse; normal use stays well below it.
- Guests can try 5 messages a day without an account. A free account adds 500,000 tokens of web chat a month.

[Compare plans and limits](/guides/plans-and-limits) or [choose a model](/guides/choose-a-model).

## API up to 92% below official prices

- One API key works with OpenAI Chat Completions, OpenAI Responses, and Anthropic Messages clients.
- Premium includes a monthly API allowance, and top-ups cost USD 8 per 5M tokens of any supported model. [Claude API pricing](/articles/claude-api-pricing) and [OpenAI API pricing](/articles/openai-api-pricing) show how the 92% is calculated from official prices.
- The same key runs 10 documented coding agents, including Codex, Claude Code, GitHub Copilot CLI, and OpenCode. See [one API key for coding agents](/guides/one-api-key-coding-agents).

Start with the [API quickstart](/quickstart).

## Configure once

Use `openai-latest`, `claude-latest`, or `google-latest` when you want Capriole AI to keep your API or coding agent on our recommended flagship model for that provider.

Use a concrete model ID when you need one exact model version for testing, audits, or reproducible runs.
