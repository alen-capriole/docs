Capriole AI is for people who want GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, and Gemini 4 Argon without paying for several subscriptions, and for developers and coding-agent users who want one API key for all of them. One USD 8 Premium membership covers both: unlimited web chat, and an API priced up to 92% below official API prices. Chat and the API share one account but are counted separately, so chatting never uses the tokens your apps and coding agents run on.

Capriole AI is made by Capriole Investments, whose market-data platform [Capriole Quant](https://quant.capriole.com/) (formerly Capriole Charts) and investment fund are separate from Capriole AI. Active Capriole Quant subscribers receive complimentary Capriole AI access.

## Unlimited chat for USD 8

Unlimited also covers the **Thinking** presets, and you can switch models in the same chat when another one suits the next question better. [Compare plans and limits](/guides/plans-and-limits) or [choose a model](/guides/choose-a-model).

## API up to 92% below official prices

- Top-ups cost USD 8 per 5M tokens of any supported model, with up to 15% off when you buy several packs at once.
- The same key runs 10 documented coding agents, including Codex, Claude Code, GitHub Copilot CLI, and OpenCode. See [one API key for coding agents](/guides/one-api-key-coding-agents).
- Use an alias to stay on the recommended flagship as it changes, or a concrete model ID when tests, audits, or reproducible runs need one exact version.
