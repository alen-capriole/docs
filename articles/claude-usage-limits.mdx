## How Claude's usage limits work

Anthropic's help center describes two limits on paid plans:

- **A session limit** that resets every five hours.
- **A weekly limit** across all models, which resets at a fixed time assigned to your account.

Anthropic says it may also limit usage in other ways, such as monthly caps or limits on specific models and features. You can see your progress in **Settings** → **Usage** on claude.ai.

The limits are shared. Usage in claude.ai, Claude Desktop, and Claude Code counts toward the same allowance, so a long Claude Code session can leave little room for chat. Switching to another Claude model does not reset it, because the weekly limit covers all models.

## Why you hit the limit faster than expected

Anthropic lists what uses more of your allowance:

- long and complex conversations
- the model you choose
- higher effort levels and extended thinking
- tools and connectors, which use many tokens
- large project files, which take up context
- long chats that trigger automatic context management

Fable 5.1 adds its own rule. On Pro, Fable 5 and Fable 5.1 are not part of the plan's usage limits, so every Fable message runs on usage credits billed at standard API rates. On Max, Fable models can use up to 50% of your weekly limits at no extra cost.

## What Anthropic suggests when you hit a limit

1. **Wait for the reset.** The session limit resets every five hours, and **Settings** → **Usage** shows when.
2. **Upgrade.** Anthropic describes Max 5x as ideal for frequent users and Max 20x as ideal for daily users who work with Claude on most tasks. A new plan's limits apply right away.
3. **Turn on usage credits.** Credits keep you working after a limit, billed at standard API rates. You can set a monthly spending cap.
4. **Use less per message.** Start a new conversation instead of extending a long one, lower the effort level, turn off extended thinking and unneeded tools, and shorten project instructions.

If you reach the five-hour limit in the middle of a Claude Code response, Claude Code may finish the current step before it stops. On Pro, that happens at most once per weekly usage period.

Unlimited web chat does not cover coding agents. For Claude Code and other agents, use a Capriole AI API key. Agent requests draw on a metered API balance that costs up to 92% less than official API prices.

|---|---|---|
| Claude Fable 5.1 | USD 10 / USD 50 | USD 8 per 5M tokens |
| Claude Opus 5.5 | USD 4 / USD 20 | USD 8 per 5M tokens |

USD 8 per 5M tokens is USD 1.60 per million, for input and output alike. Premium includes 5M API tokens a month, and top-ups cost USD 8 per 5M tokens of any supported model. Cached input counts at 10%, as [charged tokens](/articles/charged-tokens) explains.
