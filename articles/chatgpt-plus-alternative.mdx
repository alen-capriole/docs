## What ChatGPT Plus includes

OpenAI's help center lists ChatGPT Plus at USD 20 a month, billed monthly, with no annual plan. API usage is not included and is billed separately.

In Chat, GPT-6 on Plus runs on GPT-6 Sol. OpenAI's model guide shows the Extra High and Pro thinking levels as not included on Plus. GPT-6 Pro, the Chat option powered by GPT-6 Astra, is available on Pro, Business, and Enterprise plans.

Plus does include GPT-6 Astra in ChatGPT Work and Codex. Those two products share one allowance. OpenAI estimates 5 to 45 local GPT-6 Astra messages per five-hour window on Plus, and weekly limits may also apply.

OpenAI's pricing page describes everyday text chats as unlimited on every plan, subject to abuse guardrails. The limits that matter sit on the flagship model and the tools.

Two other OpenAI plans come up in this comparison:

- **ChatGPT Go** costs USD 8 a month in the US, according to [OpenAI's Go announcement](https://openai.com/index/introducing-chatgpt-go/), the same as Capriole AI Premium. Go does not include GPT-6 Astra, and OpenAI says Go users chat with GPT-5.6 Luna.
- **ChatGPT Pro** costs USD 100, USD 200, or USD 500 a month. OpenAI says a Pro subscription does not include unlimited use of GPT-6 Pro.

## What USD 8 gets you on Capriole AI

- **Unlimited web chat on every supported model.** That includes GPT-6 Astra, Claude Fable 5.1, Claude Opus 5.5, and Gemini 4 Argon. Signed-in web chat has a fair-use limit of 200 messages per account per day. It stops scripted, automated abuse; normal use stays well below it.
- **An API up to 92% below official prices.** Premium includes 5M API tokens a month. Top-ups cost USD 8 per 5M tokens of any supported model. One key works with OpenAI Chat Completions, OpenAI Responses, and Anthropic Messages clients, and with [10 documented coding agents](/guides/one-api-key-coding-agents).
- **Two vendors in one thread.** Ask GPT-6 Astra, then [switch models mid-chat](/articles/switch-models-mid-chat) and ask Claude Fable 5.1 to check the answer.
- **The rest of the workspace.** Free image generation with GPT Image 2.5 and Nano Banana 2.1, files and web search, projects, chat export, personalization, and storage controls.

API requests and coding agents use the API balance, not unlimited web chat. [Charged tokens](/articles/charged-tokens) explains how that balance is counted.

## What you give up

Capriole AI is an independent workspace. It is not ChatGPT, and it is not affiliated with OpenAI. If you leave Plus, you lose features that exist only in OpenAI's apps. OpenAI's pricing page lists these for Plus:

- ChatGPT Work and Codex with your ChatGPT sign-in
- deep research
- voice conversations, including voice with video
- memory with past chats, scheduled tasks, custom GPTs, and plugins
- the Excel, Word, PowerPoint, and Google Sheets extensions
- ChatGPT's own desktop and mobile apps

Capriole AI runs in your browser. You can use Codex with a Capriole AI API key, but those requests draw on the metered API balance instead of a ChatGPT allowance.

Keep Plus if you use these features every day. Choose Capriole AI if you mainly chat and write, want GPT-6 Astra in chat without paying for ChatGPT Pro, or want Claude and Gemini beside it.
