## OpenAI API prices per 1M tokens

OpenAI publishes these standard rates on its [API pricing page](https://developers.openai.com/api/docs/pricing). All prices are in USD per 1M tokens, for prompts up to 272K input tokens.

| Model | API model ID | Input | Cached input | 30-min cache write | 12-hour cache write | Output |
|---|---|---:|---:|---:|---:|---:|
| GPT-6 Astra | `gpt-6-astra` | USD 10 | USD 1 | USD 12.50 | USD 25 | USD 50 |
| GPT-6.1 Sol | `gpt-6.1-sol` | USD 2 | USD 0.10 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Sol | `gpt-6-sol` | USD 2 | USD 0.20 | USD 2.50 | USD 5 | USD 10 |
| GPT-6 Luna | `gpt-6-luna` | USD 0.10 | USD 0.01 | USD 0.125 | USD 0.25 | USD 0.50 |

OpenAI's pricing and model pages list the rules that change these rates:

- **Batch and Flex**: Both cost 50% of standard rates. GPT-6 Astra costs USD 5 input and USD 25 output.
- **Long prompts**: A request with more than 272K input tokens pays 2 times the input and cache rates and 1.5 times the output rate for the full request.
- **Fast mode**: Costs 2 times standard rates. GPT-6 Astra in fast mode costs USD 20 input and USD 100 output.
- **Regional processing**: Adds 10% where it is available.

## How caching and batch change the comparison

- **Cached input**: OpenAI charges 10% of the input rate, USD 1 per 1M cached tokens on GPT-6 Astra. Capriole also counts cached input at 10%, which works out to USD 0.16 per 1M cached tokens. [Charged tokens explained](/articles/charged-tokens) shows the formula.
- **Cache writes**: OpenAI charges 1.25 times input for a 30-minute cache write and 2.5 times input for a 12-hour cache write. Capriole counts every uncached input token, including cache writes, at the normal rate.
- **Batch and Flex**: At half price, the 5M-token GPT-6 Astra example costs USD 50. Capriole has no batch endpoint, and its USD 8 is still 84% less for that workload.

## Call GPT-6 Astra through Capriole's API

Capriole's API is compatible with OpenAI Responses at `POST /v1/responses` and OpenAI Chat Completions at `POST /v1/chat/completions`. Set the OpenAI SDK base URL to `https://api.caprioletech.com/v1`.

- `openai-latest` selects GPT-6 Astra, so your configuration follows the current recommended OpenAI model.
- On Responses, native IDs such as `gpt-6-astra` and prefixed IDs such as `openai/gpt-6-astra` select the same model.
- Chat Completions accepts `openai-latest` and the model IDs that `GET /v1/models` returns.

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com/v1",
)

response = client.responses.create(
    model="openai-latest",
    input="Write a release note for this change.",
)
print(response.output_text)
```
