## Claude API prices per 1M tokens

Anthropic publishes these standard rates on its [Claude API pricing page](https://platform.claude.com/docs/en/about-claude/pricing). All prices are in USD per 1M tokens.

| Model | API model ID | Input | Output | Cache read | 5-minute cache write | 1-hour cache write |
|---|---|---:|---:|---:|---:|---:|
| Claude Fable 5.1 | `claude-fable-5-1` | USD 10 | USD 50 | USD 0.25 | USD 12.50 | USD 20 |
| Claude Opus 5.5 | `claude-opus-5-5` | USD 4 | USD 20 | USD 0.20 | USD 5 | USD 8 |

The same page lists the rules that change these rates:

- **Batch API**: Asynchronous batches cost 50% less on input and output. Fable 5.1 costs USD 5 and USD 25; Opus 5.5 costs USD 2 and USD 10.
- **Long context**: Both models include the full 1M-token context window at standard rates.
- **US-only inference**: Setting `inference_geo` to `"us"` multiplies every token price by 1.1.
- **Fast mode**: Opus 5.5 in fast mode costs USD 8 input and USD 40 output, and fast mode does not work with the Batch API.

## How caching and batch change the comparison

- **Cache reads**: Anthropic charges USD 0.25 per 1M cached tokens on Fable 5.1 and USD 0.20 on Opus 5.5. Capriole counts cached input at 10%, which works out to USD 0.16 per 1M cached tokens. [Charged tokens explained](/articles/charged-tokens) shows the formula.
- **Cache writes**: Anthropic charges 1.25 times input for 5-minute writes and 2 times input for 1-hour writes. Capriole counts cache writes as normal input.
- **Batch**: At Anthropic's batch rates, the 5M-token example costs USD 50 on Fable 5.1 and USD 20 on Opus 5.5. Capriole has no batch endpoint, and its USD 8 is still 84% and 60% less for that workload.

## Call Claude through Capriole's Messages API

Capriole's API is compatible with Anthropic Messages. Point the Anthropic SDK, or any Messages client, at `https://api.caprioletech.com` and call `POST /v1/messages`.

- `claude-latest` selects Claude Fable 5.1, so your configuration follows the current recommended Claude model.
- `claude-fable-5-1` and `claude-opus-5-5` select a model explicitly.
- Send your key as a Bearer token. In the Anthropic SDK, pass it as `auth_token`.

```python
import os

from anthropic import Anthropic

client = Anthropic(
    auth_token=os.environ["CAPRIOLE_AI_API_KEY"],
    base_url="https://api.caprioletech.com",
)

message = client.messages.create(
    model="claude-latest",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Summarize this pull request."}],
)
print(message.content[0].text)
```

The same key works with OpenAI Chat Completions at `/v1/chat/completions`, which also accepts `claude-latest`. Each key allows 300 requests per minute.
